# Unigine.RenderState Class (CPP)

**Header:** #include <UnigineRender.h>

> **Notice:** Этот класс является синглтоном.


RenderState - это низкоуровневая абстракция состояния GPU-пайплайна, управляющая процессом рендеринга. Она управляет всеми настройками, необходимыми GPU перед отрисовкой: блендингом, тестированием глубины, операциями со стенсилом, растеризацией полигонов, масками записи, отсечением по scissor и привязкой ресурсов (текстур, структурированных буферов, шейдеров, материалов).


Изменения состояния являются отложенными - они накапливаются на стороне CPU и отправляются на GPU только при явном выполнении flush. Класс также предоставляет механизм сохранения/восстановления для изоляции сегментов кода рендеринга друг от друга.


Помимо управления состоянием пайплайна, RenderState используется для отправки вызовов отрисовки и диспетчеризации вычислительных шейдеров на GPU.


### Пример использования


Следующий пример иллюстрирует типовое использование методов [saveState()](#saveState_void), [clearStates()](#clearStates_int_void), [flushStates()](#flushStates_void) и [restoreState()](#restoreState_void)


```cpp
/* ... */

// saving the current render state
RenderState::saveState();

// clearing the current render state to prevent our rendering code from being affected by the previous settings
RenderState::clearStates();

/* ... */

// changing current render state
RenderState::setBlendFunc(RenderState::BLEND_SRC_ALPHA, RenderState::BLEND_ONE_MINUS_SRC_ALPHA );

// flushing the current render state to GPU
RenderState::flushStates();

/*	rendering code begin

...

rendering code end */

// clearing the current render state (if necessary)
RenderState::clearStates();

// changing current render state again
RenderState::setPolygonFront(1);

// flushing the current render state to GPU
RenderState::flushStates();

/*	rendering code begin

...

rendering code end */

// restoring the previously saved render state
RenderState::restoreState();

/* ... */

```

## void setConservativeRasterizationEnabled ( bool enabled )

Задаёт новое значение, указывающее, включена ли консервативная растеризация. Консервативная растеризация (альтернатива обычной растеризации) - это техника рендеринга графики, используемая GPU, при которой треугольник (или другой примитив) растеризуется таким образом, что гарантированно любой пиксель, даже слегка затронутый примитивом, считается покрытым. Эта техника полезна в ряде ситуаций, включая обеспечение точности определения столкновений, отсечения по перекрытию (occlusion culling) и тайлового рендеринга.
### Аргументы

- *bool* **enabled** - **true**, чтобы включить консервативную растеризацию; **false** - чтобы отключить её.

## bool isConservativeRasterizationEnabled () const

Возвращает текущее значение, указывающее, включена ли консервативная растеризация. Консервативная растеризация (альтернатива обычной растеризации) - это техника рендеринга графики, используемая GPU, при которой треугольник (или другой примитив) растеризуется таким образом, что гарантированно любой пиксель, даже слегка затронутый примитивом, считается покрытым. Эта техника полезна в ряде ситуаций, включая обеспечение точности определения столкновений, отсечения по перекрытию (occlusion culling) и тайлового рендеринга.
### Возвращаемое значение

**true**, если консервативная растеризация включена; иначе **false**.

## void dispatch ( int group_threads_x , int group_threads_y , int group_threads_z )

Выполняет команды в вычислительном шейдере (аналогично методу [ID3D12GraphicsCommandList::Dispatch](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/nf-d3d12-id3d12graphicscommandlist-dispatch) или [vkCmdDispatch](https://registry.khronos.org/vulkan/specs/latest/man/html/vkCmdDispatch.html)). Вычислительный шейдер может выполняться на множестве потоков параллельно, внутри группы потоков. Индексирование конкретного потока внутри группы потоков выполняется с помощью 3D-вектора, заданного как (x,y,z).
### Аргументы

- *int* **group_threads_x** - Локальный размер рабочей группы вычислительного шейдера по X.
- *int* **group_threads_y** - Локальный размер рабочей группы вычислительного шейдера по Y.
- *int* **group_threads_z** - Локальный размер рабочей группы вычислительного шейдера по Z.

## int render ( RenderState::RENDER_MODE mode , int base , int begin , int end , int num )

Рендерит указанное количество экземпляров поверхности, определённой начальным и конечным индексами.
> **Notice:** **Проход, материал и шейдер должны быть заданы** через *[Renderer::setShaderParameters()](../../../api/library/rendering/class.renderer_cpp.md#setShaderParameters_int_Shader_Material_int_void)* и/или *[Renderer::setMaterial()](../../../api/library/rendering/class.renderer_cpp.md#setMaterial_int_Material_void)* **перед вызовом этой функции**. В противном случае для рендеринга будет недостаточно параметров шейдера.


### Аргументы

- *[RenderState::RENDER_MODE](../../../api/library/rendering/class.renderstate_cpp.md#RENDER_MODE)* **mode** - Режим рендеринга. Одно из значений [RENDER_MODE](#RENDER_MODE).
- *int* **base** - Значение, добавляемое к каждому индексу перед чтением вершины из буфера вершин.
- *int* **begin** - Первый индекс поверхности, читаемый GPU из буфера индексов.
- *int* **end** - Последний индекс поверхности, читаемый GPU из буфера индексов.
- *int* **num** - Количество рендеримых экземпляров.

### Возвращаемое значение

Количество отрендеренных примитивов. Тип примитива определяется заданным режимом рендеринга.
