# Unigine.Ffp Class (CPP)

**Header:** #include <UnigineFfp.h>

> **Notice:** Этот класс является одиночкой (singleton).


Интерфейс для фиксированного конвейера рендеринга (fixed function pipeline).


Класс Ffp в UNIGINE отличается от классической реализации OpenGL FFP. Например, [Visualizer](../../../code/console/index.md#visualizer) и [Texture Buffers for Debugging](../../../code/console/index.md#render_show_textures) в UNIGINE реализованы с использованием Ffp. Ffp использует уже реализованные шейдерные программы D3D12 и Vulkan (без создания материалов и т.д.) для рендеринга.


Этот интерфейс позволяет рендерить базовые геометрические примитивы. Например, его можно использовать для отрисовки водяного знака проекта.


#### Пример использования


Ниже приведён пример рендеринга 2D текстуры:


```cpp
/* ... */
// начинаем рендеринг треугольников
Ffp::beginTriangles();
	// добавляем один прямоугольник из треугольников
	// этот метод создаёт индексы
	Ffp::addTriangleQuads(1);
	// добавляем 4 вершины и текстурные координаты
	Ffp::addVertex(x0,y0);
	Ffp::setTexCoord(0.0f,0.0f);
	Ffp::addVertex(x1,y0);
	Ffp::setTexCoord(1.0f,0.0f);
	Ffp::addVertex(x1,y1);
	Ffp::setTexCoord(1.0f,1.0f);
	Ffp::addVertex(x0,y1);
	Ffp::setTexCoord(0.0f,1.0f);
// завершаем рендеринг треугольников
Ffp::endTriangles();

```

## Ffp Class

### Методы класса

---

## void setColor ( unsigned int color )

Задаёт цвет рендеринга для последней добавленной вершины.
Вы можете использовать переменные [COLOR_*](#COLOR_BLACK) для задания цвета.


### Аргументы

- *unsigned int* **color** - Цвет в формате ARGB8: (a << 24) | (r << 16) | (g << 8) | (b << 0).

## void setColor ( float r , float g , float b , float a )

Задаёт цвет рендеринга для последней добавленной вершины.
### Аргументы

- *float* **r** - Красный компонент цвета.
- *float* **g** - Зелёный компонент цвета.
- *float* **b** - Синий компонент цвета.
- *float* **a** - Альфа-компонент цвета.

## bool isEnabled ( ) const

Возвращает значение, указывающее, включён ли Ffp.
### Возвращаемое значение

Возвращает **1**, если Ffp включён; иначе **0**.
## void setMode ( int mode )

Задаёт текущий режим Ffp.
### Аргументы

- *int* **mode** - Текущий режим Ffp.

## int getMode ( ) const

Возвращает текущий режим Ffp.
### Возвращаемое значение

Текущий режим Ffp.
## int getNumIndices ( ) const

Возвращает количество индексов в текущем пакете примитивов.
### Возвращаемое значение

Количество индексов.
## int getNumVertex ( ) const

Возвращает количество вершин в текущем пакете примитивов.
### Возвращаемое значение

Количество вершин.
## void setOrtho ( int width , int height )

Задаёт ортографическую проекцию для рендеринга примитива.
Например, консольная команда [`render_show_textures`](../../../code/console/index.md#render_show_textures) рендерит текстуры через Ffp с использованием ортографической проекции.


### Аргументы

- *int* **width** - Ширина примитива.
- *int* **height** - Высота примитива.

## void setTexCoord ( float x , float y , float z = 0.0f , float w = 1.0f )

Задаёт текстурные координаты для последней добавленной вершины.
### Аргументы

- *float* **x** - X текстурная координата.
- *float* **y** - Y текстурная координата.
- *float* **z** - Z текстурная координата.
- *float* **w** - W текстурная координата.

## void setTransform ( const Math:: mat4 & transform )

Задаёт матрицу трансформации для рендерящегося примитива.
### Аргументы

- *const  Math::[mat4](../../../api/library/math/class.mat4_cpp.md) &* **transform** - Матрица трансформации.

## Math:: mat4 getTransform ( ) const

Возвращает матрицу трансформации рендерящегося примитива.
### Возвращаемое значение

Матрица трансформации.
## void addIndex ( int index )

### Аргументы

- *int* **index** - Индекс вершины.

## void addIndices ( int i0 , int i1 )

Добавляет два заданных индекса в Ffp.
### Аргументы

- *int* **i0** - Первый индекс.
- *int* **i1** - Второй индекс.

## void addIndices ( ushort* OUT_indices , int indices_size , int vertex_offset )

Добавляет заданный массив индексов в Ffp с заданным смещением вершин.
### Аргументы

- *ushort** **OUT_indices** - Массив индексов для добавления. > **Notice:** Этот выходной буфер заполняется движком в результате выполнения метода.
- *int* **indices_size** - Количество элементов в массиве.
- *int* **vertex_offset** - Смещение вершин.

## void addIndices ( ushort* OUT_indices , int indices_size )

Добавляет заданный массив индексов в Ffp.
### Аргументы

- *ushort** **OUT_indices** - Массив индексов для добавления. > **Notice:** Этот выходной буфер заполняется движком в результате выполнения метода.
- *int* **indices_size** - Количество элементов в массиве.

## void addIndices ( int i0 , int i1 , int i2 , int i3 )

Добавляет четыре заданных индекса в Ffp.
### Аргументы

- *int* **i0** - Первый индекс.
- *int* **i1** - Второй индекс.
- *int* **i2** - Третий индекс.
- *int* **i3** - Четвёртый индекс.

## void addIndices ( int i0 , int i1 , int i2 )

Добавляет три заданных индекса в Ffp.
### Аргументы

- *int* **i0** - Первый индекс.
- *int* **i1** - Второй индекс.
- *int* **i2** - Третий индекс.

## void addLines ( int num )

Добавляет заданное количество линий.
Этот метод не добавляет вершины; вместо этого он выделяет индексы, для которых затем должны быть созданы вершины с помощью *addVertex()*. Индексы будут указывать на вершины, начиная с последней добавленной вершины.


### Аргументы

- *int* **num** - Количество линий.

## void addTriangleQuads ( int num )

Добавляет заданное количество прямоугольников. Этот метод не добавляет вершины; вместо этого он выделяет индексы, для которых затем должны быть созданы вершины с помощью *addVertex()*. Индексы будут указывать на вершины, начиная с последней добавленной вершины.
### Аргументы

- *int* **num** - Количество прямоугольников.

## void addTriangles ( int num )

Добавляет заданное количество треугольников. Этот метод не добавляет вершины; вместо этого он выделяет индексы, для которых затем должны быть созданы вершины с помощью *addVertex()*. Индексы будут указывать на вершины, начиная с последней добавленной вершины.
### Аргументы

- *int* **num** - Количество треугольников.

## void addVertex ( Vertex* OUT_vertex , int vertex_size )

Добавляет заданный массив вершин в Ffp.
### Аргументы

- *Vertex** **OUT_vertex** - Массив вершин для добавления. > **Notice:** Этот выходной буфер заполняется движком в результате выполнения метода.
- *int* **vertex_size** - Количество вершин в массиве.

## void addVertex ( const Ffp::Vertex & vertex )

Добавляет заданную вершину в Ffp.
### Аргументы

- *const [Ffp::Vertex](../../../api/library/rendering/class.ffp_cpp.md#Vertex) &* **vertex** - Вершина.

## void addVertex ( float x , float y , float z = 0.0f )

Добавляет вершину с заданными координатами в Ffp.
### Аргументы

- *float* **x** - X координата вершины.
- *float* **y** - Y координата вершины.
- *float* **z** - Z координата вершины.

## void beginLines ( )

Начинает рендеринг линий. Укажите список данных вершин или индексов между *beginLines()* и *endLines()*.
## void beginTriangles ( )

Начинает рендеринг треугольников. Укажите список примитивов и данные вершин между *beginTriangles()* и *endTriangles()*.
## void disable ( )

Отключает рендеринг Ffp.
## void enable ( int mode = MODE_DEFAULT , int texture_sample = 0 )

Включает рендеринг Ffp.
### Аргументы

- *int* **mode** - Режим Ffp.
- *int* **texture_sample** - Флаг сэмплера текстуры для задания. Одно из значений *[TEXTURE_SAMPLE_*](#TEXTURE_SAMPLE_2D)*.

## void endLines ( )

Завершает рендеринг линий (т.е. отрисовывает заданные линии).
## void endTriangles ( )

Завершает рендеринг треугольников (т.е. отрисовывает заданные треугольники).
## void renderScreen ( )

Рендерит полноэкранный прямоугольник. Должен использоваться при рендеринге постэффектов.
## void setTextureSample ( int sample )

Задаёт новый флаг сэмплирования текстуры.
### Аргументы

- *int* **sample** - Флаг сэмплирования текстуры для задания, одно из значений *[TEXTURE_SAMPLE_*](#TEXTURE_SAMPLE_2D)*.

## int getTextureSample ( ) const

Возвращает текущий флаг сэмплирования текстуры.
### Возвращаемое значение

Текущий используемый флаг сэмплирования текстуры, одно из значений *[TEXTURE_SAMPLE_*](#TEXTURE_SAMPLE_2D)*.
