# Unigine::MeshRender Class (CPP)

**Header:** #include <UnigineMeshRender.h>


**MeshRender** представляет ресурс меша на стороне GPU, используемый для рендеринга.


Класс **MeshRender** хранит предварительно скомпилированную геометрию меша, оптимизированную для рендеринга на GPU. В отличие от класса **[Mesh](../../../api/library/rendering/class.mesh_cpp.md)**, который хранит редактируемые данные в RAM, **MeshRender** размещается в VRAM и не предназначен для изменений.


## MeshRender Class

### Методы класса

## bool isLoaded () const

Возвращает текущее значение, указывающее, загружен ли меш.
### Возвращаемое значение

**true**, если меш загружен; иначе **false**.
## void setFlags ( int flags )

Задаёт новый [set of usage flags](#USAGE_DYNAMIC_VERTEX) (*USAGE_DYNAMIC_VERTEX, USAGE_DYNAMIC_INDICES, USAGE_DYNAMIC_ALL*), управляющий тем, как данные вершин и индексов хранятся и используются во время рендеринга.
> **Notice:** Эти флаги поддерживаются только с **DirectX12**. При использовании с **Vulkan** они игнорируются и не влияют на поведение рендеринга.


### Аргументы

- *int* **flags** - Флаги использования, определяющие поведение памяти вершин и индексов.

## int getFlags () const

Возвращает текущий [set of usage flags](#USAGE_DYNAMIC_VERTEX) (*USAGE_DYNAMIC_VERTEX, USAGE_DYNAMIC_INDICES, USAGE_DYNAMIC_ALL*), управляющий тем, как данные вершин и индексов хранятся и используются во время рендеринга.
> **Notice:** Эти флаги поддерживаются только с **DirectX12**. При использовании с **Vulkan** они игнорируются и не влияют на поведение рендеринга.


### Возвращаемое значение

Текущие флаги использования, определяющие поведение памяти вершин и индексов.
## bool isSupportedMultiThreadedLoad () const

Возвращает текущий статус поддержки многопоточной загрузки меша. Эта функция считается поддерживаемой, если доступна [GPU Upload heap](../../../code/console/index.md#d3d12_gpu_upload_heap) или включён *[USAGE_DYNAMIC_ALL](#USAGE_DYNAMIC_ALL)*.
> **Notice:** Эта функция поддерживается только для **DirectX 12**.

### Возвращаемое значение

**true**, если многопоточная загрузка включена; иначе **false**.

## void swap ( const Ptr < MeshRender > & mesh )

Меняет местами все внутренние данные между этим мешем и заданным. Это включает вершины, индексы, флаги использования и другую соответствующую информацию о меше.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[MeshRender](../../../api/library/rendering/class.meshrender_cpp.md)> &* **mesh** - Меш, с которым обмениваются данными.

## int renderSurface ( int mode , int surface , int target = 0 )

### Аргументы

- *int* **mode** - Режим рендеринга. Одна из переменных [MODE_*](#MODE_TRIANGLES).

## void updateDebugName ( )

Обновляет дружественное имя для отладки GPU (RenderDoc, NVIDIA Nsight).
## void setDebugName ( const char * name )

Задаёт дружественное имя для отладки GPU (RenderDoc, NVIDIA Nsight). Оно может помочь определить, вызвал ли утечку соответствующий указатель интерфейса объекта. Об утечках памяти сообщает [debug software layer](https://docs.microsoft.com/en-us/windows/desktop/direct3d11/overviews-direct3d-11-devices-layers#debug-layer), выводя список указателей интерфейсов объектов вместе с их дружественными именами.
### Аргументы

- *const char ** **name** - Задаваемое дружественное отладочное имя.

## const char * getDebugName ( ) const

Возвращает текущее используемое дружественное имя для отладки GPU (RenderDoc, NVIDIA Nsight). Оно может помочь определить, вызвал ли утечку соответствующий указатель интерфейса объекта. Об утечках памяти сообщает [debug software layer](https://docs.microsoft.com/en-us/windows/desktop/direct3d11/overviews-direct3d-11-devices-layers#debug-layer), выводя список указателей интерфейсов объектов вместе с их дружественными именами.
### Возвращаемое значение

Дружественное отладочное имя.
