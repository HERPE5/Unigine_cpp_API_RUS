# Unigine::ResourceExternalMemory Class (CPP)

**Header:** #include <UnigineResourceExternalMemory.h>


Этот класс предназначен для взаимодействия с объектами внешней памяти.


## ResourceExternalMemory Class

### Перечисления

## TYPE

| Name | Description |
|---|---|
| **TYPE_UNKNOWN** = 0 | Тип ресурса неизвестен. |
| **TYPE_TEXTURE** = 1 | Тип ресурса - текстура. |
| **TYPE_STRUCTURED_BUFFER** = 2 | Тип ресурса - структурированный буфер. |
| **TYPE_MESH_DYNAMIC_VERTEX_BUFFER** = 3 | Тип ресурса - буфер вершин mesh dynamic. |
| **TYPE_MESH_DYNAMIC_INDEX_BUFFER** = 4 | Тип ресурса - буфер индексов mesh dynamic. |

### Методы класса

---

## void* getWin32Handle ( ) const

Возвращает указатель на переменную, получающую значение NT HANDLE для совместно используемого ресурса. Этот дескриптор можно использовать в вызовах для доступа к ресурсу.
### Возвращаемое значение

Win32-дескриптор. При вызове в Linux возвращает nullptr.
## int getFdHandle ( ) const

Возвращает файловый дескриптор, ссылающийся на содержимое объекта памяти устройства.
### Возвращаемое значение

Linux-дескриптор. При вызове в Windows возвращает -1.
## ResourceExternalMemory::TYPE getType ( ) const

Возвращает тип объекта, для которого создана внешняя память ресурса.
### Возвращаемое значение

Тип объекта, для которого создана внешняя память ресурса.
## unsigned long long getSize ( ) const

Возвращает размер видеопамяти, занимаемой ресурсом.
### Возвращаемое значение

Размер видеопамяти, занимаемой ресурсом, в байтах.
## void closeHandle ( )

Закрывает дескриптор. Чтобы избежать утечек памяти, используйте этот метод, когда дескриптор ресурса больше не нужен (например, сразу после импорта объекта в другой графический API).
