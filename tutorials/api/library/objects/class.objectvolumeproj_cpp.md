# ObjectVolumeProj Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Этот класс используется для создания объекта [volume projected](../../../objects/effects/volumetrics/volume_proj.md), симулирующего световой луч от направленного источника света. Его можно анимировать для создания потока частиц, движущихся к концу луча и, при необходимости, вращающихся.


Объект volume projected отрисовывается как набор биллбордов, где каждый следующий биллборд больше предыдущего.


## ObjectVolumeProj Class

### Методы класса

---

## static ObjectVolumeProjPtr create ( float width , float height , float fov )

Конструктор. Создаёт новый объект volume projected с заданными свойствами.
### Аргументы

- *float* **width** - Размер наименьшего биллборда, в единицах.
- *float* **height** - Длина светового луча вдоль оси Z, в единицах.
- *float* **fov** - Угол конуса луча, в градусах. Определяет ширину светового луча.

## void setFov ( float fov )

Задаёт ширину светового луча, задаваемую как угол конуса луча.
### Аргументы

- *float* **fov** - Угол в градусах. Указанное значение будет ограничено диапазоном [10;90].

## float getFov ( ) const

Возвращает ширину светового луча, задаваемую как угол конуса луча.
### Возвращаемое значение

Угол в градусах.
## void setRadius ( float radius )

Задаёт длину светового луча.
### Аргументы

- *float* **radius** - Длина, в единицах. Если указано отрицательное значение, вместо него будет использовано 0.

## float getRadius ( ) const

Возвращает длину светового луча вдоль оси Z, в единицах.
### Возвращаемое значение

Текущая длина, в единицах.
## void setSize ( float size )

Задаёт размер наименьшего биллборда в начале светового луча.
### Аргументы

- *float* **size** - Размер наименьшего биллборда, в единицах. Если указано слишком малое значение, вместо него будет использовано 0.001.

## float getSize ( ) const

Возвращает размер наименьшего биллборда в начале светового луча.
### Возвращаемое значение

Размер наименьшего биллборда, в единицах.
## void setStep ( float step )

Задаёт шаг между соседними биллбордами. Шаг определяет, сколько биллбордов используется для отрисовки объекта volume projected. Чем больше шаг, тем меньше биллбордов используется для отрисовки объекта.
### Аргументы

- *float* **step** - Шаг между биллбордами. Указанное значение будет ограничено диапазоном [0.1; 1]. При значении 1 луч отрисовывается дискретно.

## float getStep ( ) const

Возвращает расстояние между соседними биллбордами. Шаг определяет, сколько биллбордов используется для отрисовки объекта volume projected. Чем больше шаг, тем меньше биллбордов используется для отрисовки объекта.
### Возвращаемое значение

Шаг между биллбордами.
## void setVelocity ( float velocity )

Задаёт скорость, с которой биллборды перемещаются к концу светового луча.
### Аргументы

- *float* **velocity** - Скорость биллбордов.

## float getVelocity ( ) const

Возвращает скорость, с которой биллборды перемещаются к концу светового луча.
### Возвращаемое значение

Скорость биллбордов.
## void setVolumeRotation ( float rotation )

Задаёт угол вращения биллбордов. Этот угол задаётся для биллборда в конце светового луча.
### Аргументы

- *float* **rotation** - Угол вращения. Если задано положительное значение, биллборды будут вращаться по часовой стрелке; если отрицательное — против часовой стрелки.

## float getVolumeRotation ( ) const

Возвращает угол вращения биллбордов. Этот угол задаётся для биллборда в конце луча. Если задано положительное значение, биллборды вращаются по часовой стрелке; если отрицательное — против часовой стрелки.
### Возвращаемое значение

Угол вращения.
## static int type ( )

Возвращает тип узла.
### Возвращаемое значение

Идентификатор типа [Object](../../../api/library/objects/class.object_cpp.md).
