# ObjectText Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Этот класс используется для рендеринга [flat text](../../../api/library/objects/class.objecttext_cpp.md) в сцене.


### Usage Example


Ниже приведён пример создания *ObjectText*, который будет поворачиваться, следуя за позицией игрока, при этом вращение родителя остаётся неизменным, что позволяет родительскому узлу свободно перемещаться, увлекая текст за собой. Чтобы попробовать это самостоятельно, [create](../../../principles/component_system/component_system_cpp/index.md#workflow) новый класс с именем **TextCreator** и скопируйте файлы **.h** и **.cpp** в соответствующие файлы класса. Затем [assign](../../../principles/component_system/component_system_cpp/index.md#workflow) компонент любому нужному узлу, который будет родительским для *ObjectText*.


<details>
<summary>TextCreator.cpp | Закрыть</summary>

```cpp
#include "TextCreator.h"
#include <UnigineMathLib.h>

REGISTER_COMPONENT(TextCreator);

using namespace Unigine;

Unigine::ObjectTextPtr text;

void TextCreator::init() {
	// создаём Object Text (создаётся без шрифта и текста)
	text = Unigine::ObjectText::create();
	// задаём текст для отображения и шрифт
	text->setText(textStr.get());
	text->setFontName("font.ttf");
	text->setFontSize(100);
	text->setFontResolution(100);
	// задаём объект компонента в качестве родителя
	text->setParent(this->getNode());
}

void TextCreator::update() {
	// поворачиваем текст, чтобы он всегда был направлен на игрока
	// точка опоры будет направлена на игрока, поэтому требуется небольшая корректировка
	text->worldLookAt(Game::getPlayer()->getPosition());
	// немного поворачиваем текст, чтобы он отображался правильно
	text->rotate(270, 0, 180);
}

```

</details>

#include <UnigineGame.h>

class TextCreator : public Unigine::ComponentBase
{
	public:
		COMPONENT_DEFINE(TextCreator, ComponentBase)
		COMPONENT_INIT(init);
		COMPONENT_UPDATE(update);

		//создаём параметр для определения текста
		PROP_PARAM(String, textStr);
	protected:
		void init();
		void update();
};

## void setFontResolution ( int resolution )

Задаёт новое разрешение текстуры, в которую будет рендериться текст. Чем ниже значение, тем менее детализированным будет текст и тем меньше видеопамяти потребуется для текстуры. Это не влияет на физический размер текста.
### Аргументы

- *int* **resolution** - Значение разрешения шрифта текста.

## int getFontResolution () const

### Возвращаемое значение

Текущее значение разрешения шрифта текста.
## void setFontSize ( int size )

Задаёт новый размер шрифта текста. Чем больше точек, тем крупнее размер шрифта. Для соответствия точек 3D-пространству используется значение: **288** точек на единицу. Например, для шрифта *Arial* размером **20** физическую высоту буквы можно вычислить как 20/288=0.0694 единиц.
### Аргументы

- *int* **size** - Размер шрифта текста, в точках.

## int getFontSize () const

Возвращает текущий размер шрифта текста. Чем больше точек, тем крупнее размер шрифта. Для соответствия точек 3D-пространству используется значение: **288** точек на единицу. Например, для шрифта *Arial* размером **20** физическую высоту буквы можно вычислить как 20/288=0.0694 единиц.
### Возвращаемое значение

Текущий размер шрифта текста, в точках.
## void setFontRich ( int rich )

Задаёт новый флаг, указывающий, включён ли форматированный (rich) текст. При включении можно использовать следующие теги для форматирования текста:
- **<b>**текст**</b>** задаёт полужирный текст.
- **<i>**текст**</i>** задаёт курсивный текст.
- **<br>**текст**<br/>** вставляет одиночный разрыв строки.
- **<left>**текст**</left>** выравнивает текст по левому краю.
- **<right>**текст**</right>** выравнивает текст по правому краю.
- **<center>**текст**</center>** выравнивает текст по центру.
- **<p align=left|right|center|justify>**текст**</p>** задаёт выравнивание текста внутри абзаца: > **Notice:** Для выравнивания текста требуется включённый перенос текста: значение параметра [**Wrap Width**](#setTextWrapWidth_float_void) должно быть больше 0.

  - *left* - выравнивает текст по левому краю
  - *right* - выравнивает текст по правому краю
  - *center* - выравнивает текст по центру
  - *justify* - растягивает строки так, чтобы каждая строка имела одинаковую ширину (как в газетах и журналах)
- **<font size=12 color=magenta face=verdana>** текст**</font>** задаёт начертание, размер и цвет шрифта текста.
- **<sub>** текст**</sub>** определяет подстрочный текст. Подстрочный текст отображается на половину символа ниже обычной строки и иногда рендерится меньшим шрифтом.
- **<sup>** текст**</sup>** определяет надстрочный текст. Надстрочный текст отображается на половину символа выше обычной строки и иногда рендерится меньшим шрифтом.


> **Notice:** Теги **<image/>** и **<table/>** недоступны.


### Аргументы

- *int* **rich** - **1** — чтобы включить форматированный текст; **0** — чтобы отключить.
