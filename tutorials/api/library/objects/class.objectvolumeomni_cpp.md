# ObjectVolumeOmni Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Этот класс используется для создания объекта [volume omni](../../../objects/effects/volumetrics/volume_omni.md). Он симулирует видимый объём света, испускаемого плоским источником света.


Объект volume omni отрисовывается как плоский прямоугольник с биллбордами по его краям. Прямоугольник симулирует поверхность, излучающую свет, а биллборды создают вокруг неё объём света.


## ObjectVolumeOmni Class

### Методы класса

---

## static ObjectVolumeOmniPtr create ( float width , float height , float radius )

Конструктор. Создаёт новый объект volume omni с заданными свойствами.
### Аргументы

- *float* **width** - Ширина центрального прямоугольника, в единицах.
- *float* **height** - Высота центрального прямоугольника, в единицах.
- *float* **radius** - Размер биллбордов, в единицах.

## void setAttenuation ( float attenuation )

Задаёт затухание, определяющее скорость исчезновения объекта volume omni при взгляде на него камерой сбоку.
### Аргументы

- *float* **attenuation** - Коэффициент затухания. Если указано слишком малое значение, вместо него будет использовано 1E-6.

## float getAttenuation ( ) const

Возвращает затухание, модулирующее плавное исчезновение объекта volume omni при взгляде на него камерой сбоку.
### Возвращаемое значение

Текущий коэффициент затухания.
## float getHeight ( ) const

Возвращает высоту центрального плоского прямоугольника, в единицах.
### Возвращаемое значение

Высота центрального прямоугольника, в единицах.
## void setRadius ( float radius )

Задаёт ширину биллбордов по краям.
### Аргументы

- *float* **radius** - Новая ширина, в единицах. Если указано отрицательное значение, вместо него будет использовано 0.

## float getRadius ( ) const

Возвращает размер биллбордов.
### Возвращаемое значение

Размер биллбордов, в единицах.
## void setSize ( float width , float height )

Задаёт новые размеры объекта volume omni.
### Аргументы

- *float* **width** - Новая ширина центрального плоского прямоугольника, в единицах. Если указано отрицательное значение, вместо него будет использовано 0.
- *float* **height** - Новая высота центрального плоского прямоугольника, в единицах. Если указано отрицательное значение, вместо него будет использовано 0.

## float getWidth ( ) const

Возвращает ширину центрального плоского прямоугольника.
### Возвращаемое значение

Ширина центрального прямоугольника, в единицах.

Возвращает тип узла.

Идентификатор типа [Object](../../../api/library/objects/class.object_cpp.md).
