# ObjectWaterMesh Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Интерфейс для работы с объектом [object water mesh](../../../objects/objects/water/water_mesh.md). Меш воды может иметь четыре синусоидальные волны. Объект используется для создания небольших водоёмов, таких как пруды, озёра и т.д. ObjectWaterMesh имеет [physics support](../../../objects/objects/water/water_mesh.md#water_physics), поэтому ему можно назначить тело, и, следовательно, он может взаимодействовать с другими объектами сцены.

## int setMesh ( const Ptr < Mesh > & mesh )

Позволяет выполнить повторную инициализацию объекта меша воды: копирует заданный меш в текущий меш воды.
```cpp
// создаём пустой меш decal
ObjectWaterMeshPtr waterMesh = ObjectWaterMesh::create();
// создаём меш
MeshPtr mesh = Mesh::create("lake.mesh");
// копируем меш в меш воды
waterMesh->setMesh(mesh);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Mesh](../../../api/library/rendering/class.mesh_cpp.md)> &* **mesh** - Умный указатель на меш.

### Возвращаемое значение

1, если меш успешно скопирован; иначе 0.
## int getMesh ( const Ptr < Mesh > & mesh )

Копирует текущий меш воды в полученный меш.
```cpp
// меш воды, из которого будет получена геометрия
ObjectWaterMeshPtr waterMesh = ObjectWaterMesh::create("lake.mesh");
// создаём новый меш
MeshPtr mesh = Mesh::create();
// копируем геометрию в созданный меш
if (waterMesh->getMesh(mesh)) {
	// выполняем какие-то действия с полученным мешем
}
else {
	Log::error("Не удалось скопировать меш\n");
}

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Mesh](../../../api/library/rendering/class.mesh_cpp.md)> &* **mesh** - Умный указатель на полученный меш.

### Возвращаемое значение

1, если меш успешно скопирован; иначе 0.
## int setMeshPath ( const char * path , int force_load = 0 )

Задаёт новый путь к файлу `.mesh`, используемому для объекта, и принудительно загружает меш.
### Аргументы

- *const char ** **path** - Новый путь к файлу `.mesh`, который нужно задать.
- *int* **force_load** - Флаг принудительной загрузки.

  - Если указано 1, меш с новым именем будет немедленно загружен из файла, указанного в первом аргументе этой функции.
  - Если указано 0, будет обновлено только имя меша.

### Возвращаемое значение

1, если:
- Текущее имя меша совпадает с новым именем.
- Меш с новым именем был успешно загружен.
- Флаг принудительной загрузки установлен в 0.

В остальных случаях — 0.

## void setWaveAngle ( int num , float angle )

Задаёт направление (угол распространения) для указанной волны:
- Если указано 0, волна распространяется вдоль оси Y и параллельна оси X.
- Если указано положительное значение, направление волны наклонено против часовой стрелки относительно исходного распространения.
- Если указано отрицательное значение, волна поворачивается по часовой стрелке.


### Аргументы

- *int* **num** - Номер волны в диапазоне [0;3].
- *float* **angle** - Угол, в градусах. Допустимы как положительные, так и отрицательные значения.
