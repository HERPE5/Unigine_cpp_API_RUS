# ObjectMeshClutter Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


[MeshClutter](../../../objects/objects/mesh_clutter/index.md) используется для рассеивания идентичных мешей (с одним и тем же материалом, применённым к их поверхностям), а также для случайного масштабирования и ориентирования их. Рассеянные меши запекаются в один объект, что позволяет сделать пространственное дерево менее загромождённым, снижает количество выборок текстур и ускоряет рендеринг.


Меши рендерятся в пределах заданного [distance](#setVisibleDistance_float_void) от камеры. За пределами этого расстояния узлы [fade out](#setFadeDistance_float_void), а затем полностью исчезают.


Вы можете использовать [mask](#setCutoutIntersectionMask_int_void) для вырезания clutter-объектов в областях пересечения с другими объектами и декалями (например, для удаления растительности под домами или с поверхности дорог, спроецированных с помощью декалей).


### Важные замечания


Количество элементов clutter в каждой ячейке определяется размером (*Size*) clutter вдоль осей *[X](#setSizeX_float_void)* и *[Y](#setSizeY_float_void)*, а также значениями *[Density](#setDensity_float_void)* и *[Step](#setStep_float_void)*. Соотношение между этими значениями во внутренних вычислениях может приводить к невидимому clutter (сгенерированному с пустыми ячейками), когда рассчитанная плотность для ячеек становится меньше 1 (в каждой ячейке будет "менее 1 элемента" — то есть вообще никаких элементов clutter). Пожалуйста, учитывайте это при задании данных значений.


Количество ячеек clutter вычисляется по следующим формулам:


```cpp
num_cells_x = max(Math::ftoi(Math::ceil(clutter_size_x / step)), 1);
num_cells_y = max(Math::ftoi(Math::ceil(clutter_size_y / step)), 1);

```


Размер каждой ячейки вдоль осей X и Y вычисляется следующим образом:


```cpp
cell_size_x = clutter_size_x / Math::itof(num_cells_x);
cell_size_y = clutter_size_y / Math::itof(num_cells_y);

```


И итоговая плотность ячейки:


```cpp
cell_density = cell_size_x * cell_size_y * density;

```


**Пример:**


Значения *[Step](#setStep_float_void)* и *[Density](#setDensity_float_void)* по умолчанию для clutter равны 1.0f. Задание размера clutter вдоль любой из осей нецелым значением с ненулевой дробной частью (например, 200.1) автоматически увеличивает количество ячеек вдоль соответствующей оси на 1 (например, 201 вместо 200). Это приводит к размеру ячейки < 1, что снижает плотность ячейки ниже 1.
