# Unigine.TerrainGlobalLodHeight Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** TerrainGlobalLod


Этот класс наследуется от класса [TerrainGlobalLod](../../../api/library/objects/class.terraingloballod_cpp.md) и используется для управления одним [LOD](../../../objects/objects/terrain/terrain_global/index.md#lods) (уровнем детализации) высот объекта [global terrain](../../../objects/objects/terrain/terrain_global/index.md). LOD-ы высот используются для обнаружения столкновений и пересечений.


## TerrainGlobalLodHeight Class

### Методы класса

---

## void setCastShadows ( int shadows )

Включает или отключает отбрасывание теней от источников света, не относящихся к World-типу, для LOD высот.
### Аргументы

- *int* **shadows** - **1** для включения отбрасывания теней, 0 для отключения.

## int isCastShadows ( )

Возвращает значение, указывающее, включено ли отбрасывание теней для LOD высот.
### Возвращаемое значение

**1**, если отбрасывание теней для LOD высот включено; иначе 0.
## void setCollision ( int collision )

Включает или отключает определение столкновений для LOD высот.
### Аргументы

- *int* **collision** - **1** для включения определения столкновений, 0 для отключения.

## int isCollision ( )

Возвращает значение, указывающее, включено ли определение столкновений для LOD высот.
### Возвращаемое значение

**1**, если определение столкновений для LOD высот включено; иначе 0.
## void setCollisionMask ( int mask )

Задаёт маску столкновений для LOD высот. Столкновение объекта с LOD высот будет обнаружено, если у них обоих совпадают маски.
### Аргументы

- *int* **mask** - Маска столкновений, целое значение, каждый бит которого является маской.

## int getCollisionMask ( )

Возвращает текущую маску столкновений для LOD высот. Столкновение объекта с LOD высот будет обнаружено, если у них обоих совпадают маски.
### Возвращаемое значение

Маска столкновений, целое значение, каждый бит которого является маской.
