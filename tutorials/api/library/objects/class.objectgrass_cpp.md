# ObjectGrass Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Этот класс используется для создания [grass](../../../objects/objects/grass/index.md). Объект травы рендерится в ячейках [grid](../../../objects/objects/grass/index.md#step).


Вы можете использовать [mask](#setCutoutIntersectionMask_int_void) для вырезания травы в областях пересечения с другими объектами и декалями (например, для удаления растительности под домами или с поверхности дорог, спроецированных с помощью декалей).

## void setMaxBend ( const Math:: vec4 & mean , const Math:: vec4 & spread )

Задаёт параметры максимального изгиба травы (рендерится в областях с наибольшей плотностью согласно маске). Углы изгиба (среднее и разброс) заданы для четырёх колонок диффузной текстуры. Результирующее значение определяется следующим образом: `Result = Mean + Random * Spread`, где `Random` — случайное значение в диапазоне от -1 до 1.
### Аргументы

- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md) &* **mean** - Вектор средних значений углов изгиба травы, задаваемых для четырёх колонок диффузной текстуры.

## void setCutoutIntersectionMask ( int mask )

Задаёт новую маску вырезающего пересечения. Эта маска позволяет вырезать траву в областях пересечения с объектами и декалями (например, может использоваться для удаления травы под домами или с поверхности дорог, спроецированных с помощью декалей). Трава будет вырезана объектами и декалями, чья маска пересечения совпадает с этой (хотя бы по одному биту).
> **Notice:** Для установки масок пересечения могут использоваться следующие методы:
> - **для декалей** используйте *[getIntersectionMask()](../../../api/library/decals/class.decal_cpp.md#getIntersectionMask_int)*
> - **для объектов** используйте *[getIntersectionMask()](../../../api/library/objects/class.object_cpp.md#getIntersectionMask_int_int)*


### Аргументы

- *int* **mask** - Целое число, каждый бит которого является маской.

> **Notice:** Для установки масок пересечения могут использоваться следующие методы:
