# Unigine.LandscapeTextures Class (CPP)

**Header:** #include <UnigineObjects.h>


Этот класс используется для управления фрагментом данных террейна на стороне GPU (например, изменение высот, альбедо, масок и т.д.). По сути он представляет собой контейнер данных для фрагмента области террейна заданного разрешения. Этот класс можно использовать, например, при реализации кистей на основе GPU.


## LandscapeTextures Class

### Методы класса

---

## Ptr < LandscapeTextures > LandscapeTextures ( const Math:: ivec2 & resolution )

Создаёт новый объект LandscapeTextures для хранения данных области террейна заданного разрешения.
### Аргументы

- *const  Math::[ivec2](../../../../api/library/math/class.ivec2_cpp.md) &* **resolution** - Двухкомпонентный вектор, содержащий разрешение текстуры по осям X и Y.

## Ptr < Texture > getHeight ( )

Возвращает данные высот в виде текстуры R32F.
### Возвращаемое значение

Текстура (R32F), содержащая данные высот.
## Ptr < Texture > getAlbedo ( )

Возвращает данные альбедо в виде текстуры RGBA8. Данные непрозрачности хранятся в альфа-канале.
### Возвращаемое значение

Текстура (RGBA8), содержащая данные альбедо.
## Ptr < Texture > getMask ( int num )

Возвращает данные маски в виде текстуры RGBA8.
> **Notice:** Каждая детализирующая маска может быть представлена одноканальной текстурой. В целях оптимизации данные детализирующих масок хранятся блоками — текстурами RGBA8 (каждая содержит 4 маски, по одной маске на канал). Всего 5 блоков, так как террейн поддерживает 20 детализирующих масок. Таким образом, данные **9**-й детализирующей маски будут храниться в R-канале третьего блока (индекс = 2).

### Аргументы

- *int* **num** - Индекс блока данных масок.

### Возвращаемое значение

Текстура (RGBA8), содержащая данные маски.
## Ptr < Texture > getOpacityHeight ( )

Возвращает информацию о непрозрачности данных высот в виде текстуры R32F.
### Возвращаемое значение

Текстура (R32F), содержащая информацию о непрозрачности текстуры высот.

> **Notice:** Каждая маска может быть представлена одноканальной текстурой. В целях оптимизации информация о непрозрачности данных масок хранится блоками — текстурами RGBA8 (каждая содержит 4 маски, по одной маске на канал). Всего 5 блоков, так как террейн поддерживает 20 детализирующих масок. Таким образом, данные **9**-й детализирующей маски будут храниться в R-канале третьего блока (индекс = 2).

### Аргументы

- *int* **num** - Индекс блока данных масок.

### Возвращаемое значение

Текстура (RGBA8), содержащая информацию о непрозрачности данных маски.
