# Unigine.LandscapeImages Class (CPP)

**Header:** #include <UnigineObjects.h>

Этот класс используется для управления фрагментом данных террейна на стороне CPU (например, изменение высот, альбедо, масок и т.д.). По сути он представляет собой контейнер данных для фрагмента области террейна заданного разрешения. Этот класс можно использовать, например, при реализации кистей на основе CPU.


## LandscapeImages Class

### Методы класса

---

## Ptr < LandscapeImages > LandscapeImages ( const Math:: ivec2 & resolution )

Создаёт новый объект LandscapeImages для хранения данных области террейна заданного разрешения.
### Аргументы

- *const  Math::[ivec2](../../../../api/library/math/class.ivec2_cpp.md) &* **resolution** - Двухкомпонентный вектор, содержащий разрешение изображения по осям X и Y.

### Возвращаемое значение

Экземпляр LandscapeImages — контейнер данных для области террейна заданного размера.
## Ptr < Image > getHeight ( )

Возвращает данные высот в виде изображения.
### Возвращаемое значение

Изображение (R32F), содержащее данные высот.
## Ptr < Image > getAlbedo ( )

Возвращает данные альбедо в виде изображения RGBA8. Данные непрозрачности хранятся в альфа-канале.
### Возвращаемое значение

Изображение (RGBA8), содержащее данные альбедо.
## Ptr < Image > getMask ( int num )

Возвращает данные маски в виде изображения RGBA8.
> **Notice:** Каждая детализирующая маска может быть представлена одноканальным изображением. В целях оптимизации данные детализирующих масок хранятся блоками — изображениями RGBA8 (каждое содержит 4 маски, по одной маске на канал). Всего 5 блоков, так как террейн поддерживает 20 детализирующих масок. Таким образом, данные **9**-й детализирующей маски будут храниться в R-канале третьего блока (индекс = 2).

### Аргументы

- *int* **num** - Индекс блока данных масок.

### Возвращаемое значение

Изображение (RGBA8), содержащее данные маски.
## Ptr < Image > getOpacityHeight ( )

### Возвращаемое значение

В целях оптимизации информация о непрозрачности данных масок хранится блоками — изображениями RGBA8 (каждое содержит 4 маски, по одной маске на канал). Всего 5 блоков, так как террейн поддерживает 20 детализирующих масок. Таким образом, данные **9**-й детализирующей маски будут храниться в R-канале третьего блока (индекс = 2).

### Аргументы
