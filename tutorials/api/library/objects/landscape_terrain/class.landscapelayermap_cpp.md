# Unigine.LandscapeLayerMap Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Node


Этот класс используется для управления [layer maps](../../../../objects/objects/terrain/landscape_terrain/landscape_layer_map.md) landscape объекта [Landscape Terrain](../../../../objects/objects/terrain/landscape_terrain/index.md). Данные карты слоёв landscape (высоты, альбедо, маски, настройки) хранятся в файле `.lmap` (см. классы [LandscapeMapFileCreator](../../../../api/library/objects/landscape_terrain/class.landscapemapfilecreator_cpp.md) и [LandscapeMapFileSettings](../../../../api/library/objects/landscape_terrain/class.landscapemapfilesettings_cpp.md)). Карта landscape имеет единое разрешение и плотность и не может содержать вставки (insets). Вставки создаются путём добавления карты слоя landscape с высоким разрешением поверх карты с низким разрешением.


![](../../../../objects/objects/terrain/landscape_terrain/landscape_layers.png)


Несколько карт могут быть смешаны друг с другом. Параметры смешивания карты слоя landscape управляются соответствующими методами класса [*LandscapeMapFilesettings*](../../../../api/library/objects/landscape_terrain/class.landscapemapfilesettings_cpp.md).


### Максимальная и минимальная высота террейна


Этот пример демонстрирует, как получить минимальное и максимальное значения высоты для всего [Landscape Terrain](../../../../objects/objects/terrain/landscape_terrain/index.md) (всех карт слоёв) вместе с охватывающим ограничивающим объёмом. Для этого нужно найти все объекты *LandscapeLayerMap* в мире, расширить ограничивающий объём так, чтобы он охватывал их все, и использовать метод [*getExtremumHeight()*](#getExtremumHeight_float_Vec2) для получения минимального и максимального значений высоты.


```cpp
WorldBoundBox b;
float min = 99999, max = -9999;
Vector<NodePtr> v;
World::getNodes(v);
for (auto & it : v)
{
	if (it->getType() == Node::LANDSCAPE_LAYER_MAP)
	{
		b.expand(it->getWorldBoundBox());
		auto ext = checked_ptr_cast<LandscapeLayerMap>(it)->getExtremumHeight();
		if (ext.x < min)
			min = ext.x;
		if (ext.y > max)
			max = ext.y;
	}
}
vec3 minp = vec3(b.getMin());
vec3 maxp = vec3(b.getMax());
minp.z = min;
maxp.z = max;
BoundBox bb = BoundBox(minp, maxp);
Visualizer::renderBoundBox(bb, Mat4_identity, vec4_red);

```

## void setCulling ( bool culling )

Задаёт значение, указывающее, используются ли данные высот карты слоя для предрасчёта отсечения (culling). Для определения того, какие части террейна должны отрисовываться, требуется тест отсечения. Этот тест выполняется на основе предварительно рассчитанной карты высот низкой детализации, объединяющей данные высот всех карт слоёв landscape, оказывающих значительное влияние на результат. Предрасчёт выполняется на стороне CPU, поэтому обработка большого количества карт слоёв landscape может снизить производительность. Кроме того, некоторые карты слоёв могут использоваться как декали (т.е. их влияние на результирующую карту высот незначительно). В таких случаях можно просто отключить эту опцию, чтобы избежать лишних вычислений.
> **Notice:** Отключение этой опции для одной


### Аргументы

- *bool* **culling** - true, чтобы использовать карту слоя для отсечения, false — чтобы игнорировать её.
