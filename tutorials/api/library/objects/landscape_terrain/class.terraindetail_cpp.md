# Unigine.TerrainDetail Class (CPP)

**Header:** #include <UnigineObjects.h>


Этот класс используется для управления деталями объекта [Landscape Terrain](../../../../objects/objects/terrain/landscape_terrain/index.md). Детали определяют внешний вид террейна, каждая из них может иметь неограниченное количество дочерних элементов. Детали привязываются к [detail masks](../../../../api/library/objects/landscape_terrain/class.terraindetailmask_cpp.md) и отрисовываются в соответствии с их порядком рендеринга (деталь с наивысшим порядком отрисовывается поверх всех остальных).

Задаёт новый цвет, используемый в качестве маски для детали. В этом случае все области террейна с выбранным цветом будут покрыты этой деталью.
