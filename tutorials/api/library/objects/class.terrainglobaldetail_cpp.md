## void setBlendTriplanar ( float triplanar )

Задаёт пороговое значение, контролирующее плавность смешивания между разными проекциями трипланарного текстурирования.
> **Notice:** Этот параметр используется только тогда, когда трипланарное текстурирование [enabled](#setTriplanar_int_void) для детали.


### Аргументы

- *float* **triplanar** - Значение трипланарного смешивания в диапазоне [0.0f; 1.0f]. **Меньшие** значения дают более резкие переходы между проекциями, а **большие** значения делают их более плавными.

## float getBlendTriplanar ( )

Возвращает пороговое значение, контролирующее плавность смешивания между разными проекциями трипланарного текстурирования.
> **Notice:** Этот параметр используется только тогда, когда трипланарное текстурирование [enabled](#setTriplanar_int_void) для детали.

Значение трипланарного смешивания в диапазоне [0.0f; 1.0f].

## void setDisplacementOffset ( float offset )

Задаёт смещение displacement. Этот параметр контролирует направление смещения (внутрь или наружу).
### Аргументы

- *float* **offset** - Значение смещения displacement в диапазоне [-1.0f; 1.0f].

  - **положительное значение** - смещение наружу.
  - **0** - точки, соответствующие значениям [height texture](#setHeightTextureName_cstr_void) меньше 0.5, смещаются внутрь, остальные — наружу.
  - **отрицательное значение** - смещение внутрь.

## float getDisplacementOffset ( )

Возвращает смещение displacement. Этот параметр контролирует направление смещения (внутрь или наружу).
### Возвращаемое значение

Значение смещения displacement в диапазоне [-1.0f; 1.0f].
- **положительное значение** - смещение наружу.
- **0** - точки, соответствующие значениям [height texture](#setHeightTextureName_cstr_void) меньше 0.5, смещаются внутрь, остальные — наружу.
