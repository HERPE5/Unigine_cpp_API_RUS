# Unigine.TileSetFile Class (CPP)

**Header:** #include <UnigineTilesetFile.h>


Этот класс используется для создания файла tileset — файла, хранящего данные на основе индексов X и Y. Значения X и Y ограничены целым числом и могут быть как положительными, так и отрицательными. Максимальный размер тайла ограничен 2 ГБ. Максимальный размер tileset ограничен значением беззнакового целого числа. Файлы tileset хранятся в форматах .UTS и .UTSH.

## int setTile ( int x , int y , unsigned char * OUT_data , int force = 1 )

Задаёт данные указанного тайла, копируя их из исходного буфера.
### Аргументы

- *int* **x** - Значение координаты X.
- *int* **y** - Значение координаты Y.
- *unsigned char ** **OUT_data** - Исходный буфер. > **Notice:** Этот выходной буфер заполняется движком в результате выполнения метода.
- *int* **force** - Флаг принудительной загрузки. > **Notice:** Для повышения производительности рекомендуется устанавливать этот флаг в 0, чтобы накапливать несколько операций обновления тайлов и применять их все сразу вызовом метода [flushHeader()](#flushHeader_int).

  - Если указано 1, данные будут обновлены немедленно.
  - Если указано 0, данные будут обновлены только при вызове метода [flushHeader()](#flushHeader_int).

### Возвращаемое значение

1, если операция выполнена успешно; иначе 0.
