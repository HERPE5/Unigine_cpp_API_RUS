# ObjectGui Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Этот класс позволяет создать плоский объект [GUI](../../../objects/objects/gui/gui_object.md), который располагается в мире и которому назначаются различные [widgets](../../../api/library/gui/class.widget_cpp.md) для отображения. По сути, ObjectGui — это плоский экран, к которому игрок может подойти и нажимать на кнопки. Объекты GUI могут подвергаться постобработке, например размытию или другой фильтрации.


> **Notice:** При создании экземпляра класса *ObjectGui* он автоматически связывается с экземпляром класса [*Gui*](../../../api/library/gui/class.gui_cpp.md).

### Методы класса

## static ObjectGuiPtr create ( float width , float height , const char * name = 0 )

Конструктор. Создаёт новый объект GUI с заданными свойствами.
### Аргументы

- *float* **width** - Физическая ширина нового объекта GUI в единицах.
- *float* **height** - Физическая высота нового объекта GUI в единицах.
- *const char ** **name** - Путь к папке со скином GUI ([RC file](../../../code/gui/rc.md) и текстуры). Если значение не указано, будет использован скин GUI по умолчанию.

## void setBackground ( bool background )

Задаёт значение, указывающее, должен ли отображаться фон GUI (чёрный экран).
### Аргументы

- *bool* **background** - true для отображения фона GUI, false, чтобы оставить его прозрачным.

## bool isBackground ( ) const

Возвращает значение, указывающее, отображается ли фон GUI (чёрный экран).
### Возвращаемое значение

true, если фон отображается; в противном случае — false.
## void setBillboard ( bool billboard )

Задаёт значение, указывающее, должен ли объект GUI быть биллбордом.
### Аргументы

- *bool* **billboard** - true для рендеринга объекта GUI как биллборда; в противном случае — false.

## bool isBillboard ( ) const

Возвращает значение, указывающее, является ли объект GUI биллбордом.
### Возвращаемое значение

**true**, если объект GUI является биллбордом; в противном случае — **false**.
## void setControlDistance ( float distance )

Задаёт расстояние, на котором GUI становится управляемым.
### Аргументы

- *float* **distance** - Новое расстояние в единицах. Если указано отрицательное значение, вместо него будет использовано 0.

## float getControlDistance ( ) const

Возвращает расстояние, на котором GUI становится управляемым.
### Возвращаемое значение

Расстояние в единицах.
## void setDepthTest ( bool test )

Задаёт значение, указывающее, должен ли использоваться тест глубины для объекта GUI.
### Аргументы

- *bool* **test** - true для использования теста глубины; в противном случае — false.

## bool isDepthTest ( ) const

Возвращает значение, указывающее, использует ли объект GUI тест глубины.
### Возвращаемое значение

true, если объект GUI использует тест глубины; в противном случае — false.
## Ptr < Gui > getGui ( ) const

Возвращает экземпляр [Gui](../../../api/library/gui/class.gui_cpp.md), связанный с объектом. Эта функция используется при назначении виджета объекту GUI.
> **Notice:** При создании экземпляра класса *ObjectGui* он автоматически связывается с экземпляром *[Gui](../../../api/library/gui/class.gui_cpp.md)*.


### Возвращаемое значение

Умный указатель Gui.
## void setMouse ( const Math:: Vec3 & p0 , const Math:: Vec3 & p1 , int mouse_button , int mouse_show )

Задаёт позицию курсора мыши в [virtual control mode](#MOUSE_VIRTUAL).
### Аргументы

- *const  Math::[Vec3](../../../api/library/math/class.vec3_cpp.md) &* **p0** - Начальная точка. Отрезок между начальной и конечной точками должен пересекать ObjectGui. Точка пересечения определяет координаты x и y на ObjectGui.
- *const  Math::[Vec3](../../../api/library/math/class.vec3_cpp.md) &* **p1** - Конечная точка. Отрезок между начальной и конечной точками должен пересекать ObjectGui. Точка пересечения определяет координаты x и y на ObjectGui.
- *int* **mouse_button** - Состояние кнопки мыши. Установите 1, чтобы указать, что кнопка нажата; в противном случае — 0.
- *int* **mouse_show** - Состояние курсора мыши. Установите 1, чтобы показать курсор мыши; в противном случае — 0.

## void setMouseMode ( int mode )

Задаёт режим мыши. Этот метод можно использовать для задания [virtual control mode](#MOUSE_VIRTUAL) для мыши.
### Аргументы

- *int* **mode** - Режим мыши. Одна из переменных [MOUSE_*](#MOUSE_VIRTUAL).

## int getMouseMode ( ) const

Возвращает текущий режим мыши.
### Возвращаемое значение

Режим мыши. Одна из переменных [MOUSE_*](#MOUSE_VIRTUAL).

## bool isMouseShow ( ) const
