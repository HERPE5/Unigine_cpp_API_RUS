## static ObjectExternPtr create ( int class_id )

Конструктор. Создаёт пользовательский объект, определяемый пользователем.
### Аргументы

- *int* **class_id** - Уникальный идентификатор класса.

## int getClassID ( ) const

Возвращает уникальный идентификатор класса объекта.
### Возвращаемое значение

Идентификатор класса, если объект существует; в противном случае — 0.
## void setMaterialNodeType ( int type )

Задаёт тип узла, используемый рендерером для определения того, какие материалы могут быть применены к объекту.
> **Notice:** Поскольку ObjectExtern является пользовательским объектом, определяемым пользователем, именно пользователь должен определить тип узла, чтобы рендерер корректно обрабатывал этот объект. Указание неподходящего типа узла может привести к сбоям системы.


### Аргументы

- *int* **type** - Идентификатор типа узла. Один из [node type identifiers](../../../api/library/nodes/class.node_cpp.md#DECAL_BEGIN).
