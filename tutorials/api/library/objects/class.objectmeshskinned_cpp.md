# ObjectMeshSkinned Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Этот класс представляет объект скининг-меша (skinned mesh), используемый для рендеринга персонажей со скелетной анимацией. В отличие от [ObjectMeshSkinnedLegacy](../../../api/library/objects/class.objectmeshskinnedlegacy_cpp.md), этот класс не управляет слоями анимации или их воспроизведением внутренне — анимация управляется извне через [AnimScript](../../../api/library/animations/skeletal/class.animscript_cpp.md) или [NodeSkeletonPose](../../../api/library/nodes/class.nodeskeletonpose_cpp.md), которые вычисляют позу скелета и применяют её к мешу.


ObjectMeshSkinned загружает геометрию из файлов *.mesh_skinned* и предоставляет доступ на чтение к данным меша (вершинам, нормалям, касательным, текстурным координатам, цветам и индексам), а также к их скининг-версиям (skinned) — позициям вершин и нормалям, пересчитанным после деформации скелета. Класс также предоставляет доступ к исходной иерархии суставов, встроенной в меш, что позволяет запрашивать имена суставов, отношения родитель-потомок и трансформации в различных пространствах координат (базовая поза, скининг, объект).


Поддерживаются морф-таргеты (target-поверхности) с возможностью включения/отключения и управления весом для каждого таргета отдельно. Доступен процедурный режим меша для замены геометрии во время выполнения через *[applyMeshProcedural()](../../...md#applyMeshProcedural_ConstMeshSkinned_int)*. Для отладки класс предоставляет методы *[renderBones()](../../...md#renderBones_Mat4_vec4_float_flag_void)*, *[renderJoints()](../../...md#renderJoints_Mat4_float_flag_void)* и *[renderJointNames()](../../...md#renderJointNames_Mat4_vec4_int_int_void)* для визуализации наложения скелета.

## void setMeshProceduralMode ( bool mode )

Задаёт новое значение, указывающее, включён ли для объекта режим использования процедурного меша. При включённом процедурном режиме геометрию ObjectMeshSkinned можно изменять через *[applyMeshProcedural()](../../...md#applyMeshProcedural_ConstMeshSkinned_int)*. Отключение процедурного режима восстанавливает исходную геометрию объекта, удаляя все применённые изменения.
### Аргументы

- *bool* **mode** - Установите **true**, чтобы включить режим использования процедурного меша; **false** — чтобы отключить.

## bool applyMeshProcedural ( const Ptr <ConstMeshSkinned> & mesh )

Заменяет текущую геометрию объекта предоставленным мешем и загружает его в VRAM. Может вызываться только если процедурный режим включён через *[setMeshProceduralMode()](../../...md#isMeshProceduralMode_int)*. Если исходный меш содержит совместимые элементы (например, суставы, поверхности, данные скининга), соответствующие оригиналу, то анимации, морф-таргеты и другое поведение продолжат работать. В противном случае меш останется статическим, без применения анимации или морфинга.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<ConstMeshSkinned> &* **mesh** - Исходный меш, который нужно применить.

### Возвращаемое значение

true, если меш успешно применён; иначе false.
