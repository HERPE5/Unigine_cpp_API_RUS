# ObjectBillboards Class (CPP)

**Header:** #include <UnigineObjects.h>

**Inherits from:** Object


Класс [Billboards](../../../objects/objects/billboards/index.md) используется для объединения биллбордов с одинаковым материалом в один объект. (При необходимости может применяться текстурный атлас.) Это позволяет оптимизировать производительность приложения при рендеринге большого количества биллбордов: поскольку количество выборок текстур уменьшается, а пространственное дерево становится менее загруженным, рендеринг ускоряется.

## void setAngle ( int num , float angle )

Обновляет угол заданного биллборда, который используется для задания его ориентации.
### Аргументы

- *int* **num** - Номер биллборда в диапазоне от 0 до общего количества биллбордов.
- *float* **angle** - Угол биллборда в градусах для задания его ориентации. Положительные значения поворачивают биллборд по часовой стрелке, отрицательные — против часовой стрелки.

## void setDepthSort ( int sort )

Задаёт значение, указывающее, должны ли биллборды сортироваться в порядке от дальних к ближним в соответствии с их позицией. Эту опцию следует включать, если для материала биллборда используется [alpha blending](../../../principles/render/blending/index.md) (за исключением аддитивного смешивания).
### Аргументы

- *int* **sort** - 1 для включения сортировки по глубине, 0 для отключения. Значение по умолчанию — 0.

## int getDepthSort ( ) const

Возвращает значение, указывающее, включена ли сортировка по глубине (в порядке от дальних к ближним) для биллбордов. Эту опцию следует включать, если для материала биллборда используется [alpha blending](../../../principles/render/blending/index.md) (за исключением аддитивного смешивания).
### Возвращаемое значение

**1**, если сортировка по глубине включена; в противном случае — **0**.

## void setTexCoord ( int num , const Math:: vec4 & texcoord )

Обновляет текстурные координаты заданного биллборда. Значение по умолчанию — vec4(1,1,0,0).
- Первая пара координат (x и x) задаёт масштаб текстуры по осям X и Y. Например, при масштабе 2 текстура повторяется дважды на биллборде.
- Вторая пара (z и w) задаёт смещение текстуры по осям X и Y. Например, при смещении 0.5 по оси X текстура смещается вправо (так что край текстуры отображается в центре).


### Аргументы

- *int* **num** - Номер биллборда в диапазоне от 0 до общего количества биллбордов.
- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md) &* **texcoord** - Текстурные координаты.

## Math:: vec4 getTexCoord ( int num ) const

### Аргументы

## int addBillboard ( float width , float height )

Добавляет биллборд с заданной шириной и высотой для управления объектом Billboards. Позиция, текстурные координаты и угол нового биллборда задаются по умолчанию:
- позиция задаётся как vec3(0,0,0)
- текстурные координаты задаются как vec4(1,1,0,0)
- угол задаётся равным 0.


### Аргументы

- *float* **width** - Ширина биллборда в единицах.
- *float* **height** - Высота биллборда в единицах.

### Возвращаемое значение

Номер добавленного биллборда.

## bool saveStateSelf ( const Ptr < Stream > & stream ) const

Сохраняет состояние объекта в указанный поток.
> **Notice:** Этот метод сохраняет все параметры объекта, включая список биллбордов. Чтобы сохранить только биллборды объекта, используйте [saveStateBillboards()](#saveStateBillboards_Stream_int).


Для сохранения в поток требуется создать blob для записи. Для восстановления сохранённого состояния используется метод [restoreStateSelf()](#restoreStateSelf_Stream_int):


```cpp
// инициализируем узел и задаём его состояние
//...//

// сохраняем состояние
BlobPtr blob_state = Blob::create();
billboards1->saveStateSelf(blob_state);

// изменяем состояние
//...//

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем каретку в начало blob'а
billboards1->restoreStateSelf(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель на поток.

### Возвращаемое значение

true в случае успеха; в противном случае — false.
