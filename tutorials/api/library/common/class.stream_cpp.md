# Unigine::Stream Class (CPP)

**Header:** #include <UnigineStreams.h>


Этот класс не может быть инстанцирован. Это базовый класс для:

- класса *[File](../../../api/library/filesystem/class.file_cpp.md)*
- класса *[Blob](../../../api/library/common/class.blob_cpp.md)*
- класса *[Socket](../../../api/library/networking/class.socket_cpp.md)*


Класс Stream позволяет записывать данные в поток, то есть в файлы (хранящиеся на диске), blob'ы (хранящиеся в системной памяти) и сокеты (для отправки по сети), а также читать данные из потока.


## Stream Class

### Перечисления

## TYPE

| Name | Description |
|---|---|
| **BLOB** = 0 | Поток для blob'ов. |
| **FILE** = 1 | Поток для файлов. |
| **SOCKET** = 2 | Поток для сокетов. |
| **SSL_SOCKET** = 3 | Поток для [SSL-сокетов](../../../api/library/networking/class.sslsocket_cpp.md). |
| **USER** = 4 | Пользовательский поток, унаследованный от StreamBase. |
| **NUM_STREAMS** = 5 | Количество типов потоков. |

### Методы класса

## void setByteOrder ( int order )

Задаёт новое значение, указывающее порядок байтов потока: значение **0** — для LSB (младший значащий), **1** — для MSB (старший значащий).
### Аргументы

- *int* **order** - Значение, указывающее порядок байтов потока: значение **0** — для LSB (младший значащий), **1** — для MSB (старший значащий).

## int getByteOrder () const

Возвращает текущее значение, указывающее порядок байтов потока: значение **0** — для LSB (младший значащий), **1** — для MSB (старший значащий).
### Возвращаемое значение

Текущее значение, указывающее порядок байтов потока: значение **0** — для LSB (младший значащий), **1** — для MSB (старший значащий).
## bool isAvailable () const

Возвращает текущее значение, указывающее, доступны ли данные потока.
### Возвращаемое значение

**true**, если данные потока доступны; иначе **false**.
## bool isOpened () const

Возвращает текущее значение, указывающее, открыт ли поток.
### Возвращаемое значение

**true**, если поток открыт; иначе **false**.

## String readToken ( )

Читает токен из потока. Токен — это одно слово, отделённое пробелом, или строка в кавычках, например, "word" или "many words". Токен читается начиная с текущей позиции до пробела или перевода строки ("\n"), либо, если первый символ — двойная кавычка ("), до второй двойной кавычки (возвращённый токен не будет содержать кавычек). Максимальная длина строки — 4096 байт.
### Возвращаемое значение

Полученный токен.
