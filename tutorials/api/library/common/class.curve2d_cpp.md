# Curve2d Class (CPP)

**Header:** #include <UnigineCurve2d.h>


Этот класс представляет собой интерфейс, позволяющий [create and manage 2D curves](../../../editor2/curve_editor/index.md). Эти кривые используются, например, для управления поведением различных параметров систем частиц (как они изменяются со временем).


## Curve2d Class

### Перечисления

## REPEAT_MODE

Режим, используемый для повторения последовательности, определяемой ключевыми точками кривой (тайлинг кривых).
| Name | Description |
|---|---|
| **REPEAT_MODE_CLAMP** = 0 | Сохраняется значение начального или конечного ключа. Используйте этот вариант, если не хотите никаких изменений до или после эффекта, создаваемого кривой. |
| **REPEAT_MODE_LOOP** = 1 | Кривая замощается плиткой. Созданный эффект повторяется циклически. Если значения первого и последнего ключа различаются, переход между кривыми будет резким. |
| **REPEAT_MODE_PING_PONG** = 2 | Каждый следующий сегмент кривой является отражением предыдущего сегмента кривой. Созданный эффект повторяется в прямом и обратном направлении. |
| **NUM_REPEAT_MODES** = 3 | Количество режимов повторения. |

## Event<> getEventChanged () const

Событие, вызываемое при изменении кривой. Вы можете подписываться на события через *connect()* и отписываться через *disconnect()*. Также для удобства можно использовать классы *[EventConnection](../../../api/library/common/events/class.eventconnection_cpp.md)* и *[EventConnections](../../../api/library/common/events/class.eventconnections_cpp.md)* (см. примеры ниже).

> **Notice:** Подробнее см. статью [Event Handling](../../../code/fundamentals/events/index_cpp.md).

 Сигнатура обработчика события выглядит следующим образом: *myhandler()*

<summary>Показать пример | Скрыть</summary>

**Пример использования**

```cpp
// реализация обработчика события Changed
void changed_event_handler()
{
	Log::message("\Обработка события Changed\n");
}

//////////////////////////////////////////////////////////////////////////////
//  1. Несколько подписок можно связать с экземпляром класса EventConnections,
//  который затем можно использовать для отмены всех этих подписок сразу
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnections
EventConnections changed_event_connections;

// связываем с этим экземпляром при подписке на событие (можно связывать подписки на разные события)
publisher->getEventChanged().connect(changed_event_connections, changed_event_handler);

// другие подписки также связаны с этим экземпляром EventConnections
// (например, можно подписываться с помощью лямбда-функций)
publisher->getEventChanged().connect(changed_event_connections, []() {
		Log::message("\Обработка события Changed (лямбда).\n");
	}
);

// ...

// позже все эти связанные подписки можно удалить одной строкой
changed_event_connections.disconnectAll();

//////////////////////////////////////////////////////////////////////////////
//  2. Можно подписываться и отписываться через экземпляр класса EventConnection.
//  А также включать и отключать это конкретное соединение при необходимости.
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnection
EventConnection changed_event_connection;

// подписываемся на событие Changed с функцией-обработчиком, сохраняя соединение
publisher->getEventChanged().connect(changed_event_connection, changed_event_handler);

// ...

// можно временно отключить конкретное соединение события для выполнения определённых действий
changed_event_connection.setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
changed_event_connection.setEnabled(true);

// ...

// удаляем подписку на событие Changed через соединение
changed_event_connection.disconnect();

//////////////////////////////////////////////////////////////////////////////
//  3. Можно добавить экземпляр EventConnection/EventConnections как член класса,
//  обрабатывающего событие. В этом случае все связанные подписки будут
//  автоматически удалены при вызове деструктора класса
//////////////////////////////////////////////////////////////////////////////

// Класс, обрабатывающий событие
class SomeClass
{
public:
	// экземпляр класса EventConnections как член класса
	EventConnections e_connections;

	// Обработчик события Changed, реализованный как член класса
	void event_handler()
	{
		Log::message("\Обработка события Changed\n");
		// ...
	}
};

SomeClass *sc = new SomeClass();

// ...

// указываем экземпляр класса, если метод-обработчик принадлежит какому-либо классу
publisher->getEventChanged().connect(sc->e_connections, sc, &SomeClass::event_handler);

// ...

// экземпляр класса-обработчика удаляется, а все его подписки автоматически отменяются
delete sc;

//////////////////////////////////////////////////////////////////////////////
//   4. Подписка на событие с сохранением идентификатора соединения
//   и последующей отпиской по этому идентификатору
//////////////////////////////////////////////////////////////////////////////
// экземпляр класса EventConnections для управления соединениями событий
EventConnections e_connections;

// определяем идентификатор соединения, который будет использован для отписки позже
EventConnectionId changed_handler_id;

// подписываемся на событие Changed с лямбда-обработчиком, сохраняя идентификатор соединения
changed_handler_id = publisher->getEventChanged().connect(e_connections, []() {
		Log::message("\Обработка события Changed (лямбда).\n");
	}
);

// удаляем подписку позже, используя идентификатор
publisher->getEventChanged().disconnect(changed_handler_id);

//////////////////////////////////////////////////////////////////////////////
//   5. Игнорирование всех событий Changed при необходимости
//////////////////////////////////////////////////////////////////////////////

// можно временно отключить событие для выполнения определённых действий без его срабатывания
publisher->getEventChanged().setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
publisher->getEventChanged().setEnabled(true);

```

## int moveKey ( int index , const Math:: vec2 & point )

Перемещает ключевую точку с указанным номером в новую позицию (с сохранением касательных). По завершении этой операции вызывается событие [*CHANGED*](#getEventChanged_Event). Индекс ключевой точки будет обновлён автоматически. Этот метод можно использовать для реализации перетаскивания ключей на кривой. В случае перемещения нескольких ключей рекомендуется использовать метод [*setKeyPoint()*](#setKeyPoint_int_vec2_void) для установки новых значений ключей, а затем отсортировать их все сразу с помощью метода [*sortKeys()*](#sortKeys_void) для экономии производительности.
### Аргументы

- *int* **index** - Номер ключевой точки, в диапазоне от 0 до [total number of key points](#getNumKeys_int) в кривой.
- *const  Math::[vec2](../../../api/library/math/class.vec2_cpp.md) &* **point** - Новые координаты ключевой точки.

### Возвращаемое значение

Новый индекс ключа.

## void setKeyPoint ( int index , const Math:: vec2 & point )

Этот метод, в отличие от [*moveKey()*](#moveKey_int_vec2_int), не обновляет индекс ключевой точки автоматически. Его можно использовать для реализации перетаскивания нескольких ключей с установкой новых значений для них с последующей сортировкой всех ключей сразу с помощью метода [*sortKeys()*](#sortKeys_void) для экономии производительности.
### Аргументы

- *int* **index** - Номер ключевой точки, в диапазоне от 0 до [total number of key points](#getNumKeys_int) в кривой.
- *const  Math::[vec2](../../../api/library/math/class.vec2_cpp.md) &* **point** - Новые координаты для установки указанной точки.

## int saveState ( const Ptr < Stream > & stream ) const

Сохраняет данные кривой в бинарный поток.
**Пример** использования методов saveState() и [restoreState()](#restoreState_Stream_int):


```cpp
// инициализируем узел и задаём его состояние
Curve2dPtr curve = Curve2d::create();
curve->addKey(vec2(1, 0));
curve->addKey(vec2(2, 1));
curve->addKey(vec2(4, 3));

// сохраняем состояние
BlobPtr blob_state = Blob::create();
curve->saveState(blob_state);

// изменяем состояние
curve->removeKey(1);

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем каретку в начало blob
curve->restoreState(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Поток, в который будут сохранены данные кривой.

### Возвращаемое значение

true, если данные кривой успешно сохранены; иначе false.

Возвращает вычисленное значение кривой в указанной точке времени.
### Аргументы

- *float* **time** - Время внутри кривой, которое вы хотите вычислить (горизонтальная ось на графике кривой).

### Возвращаемое значение

Значение кривой в указанной точке времени.
