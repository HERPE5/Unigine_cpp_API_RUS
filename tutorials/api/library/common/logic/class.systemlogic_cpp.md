# Unigine::SystemLogic Class (CPP)

**Header:** #include <UnigineLogic.h>


Класс SystemLogic используется для управления логикой приложения. Методы этого класса вызываются после соответствующих методов системного скрипта.


## SystemLogic Class

### Методы класса

---

## virtual int init ( )

Движок вызывает эту функцию при инициализации движка. Аналогична функции *init()* системного скрипта.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int shutdown ( )

Движок вызывает эту функцию при завершении работы движка. Аналогична функции *shutdown()* системного скрипта.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int update ( )

Движок вызывает эту функцию перед обновлением каждого кадра рендеринга. Аналогична функции *update()* системного скрипта.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int postUpdate ( )

Движок вызывает эту функцию перед рендерингом каждого кадра рендеринга. Аналогична функции *postUpdate()* системного скрипта.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
