# Unigine::WorldLogic Class (CPP)

**Header:** #include <UnigineLogic.h>


Класс WorldLogic используется для управления логикой мира. Методы этого класса вызываются после соответствующих методов скрипта мира **только если мир загружен**.


> **Notice:** Экземпляры класса WorldLogic не следует добавлять или удалять через соответствующие методы класса Engine (*[addWorldLogic()](../../../../api/library/engine/class.engine_cpp.md#addWorldLogic_WorldLogic_ptr_bool) / [removeWorldLogic()](../../../../api/library/engine/class.engine_cpp.md#removeWorldLogic_WorldLogic_ptr_bool)*), пока мир загружен и выполняется скрипт мира (так как нельзя изменить скрипт мира, пока мир загружен). В таком случае **нет гарантии, что методы *init() / shutdown()* будут вызваны**:
> - метод ***init()*** не будет вызван, если WorldLogic добавлен после открытия мира;
> - метод ***shutdown()*** не будет вызван, если WorldLogic удалён до закрытия мира.

## WorldLogic Class

### Методы класса

---

## virtual int init ( )

 Движок вызывает эту функцию при инициализации мира и инициализирует ресурсы для сцены мира во время запуска мира.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int shutdown ( )

Движок вызывает эту функцию при завершении работы мира. Здесь можно удалить ресурсы, созданные во время выполнения скрипта мира, чтобы избежать утечек памяти.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int update ( )

Движок вызывает эту функцию перед обновлением каждого кадра рендеринга. Здесь можно указать все функции, связанные с логикой, которые должны вызываться каждый кадр во время выполнения приложения.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual void updateSyncThread ( int id , int size )

Движок вызывает эту функцию перед [*update()*](#update_int) и [*postUpdate()*](#postUpdate_int).
 Ограничения: не следует создавать или изменять узлы, если вы не абсолютно уверены, что ни один другой поток не делает то же самое. Эта функция вызывается **size** раз каждый кадр и выполняется в параллельных потоках. Каждый раз функция вызывается с индексом в диапазоне [0; size), т. е.: 0, 1, ..., size-1. Эта функция **блокирует главный поток**, пока не будут завершены все **size** вызовов.
 В отличие от [*SyncThread()*](#updateAsyncThread_int_int_void), эта функция имеет меньше времени на выполнение, но она более безопасна и подходит для сложных вычислений, применяемых к текущему узлу.
### Аргументы

- *int* **id** - Индекс текущего потока, вызвавшего эту функцию, в диапазоне [0; size).
- *int* **size** - Количество потоков для выполнения. Функция вызывается **size** раз каждый кадр и выполняется в параллельных потоках. Каждый раз функция вызывается с индексом в диапазоне [0; size), т. е.: 0, 1, ..., size-1.

## virtual void updateAsyncThread ( int id , int size )

 Движок вызывает эту функцию перед выполнением всех функций [*updateSyncThread()*](#updateSyncThread_int_int_void). Как и *updateSyncThread()*, она вызывается **size** раз каждый кадр и выполняется параллельно с пользовательскими функциями [*postUpdate()*](#postUpdate_int) и [*updatePhysics()*](#updatePhysics_int), но **не блокирует главный поток** до тех пор, пока движок не достигнет стадии *doSwap()* (аналогично функции [*updatePhysics()*](#updatePhysics_int)).
 Эта функция наиболее плавная и не вызывает всплесков, у неё много времени на выполнение. Но у неё также много ограничений.
 Она подходит для определённых ресурсоёмких вычислений, которые должны выполняться каждый кадр, таких как поиск пути, генерация процедурных текстур и т. д.
### Аргументы

- *int* **id** - Индекс текущего потока, вызвавшего эту функцию, в диапазоне [0; size).
- *int* **size** - Количество потоков для выполнения. Функция вызывается **size** раз каждый кадр и выполняется в параллельных потоках. Каждый раз функция вызывается с индексом в диапазоне [0; size), т. е.: 0, 1, ..., size-1.

## virtual int postUpdate ( )

Движок вызывает эту функцию перед рендерингом каждого кадра рендеринга. Здесь можно скорректировать поведение после обновления состояния узла. Аналогична функции [*postUpdate()*](../../../../code/fundamentals/execution_sequence/code_update.md#code_postUpdate) скрипта мира.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int updatePhysics ( )

Движок вызывает эту функцию перед обновлением каждого кадра физики. Эта функция используется для управления физикой в вашем приложении. Движок вызывает *updatePhysics()* с фиксированной частотой (по умолчанию 60 раз в секунду) независимо от количества кадров в секунду. Аналогична функции [*updatePhysics()*](../../../../code/fundamentals/execution_sequence/code_update.md#code_updatePhysics) скрипта мира.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
## virtual int swap ( )

Движок вызывает эту функцию после завершения следующих процессов: рендеринг (часть, выполняемая на CPU), вычисления физики и поиск пути, рендеринг GUI и все асинхронные потоки. Функция предназначена для работы с результатами метода updateAsyncThread() — все остальные методы (потоки) уже выполнены и простаивают. После этой функции происходят только два действия:
- Удаляются все объекты, поставленные в очередь на удаление.
- Обновляется профилировщик.

 Эта функция аналогична функции [*swap()*](../../../../code/fundamentals/execution_sequence/code_update.md#code_swap) скрипта мира.
### Возвращаемое значение

Возвращает **1**, если не было ошибок; иначе **0**.
