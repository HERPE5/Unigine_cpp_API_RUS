# Unigine::String class (CPP)

**Header:** #include <UnigineString.h>


Предоставляет интерфейс для работы с входными и выходными данными, упакованными во внутренний (не стандартный C++) класс *String*. Строки хранятся в куче, поэтому они медленнее, чем строки *[StringStack](../../../api/library/common/class.stringstack_cpp.md)*.


Такие строки обычно используются в следующих случаях:


- Когда создаётся строка для передачи в контейнер. ```cpp #include <UnigineString.h> #include <UnigineVector.h> using namespace Unigine; String AppWorldLogic::get_title() { String s = WindowManager::getMainWindow()->getTitle(); s += " Window"; return s; } int AppWorldLogic::init() { Vector<String> v; // создаём строку String s = "Modifier "; s += get_title(); // добавляем её в вектор v.append(std::move(s)); // делаем что-то с вектором // ... return 1; } ```
- Когда создаётся строка, используемая как возвращаемое значение функции. ```cpp String AppWorldLogic::get_title() { String s = WindowManager::getMainWindow()->getTitle(); s += " Window"; return s; } ```
- Когда сохраняется строка, представляющая возвращаемое значение функции, и её не планируется изменять. ```cpp void AppWorldLogic::log_file_guid(const UGUID &guid) { // строка, хранящая возвращаемое значение внешней функции const String str = FileSystem::getAbsolutePath(guid); Log::message("Path: %s\n", str.get()); } ``` > **Notice:** Обращайте внимание на тип возвращаемого значения функции для его оптимального использования. Это может помочь избежать обращения к очищенной памяти или других проблем. ```cpp // Строка, возвращаемая этой функцией, будет автоматически удалена const char *s = FileSystem::getAbsolutePath(guid); // и указатель s теперь будет указывать на освобождённую память Log::message("Path: %s\n", s); 		// приложение может аварийно завершиться ```
- Когда сохраняются большие тексты (например, прочитанные из файла).


Строки поддерживают *Small String Optimization (SSO)*: можно хранить *7* символов вместе с символом *завершения строки*. Это означает, что следующий код не вызовет динамического выделения памяти:


```cpp
String s = “1234567”;

```

## static StringStack <> dtoa ( double value , int precision , int use_inf )

Преобразует значение double в строку с указанной точностью.
### Аргументы

- *double* **value** - Входное значение.
- *int* **precision** - Точность в диапазоне **[-1; 17]**. Данные представляются следующим образом: | Precision | Representation | Example | |---|---|---| | -1 | Кратчайшее представление: десятичная плавающая точка или научная нотация (мантисса/экспонента). | 2.6265e+2 | | 0-8 | Десятичная плавающая точка. | 262.65 | | 9-17 | Кратчайшее представление: десятичная плавающая точка или научная нотация (мантисса/экспонента) с выводом *precision* цифр после десятичной точки. | 2.6264999e+2 |
- *int* **use_inf** - Флаг, указывающий, следует ли использовать значения -inf и inf, если входное значение выходит за диапазон **(-1e9; 1e9)**.

### Возвращаемое значение

Строковое представление значения *value*.

## static StringStack <> format ( const char * format , va_list argptr )

Возвращает стек форматированных строк. Строка формата состоит из нуля или более обычных символов (кроме %), которые копируются непосредственно в результирующую строку, и управляющих последовательностей, каждая из которых приводит к получению своего собственного параметра. Каждая управляющая последовательность состоит из знака процента (%), за которым по порядку следует один или несколько из этих элементов:
- Необязательное число, спецификатор ширины, указывающее, сколько символов (минимум) должно получиться в результате этого преобразования.
- Необязательный спецификатор точности, указывающий, сколько десятичных цифр должно отображаться для чисел с плавающей точкой.
- Спецификатор типа, указывающий, каким типом следует считать данные аргумента. Возможные типы:

  - **c**: аргумент рассматривается как целое число и представляется как символ с этим ASCII-значением.
  - **d** или **i**: аргумент рассматривается как целое число и представляется как (знаковое) десятичное число.
  - **o**: аргумент рассматривается как целое число и представляется как восьмеричное число.
  - **u**: аргумент рассматривается как целое число и представляется как беззнаковое десятичное число.
  - **x**: аргумент рассматривается как целое число и представляется как шестнадцатеричное число (строчными буквами).
  - **X**: аргумент рассматривается как целое число и представляется как шестнадцатеричное число (прописными буквами).
  - **f**: аргумент рассматривается как float и представляется как число с плавающей точкой.
  - **g**: то же, что e или f, выбирается более короткий вариант.
  - **G**: то же, что E или F, выбирается более короткий вариант.
  - **e**: аргумент представляется в научной нотации со строчной 'e' (например, 1.2e+2).
  - **E**: аргумент представляется в научной нотации с прописной 'E' (например, 1.2E+2).
  - **s**: аргумент рассматривается и представляется как строка.
  - **p**: аргумент рассматривается и представляется как адрес указателя.
  - **%**: буквальный символ процента. Аргумент не требуется.


### Аргументы

- *const char ** **format** - Строка формата.
- *va_list* **argptr** - Указатель на аргументы.

### Возвращаемое значение

[Stack](../../../api/library/common/class.stringstack_cpp.md) форматированных строк.

### Аргументы

- *const char ** **format** - Строка формата.
- *va_list* **argptr** - Указатель на аргументы.

## int vscanf ( const char * format , va_list argptr )

Сканирует форматированную строку.
### Аргументы

- *const char ** **format** - Строка формата.
- *va_list* **argptr** - Указатель на аргументы.

### Возвращаемое значение

Количество успешно прочитанных аргументов, или EOF, если произошёл сбой.
