# Unigine::Resource Class (CPP)

**Header:** #include <UnigineResource.h>


Класс Resource Unigine.


Этот класс позволяет загружать и сохранять данные в бинарный файл. В этом случае ресурс будет находиться внутри бинарного файла и, следовательно, не зависеть от платформы. В ресурсы можно сохранять изображения, шейдеры или другое содержимое, которое будет упаковано.


## Resource Class

### Методы класса

---

## unsigned char * load ( const char *[] data )

Загружает ресурс из ascii-строки (base64).
### Аргументы

- *const char *[]* **data** - Закодированная ascii-строка ресурса.

### Возвращаемое значение

Указатель на декодированные данные (с завершающим нулём).
## unsigned char * load ( const char *[] data , int & size )

Загружает ресурс из ascii-строки.
### Аргументы

- *const char *[]* **data** - Закодированная ascii-строка (base64) ресурса.
- *int &* **size** - Размер декодированных данных.

### Возвращаемое значение

Указатель на декодированные данные (с завершающим нулём).
## const char * save ( const char * name , const unsigned char * data , int size )

Сохраняет данные в ascii-строку (base64).
### Аргументы

- *const char ** **name** - Имя ресурса.
- *const unsigned char ** **data** - Данные ресурса.
- *int* **size** - Размер ресурса.

### Возвращаемое значение

Закодированная ascii-строка (base64) ресурса.
