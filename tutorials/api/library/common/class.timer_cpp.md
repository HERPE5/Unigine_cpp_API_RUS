# Unigine::Timer Struct (CPP)

**Header:** #include <UnigineTimer.h>


Эта структура реализует функциональность таймера.


## Timer Class

### Методы класса

---

## void begin ( )

Запускает таймер.
## long long end ( )

Возвращает прошедшее время в микросекундах и останавливает таймер.
### Возвращаемое значение

Прошедшее время в микросекундах.
## double endSeconds ( )

Возвращает прошедшее время в секундах и останавливает таймер.
### Возвращаемое значение

Прошедшее время в секундах.
## double endMilliseconds ( )

Возвращает прошедшее время в миллисекундах и останавливает таймер.
### Возвращаемое значение

Прошедшее время в миллисекундах.
## long long getBeginTime ( )

Возвращает время, когда таймер был запущен.
### Возвращаемое значение

Время начала.
