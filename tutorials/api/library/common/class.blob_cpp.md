# Unigine::Blob Class (CPP)

**Header:** #include <UnigineStreams.h>

**Inherits from:** Stream


Этот класс используется для хранения данных в памяти (в отличие от *[File](../../../api/library/filesystem/class.file_cpp.md)*, который хранится на диске). Blob использует либо аллокатор Unigine (если задан `#define USE_MEMORY`, по умолчанию), либо системный аллокатор.


### Пример


Код ниже иллюстрирует следующий процесс:

- Упаковку данных в blob и сохранение сжатых данных в [file](../../../api/library/filesystem/class.file_cpp.md)
- Чтение и распаковку данных из файла в целевой blob
- Чтение данных из целевого blob


```cpp
// создаём исходный blob для хранения данных
BlobPtr blob1 = Blob::create();

// создаём файл для сохранения данных нашего blob
FilePtr file = File::create("test.dat", "w+");

// очищаем blob
blob1->clear();

// записываем данные в blob (префикс, вектор и постфикс)
blob1->writeChar('B');
blob1->writeVec3(Math::vec3(0.1f, 0.2f, 0.3f));
blob1->writeChar('E');

// сжимаем данные blob с низким уровнем сжатия и сохраняем их в файл
blob1->compress(file, 0);

// закрываем файл
file->close();

// очищаем blob
blob1.clear();

// открываем файл данных для чтения
file->open("test.dat", "r");

// создаём второй blob
BlobPtr blob2 = Blob::create();

// читаем и распаковываем данные из файла
blob2->decompress(file);

// закрываем файл
file->close();

// устанавливаем текущую позицию в начало blob
blob2->seekSet(0);

// читаем данные из blob (префикс, вектор и постфикс)
char pref = blob2->readChar();
Math::vec3 v = blob2->readVec3();
char postf = blob2->readChar();

// выводим декодированные данные blob и контрольную сумму SHA1
Log::message("\nDESTINATION: [%c] vec(%f, %f, %f) [%c] - SHA1 checksum (%s)", pref, v.x, v.y, v.z, postf, blob2->getSHA1().get());

// очищаем blob
blob2.clear();


```


## Blob Class

### Методы класса

---

## static BlobPtr create ( size_t size = 0 )

Конструктор. Создаёт новый blob указанного размера.
### Аргументы

- *size_t* **size** - Размер blob.

## void set ( size_t offset , unsigned char value )

Устанавливает значение указанного байта в blob.
### Аргументы

- *size_t* **offset** - Смещение в blob.
- *unsigned char* **value** - Значение байта.

## unsigned char get ( size_t offset )

Возвращает значение указанного байта в blob.
### Аргументы

- *size_t* **offset** - Смещение в байтах.

### Возвращаемое значение

Значение байта.
## int getc ( )

Получает следующий символ из blob.
### Возвращаемое значение

Символ, прочитанный из blob.
## String getCRC32 ( )

Возвращает 32-битную контрольную сумму CRC.
### Возвращаемое значение

32-битная контрольная сумма CRC.
## void setData ( unsigned char * OUT_data , size_t size )

Устанавливает новые данные для экземпляра Blob.
> **Внимание:** Управление ранее сохранёнными данными вы должны выполнять самостоятельно.


### Аргументы

- *unsigned char ** **OUT_data** - Данные, устанавливаемые для экземпляра Blob. > **Внимание:** Этот выходной буфер должен быть заполнен движком в результате выполнения метода.
- *size_t* **size** - Размер blob.

## unsigned char * getData ( )

Возвращает текущие данные blob.
### Возвращаемое значение

Данные blob.
## String getMD5 ( )

Возвращает 128-битную контрольную сумму MD5.
### Возвращаемое значение

128-битная контрольная сумма MD5.
## String getSHA1 ( )

Возвращает 160-битную контрольную сумму SHA1.
### Возвращаемое значение

160-битная контрольная сумма SHA1.
## String getSHA256 ( )

Возвращает 256-битную контрольную сумму SHA256.
### Возвращаемое значение

256-битная контрольная сумма SHA256.
## size_t getSize ( )

Возвращает текущий размер blob.
### Возвращаемое значение

Размер blob.
## void allocate ( size_t size )

Выделяет требуемый объём памяти без изменения размера blob.
> **Внимание:** Blob будет динамически изменять размер по мере заполнения выделенной памяти.


### Аргументы

- *size_t* **size** - Размер выделяемой памяти в байтах.

## void clear ( )

Обнуляет размер blob.
## int compress ( const Ptr < Stream > & dest , int quality )

Сжимает blob и записывает его в указанный поток.
> **Внимание:** Этот метод использует сжатие zlib, которое лучше, чем Lz4 (см. метод [compressLz4()](#compressLz4_Stream_int_int)), но значительно медленнее.


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **dest** - Целевой поток.
- *int* **quality** - Качество сжатия (0 — быстрое сжатие, 1 — минимальный размер).

### Возвращаемое значение

**1**, если данные успешно сжаты; иначе 0.
## int compressLz4 ( const Ptr < Stream > & dest , int quality )

Сжимает blob алгоритмом Lz4 и записывает его в указанный поток.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **dest** - Целевой поток.
- *int* **quality** - Качество сжатия (0 — быстрое сжатие, 1 — минимальный размер).

### Возвращаемое значение

**1**, если данные успешно сжаты; иначе **0**.
## int decode ( const char * src )

Декодирует строку в кодировке base64 в blob.
### Аргументы

- *const char ** **src** - Исходная строка в кодировке base64.

### Возвращаемое значение

Возвращает **1**, если данные успешно декодированы; иначе **0**.
## int decodeZBase32 ( const char * src )

Декодирует строку в кодировке Zbase32 в blob.
### Аргументы

- *const char ** **src** - Исходная строка в кодировке Zbase32.

### Возвращаемое значение

Возвращает **1**, если данные успешно декодированы; иначе **0**.
## int decompress ( const Ptr < Stream > & src )

Читает сжатый blob из потока и распаковывает его.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **src** - Исходный поток для чтения данных.

### Возвращаемое значение

**1**, если blob успешно распакован; иначе **0**.
## int decompressLz4 ( const Ptr < Stream > & src )

Читает и распаковывает ранее [compressed](#compressLz4_Stream_int_int) алгоритмом Lz4 blob из указанного потока.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **src** - Исходный поток для чтения данных.

### Возвращаемое значение

**1**, если blob успешно распакован; иначе **0**.
## String encode ( )

Кодирует blob в строку в кодировке base64.
### Возвращаемое значение

Строка в кодировке base64.
## String encodeZBase32 ( )

Кодирует blob в строку в кодировке ZBase32.
### Возвращаемое значение

Строка в кодировке ZBase32.
## int eof ( )

Проверяет, достигнут ли конец blob.
### Возвращаемое значение

Возвращает **1**, если конец blob достигнут; иначе 0.
## int flush ( )

Сбрасывает blob.
### Возвращаемое значение

Возвращает **1**, если blob успешно сброшен; иначе 0.
## void reserve ( size_t size )

Резервирует память для blob, т.е. выделяет (size * 1.5) байт без изменения размера blob. Размер будет динамически изменяться по мере заполнения выделенной памяти.
### Аргументы

- *size_t* **size** - Размер выделяемой памяти.

## void resize ( size_t size )

Выделяет требуемый объём памяти и изменяет размер blob.
### Аргументы

- *size_t* **size** - Размер blob в байтах.

## int seekCur ( size_t offset )

Устанавливает позицию относительно текущего смещения.
### Аргументы

- *size_t* **offset** - Смещение в байтах от текущей позиции указателя.

### Возвращаемое значение

Возвращает **1**, если позиция blob успешно установлена; иначе 0.
## int seekEnd ( size_t offset )

Устанавливает позицию относительно конца blob.
### Аргументы

- *size_t* **offset** - Смещение в байтах от конца blob.

### Возвращаемое значение

Возвращает **1**, если позиция blob успешно установлена; иначе 0.
## int seekSet ( size_t offset )

Устанавливает позицию относительно начала blob.
### Аргументы

- *size_t* **offset** - Смещение в байтах от начала blob.

### Возвращаемое значение

Возвращает **1**, если позиция blob успешно установлена; иначе 0.
## size_t tell ( )

Получает текущую позицию указателя смещения blob.
### Возвращаемое значение

Возвращает текущее смещение blob.
