# CallbackBase2 Class (CPP)

**Header:** #include <UnigineCallback.h>


Базовый класс для callback'ов движка.


Этот класс позволяет создавать собственные callback'и с одним или двумя аргументами.


## CallbackBase2 Class

### Методы класса

---

## void run ( A0 a0 )

Выполняет функцию обратного вызова с одним аргументом.
### Аргументы

- *A0* **a0** - Аргумент функции обратного вызова.

## void run ( A0 a0 , A1 a1 )

Выполняет функцию обратного вызова с двумя аргументами.
### Аргументы

- *A0* **a0** - Первый аргумент функции обратного вызова.
- *A1* **a1** - Второй аргумент функции обратного вызова.
