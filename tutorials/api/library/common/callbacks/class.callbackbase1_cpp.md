# CallbackBase1 Class (CPP)

**Header:** #include <UnigineCallback.h>


Базовый класс для callback'ов движка.


Этот класс позволяет создавать собственные callback'и с нулевым или одним аргументом.


## CallbackBase1 Class

### Методы класса

---

## void run ( )

Выполняет функцию обратного вызова без аргументов.
## void run ( A0 a0 )

Выполняет функцию обратного вызова с одним аргументом
### Аргументы

- *A0* **a0** - Аргумент функции обратного вызова.
