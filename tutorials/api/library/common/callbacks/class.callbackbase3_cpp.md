# CallbackBase3 Class (CPP)

**Header:** #include <UnigineCallback.h>


Базовый класс для callback'ов движка.


Этот класс позволяет создавать собственные callback'и с двумя или тремя аргументами.


## CallbackBase3 Class

### Методы класса

---

## void run ( A0 a0 , A1 a1 )

Выполняет функцию обратного вызова с двумя аргументами.
### Аргументы

- *A0* **a0** - Первый аргумент функции обратного вызова.
- *A1* **a1** - Второй аргумент функции обратного вызова.

## void run ( A0 a0 , A1 a1 , A2 a2 )

Выполняет функцию обратного вызова с тремя аргументами.
### Аргументы

- *A0* **a0** - Первый аргумент функции обратного вызова.
- *A1* **a1** - Второй аргумент функции обратного вызова.
- *A2* **a2** - Третий аргумент функции обратного вызова.
