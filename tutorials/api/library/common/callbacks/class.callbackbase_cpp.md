# CallbackBase Class (CPP)

**Header:** #include <UnigineCallback.h>


Базовый класс для callback'ов движка.


Этот класс позволяет создавать собственные callback'и с количеством аргументов до 5.


### Пример использования


Этот раздел содержит простой пример использования CallbackBase.


В файле заголовка:


```cpp
#include <UnigineLogic.h>
#include <UnigineStreams.h>
#include <UnigineCallback.h>

class AppWorldLogic : public Unigine::WorldLogic {

public:
	/* other methods */

	// function
	void setNewCallback(Unigine::CallbackBase *cb);

private:
	// Callback function
	Unigine::CallbackBase *callback_func;
};

```


Файл реализации выглядит так:


```cpp
#include "AppWorldLogic.h"
#include "UnigineCallback.h"

using namespace Unigine;
CallbackBase *func;

/* other methods */

void AppWorldLogic::setNewCallback(CallbackBase *func) {
	callback_func = func;
}

```

## void run ( A0 a0 , A1 a1 )

Выполняет функцию обратного вызова с двумя аргументами.
### Аргументы

- *A0* **a0** - Первый аргумент функции обратного вызова.
- *A1* **a1** - Второй аргумент функции обратного вызова.
