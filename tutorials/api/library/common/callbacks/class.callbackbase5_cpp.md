# CallbackBase5 Class (CPP)

**Header:** #include <UnigineCallback.h>


Базовый класс для callback'ов движка.


Этот класс позволяет создавать собственные callback'и с четырьмя или пятью аргументами.


## CallbackBase5 Class

### Методы класса

---

## void run ( A0 a0 , A1 a1 , A2 a2 , A3 a3 )

Выполняет функцию обратного вызова с четырьмя аргументами.
### Аргументы

- *A0* **a0** - Первый аргумент функции обратного вызова.
- *A1* **a1** - Второй аргумент функции обратного вызова.
- *A2* **a2** - Третий аргумент функции обратного вызова.
- *A3* **a3** - Четвёртый аргумент функции обратного вызова.

## void run ( A0 a0 , A1 a1 , A2 a2 , A3 a3 , A4 a4 )

Выполняет функцию обратного вызова с пятью аргументами.
### Аргументы

- *A0* **a0** - Первый аргумент функции обратного вызова.
- *A1* **a1** - Второй аргумент функции обратного вызова.
- *A2* **a2** - Третий аргумент функции обратного вызова.
- *A3* **a3** - Четвёртый аргумент функции обратного вызова.
- *A4* **a4** - Пятый аргумент функции обратного вызова.
