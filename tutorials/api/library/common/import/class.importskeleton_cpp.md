# Unigine::ImportSkeleton Class (CPP)

**Header:** #include <UnigineImport.h>


Этот класс является промежуточным представлением скелета из исходного файла. Он хранит иерархию суставов в виде списка элементов [ImportNode](../../../../api/library/common/import/class.importnode_cpp.md), где каждый узел определяет имя сустава, отношение родитель-потомок и трансформацию bind pose. Во время импорта он преобразуется в ассет Skeleton (файл .skeleton).

### Возвращаемое значение

## static ImportSkeletonPtr create ( )

Конструктор. Создаёт пустой экземпляр *ImportSkeleton*.
## int getNumJointNodes ( ) const

Возвращает количество узлов суставов в скелете.
### Возвращаемое значение

Количество узлов суставов в скелете.
## Ptr < ImportNode > addJointNode ( )

Добавляет новый узел сустава в скелет и возвращает соответствующий экземпляр [ImportNode](../../../../api/library/common/import/class.importnode_cpp.md).
### Возвращаемое значение

Новый узел сустава, добавленный в скелет.
## Ptr < ImportNode > getJointNode ( int index ) const

Возвращает узел сустава с указанным индексом.
### Аргументы

- *int* **index** - Индекс узла сустава.

### Возвращаемое значение

Узел сустава с указанным индексом.
## int getJointNodeIndex ( const Ptr < ImportNode > & node ) const

Возвращает индекс указанного узла сустава в скелете.
### Аргументы

- *const [Ptr](../../../../api/library/common/class.ptr_cpp.md)<[ImportNode](../../../../api/library/common/import/class.importnode_cpp.md)> &* **node** - Искомый узел сустава.

### Возвращаемое значение

Индекс указанного узла сустава или -1, если он не найден.
## void createSortedJointsHierarchy ( )

Сортирует узлы суставов в правильном порядке иерархии родитель-потомок. Это гарантирует, что родительские суставы всегда предшествуют своим потомкам в списке суставов, что необходимо для корректной обработки скелета во время импорта.
