# Unigine::ImportMaterial Class (CPP)

**Header:** #include <UnigineImport.h>


Этот класс является промежуточным представлением материала из исходного файла. Он хранит именованные параметры и назначения слотов текстур, как определено в исходном формате. Во время импорта [import processor](../../../../api/library/common/import/class.importprocessor_cpp.md) использует эти метаданные для заполнения [Material](../../../../api/library/rendering/class.material_cpp.md) UNIGINE.


## ImportMaterial Class

### Методы класса

## void setData ( void * data )

Задаёт новые метаданные импортированного материала.
### Аргументы

- *void ** **data** - Метаданные материала.

## void * getData () const

Возвращает текущие метаданные импортированного материала.
### Возвращаемое значение

Текущие метаданные материала.
## void setName ( const char * name )

Задаёт новое имя импортированного материала.
### Аргументы

Возвращает текущее имя импортированного материала.
### Возвращаемое значение

Текущее имя материала.

Задаёт новый путь к выходному файлу материала `*.mat`.
### Аргументы

## const char * getFilepath () const

Возвращает текущий путь к выходному файлу материала `*.mat`.
### Возвращаемое значение

Текущий путь к выходному файлу материала.
