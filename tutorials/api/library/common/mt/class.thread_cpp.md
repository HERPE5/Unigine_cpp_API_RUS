# Unigine::Thread Class (CPP)

**Header:** #include <UnigineThread.h>


Базовый класс для создания и управления потоками в движке. Предоставляет функциональность для запуска, остановки, сигнализации и опроса потоков, а также для установки приоритета потока и привязки к процессору.


Чтобы создать пользовательский поток, унаследуйтесь от этого класса и реализуйте чисто виртуальный метод *process()*.


## Thread Class

### Перечисления

### Методы класса

---

## Thread ( bool auto_shutdown = true , Type type = Type::Unknown , const char * name = nullptr , int microprofile_priority = -1 )

Создаёт новый экземпляр Thread.
### Аргументы

- *bool* **auto_shutdown** - Если true, поток будет автоматически завершён при выходе движка.
- *[Type](/api/library/common/mt/class.thread#Type)* **type** - Идентификатор типа потока.
- *const char ** **name** - Имя потока, отображаемое в инструменте [Microprofile](../../../../tools/profiling/microprofile/index_cpp.md). Если не задано, используется имя типа потока.
- *int* **microprofile_priority** - Приоритет потока в [Microprofile](../../../../tools/profiling/microprofile/index_cpp.md).

## virtual bool run ( size_t size = 0x100000 )

Создаёт поток ОС и начинает выполнение метода *process()*. Возвращает false, если поток уже выполняется.
### Аргументы

- *size_t* **size** - Размер стека потока в байтах.

### Возвращаемое значение

true, если поток был успешно запущен; иначе false.
## void process ( )

Защищённый чисто виртуальный метод, определяющий рабочую нагрузку потока. Переопределите этот метод в вашем подклассе для реализации логики потока. Вызывается автоматически при вызове *[run()](../../../...md#run_size_t_bool)*.
## bool stop ( )

Корректно останавливает поток: подаёт ему сигнал пробуждения и ожидает (join), пока *process()* не завершится.
### Возвращаемое значение

true, если поток завершился корректно; иначе false.
## void signal ( )

Подаёт потоку сигнал пробуждения из состояния ожидания.
## bool terminate ( )

Принудительно немедленно завершает поток. Может привести к утечкам ресурсов. Ничего не делает, если поток уже корректно остановлен.
### Возвращаемое значение

true, если поток был завершён; иначе false.
## virtual bool shutdown ( )

Выполняет двухэтапное завершение работы: сначала пытается корректно [stop()](#stop_bool) поток с тайм-аутом, затем принудительно [terminates](#terminate_bool) его, если поток не завершился.
### Возвращаемое значение

true, если операция выполнена успешно; иначе false.
## static void allThreadsShutdown ( )

Инициирует завершение работы всех потоков движка.
## static bool isShutdown ( )

Возвращает значение, указывающее, инициировано ли завершение работы движка.
### Возвращаемое значение

true, если потоки движка завершают работу; иначе false.

### Возвращаемое значение
