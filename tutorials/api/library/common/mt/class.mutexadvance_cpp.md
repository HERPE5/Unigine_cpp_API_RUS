# Unigine::MutexAdvance<MutexType> Class (CPP)

**Header:** #include <UnigineThread.h>


Шаблонный класс, оборачивающий обобщённый тип мьютекса с дополнительным отслеживанием состояния блокировки для более быстрых запросов состояния блокировки и уменьшения конкуренции в некоторых сценариях конкурентного доступа.


Поддерживая атомарный флаг (*is_locked*), этот класс позволяет быстро проверять статус блокировки без захвата базового мьютекса, предоставляя при этом стандартные интерфейсы блокировки.


***MutexType*** - Базовый тип мьютекса, используемый для блокировки. Тип должен предоставлять методы *lock()*, *tryLock()*, *unlock()*.

## MutexAdvance<MutexType> Class

### Методы класса

---

## MutexAdvance ( )

Конструктор по умолчанию. Инициализирует внутренний мьютекс и устанавливает состояние блокировки как разблокированное.
## void lock ( )

Захватывает внутренний мьютекс и помечает состояние блокировки как активное.
## void unlock ( )

Освобождает внутренний мьютекс и помечает состояние блокировки как неактивное.
## bool tryLock ( )

Пытается захватить блокировку без ожидания. Сначала проверяет внутренний флаг для быстрого отклонения, затем пытается захватить базовый мьютекс.
### Возвращаемое значение

Возвращает true, если блокировка была успешно захвачена, иначе false.
## bool isLocked ( )

Возвращает текущий статус блокировки мьютекса, проверяя внутренний флаг.
### Возвращаемое значение

Возвращает true, если блокировка в данный момент удерживается, иначе false.
## void waitForce ( )

Принудительно заставляет текущий поток ожидать, захватывая и немедленно освобождая блокировку.
## void wait ( )

Ожидает освобождения мьютекса, если он в данный момент заблокирован. Немедленно возвращает управление, если блокировка не удерживается.
