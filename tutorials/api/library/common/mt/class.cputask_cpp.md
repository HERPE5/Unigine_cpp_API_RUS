# Unigine::CPUTask Class (CPP)

**Header:** #include <UnigineThread.h>


**CPUTask** — это однопоточная задача, которая может быть направлена в любой из пулов потоков движка. В отличие от **[CPUShader](../../../../api/library/common/mt/class.cpushader_cpp.md)**, который распределяет работу между несколькими потоками, CPUTask выполняет свой метод *process()* один раз в одном рабочем потоке внутри выбранного пула.


Унаследуйтесь от этого класса и переопределите чисто виртуальный метод *process()*, чтобы определить логику вашей задачи, затем вызовите один из методов *run*Thread()*, чтобы отправить её в определённый пул.


## CPUTask Class

### Методы класса

---

## CPUTask ( )

Конструктор по умолчанию.
## CPUTask ( const CPUTask& task )

Конструктор копирования. Копирует приоритет и режим синхронизации кадра из указанной задачи.
### Аргументы

- *const CPUTask&* **task** - Исходная задача, из которой копируются настройки приоритета и синхронизации кадра.

## CPUTask ( Priority priority_ )

Конструктор с приоритетом.
### Аргументы

- *[Priority](#Priority)* **priority_** - Приоритет задачи в очереди пула.

## CPUTask ( FrameSyncMode frame_sync_ )

Конструктор с режимом синхронизации кадра.
### Аргументы

- *[FrameSyncMode](#FrameSyncMode)* **frame_sync_** - Режим синхронизации кадра.

## CPUTask ( Priority priority_ , FrameSyncMode frame_sync_ )

Конструктор с приоритетом и режимом синхронизации кадра.
### Аргументы

- *[Priority](#Priority)* **priority_** - Приоритет задачи в очереди пула.
- *[FrameSyncMode](#FrameSyncMode)* **frame_sync_** - Режим синхронизации кадра.

## PoolThread getRunPoolThread ( ) const

Возвращает поток пула, в который была направлена эта задача.
### Возвращаемое значение

Поток пула, в который была отправлена задача.
## Priority getPriority ( ) const

Возвращает приоритет задачи в очереди пула.
### Возвращаемое значение

Текущий приоритет.
## void setPriority ( Priority v )

Задаёт приоритет задачи в очереди пула.
### Аргументы

- *[Priority](#Priority)* **v** - Устанавливаемый приоритет.

## FrameSyncMode getFrameSync ( ) const

Возвращает режим синхронизации кадра.
### Возвращаемое значение

Текущий режим синхронизации кадра.
## void setFrameSync ( FrameSyncMode v )

Задаёт режим синхронизации кадра.
### Аргументы

- *[FrameSyncMode](#FrameSyncMode)* **v** - Устанавливаемый режим синхронизации кадра.

## static int generateID ( )

Генерирует уникальный идентификатор задачи. Можно вызвать перед созданием задачи для предварительного выделения ID.
### Возвращаемое значение

Уникальный идентификатор задачи.
## void run ( PoolThread thread )

Отправляет задачу в указанный поток пула.
### Аргументы

- *[PoolThread](#PoolThread)* **thread** - Целевой поток пула для выполнения задачи.

## void runMainThread ( )

Отправляет задачу в очередь главного потока. Задача будет выполнена в главном потоке во время следующего цикла обновления.
## void runSyncThread ( )

Отправляет задачу в синхронный пул (Sync Pool).
## void runAsyncThread ( )

Отправляет задачу в асинхронный пул (Async Pool).
## void runCriticalThread ( )

Отправляет задачу в критический пул (Critical Pool).
## void runCommonThread ( )

Отправляет задачу в общий пул (Common Pool).
## void runBackgroundThread ( )

Отправляет задачу в фоновый пул (Background Pool).
## void runRenderFlushThread ( )

Отправляет задачу в пул сброса рендеринга (Render-Flush Pool).
## void runFileStreamThread ( )

Отправляет задачу в пул потоковой передачи файлов (File Stream Pool).
## void runGPUStreamThread ( )

Отправляет задачу в пул потоковой передачи GPU (GPU Stream Pool).
## void unsafeStop ( )

Удаляет задачу из очереди пула. Этот метод не является потокобезопасным и должен вызываться только тогда, когда вы уверены, что обработка задачи ещё не началась.
## void destroy ( )

Уничтожает задачу. Использует асинхронную очередь уничтожения движка для безопасного удаления объекта задачи.
## virtual void process ( )

Чисто виртуальный метод для переопределения логикой вашей задачи. Вызывается один раз в назначенном рабочем потоке при выполнении задачи.
