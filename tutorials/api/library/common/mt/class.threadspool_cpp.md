# Unigine::ThreadsPool Class (CPP)

**Header:** #include <UnigineThread.h>


ThreadsPool — это планировщик работы CPU движка. Он запускает задачи CPUTask и CPUShader в выделенных рабочих пулах (sync/async/critical/background/render-flush/file-stream/GPU-stream), а также поддерживает выполнение в главном потоке.


Задачи могут быть помечены как кадро-синхронизированные (FrameSyncMode::Swap). Ожидается, что такая работа завершится в текущем кадре, и она вычерпывается на этапе завершения кадра Swap через ThreadsPool::frameSync().


## ThreadsPool Class

### Перечисления

## Priority

Приоритет задачи, используемый внутренними очередями (меньшее значение означает более высокий приоритет).
| Name | Description |
|---|---|
| **Critical** = 0 | Наивысший приоритет. |
| **Highest** = 1 | Очень высокий приоритет. |
| **AboveNormal** = 2 | Приоритет выше обычного. |
| **Normal** = 3 | Приоритет по умолчанию. |
| **BelowNormal** = 4 | Приоритет ниже обычного. |
| **Lowest** = 5 | Низкий приоритет. |
| **Background** = 6 | Фоновый приоритет. |
| **Idle** = 7 | Простаивающий (наименьший) приоритет. |
| **Landscape** = 1 | Псевдоним Priority::Highest. |
| **Streaming** = 6 | Псевдоним Priority::Background. |

## PoolThread

Селектор пула выполнения для планирования CPUTask/CPUShader.
| Name | Description |
|---|---|
| **Main** = 0 | Выполнение в главном потоке. |
| **Sync** = 1 | Синхронный рабочий пул. |
| **Async** = 2 | Асинхронный рабочий пул. |
| **Critical** = 3 | Критический рабочий пул. |
| **Common** = 4 | Общий рабочий пул. |
| **Background** = 5 | Фоновый рабочий пул. |
| **FileStream** = 6 | Рабочий пул потоковой передачи файлов. |
| **GPUStream** = 7 | Рабочий пул потоковой передачи GPU. |
| **RenderFlush** = 8 | Рабочий пул сброса рендеринга. |

## FrameSyncMode

Управляет тем, блокирует ли движок выполнение на этапе swap и ожидает ли завершения работы перед переходом к следующему кадру.
| Name | Description |
|---|---|
| **Disabled** = 0 | Работа не кадро-синхронизирована. |
| **Swap** = 1 | Режим конца кадра (Swap). Движок блокирует выполнение на этапе swap и ожидает завершения всей такой работы перед переходом к следующему кадру. |

### Методы класса

---

## int isInitialized ( )

Проверяет, инициализирована ли подсистема ThreadsPool.
### Возвращаемое значение

Ненулевое значение, если пулы потоков были инициализированы.
## int getCurrentThreadIndex ( )

Возвращает индекс рабочего потока пула для текущего потока.
### Возвращаемое значение

Текущий индекс рабочего потока пула или -1, если это не рабочий поток пула.
## int getNumAllThreads ( )

Возвращает общее количество рабочих потоков во всех пулах.
### Возвращаемое значение

Общее количество рабочих потоков во всех пулах (главный поток не включён).
## int getNumAsyncThreads ( )

Возвращает количество потоков асинхронного пула.
### Возвращаемое значение

Количество потоков в асинхронном пуле.
## int getNumSyncThreads ( )

Возвращает количество потоков синхронного пула.
### Возвращаемое значение

Количество потоков в синхронном пуле.
## int getNumDefaultAsyncThreads ( )

Возвращает количество потоков по умолчанию для асинхронного CPUShader.
### Возвращаемое значение

Количество потоков по умолчанию, используемое CPUShader::runAsync(), когда num_threads равно -1.
## int getNumDefaultSyncThreads ( )

Возвращает количество потоков по умолчанию для синхронного CPUShader.
### Возвращаемое значение

Количество потоков по умолчанию, используемое CPUShader::runSync(), когда num_threads равно -1.
## void frameSync ( )

 Ожидание в конце кадра кадро-синхронизированной работы. Подаёт сигнал рабочим потокам и продолжает обработку, пока внутренний счётчик кадровой синхронизации не достигнет нуля или движок не начнёт завершение работы.
## bool yield ( int pool_mask = POOL_THREAD_MASK_ALL , int priority_mask = PRIORITY_MASK_ALL , bool only_frame_sync = false )

 Пытается выполнить одну ожидающую задачу, соответствующую указанным маскам пула и приоритета. Если вызывается из рабочего потока пула, pool_mask дополнительно ограничивается разрешёнными пулами этого рабочего потока.
### Аргументы

- *int* **pool_mask** - Маска выбора пула (POOL_THREAD_MASK_*).
- *int* **priority_mask** - Маска выбора приоритета (PRIORITY_MASK_*).
- *bool* **only_frame_sync** - Если true, обрабатываются только кадро-синхронизированные очереди.

### Возвращаемое значение

True, если задача была выполнена; иначе false.
## bool runProcess ( int pool_mask = POOL_THREAD_MASK_ALL , int priority_mask = PRIORITY_MASK_ALL , bool only_frame_sync = true )

 Пытается выполнить одну ожидающую задачу из выбранных пулов. Задачи сканируются в порядке приоритета и фильтруются по priority_mask. Когда only_frame_sync равно false, также могут обрабатываться некадро-синхронизированные очереди.
### Аргументы

- *int* **pool_mask** - Маска выбора пула (POOL_THREAD_MASK_*).
- *int* **priority_mask** - Маска выбора приоритета (PRIORITY_MASK_*).
- *bool* **only_frame_sync** - Если true, обрабатываются только кадро-синхронизированные очереди.

### Возвращаемое значение

True, если задача была выполнена; иначе false.
## void forceWakeAll ( )

Пробуждает все рабочие потоки пула, ожидающие работы.
## void runNewThread ( CallbackBase* process , int priority = -3 )

 Запускает обратный вызов в переиспользуемом обобщённом пользовательском потоке. Если нет доступного простаивающего потока, создаётся новый. Обратный вызов удаляется после выполнения.
### Аргументы

- *CallbackBase** **process** - Объект обратного вызова для выполнения в обобщённом пользовательском потоке (право владения передаётся).
- *int* **priority** - Приоритет потока для обобщённого пользовательского потока.
