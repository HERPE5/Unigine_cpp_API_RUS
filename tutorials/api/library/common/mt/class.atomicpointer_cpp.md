# Unigine::AtomicPointer<Type> Struct (CPP)

**Header:** #include <UnigineThread.h>


**AtomicPointer<Type>** — это **lock-free** атомарная обёртка, разработанная специально для работы с необработанными указателями потокобезопасным способом.


**Параметры шаблона:**

- **Type** - Тип необработанного указателя (например, *int**, *MyStruct**)
- Указатель хранится внутренне как 64-битное целое число (long long).


## AtomicPointer<Type> Struct

### Методы класса

---

## AtomicPointer ( )

Конструктор по умолчанию.
## AtomicPointer ( Type v )

Конструктор. Создаёт атомарный указатель, инициализированный указанным значением необработанного указателя.
### Аргументы

- *Type* **v** - Значение указателя для инициализации (например, *int**, *MyStruct**).

## AtomicPointer ( const AtomicPointer& v )

Конструктор копирования. Атомарно копирует значение указателя из другого экземпляра **AtomicPointer<Type>**.
### Аргументы

- *const AtomicPointer&* **v**

## Type operator Type() ( ) const

Неявно преобразует объект **AtomicPointer** в значение типа **Type**. Внутренне вызывает *[fetch()](#fetch_Type)* для возврата потокобезопасного снимка текущего значения.
## volatile long long & getUnsafeRawValue ( )

Возвращает неатомарную ссылку на внутреннее необработанное 64-битное представление указателя. Вызов этого метода обходит всю потокобезопасность и должен использоваться только тогда, когда вызывающая сторона гарантирует внешнюю синхронизацию.
### Возвращаемое значение

Ссылка на внутреннее значение, хранящее указатель.
## const volatile long long & getUnsafeRawValue ( ) const

Const-версия *[getUnsafeRawValue()](#getUnsafeRawValue_volatile_llong_ref)*. Предоставляет доступ только для чтения, небезопасный для потоков, к хранимому значению.
### Возвращаемое значение

Ссылка на внутреннее значение, хранящее указатель.
## volatile long long * getRawValuePtr ( )

Возвращает указатель на необработанное хранилище атомарного указателя. Вызов этого метода обходит всю потокобезопасность и должен использоваться только тогда, когда вызывающая сторона гарантирует внешнюю синхронизацию.
### Возвращаемое значение

Указатель на внутреннее значение.
## const volatile long long * getRawValuePtr ( ) const

Const-версия *[getRawValue()](#getRawValuePtr_volatile_llong_ptr)*. Предоставляет доступ только для чтения, небезопасный для потоков, к хранимому значению.
### Возвращаемое значение

Const-указатель на внутреннее значение.
## Type & getUnsafeValue ( )

### Возвращаемое значение

## const Type & getUnsafeValue ( ) const

### Возвращаемое значение

Атомарно копирует значение указателя из другого экземпляра **AtomicPointer<Type>**.

### Возвращаемое значение

Новое присвоенное значение указателя.
## Type swap ( Type v )

Атомарно заменяет текущее значение указателя переданным значением и возвращает предыдущее значение.
### Аргументы

- *Type* **v** - Значение указателя для атомарного присвоения.

### Возвращаемое значение

Значение указателя, которое было до замены.
## bool compareAndSwap ( Type old_value , Type new_value )

Выполняет **lock-free** операцию *compare-and-swap*. Если текущее значение равно old_value, оно заменяется на new_value.
### Аргументы

- *Type* **old_value** - Ожидаемое текущее значение.
- *Type* **new_value** - Новое значение для присвоения, если текущее совпадает с ожидаемым.

### Возвращаемое значение

Возвращает true, если внутреннее значение было обновлено; false, если текущее значение не совпадало с old_value.
## void spinLock ( Type old_value , Type new_value )

Непрерывно пытается атомарно заменить значение с old_value на new_value с помощью *[compareAndSwap()](#compareAndSwap_Type_Type_bool)*.
### Аргументы

- *Type* **old_value** - Ожидаемое текущее значение.
- *Type* **new_value** - Новое значение для присвоения, если текущее совпадает с ожидаемым.

## void waitValue ( Type v )

Блокирует текущий поток в цикле активного ожидания, пока внутреннее значение не станет равным переданному. Внутренне вызывает *[spinLock(v, v)](#spinLock_Type_Type_void)* и повторно проверяет после каждой неудачи.
### Аргументы

- *Type* **v** - Значение, которого следует дождаться.

## Type fetchAdd ( long long v )

Атомарно перемещает указатель вперёд на заданное количество позиций.
### Аргументы

- *long long* **v** - Количество элементов для добавления; внутренне умножается на sizeof(*Type). (Например, если **Type** = *int** и v = 2, указатель перемещается на 2 * 4 = 8 байт вперёд.

### Возвращаемое значение

Возвращает значение, которое было до сложения.
## Type fetchSub ( long long v )

Атомарно перемещает указатель назад на заданное количество позиций.
### Аргументы

- *long long* **v** - Количество элементов для вычитания; внутренне умножается на sizeof(*Type). (Например, если **Type** = *int** и v = 2, указатель перемещается на 2 * 4 = 8 байт назад.

### Возвращаемое значение

Возвращает значение, которое было до вычитания.
