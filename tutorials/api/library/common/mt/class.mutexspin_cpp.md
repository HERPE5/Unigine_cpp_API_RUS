# Unigine::MutexSpin Class (CPP)

**Header:** #include <UnigineThread.h>


Лёгковесная реализация мьютекса на основе спин-блокировки для синхронизации с низкими накладными расходами в многопоточных средах. Вместо блокирования этот мьютекс непрерывно проверяет состояние блокировки в цикле (spins), пока она не станет доступной.


Этот класс имеет следующие псевдонимы:


| Alias | Description |
|---|---|
| **Mutex** | Псевдоним по умолчанию для **MutexSpin**. |


## MutexSpin Class

### Методы класса

---

## MutexSpin ( )

Конструктор по умолчанию. Инициализирует внутреннее состояние блокировки как разблокированное.
## void lock ( )

Захватывает спин-блокировку, непрерывно проверяя внутреннюю переменную блокировки, пока она не станет доступной. После захвата блокировки устанавливает состояние блокировки.
## bool tryLock ( )

Пытается захватить спин-блокировку без ожидания.
### Возвращаемое значение

Возвращает true, если блокировка была успешно захвачена; false, если блокировка уже удерживается другим потоком.
## void unlock ( )

Освобождает спин-блокировку, устанавливая внутреннюю переменную блокировки в состояние разблокировано.
## bool isLocked ( ) const

Проверяет, удерживается ли спин-блокировка в данный момент каким-либо потоком.
### Возвращаемое значение

Возвращает true, если спин-блокировка в данный момент заблокирована; иначе false.
## void wait ( )

Ожидает в цикле активного ожидания, пока блокировка не освободится, не пытаясь её захватить.
