# Unigine::RWMutexSpin Class (CPP)

**Header:** #include <UnigineThread.h>


Реализация мьютекса чтения-записи на основе спин-блокировки, позволяющая нескольким конкурентным читателям или эксклюзивный доступ для одного писателя. Внутренне использует атомарные операции и класс **[BackoffSpinner](../../../../api/library/common/mt/class.backoffspinner_cpp.md)** для управления доступом.


Этот класс имеет следующие псевдонимы:


| Alias | Description |
|---|---|
| **RWMutex** | Псевдоним по умолчанию для **RWMutexSpin**. |


## RWMutexSpin Class

### Методы класса

---

## RWMutexSpin ( )

Конструктор по умолчанию. Инициализирует внутреннее состояние блокировки без активных читателей или писателей.
## void lockRead ( )

Захватывает разделяемую (read) блокировку. Несколько потоков могут получить доступ на чтение одновременно, пока ни один писатель не удерживает блокировку.
## bool tryLockRead ( )

Пытается захватить блокировку чтения без ожидания. Завершается неудачей, если писатель в данный момент удерживает блокировку.
### Возвращаемое значение

Возвращает true, если блокировка чтения была успешно захвачена; иначе false.
## void unlockRead ( )

Освобождает ранее захваченную блокировку чтения, уменьшая счётчик читателей.
## void lockWrite ( )

Захватывает эксклюзивную (write) блокировку. Блокирует выполнение, пока ни один другой поток не удерживает блокировку чтения или записи.
## bool tryLockWrite ( )

Пытается захватить блокировку записи без ожидания. Успешно завершается, только если ни читатели, ни писатели в данный момент не удерживают блокировку.
### Возвращаемое значение

Возвращает true, если блокировка записи была успешно захвачена; иначе false.
## void unlockWrite ( )

Освобождает ранее захваченную блокировку записи, сбрасывая флаг писателя.
## void lock ( )

Псевдоним для *[lockWrite()](#lockWrite_void)*. Позволяет использовать ***RWMutexSpin*** в обобщённых интерфейсах блокировки.
## bool tryLock ( )

Псевдоним для *[tryLockWrite()](#tryLockWrite_bool)*. Позволяет использовать ***RWMutexSpin*** в обобщённых интерфейсах блокировки.
## void unlock ( )

Псевдоним для *[unlockWrite()](#unlockWrite_void)*. Позволяет использовать ***RWMutexSpin*** в обобщённых интерфейсах блокировки.
