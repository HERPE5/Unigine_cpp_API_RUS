# Unigine::ReentrantMutexBase<MutexType> Class (CPP)

**Header:** #include <UnigineThread.h>


Шаблонный класс, реализующий базовый повторно входимый (рекурсивный) мьютекс с использованием пользовательского типа мьютекса. Этот класс позволяет одному потоку захватывать одну и ту же блокировку несколько раз без возникновения взаимоблокировки, отслеживая глубину блокировки и владение потоком.


Он предоставляет базовые функции взаимного исключения, подходящие для многопоточных сред, где требуется повторная входимость.


***MutexType*** - Базовый тип мьютекса, используемый для блокировки. Тип должен предоставлять методы *lock()*, *tryLock()*, *unlock()*.

## ReentrantMutexBase<MutexType> Class

### Методы класса

---

## ReentrantMutexBase ( )

Конструктор по умолчанию. Инициализирует внутреннее состояние, устанавливая блокировку как доступную.
## void lock ( )

Захватывает мьютекс. Если текущий поток уже владеет блокировкой, увеличивает глубину повторной входимости вместо повторной блокировки базового мьютекса.
## bool tryLock ( )

Пытается захватить мьютекс без ожидания. Если текущий поток уже владеет блокировкой, увеличивает глубину повторной входимости.
### Возвращаемое значение

Возвращает true, если мьютекс был успешно захвачен; false, если мьютекс в данный момент удерживается другим потоком.
## void unlock ( )

Освобождает мьютекс. Если блокировка была захвачена несколько раз одним и тем же потоком, уменьшает глубину повторной входимости. Когда глубина достигает нуля, освобождает базовый мьютекс и очищает владение потоком.
## bool isLocked ( )

Проверяет, считается ли мьютекс в данный момент заблокированным каким-либо потоком.
### Возвращаемое значение

Возвращает true, если мьютекс заблокирован; иначе false.
## void waitForce ( )

Принудительно заставляет текущий поток ожидать, пока мьютекс не станет доступным, захватывая и затем немедленно освобождая блокировку.
## void wait ( )

Ожидает освобождения мьютекса другим потоком. Если мьютекс в данный момент никем не владеет или уже принадлежит вызывающему потоку, метод немедленно возвращает управление. В противном случае блокирует выполнение, вызывая *[waitForce().](#waitForce_void)*
