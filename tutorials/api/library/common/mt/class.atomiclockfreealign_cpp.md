# Unigine::AtomicLockFreeAlign<Type> Struct (CPP)

**Header:** #include <UnigineThread.h>


AtomicLockFreeAlign<Type> — это **lock-free** атомарная обёртка, используемая, когда тип <Type> не соответствует точно поддерживаемому необработанному целочисленному типу (*char, short, int, long long*) по размеру или выравниванию, но всё же вписывается в ограничения атомарной системы.


Внутренне используется объединение (union) для преобразования между <Type> и **RawType**, обеспечивая правильность выравнивания и компоновки.


Значение хранится в выровненном блоке памяти, и весь доступ выполняется атомарно, без необходимости во внешних механизмах синхронизации, таких как мьютексы.

## bool compareAndSwap ( Type old_value , Type new_value )

Выполняет **lock-free** операцию *compare-and-swap*. Если текущее значение равно old_value, оно заменяется на new_value.
### Аргументы

- *Type* **old_value** - Ожидаемое текущее значение.
- *Type* **new_value** - Новое значение для присвоения, если текущее совпадает с ожидаемым.

### Возвращаемое значение

Возвращает true, если внутреннее значение было обновлено; false, если текущее значение не совпадало с old_value.
## void spinLock ( Type old_value , Type new_value )

Непрерывно пытается атомарно заменить значение с old_value на new_value с помощью *[compareAndSwap()](#compareAndSwap_Type_Type_bool)*.
### Аргументы

- *Type* **old_value** - Ожидаемое текущее значение.
- *Type* **new_value** - Новое значение для присвоения, если текущее совпадает с ожидаемым.

## void waitValue ( Type v )

Блокирует текущий поток в цикле активного ожидания, пока внутреннее значение не станет равным переданному. Внутренне вызывает *[spinLock(v, v)](#spinLock_Type_Type_void)* и повторно проверяет после каждой неудачи.
### Аргументы

- *Type* **v** - Значение, которого следует дождаться.
