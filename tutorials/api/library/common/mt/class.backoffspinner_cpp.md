# Unigine::BackoffSpinner Class (CPP)

**Header:** #include <UnigineThread.h>

Этот класс реализует механизм экспоненциальной задержки (exponential backoff) для [SpinLock](../../../../api/library/common/class.unigine.namespace_cpp.md#SpinLockTemplate_volatiletmplptr_consttmpl_consttmpl), уменьшая влияние на производительность процессора.


## BackoffSpinner Class

### Методы класса

---

## static BackoffSpinner ( )

Конструктор. Создаёт новый Backoff Spinner.
## void spin ( )

Реализует адаптивную задержку путём постепенного увеличения интервалов ожидания. Начинает с экспоненциально возрастающих инструкций паузы процессора на основе внутреннего счётчика; после достижения порога уступает управление, чтобы позволить выполниться другим потокам. Увеличивает счётчик задержки при каждом вызове.
## void clear ( )

Сбрасывает внутренний счётчик задержки на ноль, перезапуская последовательность экспоненциальной задержки с начала.
