# Unigine::ProcessTask Class (CPP)

**Header:** #include <UnigineThread.h>

**Inherits from:** CPUTask


**ProcessTask** — это абстрактный базовый класс, построенный поверх **[CPUTask](../../../../api/library/common/mt/class.cputask_cpp.md)**, реализующий шаблон повторно входимого цикла со встроенной защитой мьютексом от конкурентного выполнения.


Унаследуйтесь от этого класса и переопределите два чисто виртуальных метода:


- *[do_process()](#do_process_void)* — выполняет одну единицу работы.
- *[is_active()](#is_active_bool)* — возвращает, должна ли задача продолжать цикл после завершения текущей единицы работы.


Затем вызовите *[runProcess()](#runProcess_void)*, чтобы отправить задачу. Внутренний цикл повторно вызывает *[do_process()](#do_process_void)*, пока *[is_active()](#is_active_bool)* не вернёт false или пока управление не перехватит другой вызов *[runProcess()](#runProcess_void)*. Мьютекс гарантирует, что одновременно активно только одно выполнение — вызов *[runProcess()](#runProcess_void)*, пока задача уже выполняется, безопасно игнорируется.


## ProcessTask Class

### Методы класса

---

## ProcessTask ( PoolThread pool = PoolThread::Background )

Создаёт новый экземпляр ProcessTask.
### Аргументы

- *[PoolThread](#PoolThread)* **pool** - Целевой поток пула для этой задачи.

## void runProcess ( )

Отправляет задачу на выполнение в назначенный пул. Если движок завершает работу, вызов игнорируется. Если задача уже выполняется, вызов безопасно игнорируется (внутренний мьютекс предотвращает конкурентное выполнение).
## virtual void do_process ( )

Чисто виртуальный метод для переопределения логикой вашей работы. Вызывается один раз за итерацию цикла внутри внутреннего цикла *[process()](../../../../api/library/common/mt/class.cputask_cpp.md#process_void)*.
## virtual bool is_active ( )

Чисто виртуальный метод, управляющий циклом. Вызывается после каждого вызова *[do_process()](#do_process_void)*. Если возвращает false, задача останавливается, и мьютекс освобождается.
### Возвращаемое значение

Возвращает true для продолжения цикла, false для остановки.
