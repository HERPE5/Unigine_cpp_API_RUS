# Unigine::AtomicWithMutex<Type, MutexType> Struct (CPP)

**Header:** #include <UnigineThread.h>


Шаблонная структура, предоставляющая **потокобезопасную атомарную обёртку** вокруг пользовательского значения с использованием **синхронизации на основе мьютекса** вместо lock-free атомарных операций.


**Параметры шаблона:**

- **Type** - Тип хранимого значения. Должен поддерживать копирование и сравнение.
- **MutexType** - Реализация мьютекса, используемая для защиты доступа. По умолчанию ***[MutexSpin](../../../../api/library/common/mt/class.mutexspin_cpp.md)***.


## AtomicWithMutex<Type, MutexType> Struct

### Методы класса

---

## AtomicWithMutex ( )

Конструктор по умолчанию. Инициализирует внутреннее значение с помощью его конструктора по умолчанию.
## AtomicWithMutex ( const Type& v )

Конструктор. Инициализирует внутреннее значение переданным значением.
### Аргументы

- *const Type&* **v** - Начальное значение.

## AtomicWithMutex ( const AtomicWithMutex& v )

Конструктор копирования. Блокирует мьютексы источника и назначения, чтобы безопасно скопировать переданное значение.
### Аргументы

- *const AtomicWithMutex&* **v**

## Type operator Type() ( ) const

Неявно преобразует объект **AtomicWithMutex** в значение типа **Type**. Внутренне вызывает *[fetch()](#fetch_Type)* для возврата потокобезопасного снимка текущего значения.
### Возвращаемое значение

Возвращает копию текущего значения.
## Type & getUnsafeValue ( )

Предоставляет прямой, несинхронизированный доступ к внутреннему значению. Вызов этого метода обходит всю потокобезопасность и должен использоваться только тогда, когда вызывающая сторона гарантирует внешнюю синхронизацию.
### Возвращаемое значение

Возвращает небезопасную для потоков ссылку на хранимое значение.
## const Type & getUnsafeValue ( ) const

Const-версия *[getUnsafeValue()](#getUnsafeValue_Type_ref)*. Предоставляет доступ только для чтения, небезопасный для потоков, к хранимому значению.
### Возвращаемое значение

Возвращает небезопасную для потоков const-ссылку на хранимое значение.
## Type * getValuePtr ( )

Возвращает необработанный указатель на внутреннее значение без блокировки. Небезопасно в многопоточном контексте, если не обеспечена внешняя синхронизация.
### Возвращаемое значение

Возвращает указатель на внутреннее значение.
## const Type * getValuePtr ( ) const

Const-версия *[getValuePtr()](#getValuePtr_Type_ptr)*.
### Возвращаемое значение

Возвращает const-указатель на внутреннее значение.
## MutexType & getMutex ( )

Предоставляет прямой доступ к внутреннему объекту мьютекса. Это позволяет внешнему коду вручную блокировать или разблокировать мьютекс.
### Возвращаемое значение

Возвращает ссылку на мьютекс, используемый для защиты внутреннего значения.
## const MutexType & getMutex ( ) const

Const-версия *[getMutex()](#getMutex_MutexType_ref)*.
### Возвращаемое значение

Возвращает const-ссылку на мьютекс, используемый для защиты внутреннего значения.
## Type fetch ( ) const

Извлекает текущее значение потокобезопасным способом. Захватывает мьютекс, копирует внутреннее значение, затем освобождает мьютекс. Предпочтительнее прямого доступа, когда требуется согласованное чтение.
### Возвращаемое значение

Возвращает копию хранимого значения.
## void store ( const Type& v )

Задаёт внутреннее значение новым значением потокобезопасным способом. Всё присваивание защищено мьютексом во избежание состояний гонки с читателями или другими писателями.
### Аргументы

- *const Type&* **v** - Новое значение для сохранения.

## const Type & operator= ( const Type& v )

Потокобезопасный оператор присваивания, сохраняющий новое значение внутренне. Эквивалентен вызову *[store()](#store_const_Type_ref_void)*.
### Аргументы

- *const Type&* **v** - Новое значение для присвоения.

### Возвращаемое значение

Возвращает const-ссылку на присвоенное значение.
## Type operator= ( const AtomicWithMutex& v )

Потокобезопасное присваивание копированием из другого **AtomicWithMutex**. Блокирует мьютексы источника и назначения, чтобы предотвратить состояния гонки данных.
### Аргументы

- *const AtomicWithMutex&* **v** - Другой **AtomicWithMutex**, из которого копируется значение.

### Возвращаемое значение

Возвращает скопированное значение.
## Type swap ( const Type& v )

Атомарно заменяет текущее значение новым и возвращает старое значение.
### Аргументы

- *const Type&* **v** - Новое значение для установки.

### Возвращаемое значение

Возвращает значение, которое было сохранено до замены.
## bool compareAndSwap ( const Type& old_value , const Type& new_value )

Выполняет операцию *compare-and-swap*. Если текущее значение равно old_value, оно заменяется на new_value.
### Аргументы

- *const Type&* **old_value** - Ожидаемое текущее значение.
- *const Type&* **new_value** - Новое значение для присвоения, если текущее совпадает с ожидаемым.

### Возвращаемое значение

true, если внутреннее значение было обновлено; false, если текущее значение не совпадало с old_value.
## void spinLock ( const Type& old_value , const Type& new_value )

Непрерывно пытается атомарно заменить значение с old_value на new_value с помощью *[compareAndSwap()](#compareAndSwap_const_Type_ref_const_Type_ref_bool)*.
### Аргументы

- *const Type&* **old_value** - Ожидаемое текущее значение.
- *const Type&* **new_value** - Новое значение для присвоения, если текущее совпадает с ожидаемым.

## void waitValue ( const Type& v )

Блокирует текущий поток в цикле активного ожидания, пока внутреннее значение не станет равным переданному. Внутренне вызывает *[spinLock(v, v)](#spinLock_const_Type_ref_const_Type_ref_void)* и повторно проверяет после каждой неудачи.
### Аргументы

- *const Type&* **v** - Значение, которого следует дождаться.
