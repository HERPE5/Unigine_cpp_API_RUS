### Хранение данных (уровни, слои, грани)


Хранилище изображения содержит одно или несколько под-изображений определённых размеров. Каждый тип изображения имеет специфическое расположение под-изображений в своём хранилище. Изображения могут иметь **мипмапы** — уменьшенные версии того же изображения, используемые для помощи в сэмплировании и фильтрации. Каждый уровень мипмапа имеет отдельный набор под-изображений.


Поскольку изображение может хранить несколько под-изображений, важно иметь возможность идентифицировать конкретное под-изображение в нём. Каждое под-изображение можно однозначно идентифицировать по следующим числам, в зависимости от типа изображения:


- Для изображений, которые могут иметь мипмапы, — **уровень мипмапа**​, содержащий под-изображение.
- Для массивов изображений (Array Images) — **слой массива​**, содержащий под-изображение.
- Для кубических изображений (Cubemap Images) — **грань** внутри этого слоя массива и уровня мипмапа. > **Notice:** Для кубических массивов изображений слой и грань объединяются в слои-грани.


Таким образом, изображение можно представить как трёхмерный массив под-изображений. Первый индекс — это *уровень мипмапа*, второй — *слой массива*, а третий — *грань кубической карты*. Другой способ представить это — изображение имеет определённое количество уровней мипмапов. Каждый мипмап может иметь определённое количество слоёв массива. А каждый слой массива имеет определённое количество граней. **Таким образом, каждое под-изображение изображения можно однозначно определить по индексам грани, слоя и уровня.**


### Пиксели


Цвет каждого пикселя изображения представлен структурой **Pixel**. В зависимости от **формата изображения**, значения записываются либо в **целочисленное** представление (Pixel.i), либо в представление с **плавающей точкой** (Pixel.f) структуры.


Тип **Pixel** реализован как структура-объединение (union), где ***Pixel.i*** и ***Pixel.f*** перекрываются в памяти. Запись в одно представление перезаписывает память другого. Это означает, что следует использовать только правильный аксессор в зависимости от формата (см. таблицу ниже).


| Image type | Image format | Accessor | Valid Range in Pixel (per channel, via accessor) |
|---|---|---|---|
| **8-bit unsigned formats** | [R8](#FORMAT_R8), [RG8](#FORMAT_RG8), [RGB8](#FORMAT_RGB8), [RGBA8](#FORMAT_RGBA8) | ***Pixel.i*** | Компоненты цвета пикселя находятся в диапазоне от **0** до **255**. |
| **16-bit unsigned formats** | [R16](#FORMAT_R16), [RG16](#FORMAT_RG16), [RGB16](#FORMAT_RGB16), [RGBA16](#FORMAT_RGBA16) | ***Pixel.i*** | Компоненты цвета пикселя находятся в диапазоне от **0** до **65535**. |
| **16-bit float formats** | [R16F](#FORMAT_R16F), [RG16F](#FORMAT_RG16F), [RGB16F](#FORMAT_RGB16F), [RGBA16F](#FORMAT_RGBA16F) | ***Pixel.i*** | Компоненты цвета пикселя находятся в диапазоне от **0** до **65535**. |
| **32-bit float formats** | [R32F](#FORMAT_R32F), [RG32F](#FORMAT_RG32F), [RGB32F](#FORMAT_RGB32F), [RGBA32F](#FORMAT_RGBA32F) | ***Pixel.f*** | Полный диапазон значений float 32-бит. |

 Best Practice
***Pixel.i*** и ***Pixel.f*** хранят необработанное представление в памяти цветовых каналов для всех форматов (int или float), при этом значения могут быть обрезаны до допустимого диапазона, а альфа по умолчанию равна 1.0. Например, для **16-битных форматов с плавающей точкой** ***Pixel.i*** хранит необработанные биты half-float, которые соответствуют -HALF_MAX ... +HALF_MAX при преобразовании во float.


- Используйте *[toPixel()](../../...md#toPixel_vec4_Pixel)* для преобразования значений цвета в Pixel. ```cpp Math::vec4 color(0.5f, 0.5f, 0.0f, 1.0f); Image::Pixel pixel = image->toPixel(color); image->set2D(x, y, pixel); ```
- Используйте *[toVec4()](../../...md#toVec4_Pixel_vec4)* для чтения пикселей как нормализованных значений float. ```cpp Image::Pixel pixel = image->get2D(x, y); Math::vec4 color = image->toVec4(pixel); ```

 В этом случае формат изображения определяется автоматически, и преобразование типов выполняется корректно.

```cpp
#include "ImageClass.h"
REGISTER_COMPONENT(ImageClass);

using namespace Unigine;

void ImageClass::init()
{
	// параметры размера изображения
	const int ASPECT_RATIO = 1;
	const int width = 256;
	const int height = width / ASPECT_RATIO;

	ImagePtr image = Image::create();

	// создаём изображение указанного размера
	image->create2D(width, height, Image::FORMAT_RGBA8);

	// объявляем пиксель для хранения цветовой информации
	Image::Pixel pixel;

	for (int x = 0; x < width; x++)
		for (int y = 0; y < height; y++)
		{
			// задаём компоненты пикселя
			pixel.i.r = x;
			pixel.i.g = 0;
			pixel.i.b = 0;
			pixel.i.a = 195;

			// задаём цвет пикселя изображения в позиции (x,y)
			image->set2D(x, y, pixel);
		}

	// если узел является объектом, задаём наше изображение как текстуру albedo его материала
	if (getNode()->isObject()) {
		ObjectPtr obj = checked_ptr_cast<Object>(getNode());
		MaterialPtr material = obj->getMaterial(0)->inherit();

		// задаём наше изображение как текстуру albedo материала
		material->setTextureImage(material->findTexture("albedo"), image);
		obj->setMaterial(material, 0);
	}
	else {
		Log::message("\nNode is not an object!");
	}

	// сохраняем наше изображение в файл *.DDS
	image->save("myimage.dds");

	// выводим текущий формат изображения в консоль
	Log::message("\nImage format: %s", image->getFormatName());

	// преобразуем наше изображение в 32-битный формат с плавающей точкой
	image->convertToFormat(Image::FORMAT_RGBA32F);

	// выводим формат изображения после преобразования в консоль
	Log::message("\nImage format after conversion: %s", image->getFormatName());

	// сохраняем преобразованное изображение в файл *.DDS
	image->save("myimage_converted.dds");

	// получаем первый пиксель каждой строки изображения и выводим его цветовое значение в консоль
	for (int x = 0; x < width; x++)
	{
		pixel = image->get2D(x, 0);
		Log::message("\nPixel(%d, 0) color = (%f,%f,%f,%f)", x, pixel.f.r, pixel.f.g, pixel.f.b, pixel.f.a);
	}

	// очищаем изображение
	image->clear();
}

```

## void set ( size_t offset , const Math:: dvec4 & value )

Задаёт значение для пикселя по его смещению. Сжатые и комбинированные форматы изображения не поддерживаются. Код ниже задаёт указанное значение цвета для всех пикселей изображения:
```cpp
void image_set_pixel_color(ImagePtr& image, const Math::dvec4& value)
{
	// получаем размер изображения
	int width = image->getWidth();
	int height = image->getHeight();

	// проходим по всем пикселям изображения указанного канала в цикле
	for (int y = 0; y < height; y++)
	{
		for (int x = 0; x < width; x++)
		{
			// составляем смещение пикселя из его координат; (0, 0) - верхний левый угол
			int offset = x + y * width;

			// задаём значение для пикселя по его смещению
			image->set(offset, value);
		}
	}
}

```


### Аргументы

- *size_t* **offset** - Смещение пикселя: `offset = image_width * Y + X`, ( 0 , 0) - верхний левый угол изображения.
- *const  Math::[dvec4](../../../api/library/math/class.dvec4_cpp.md) &* **value** - RGBA-цвет пикселя с указанным идентификатором.

## Math:: vec4 get ( const Math::ivec2& coord , int offset ) const

## unsigned char * getPixels ( ) const

Возвращает указатель на массив пикселей. Код ниже заполняет указанный канал изображения указанным значением:
```cpp
// int channel - номер целевого канала для записи указанного значения
// unsigned char value   - значение цвета
void image_fill_channel(ImagePtr& image, int channel, unsigned char value)
{
	// получаем пиксели изображения в буфер
	unsigned char *data = image->getPixels();

	// получаем размер изображения и количество каналов
	int channel_num = image->getNumChannels();
	int width = image->getWidth();
	int height = image->getHeight();

	// проходим по всем пикселям изображения указанного канала в цикле
	for (int y = 0; y < height; y++)
	{
		for (int x = 0; x < width; x++)
		{
			// составляем идентификатор пикселя из его координат и номера канала; (0, 0) - верхний левый угол
			int id = (x + y * width) * channel_num + channel;

			// задаём значение для пикселя по его идентификатору
			data[id] = value;
		}
	}
}

```


### Возвращаемое значение

Указатель на массив пикселей.

## bool blend ( const Ptr < Image > & image , int x0 , int y0 , int x1 , int y1 , int width , int height , float scale = 1.0f , bool safe = 0 )

Смешивает указанное изображение с текущим. Смешивание происходит в пределах указанной области. Если флаг *safe* установлен в 1, рендеринг смешиваемых изображений не будет выполняться за пределами границ целевого изображения. Сжатые, комбинированные, half-float и float форматы не поддерживаются. Изображения разных форматов могут смешиваться следующим образом:
- R8 с R8, RG8;
- RG8 с RG8, RGB8;
- RGB8 с RGB8, RGBA8;
- RGBA8 только с RGBA8;
- R16 с R16, RG16;
- RG16 с RG16, RGB16;
- RGB16 с RGB16, RGBA16;
- RGBA16 только с RGBA16;


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Image](../../../api/library/common/class.image_cpp.md)> &* **image** - Исходное изображение для смешивания с текущим изображением.
- *int* **x0** - Координата X позиции в текущем изображении.
- *int* **y0** - Координата Y позиции в текущем изображении.
- *int* **x1** - Координата X позиции в исходном изображении, которое смешивается с текущим изображением.
- *int* **y1** - Координата Y позиции в исходном изображении, которое смешивается с текущим изображением.
- *int* **width** - Ширина области смешивания.
- *int* **height** - Высота области смешивания.
- *float* **scale** - Масштаб смешивания:

  - Если смешиваемые изображения одного формата, смешиваемое изображение умножается на значение масштаба и добавляется к целевому изображению.
  - Если исходное изображение имеет на один канал больше по сравнению с текущим, этот канал будет служить значением альфы. Значение этого канала умножается на масштаб и используется для альфа-смешивания изображений.
  - Значение масштаба по умолчанию — 1.0f.
- *bool* **safe** - true для безопасного смешивания с учётом границ целевого изображения; иначе false.

### Возвращаемое значение

Возвращает **1**, если смешивание выполнено успешно; иначе **0**.

## bool copy ( const Ptr < Image > & src_image , int layer )

Копирует данные из указанного исходного изображения согласно указанному параметру **layer**. В зависимости от типов изображения и исходного изображения параметр **layer** определяет либо индекс слоя/грани, ИЗ которого копируются данные (источник), либо индекс слоя/грани, В который копируются данные (назначение):
| Image | Source Image | Copy |
|---|---|---|
| Cube | 2D | Указанное исходное 2D-изображение копируется в грань кубического изображения, указанную аргументом layer в диапазоне **[0; 5]**: 2D_image **TO** cubemap_face[ ***layer*** ] |
| 2D Array | 2D | Указанное исходное 2D-изображение копируется в указанный слой массива 2D-изображений: 2D image **TO** 2D_array[ ***layer*** ] |
| Cube Array | Cube | Указанное исходное кубическое изображение (все 6 граней) копируется в указанный слой массива кубических изображений: cubemap_image **TO** cubemap_array[ ***layer*** ] |
| 2D | Cube | Грань исходного кубического изображения, указанная аргументом layer в диапазоне **[0; 5]**, копируется в 2D-изображение: 2D_image **FROM** cubemap_face[ ***layer*** ] |
| 2D | 2D Array | Указанный слой исходного массива 2D-изображений копируется в 2D-изображение: 2D image **FROM** 2D_array[ ***layer*** ] |
| Cube | Cube Array | Указанный слой исходного массива кубических изображений копируется в кубическое изображение (все 6 граней): cubemap_image **FROM** cubemap_array[ ***layer*** ] |


```cpp
src_image->load(src_image_path);
src_image->convertToFormat(Image::FORMAT_RGB8);// 2D-изображение 1024x1024

dest_image->create2DArray(1024, 1024, 5, Image::FORMAT_RGB8);
dest_image->copy(src_image, 4); // созданное 2D-изображение копируется в 5-й слой массива 2D-изображений

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Image](../../../api/library/common/class.image_cpp.md)> &* **src_image** - Исходное изображение.
- *int* **layer** - Индекс с нуля, определяющий слой/грань, В который или ИЗ которого копируются данные.

### Возвращаемое значение

true, если данные успешно скопированы; иначе false.
