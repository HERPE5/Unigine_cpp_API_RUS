# Unigine.EventConnection Class (CPP)

**Header:** #include <UnigineCallback.h>


Этот класс хранит информацию о связи между событием и обратным вызовом (UnigineCallback.h).


## EventConnection Class

### Методы класса

## void setEnabled ( bool enabled )

Задаёт новое значение, указывающее, включён ли обратный вызов. Если обратный вызов отключён, он не будет вызван при срабатывании события.
### Аргументы

- *bool* **enabled** - Установите **true**, чтобы включить обратный вызов; **false** — чтобы отключить его.

## bool isEnabled () const

Возвращает текущее значение, указывающее, включён ли обратный вызов. Если обратный вызов отключён, он не будет вызван при срабатывании события.
### Возвращаемое значение

**true**, если обратный вызов включён; иначе **false**.
## bool isValid () const

Возвращает текущее значение, указывающее, является ли связь между событием и обратным вызовом действительной.
### Возвращаемое значение

**true**, если связь между событием и обратным вызовом действительна; иначе **false**.
---

## void disconnect ( )

Отменяет связь между событием и обратным вызовом.
