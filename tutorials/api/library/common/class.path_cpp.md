# Unigine::Path Class (CPP)

**Header:** #include <UniginePath.h>


Интерфейс для загрузки, изменения и сохранения путей.


**Путь (path)** — это сплайн, вдоль которого может перемещаться объект. Такие сплайны можно создавать, например, в 3ds Max, а затем [exported](../../../tools/plugins/3dsmax/index.md#path_export) в файл `*.path`. Либо их можно создавать в коде средствами класса *Path*, а затем сохранять в файл `*.path`.


> **Warning:** Между функциями класса *Path* и функциями, связанными с поиском пути (pathfinding), нет связи.


### Создание простого пути из кода


Как было сказано ранее, ассет `*.path` можно создать с помощью кода. В общем случае реализация включает следующие шаги:


- Создать новый экземпляр класса *Path*.
- Добавить точки в путь.
- Сохранить вычисленный путь в файл `*.path`.


Приведённый ниже код создаёт простой путь между двумя контрольными точками и сохраняет его в файл `*.path`.


```cpp
#include "AppWorldLogic.h"
#include <UniginePath.h>

using namespace Unigine;
using namespace Math;

AppWorldLogic::AppWorldLogic()
{}

AppWorldLogic::~AppWorldLogic()
{}

int AppWorldLogic::init()
{
	// задаём контрольные точки
	Vector<Vec3> points;
	points.append({ 0.0, 0.0, 0.0 });
	points.append({ 10.0, 0.0, 0.0 });
	points.append({ 10.0, 10.0, 0.0 });
	points.append({ 0.0, 10.0, 0.0 });

	// создаём новый путь
	PathPtr path = Path::create();

	// добавляем точки в путь
	for (int i = 0; i < points.size(); i++)
	{
		path->addFrame();
		path->setFramePosition(i, points[i]);
		// нормализованное время прохождения точки (0 - начало пути, 1 - конец пути)
		float t = (float)i/(points.size()-1);
		path->setFrameTime(i, t);
	}

	// сохраняем путь
	path->save("test_path.path");

	return 1;
}


```


> **Notice:** Для простоты в примере мы передаём индекс точки в качестве второго аргумента методу *[setFrameTime()](#setFrameTime_int_float_void)*, чтобы прохождение точки занимало одну секунду.

## Math:: vec3 getAngularVelocity ( float time , int loop = 0 )

Возвращает угловую скорость объекта, движущегося вдоль пути, в указанный момент времени. Если путь не зациклен, а указанное время больше текущего времени пути, будет возвращена последняя позиция пути. Если путь зациклен, для отсчёта времени можно использовать несколько циклов.
### Аргументы

- *float* **time** - Время в секундах.
- *int* **loop** - Флаг, указывающий, зациклен ли путь. По умолчанию 0 (путь не зациклен).

### Возвращаемое значение

Угловая скорость. Если количество кадров равно 0 или 1, функция возвращает вектор (0,0,0).
