# Unigine::Signal Class (CPP)

**Header:** #include <UnigineSignal.h>


Этот класс реализует систему сигналов, позволяющую синхронизировать определённые действия с определёнными событиями, происходящими асинхронно.


### Пример


Следующий пример иллюстрирует, как сделать несколько подписок на сигнал и отменить их, когда они больше не нужны, а также как вызывать сигналы при необходимости.


```cpp
#include <UnigineSignal.h>

class MyClass1
{
public:
	MyClass1() {}
	virtual ~MyClass1() {}

	// первая функция обратного вызова, срабатывающая при вызове сигнала
	int MySignalCallback1() {
		// выполняем некоторые действия
		Log::message("REPORT: MySignalCallback1() is called!");

		return 1;
	}
};

// вторая функция обратного вызова, срабатывающая при вызове сигнала
int MySignalCallback2() {
	// выполняем некоторые действия (например, воспроизводим звук)
	Log::message("REPORT: MySignalCallback2() is called!");
	return 1;
}

// объявляем экземпляр MyClass1
MyClass1 MyClass1Instance;

class MyClass2
{
public:
	Signal my_signal;	// объявление сигнала

	int init()
	{
		// подписываем MyClass1Instance на сигнал, добавляя обратный вызов
		my_signal.add(MakeCallback(&MyClass1Instance, &MyClass1::MySignalCallback1));

		// подписываемся на сигнал, добавляя ещё один обратный вызов и сохраняя его идентификатор для последующей отписки
		void *cb2_id = my_signal.add(MakeCallback(MySignalCallback2));

		//...

		// в любой момент, когда нужно, выполняем событие (в этот момент сработают оба обратных вызова)
		my_signal.invoke();

		// отменяем подписку, удаляя обратный вызов по идентификатору
		my_signal.remove(cb2_id);

		return 0;

	}
	int shutdown(){
		// выполняем событие при завершении работы (в этот момент сработает только обратный вызов MyClass1::MySignalCallback1(), поскольку второй уже не подписан)
		my_signal.invoke();
	}
};


```

## void * add ( CallbackBase* callback )

Добавляет функцию обратного вызова, срабатывающую при вызове сигнала (подписка на сигнал). Функции обратного вызова можно использовать для определения конкретных действий, выполняемых при вызове сигнала.
### Аргументы

- *CallbackBase** **callback**

### Возвращаемое значение

Идентификатор добавленного обратного вызова, если обратный вызов успешно добавлен; иначе **nullptr**. Этот идентификатор можно использовать для [removing](#remove_void_ptr_bool) этого обратного вызова при необходимости.
## bool remove ( void* id )

Удаляет указанный обратный вызов из списка обратных вызовов, связанных с сигналом. Функции обратного вызова можно использовать для определения конкретных действий, выполняемых при вызове сигнала.
### Аргументы

- *void** **id** - Идентификатор обратного вызова, полученный при его [adding](#add_CallbackBase_ptr_void_ptr).

### Возвращаемое значение

true, если обратный вызов с указанным идентификатором успешно удалён; иначе false.
## void clear ( )

Очищает список обратных вызовов, подписанных на сигнал (все подписки удаляются).
## bool empty ( ) const

Возвращает значение, указывающее, пуст ли список подписок на сигнал.
### Возвращаемое значение

true, если список подписок на сигнал пуст, иначе false.
## int size ( ) const

Возвращает общее количество функций обратного вызова, подписанных на сигнал.
### Возвращаемое значение

Количество подписок на сигнал.
## template<typename ... Ts> invoke ( Ts&& args )

Вызывает сигнал. Функции обратного вызова, подписанные на этот сигнал, выполняются в порядке их следования в списке.
### Аргументы

- *Ts&&* **args**

## void swap ( Signal& first , Signal& second )

Меняет местами два указанных сигнала.
### Аргументы

- *Signal&* **first** - Первый сигнал.
- *Signal&* **second** - Второй сигнал.
