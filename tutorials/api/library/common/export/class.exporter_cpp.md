# Unigine::Exporter Class (CPP)

**Header:** #include <UnigineExport.h>


Этот класс используется для управления экспортёром узлов. Экспортёры узлов используются [export system](../../../../principles/export_system/index.md) движка для экспорта узлов UNIGINE в файлы различных форматов. Один экспортёр может использоваться для экспорта нескольких узлов, но **для одного типа узла не должно быть [registered](../../../../api/library/common/export/class.export_cpp.md#registerExporter_const_char_ptr_const_Vectortmplargs_ref_void) двух или более экспортёров**.


Каждый экспортёр имеет набор параметров, управляющих всем процессом экспорта (например, экспортировать ли источники света, камеры и карты нормалей материалов, сбрасывать ли трансформацию корневого узла и т. д.). Перед использованием экспортёр должен быть [initialized](../../../../api/library/common/export/class.exporter_cpp.md#init_int).


> **Notice:** Это базовый класс для всех экспортёров. Ваш пользовательский класс экспортёра должен быть унаследован от него.

## int containsParameter ( const char* name ) const

Возвращает значение, указывающее, содержит ли список параметров экспорта параметр с указанным именем.
### Аргументы

- *const char** **name** - Имя параметра.

### Возвращаемое значение

1, если список параметров экспорта содержит параметр с указанным именем; иначе 0.

## int init ( )

Инициализирует экспортёр.
## int doExport ( const NodePtr& root_node , const char* output_filepath )

Экспортирует узел в указанный выходной файл.
> **Notice:** Чтобы настроить действия, выполняемые при обработке экспорта узла, вы можете переопределить метод [*onExport()*](#onExport_const_NodePtr_ref_const_char_ptr_bool).


### Аргументы

- *const NodePtr&* **root_node** - Корневой узел иерархии для экспорта.
- *const char** **output_filepath** - Выходной путь для сохранения сгенерированных файлов с экспортированными данными.

## void deinit ( )

## bool onInit ( )

Инициализирует экспортёр. Эта функция вызывается каждый раз при вызове функции [init()](#init_int). Вы можете задать собственные действия, выполняемые при инициализации экспортёра.
## bool onExport ( const NodePtr& root_node , const char* output_filepath )

Функция-обработчик события обработки экспорта узла. Эта функция вызывается каждый раз при вызове функции [doExport()](#doExport_const_NodePtr_ref_const_char_ptr_int). Вы можете задать собственные действия, выполняемые при обработке экспорта узла.
### Аргументы

- *const NodePtr&* **root_node** - Корневой узел иерархии для экспорта.
- *const char** **output_filepath** - Выходной путь для сохранения сгенерированных файлов с экспортированными данными.

### Возвращаемое значение

true, если операция экспорта для указанного выходного пути была успешной; иначе false.
## void onDeinit ( )
