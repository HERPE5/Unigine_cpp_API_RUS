# Unigine::Plugin Class (CPP)

**Header:** #include <UniginePlugin.h>


Класс Plugin Unigine позволяет динамически загружать пользовательскую библиотеку во время выполнения Unigine.


## Plugin Class

### Методы класса

---

## virtual void * get_data ( )

Возвращает данные плагина.
### Возвращаемое значение

Данные плагина.
## virtual const char * get_name ( )

Возвращает имя плагина.
### Возвращаемое значение

Имя плагина.
## int get_order ( )

Возвращает порядок выполнения плагина. Каждый плагин имеет свой порядок выполнения, который определяет последовательность, в которой будут выполняться функции плагина (*[update](#update_void) / [postUpdate](#postUpdate_void) / [render](#render_const_EngineWindowViewportPtr_ref_void) / [shutdown](#shutdown_int)*). Единственное исключение — функция [*init*](#init_int), поскольку она вызывается сразу после загрузки плагина.
> **Notice:** Помните, что при [writing your own plugin](../../../code/cpp/plugin.md), который требует взаимодействия с другими плагинами, необходимо указывать правильное значение порядка, чтобы избежать проблем и обеспечить правильную последовательность выполнения. Если в вашем случае порядок не важен, установите значение по умолчанию 0.


### Возвращаемое значение

Порядок выполнения плагина.
## virtual int getCompilationFlags ( ) const

Возвращает флаги компиляции Unigine.
### Возвращаемое значение

Флаги компиляции Unigine.
## virtual void updatePhysics ( )

Движок вызывает эту функцию перед обновлением каждого физического кадра.
## virtual void gui ( EngineWindowViewportPtr& window )

Движок вызывает эту функцию перед gui каждого кадра рендеринга для указанного окна просмотра движка.
### Аргументы

- *EngineWindowViewportPtr&* **window** - Целевое окно просмотра движка.

## virtual int init ( )

Движок вызывает эту функцию при инициализации плагина.
### Возвращаемое значение

true при успехе, или false, если произошла ошибка.
## virtual bool loadWorld ( const Xml Ptr & xml )

Движок вызывает эту функцию при загрузке мира.
### Аргументы

- *const [Xml](../../../api/library/common/class.xml_cpp.md)Ptr &* **xml** - Экземпляр Xml, из которого загружаются данные.

### Возвращаемое значение

true при успехе; иначе false.
## virtual void render ( const EngineWindowViewportPtr& window )

Движок вызывает эту функцию перед рендерингом каждого кадра рендеринга для указанного окна просмотра движка.
### Аргументы

- *const EngineWindowViewportPtr&* **window** - Целевое окно просмотра движка.

## virtual int saveWorld ( const Xml Ptr & xml )

Движок вызывает эту функцию при сохранении мира.
### Аргументы

- *const [Xml](../../../api/library/common/class.xml_cpp.md)Ptr &* **xml** - Экземпляр Xml, в который сохраняются данные.

### Возвращаемое значение

Возвращает **1** при успехе, или 0, если произошла ошибка.
## virtual int shutdown ( )

Движок вызывает эту функцию при завершении работы плагина.
### Возвращаемое значение

Возвращает **1** при успехе, или 0, если произошла ошибка.
## virtual void swap ( )

Движок вызывает эту функцию перед свопом каждого кадра рендеринга.
## virtual void update ( )

Движок вызывает эту функцию перед обновлением каждого кадра рендеринга.
## void postUpdate ( )

Движок вызывает эту функцию после обновления каждого кадра рендеринга.
