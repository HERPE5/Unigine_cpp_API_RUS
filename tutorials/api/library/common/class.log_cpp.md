# Unigine::Log Class (CPP)

**Header:** #include <UnigineLog.h>


Этот класс представляет собой интерфейс для вывода различных типов сообщений в [console](../../../code/console/index.md) и в файл лога движка. Это может быть полезно для отслеживания общего хода выполнения приложения и сообщения об ошибках, что может помочь в процессе отладки.


> **Notice:** Чтобы включить отображение системных сообщений в консоли, используйте следующую команду: [`console_onscreen 1`](../../../code/console/index.md#console_onscreen)


В SDK включены две пользовательские цветовые схемы для подсветки синтаксиса лога для Notepad++:


- `<SDK>/utils/log_styles/notepad_light.xml`
- `<SDK>/utils/log_styles/notepad_dark.xml`


> **Notice:** По умолчанию все записанные сообщения сохраняются в файл лога движка и выводятся в stdout, причём последнее **может значительно повлиять на производительность** при большом объёме логирования. Если логирование вызывает проблемы с производительностью, можно управлять этими двумя целями логирования через следующие консольные команды:
> - [`log_stdout`](../../../code/console/index.md#log_stdout)
> - [`log_file`](../../../code/console/index.md#log_file)


### Пример


Следующий код демонстрирует, как выводить различные типы сообщений.


```cpp
using namespace Unigine;

// вспомогательные переменные для сообщений
const char* file_name = "file.txt";
int ID = 10;

	// сообщение об ошибке
	Log::error("Loading mesh: can't open \"%s\" file\n", file_name);

	// обычное сообщение
	Log::message("-> Added %d UI elements.\n", ID);

	// предупреждающее сообщение
	Log::warning("ID of the \"%s\" file: %d.\n", file_name, ID);

	// сообщение о критической ошибке в файл лога и закрытие приложения (только Windows)
	Log::fatal("FATAL ERROR reading \"%s\" file!\n", file_name);


```


### Обработка событий


Вы можете [subscribe for events](#getEventMessage_Event) для определения пользовательских действий для различных типов сообщений, выводимых в *Log*. Сигнатура функции-обработчика должна быть следующей:

```cpp
void handler_function_name(const char * message_text);
```

 Вот пример отслеживания сообщений об ошибках через обработчики событий:
```cpp
void error_handler(const char * message_text)
{
	std::cout<<"My message is: "<<message_text<<std::endl;
    // ...
}

// где-то в коде

// подписываемся на событие Error нашей функцией-обработчиком
Log::getEventError().connect(error_handler);

// выводим сообщение об ошибке в Log
Log::error("An ERROR has occurred!\n");

```


## Log Class

### Методы класса

## void setDialogFatalEnabled ( bool enabled )

Задаёт новое значение, указывающее, включено ли отображение диалоговых сообщений *Fatal* (при отключении соответствующее сообщение будет выведено в лог). Может использоваться, например, для отключения при запуске консольных инструментов, таких как *[Runtimes Generator](../../../tools/runtimes_generator/index.md)* или *[Build Tool](../../../editor2/projects/build_project.md#console_build)* (используйте команду `-dialog_fatal_enabled`).
> **Notice:** Доступно только для Windows.

### Аргументы

- *bool* **enabled** - **true**, чтобы включить отображение диалоговых сообщений *Fatal*; **false** - чтобы отключить его.

## bool isDialogFatalEnabled () const

Возвращает текущее значение, указывающее, включено ли отображение диалоговых сообщений *Fatal* (при отключении соответствующее сообщение будет выведено в лог). Может использоваться, например, для отключения при запуске консольных инструментов, таких как *[Runtimes Generator](../../../tools/runtimes_generator/index.md)* или *[Build Tool](../../../editor2/projects/build_project.md#console_build)* (используйте команду `-dialog_fatal_enabled`).
> **Notice:** Доступно только для Windows.

### Возвращаемое значение

**true**, если отображение диалоговых сообщений *Fatal* включено; иначе **false**.
## Event<const char*> getEventMessage () const

Событие, вызываемое при выводе сообщения в лог. Вы можете подписываться на события через *connect()* и отписываться через *disconnect()*. Также для удобства можно использовать классы *[EventConnection](../../../api/library/common/events/class.eventconnection_cpp.md)* и *[EventConnections](../../../api/library/common/events/class.eventconnections_cpp.md)* (см. примеры ниже).

<details>
<summary>Показать пример | Скрыть</summary>

**Пример использования**


```cpp
// реализация обработчика события Message
void message_event_handler(const char * text)
{
	// Обработка события Message...
}

//////////////////////////////////////////////////////////////////////////////
//  1. Несколько подписок можно связать с экземпляром класса EventConnections,
//  который затем можно использовать для отмены всех этих подписок сразу
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnections
EventConnections message_event_connections;

// связываем с этим экземпляром при подписке на событие (можно связывать подписки на разные события)
Log::getEventMessage().connect(message_event_connections, message_event_handler);

// другие подписки также связаны с этим экземпляром EventConnections
// (например, можно подписываться с помощью лямбда-функций)
Log::getEventMessage().connect(message_event_connections, [](const char * text) {
		// Обработка события Message (лямбда)...
	}
);

// ...

// позже все эти связанные подписки можно удалить одной строкой
message_event_connections.disconnectAll();

//////////////////////////////////////////////////////////////////////////////
//  2. Можно подписываться и отписываться через экземпляр класса EventConnection.
//  А также включать и отключать это конкретное соединение при необходимости.
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnection
EventConnection message_event_connection;

// подписываемся на событие Message с функцией-обработчиком, сохраняя соединение
Log::getEventMessage().connect(message_event_connection, message_event_handler);

// ...

// можно временно отключить конкретное соединение события для выполнения определённых действий
message_event_connection.setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
message_event_connection.setEnabled(true);

// ...

// удаляем подписку на событие Message через соединение
message_event_connection.disconnect();

//////////////////////////////////////////////////////////////////////////////
//  3. Можно добавить экземпляр EventConnection/EventConnections как член класса,
//  обрабатывающего событие. В этом случае все связанные подписки будут
//  автоматически удалены при вызове деструктора класса
//////////////////////////////////////////////////////////////////////////////

// Класс, обрабатывающий событие
class SomeClass
{
public:
	// экземпляр класса EventConnections как член класса
	EventConnections e_connections;

	// Обработчик события Message, реализованный как член класса
	void event_handler(const char * text)
	{
		// Обработка события Message...
		// ...
	}
};

SomeClass *sc = new SomeClass();

// ...

// указываем экземпляр класса, если метод-обработчик принадлежит какому-либо классу
Log::getEventMessage().connect(sc->e_connections, sc, &SomeClass::event_handler);

// ...

// экземпляр класса-обработчика удаляется, а все его подписки автоматически отменяются
delete sc;

//////////////////////////////////////////////////////////////////////////////
//  4. Можно подписываться и отписываться через функцию-обработчик напрямую
//////////////////////////////////////////////////////////////////////////////

// подписываемся на событие Message с функцией-обработчиком
Log::getEventMessage().connect(message_event_handler);

// удаляем подписку на событие Message позже по функции-обработчику
Log::getEventMessage().disconnect(message_event_handler);

//////////////////////////////////////////////////////////////////////////////
//   5. Подписка на событие с сохранением идентификатора и последующей отпиской по этому идентификатору
//////////////////////////////////////////////////////////////////////////////

// определяем идентификатор соединения, который будет использован для отписки позже
EventConnectionId message_handler_id;

// подписываемся на событие Message с лямбда-обработчиком, сохраняя идентификатор соединения
message_handler_id = Log::getEventMessage().connect([](const char * text) {
		// Обработка события Message (лямбда)...
	}
);

// удаляем подписку позже, используя идентификатор
Log::getEventMessage().disconnect(message_handler_id);

//////////////////////////////////////////////////////////////////////////////
//   6. Игнорирование всех событий Message при необходимости
//////////////////////////////////////////////////////////////////////////////

// можно временно отключить событие для выполнения определённых действий без его срабатывания
Log::getEventMessage().setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
Log::getEventMessage().setEnabled(true);
```

// (например, можно подписываться с помощью лямбда-функций)
Log::getEventFatal().connect(fatal_event_connections, [](const char * text) {
		// Обработка события Fatal (лямбда)...
	}
);

// ...

// позже все эти связанные подписки можно удалить одной строкой
fatal_event_connections.disconnectAll();

//////////////////////////////////////////////////////////////////////////////
//  2. Можно подписываться и отписываться через экземпляр класса EventConnection.
//  А также включать и отключать это конкретное соединение при необходимости.
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnection
EventConnection fatal_event_connection;

// подписываемся на событие Fatal с функцией-обработчиком, сохраняя соединение
Log::getEventFatal().connect(fatal_event_connection, fatal_event_handler);

// ...

// можно временно отключить конкретное соединение события для выполнения определённых действий
fatal_event_connection.setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
fatal_event_connection.setEnabled(true);

// ...

// удаляем подписку на событие Fatal через соединение
fatal_event_connection.disconnect();

//////////////////////////////////////////////////////////////////////////////
//  3. Можно добавить экземпляр EventConnection/EventConnections как член класса,
//  обрабатывающего событие. В этом случае все связанные подписки будут
//  автоматически удалены при вызове деструктора класса
//////////////////////////////////////////////////////////////////////////////

// Класс, обрабатывающий событие
class SomeClass
{
public:
	// экземпляр класса EventConnections как член класса
	EventConnections e_connections;

	// Обработчик события Fatal, реализованный как член класса
	void event_handler(const char * text)
	{
		// Обработка события Fatal...
		// ...
	}
};

SomeClass *sc = new SomeClass();

// ...

// указываем экземпляр класса, если метод-обработчик принадлежит какому-либо классу
Log::getEventFatal().connect(sc->e_connections, sc, &SomeClass::event_handler);

// ...

// экземпляр класса-обработчика удаляется, а все его подписки автоматически отменяются
delete sc;

//////////////////////////////////////////////////////////////////////////////
//  4. Можно подписываться и отписываться через функцию-обработчик напрямую
//////////////////////////////////////////////////////////////////////////////

// подписываемся на событие Fatal с функцией-обработчиком
Log::getEventFatal().connect(fatal_event_handler);

// удаляем подписку на событие Fatal позже по функции-обработчику
Log::getEventFatal().disconnect(fatal_event_handler);

//////////////////////////////////////////////////////////////////////////////
//   5. Подписка на событие с сохранением идентификатора и последующей отпиской по этому идентификатору
//////////////////////////////////////////////////////////////////////////////

// определяем идентификатор соединения, который будет использован для отписки позже
EventConnectionId fatal_handler_id;

// подписываемся на событие Fatal с лямбда-обработчиком, сохраняя идентификатор соединения
fatal_handler_id = Log::getEventFatal().connect([](const char * text) {
		// Обработка события Fatal (лямбда)...
	}
);

// удаляем подписку позже, используя идентификатор
Log::getEventFatal().disconnect(fatal_handler_id);

//////////////////////////////////////////////////////////////////////////////
//   6. Игнорирование всех событий Fatal при необходимости
//////////////////////////////////////////////////////////////////////////////

// можно временно отключить событие для выполнения определённых действий без его срабатывания
Log::getEventFatal().setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
Log::getEventFatal().setEnabled(true);

## void error ( const char * format , ... )

Выводит сообщение об ошибке в консоль и файл лога.
### Аргументы

- *const char ** **format** - Сообщение об ошибке для вывода.
- *...*  - Аргументы, допускается несколько.

## void fatal ( const char * format , ... )

Выводит сообщение о критической ошибке в файл лога и завершает работу движка.
> **Notice:** Available for Windows OS only.

### Аргументы

- *const char ** **format** - Сообщение о критической ошибке для вывода.
- *...*  - Аргументы, допускается несколько.

## void message ( const char * format , ... )

Выводит сообщение в консоль и файл лога.
### Аргументы

- *const char ** **format** - Сообщение для вывода.
- *...*  - Аргументы, допускается несколько.

## void warning ( const char * format , ... )

Выводит предупреждение в консоль и файл лога.
### Аргументы

- *const char ** **format** - Предупреждение для вывода.
- *...*  - Аргументы, допускается несколько.
