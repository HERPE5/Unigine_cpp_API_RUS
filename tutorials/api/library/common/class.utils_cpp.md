## int convertHeightsToNormals ( Image Ptr & out , const Image Ptr & heights , float step_size )

Преобразует карту высот в карту нормалей.
### Аргументы

- *[Image](../../../api/library/common/class.image_cpp.md)Ptr &* **out** - Указатель на целевую карту нормалей.
- *const [Image](../../../api/library/common/class.image_cpp.md)Ptr &* **heights** - Исходная карта высот.
- *float* **step_size** - Шаг ячейки сетки.

### Возвращаемое значение

1, если преобразование выполнено успешно; иначе 0.

## Node Ptr loadObjectMesh ( const char * name )

Загружает меш из файла. Если меш успешно загружен, его узел не принадлежит никакой иерархии узлов, поэтому будьте внимательны и не забудьте правильно обработать его, когда он больше не будет нужен.
### Аргументы

- *const char ** **name** - Путь к мешу.

### Возвращаемое значение

Указатель на узел, соответствующий загруженному мешу; **0**, если меш не может быть загружен.
## int makeNodeCurved ( const Ptr < Node > & node )

Изгибает указанный узел, используя его геодезическую опору.
> **Notice:** Узел должен быть дочерним для узла [geodetic pivot](../../../api/library/geodetics/class.geodeticpivot_cpp.md).


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Node](../../../api/library/nodes/class.node_cpp.md)> &* **node** - Указатель на узел, который нужно изогнуть.

### Возвращаемое значение

1, если узел успешно изогнут; иначе 0.
