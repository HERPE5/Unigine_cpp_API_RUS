# Unigine::Compress Class (CPP)

**Header:** #include <UnigineCompress.h>


Класс Compress используется для сжатия и распаковки данных с использованием следующих алгоритмов:

- **Jackalless** — рекомендуется. Метод сжатия UNIGINE, оптимизированный для сжатия 2D- и 3D-текстур. Он даёт лучшие результаты, чем **LZ4** и **Zlib**, не ухудшая качество.
- **LZ4** — временный вариант, планируется к удалению в будущих релизах.
- **Zlib** — для высокого коэффициента сжатия (может обеспечить коэффициент сжатия до 2 раз выше, но занимает до 20 раз больше времени).


## Compress Class

### Методы класса

---

## bool zlibCompress ( void* dest , size_t& dest_size , const void* src , size_t src_size , bool quality )

Сжимает исходные данные с использованием алгоритма Zlib с указанным уровнем сжатия и помещает результат в указанный приёмник.
### Аргументы

- *void** **dest** - Указатель на буфер назначения.
- *size_t&* **dest_size** - Размер данных назначения.
- *const void** **src** - Указатель на исходный буфер.
- *size_t* **src_size** - Размер исходных данных.
- *bool* **quality** - Качество сжатия; false — для более быстрого сжатия, true — для более высокого сжатия (меньший размер).

### Возвращаемое значение

true, если операция выполнена успешно; иначе false.
