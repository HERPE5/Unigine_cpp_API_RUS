# Unigine::RegExp Class (CPP)

**Header:** #include <UnigineRegExp.h>


Этот класс предоставляет функциональность, необходимую для работы с регулярными выражениями. Помимо этого класса, есть несколько функций, которые могут быть удобнее в использовании, но они несколько медленнее, поскольку при каждом вызове компилируется новое регулярное выражение. Эти функции:

- *re_match()*
- *re_replace()*
- *re_search()*


Регулярные выражения — это шаблоны, описывающие наборы строк. Отдельные символы являются основными строительными блоками регулярных выражений. Однако в выражениях используется несколько операторов для правильной организации символов.


**.** (точка) соответствует любому символу.


После каждого регулярного выражения может следовать модификатор, задающий количество повторений.


***** — модификатор, означающий "от **0** до **бесконечности** повторений заданного символа или последовательности".


**+** — модификатор, означающий "от **1** до **бесконечности** повторений заданного символа или последовательности".


**?** — модификатор, означающий "либо **0**, либо **1** повторение заданного символа или последовательности".


**[]** задают класс символов — набор символов, любому из которых может соответствовать совпадение. Символы можно перечислять по одному, либо как диапазон символов. В последнем случае два крайних символа разделяются знаком **-**. Примеры: *[abc]*, *[a-c]*. Оператор **^** имеет особое значение внутри классов.


**\** начинает escape-последовательность, если за ним следует один из символов-операторов, либо начинает одну из специальных последовательностей:

- **\w** соответствует любому буквенно-цифровому символу. Эквивалентно **[a-zA-Z0-9_]**.
- **\W** соответствует любому небуквенно-цифровому символу. Эквивалентно **[^a-zA-Z0-9_]**.
- **\b** соответствует границе слова. Слово — это последовательность буквенно-цифровых символов, поэтому его конец обозначается пробелом или небуквенно-цифровым символом. Это утверждение нулевой ширины.
- **\B** соответствует только внутри слова. Это утверждение нулевой ширины.


**()** обозначают группу. Группы задают различные компоненты одного шаблона. Пример: *Mr. (\w+) (\w+)*.


**^** задаёт начало строки или означает дополнение, если используется как первый символ между **[** и **]**.


**$** задаёт конец строки.


**|** задаёт альтернативу. Соответствует любой строке, которая соответствует любому из операндов. Примеры: *milk|honey*.


*[abcd$]* соответствует любому из следующего: "a", "b", "c", "d", "$".


*[^5]* соответствует любому символу, кроме "5".


*.** соответствует чему угодно.


*home-?brew* соответствует либо "homebrew", либо "home-brew".


*bra+in[sz]* соответствует "brains", или "brainz", или "braains" и т.д.


*(\w+), let's go (.+)* соответствует, например, "Andy, let's go for a walk" и даёт две группы: "Andy" и "for a walk".


## RegExp Class

### Методы класса

---

## static RegExpPtr create ( )

Конструктор по умолчанию, создающий пустой экземпляр.
## static RegExpPtr create ( const char * pattern )

Конструктор, создающий регулярное выражение на основе указанного шаблона.
### Аргументы

- *const char ** **pattern** - Шаблон для использования при сопоставлении.

## int isCompiled ( )

Возвращает значение, указывающее, скомпилирован ли текущий шаблон и, следовательно, может ли он использоваться для сопоставления.
### Возвращаемое значение

**1**, если шаблон скомпилирован; иначе **0**.
## const char * getGroup ( int number )

Возвращает частичное совпадение, соответствующее указанной группе. Группы — это части шаблона, соответствующие разным компонентам; они обозначаются круглыми скобками (**()**) в шаблоне. Группы нумеруются начиная с **0** слева направо.
### Аргументы

- *int* **number** - Неотрицательный номер нужной группы. Номер не должен превышать значение, возвращаемое [*getNumGroups()*](#getNumGroups_int).

### Возвращаемое значение

Частичное совпадение, соответствующее группе.
## int getNumGroups ( )

Возвращает количество групп в текущем шаблоне. Группы обозначаются круглыми скобками (**()**) и нумеруются начиная с **0** слева направо.
### Возвращаемое значение

Количество групп в текущем шаблоне.
## int compile ( const char * pattern )

Компилирует указанный шаблон регулярного выражения. Это выражение будет использоваться для последующих сопоставлений.
### Аргументы

- *const char ** **pattern** - Шаблон, используемый для сопоставления и т.д.

### Возвращаемое значение

**1**, если шаблон успешно скомпилирован; иначе **0**.
## int match ( const char * str )

Сопоставляет шаблон со строкой.
### Аргументы

- *const char ** **str** - Строка для сопоставления.

### Возвращаемое значение

**1**, если вся строка совпадает; иначе **0**.
## String replace ( const char * str , const char * after )

Ищет шаблон в указанной строке и заменяет все его вхождения другой строкой.
### Аргументы

- *const char ** **str** - Строка для поиска и замены.
- *const char ** **after** - Строка замены.

### Возвращаемое значение

Изменённая строка.
## int search ( const char * str )

Ищет подстроку, соответствующую шаблону, в указанной строке.
### Аргументы

- *const char ** **str** - Строка для поиска.

### Возвращаемое значение

Количество групп в шаблоне, если совпадение найдено; иначе **0**.
