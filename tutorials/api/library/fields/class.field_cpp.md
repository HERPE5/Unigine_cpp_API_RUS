# Класс Unigine.Field (CPP)

**Заголовочный файл:** #include <UnigineFields.h>

**Наследуется от:** Node


Этот класс позволяет изменять маски [fields](../../../objects/effects/fields/index.md).


## Класс Field

### Методы класса

## void setViewportMask ( int mask )

Устанавливает новую битовую маску для отображения узла поля во вьюпорте.
### Аргументы

- *int* **mask** - Целочисленное значение, каждый бит которого используется для задания маски.

## int getViewportMask () const

Возвращает текущую битовую маску для отображения узла поля во вьюпорте.
### Возвращаемое значение

Текущее целочисленное значение, каждый бит которого используется для задания маски.
## void setFieldMask ( int mask )

Устанавливает новую маску, определяющую область применения узла Field. Объект будет подвержен влиянию поля, если у них обоих [matching masks](../../../principles/bit_masking/index.md).
### Аргументы

- *int* **mask** - Целочисленное значение, каждый бит которого используется для задания маски.

## int getFieldMask () const

Возвращает текущую маску, определяющую область применения узла Field. Объект будет подвержен влиянию поля, если у них обоих [matching masks](../../../principles/bit_masking/index.md).
### Возвращаемое значение

Текущее целочисленное значение, каждый бит которого используется для задания маски.
