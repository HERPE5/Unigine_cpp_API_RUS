## Класс FieldSpacer

### Методы класса

## void setAttenuation ( float attenuation )

Устанавливает новый коэффициент затухания для Field Spacer.
### Аргументы

- *float* **attenuation** - Значение коэффициента затухания. Этот коэффициент показывает, насколько постепенно вырезается геометрия, начиная от центра Field Spacer: Если указано слишком малое значение, вместо него будет использовано 1E-6.

  - При минимальном значении 0 будет отображаться вся геометрия внутри Field Spacer.
  - Чем выше значение, тем меньше геометрии будет отображаться внутри Field Spacer.

## float getAttenuation () const

Возвращает текущий коэффициент затухания для Field Spacer.
### Возвращаемое значение

Текущее значение коэффициента затухания. Этот коэффициент показывает, насколько постепенно вырезается геометрия, начиная от центра Field Spacer:
- При минимальном значении 0 будет отображаться вся геометрия внутри Field Spacer.
- Чем выше значение, тем меньше геометрии будет отображаться внутри Field Spacer.

 Если указано слишком малое значение, вместо него будет использовано 1E-6.
## void setSize ( const Math:: vec3 & size )

Устанавливает новый размер Field Spacer. Для поля кубической формы задаётся размер куба, для поля эллиптической формы — радиус.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md)&* **size** - Размер field spacer. Вектор [vec3](../../../api/library/math/class.vec3_cpp.md) с компонентами, представляющими размеры по осям **X**, **Y** и **Z**, в единицах. Если указано отрицательное значение, вместо него будет использовано 0.

## Math:: vec3 getSize () const

Возвращает текущий размер Field Spacer. Для поля кубической формы задаётся размер куба, для поля эллиптической формы — радиус.
### Возвращаемое значение

Текущий размер field spacer. Вектор [vec3](../../../api/library/math/class.vec3_cpp.md) с компонентами, представляющими размеры по осям **X**, **Y** и **Z**, в единицах. Если указано отрицательное значение, вместо него будет использовано 0.
## void setEllipse ( bool ellipse )

Устанавливает новое значение, указывающее, имеет ли Field Spacer эллиптическую или кубическую форму.
### Аргументы

- *bool* **ellipse** - Установите **true**, чтобы включить эллиптическую форму Field Spacer; **false** - чтобы отключить её.

## bool isEllipse () const

Возвращает текущее значение, указывающее, имеет ли Field Spacer эллиптическую или кубическую форму.
### Возвращаемое значение

**true**, если эллиптическая форма Field Spacer включена; иначе **false**.

## static FieldSpacerPtr create ( const Math:: vec3 & size )

Создаёт новый Field Spacer указанного размера:
- Если Field Spacer имеет эллиптическую форму, необходимо указать значения радиуса по осям.
- В противном случае необходимо указать размеры куба.


### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **size** - Размер Field Spacer по осям *X*, *Y* и *Z* в единицах.

## static int type ( )

### Возвращаемое значение

Идентификатор типа [FieldSpacer](../../../api/library/nodes/class.node_cpp.md#FIELD_SPACER).
