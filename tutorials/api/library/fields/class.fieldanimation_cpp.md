## void setAttenuation ( float attenuation )

Устанавливает новый коэффициент затухания для анимации поля. Это значение показывает, насколько сильно анимация затухает от центра поля анимации к его краям:
- При минимальном значении 0 анимация не будет видна.
- Чем выше значение, тем интенсивнее будет анимация на краях поля анимации.


### Аргументы

- *float* **attenuation** - Значение коэффициента затухания. Если указано слишком малое значение, вместо него будет использовано 1E-6.

## float getAttenuation () const

Возвращает текущий коэффициент затухания для анимации поля. Это значение показывает, насколько сильно анимация затухает от центра поля анимации к его краям:
- При минимальном значении 0 анимация не будет видна.
- Чем выше значение, тем интенсивнее будет анимация на краях поля анимации.


### Возвращаемое значение

Текущее значение коэффициента затухания. Если указано слишком малое значение, вместо него будет использовано 1E-6.
## void setSize ( const Math:: vec3 & size )

Устанавливает новый размер поля анимации. Для поля кубической формы задаётся размер куба, для поля эллиптической формы — радиус.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md)&* **size** - Размер поля анимации по осям X, Y и Z в единицах.

## Math:: vec3 getSize () const

Возвращает текущий размер поля анимации. Для поля кубической формы задаётся размер куба, для поля эллиптической формы — радиус.
### Возвращаемое значение

Текущий размер поля анимации по осям X, Y и Z в единицах.
## void setEllipse ( bool ellipse )

Устанавливает новое значение, указывающее, имеет ли анимация поля эллиптическую или кубическую форму.
### Аргументы

- *bool* **ellipse** - Установите **true**, чтобы включить эллиптическую форму анимации поля; **false** - чтобы отключить её.

## bool isEllipse () const

Возвращает текущее значение, указывающее, имеет ли анимация поля эллиптическую или кубическую форму.
### Возвращаемое значение

**true**, если эллиптическая форма анимации поля включена; иначе **false**.

## static FieldAnimationPtr create ( const Math:: vec3 & size )

Создаёт новый узел Field Animation указанного размера:
- Если анимация поля имеет эллиптическую форму, необходимо указать значения радиуса по осям.
- В противном случае необходимо указать размеры куба.


### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **size** - Размер Field Animation по осям X, Y и Z в единицах.

## static int type ( )

Возвращает тип объекта.
### Возвращаемое значение

Идентификатор типа [FieldAnimation](../../../api/library/nodes/class.node_cpp.md#FIELD_ANIMATION).
