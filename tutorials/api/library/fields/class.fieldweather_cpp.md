# Класс Unigine.FieldWeather (CPP)

**Заголовочный файл:** #include <UnigineFields.h>

**Наследуется от:** Field


Этот класс используется для создания и изменения [weather field](../../../objects/effects/fields/field_weather/index.md). Поле применяется к [CloudLayer object](../../../api/library/objects/class.objectcloudlayer_cpp.md) и определяет локальную область погоды. Этот тип поля позволяет создавать локальные штормы или облака с собственной текстурой покрытия, а также управлять их движением.

> **Notice:** Количество weather-полей на сцене не ограничено, так как их влияние на производительность незначительно.


### Создание поля погоды


> **Notice:** При создании узла FieldWeather следует указать для него текстуру покрытия, так как у него нет текстуры по умолчанию.


```cpp
// создаём новый экземпляр класса FieldWeather и задаём его трансформацию
FieldWeatherPtr weather = FieldWeather::create();
weather->setTransform(Mat4(1));
// задаём размер поля
weather->setSize(vec3(4096.0f, 4096.0f, 4096.0f));
// задаём текстуру покрытия
weather->setTexturePath("unigine_project/textures/coverage.png");

```

## void setWindAnimation ( const Math:: vec3 & animation )

Устанавливает новую скорость локального ветра в направлениях **X**, **Y** и **Z**. Ветер вдоль осей **X** и **Y** смещает локальную текстуру покрытия с указанными скоростями в соответствующих направлениях. Этот параметр можно использовать для анимации облаков внутри поля погоды. Смещение текстуры зациклено внутри поля, так как ветер влияет только на её смещение.
> **Notice:** Установка значений скорости ветра в 0 не возвращает текстуру в исходное состояние. Чтобы вернуть исходное состояние, отключите локальный ветер с помощью метода [setWindEnabled()](#setWindEnabled_int_void).


### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md)&* **animation** - Вектор [vec3](../../../api/library/math/class.vec3_cpp.md) скорости локального ветра с компонентами, представляющими значения скорости ветра в направлениях **X**, **Y** и **Z**.
