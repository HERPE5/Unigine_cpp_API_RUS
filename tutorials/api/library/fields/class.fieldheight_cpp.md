# Класс FieldHeight (CPP)

**Заголовочный файл:** #include <UnigineFields.h>

**Наследуется от:** Field


Этот класс используется для создания и изменения [field height](../../../objects/effects/fields/field_height/index.md). Поле применяется к [global water](../../../api/library/objects/class.objectwaterglobal_cpp.md) и определяет области, в которых должна изменяться высота волн.

> **Notice:** Максимальное количество отображаемых объектов FieldHeight на кадр/битовую маску — **8**.


### Создание поля высот


> **Notice:** При создании объекта FieldHeight следует указать для него текстуру карты высот, так как у этого объекта нет текстуры по умолчанию.


```cpp
// создаём новый экземпляр класса FieldHeight и задаём его трансформацию
FieldHeightPtr height = FieldHeight::create();
height->setTransform(Mat4(1));
// задаём размер поля
height->setSize(vec3(4096.0f, 4096.0f, 512.0f));
// задаём текстуру карты высот
height->setTexturePath("unigine_project/textures/fh_static.png");

```

## void setTexture ( const Ptr < Texture >& texture )

Устанавливает новую текстуру карты высот для FieldHeight. При необходимости текущая текстура получается с GPU и сохраняется в экземпляр текстуры.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Texture](../../../api/library/rendering/class.texture_cpp.md)>&* **texture** - Экземпляр текстуры.

## Ptr < Texture > getTexture () const

Возвращает текущую текстуру карты высот для FieldHeight. При необходимости текущая текстура получается с GPU и сохраняется в экземпляр текстуры.
### Возвращаемое значение

Текущий экземпляр текстуры.

### Аргументы

## const char * getTexturePath () const

Возвращает текущий путь к текстуре карты высот FieldHeight.
### Возвращаемое значение

Текущий путь к текстуре карты высот.
## void setBlendMode ( int mode )

Устанавливает новый режим смешивания для поля высот.
> **Notice:** Параметр затухания интерпретируется в зависимости от выбранного режима смешивания:
> - используется как множитель для аддитивного режима
> - для мультипликативного режима используется lerp(1.0f, value, attenuation)


### Аргументы

- *int* **mode** - Режим смешивания, одно из значений [BLEND_*](#BLEND_ADDITIVE).

## int getBlendMode () const

Возвращает текущий режим смешивания для поля высот.
> **Notice:** Параметр затухания интерпретируется в зависимости от выбранного режима смешивания:
> - используется как множитель для аддитивного режима
> - для мультипликативного режима используется lerp(1.0f, value, attenuation)


### Возвращаемое значение

Текущий режим смешивания, одно из значений [BLEND_*](#BLEND_ADDITIVE).
## void setOrder ( int order )

Устанавливает новый порядок отображения поля высот. Этот параметр используется для корректного применения полей со смешанными режимами смешивания.
### Аргументы

- *int* **order** - Порядок отображения.

## int getOrder () const

Возвращает текущий порядок отображения поля высот. Этот параметр используется для корректного применения полей со смешанными режимами смешивания.
### Возвращаемое значение

Текущий порядок отображения.
## void setPower ( float power )

Устанавливает новое значение мощности FieldHeight. Мощность является множителем для значений загруженной текстуры карты высот.
### Аргументы

- *float* **power** - Значение мощности. Чем выше значение, тем сильнее высоты FieldHeight будут влиять на высоты объекта глобальной воды. Значение по умолчанию — 1.0f.

## float getPower () const

Возвращает текущее значение мощности FieldHeight. Мощность является множителем для значений загруженной текстуры карты высот.
### Возвращаемое значение

Текущее значение мощности. Чем выше значение, тем сильнее высоты FieldHeight будут влиять на высоты объекта глобальной воды. Значение по умолчанию — 1.0f.
## void setAttenuation ( float attenuation )

Устанавливает новое значение коэффициента затухания FieldHeight. Коэффициент затухания указывает на скорость затухания влияния FieldHeight от центра объекта к его краям.
### Аргументы

- *float* **attenuation** - Коэффициент затухания. Чем выше значение, тем меньше высоты FieldHeight будут влиять на высоты объекта глобальной воды. Значение по умолчанию — 1.0f.

## float getAttenuation () const

Возвращает текущее значение коэффициента затухания FieldHeight. Коэффициент затухания указывает на скорость затухания влияния FieldHeight от центра объекта к его краям.
### Возвращаемое значение

Текущий коэффициент затухания. Чем выше значение, тем меньше высоты FieldHeight будут влиять на высоты объекта глобальной воды. Значение по умолчанию — 1.0f.
