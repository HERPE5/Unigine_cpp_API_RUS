# Вспомогательные типы


Список вспомогательных типов значений, используемых в некоторых функциях Math.


| Тип | Определение | Описание |
|---|---|---|
| **mat2x2_values** | float[4] | Вспомогательный тип для хранения значений [2x2 matrix](../../../api/library/math/class.mat2_cpp.md). Значения хранятся по столбцам (column-major). |
| **mat3x3_values** | float[9] | Вспомогательный тип для хранения значений [3x3 matrix](../../../api/library/math/class.mat3_cpp.md). Значения хранятся по столбцам (column-major). |
| **mat4x3_values** | float[12] | Вспомогательный тип для хранения значений матрицы 4x3. Значения хранятся по столбцам (column-major). |
| **mat4x4_values** | float[16] | Вспомогательный тип для хранения значений [4x4 matrix](../../../api/library/math/class.mat4_cpp.md). Значения хранятся по столбцам (column-major). |
| **dmat4x3_values** | double[12] | Вспомогательный тип для хранения значений матрицы 4x3 типа double. Значения хранятся по столбцам (column-major). |
| **dmat4x4_values** | double[16] | Вспомогательный тип для хранения значений матрицы 4x4 типа double. Значения хранятся по столбцам (column-major). |
