# Unigine::SHBasis Class (CPP)

**Header:** #include <UnigineMathLibSHBasis.h>


Этот класс используется для вычисления коэффициентов сферических гармоник.


## SHBasis Class

### Методы класса

---

## static SHBasisPtr create ( )

Конструктор. Инициализирует сферические гармоники.
## double factorial ( int x ) const

Возвращает факториал аргумента.
### Аргументы

- *int* **x** - Аргумент.

### Возвращаемое значение

Факториал.
## double get ( int l , int m , const float* dir ) const

Возвращает коэффициент сферической гармоники с использованием направления.
### Аргументы

- *int* **l** - Степень.
- *int* **m** - Порядок.
- *const float** **dir** - Направление.

### Возвращаемое значение

Коэффициент сферической гармоники.
## double get ( int l , int m , double phi , double theta ) const

Возвращает коэффициент сферической гармоники с использованием сферических координат.
### Аргументы

- *int* **l** - Степень.
- *int* **m** - Порядок.
- *double* **phi** - Координата phi.
- *double* **theta** - Координата theta.

### Возвращаемое значение

Коэффициент сферической гармоники.
