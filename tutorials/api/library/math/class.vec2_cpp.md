# Unigine::Math::vec2 Struct (CPP)

**Header:** #include <UnigineMathLibVec2.h>


Этот класс представляет вектор из 2 компонентов типа float.

---

## vec2 ( const hvec2& v )

Конструктор. Инициализирует вектор заданным исходным вектором [hvec2](../../../api/library/math/class.hvec2_cpp.md).
### Аргументы

- *const hvec2&* **v** - Исходный вектор.

## vec2 ( )

Конструктор по умолчанию. Создаёт нулевой вектор.
## vec2 ( const vec2& v )

- *const vec2&* **v** - Исходный вектор.

## vec2 ( float x , float y )

Конструктор. Инициализирует вектор заданными значениями типа float.
### Аргументы

- *float* **x** - Компонент X вектора.
- *float* **y** - Компонент Y вектора.

### Примеры


```cpp
vec2(2.0, 3.0);
/*
Создаёт вектор (2.0, 3.0)
*/

```

## vec2 & normalizeValid ( )

Нормализует вектор, приводя его величину к 1. При нормализации вектор сохраняет то же направление, но его длина становится равной 1. Выполняется проверка на нулевой вектор: если аргумент является нулевым вектором, возвращается нулевой вектор.
### Возвращаемое значение

Нормализованный вектор.

- *const vec2&* **v** - Вектор.

Результирующий вектор.
### Примеры


```cpp
vec2 a, b;
a = vec2(6.0, 10.0);
b = vec2(2.0, 5.0);
a /= b;
/*
Начальные значения векторов a и b:
	a (6.0, 10.0)
	b (2.0, 5.0)

	a /= b;
Вектор a после операции:
	a (3.0, 2.0)
*/

```


## vec2 & operator/= ( float v )

Выполняет покомпонентное деление вектора на скаляр. Реализовано с использованием вычисления обратного скалярного значения с последующим покомпонентным умножением.
### Аргументы

- *float* **v** - Скалярное значение.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
vec2 a = vec2(6.0, 10.0);
a /= 2.0;
/*
Начальное значение вектора a:
	a (6.0, 10.0)

	a /= 2.0;
Вектор a после операции:
	a (3.0, 5.0)
*/

```
