# Unigine::Math::vec4 Struct (CPP)

**Header:** #include <UnigineMathLibVec4.h>


Этот класс представляет собой вектор из 4 компонентов типа float.

Конструктор. Инициализирует вектор, используя заданную 128-битную переменную в качестве источника.

- *const __m128&* **v** - 128-битная переменная

## vec4 & normalizeValid ( )

Нормализует вектор, делая его величину равной 1. При нормализации вектор сохраняет то же направление, но его длина становится равной 1. Выполняется проверка на нулевой вектор: если аргумент является нулевым вектором, возвращается нулевой вектор.
### Возвращаемое значение

Нормализованный вектор.
