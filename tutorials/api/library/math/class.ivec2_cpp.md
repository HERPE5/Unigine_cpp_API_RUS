# Unigine::Math::ivec2 Struct (CPP)

**Header:** #include <UnigineMathLibIVec2.h>


Этот класс представляет вектор из 2 целочисленных компонентов.

Конструктор по умолчанию. Создаёт нулевой вектор.

### Аргументы

- *const ivec2&* **v** - Исходный вектор.

## ivec2 ( int x , int y )

Конструктор. Инициализирует вектор с использованием заданных целочисленных значений.
### Аргументы

- *int* **x** - Компонента X вектора.
- *int* **y** - Компонента Y вектора.

### Примеры


```cpp
ivec2(2, 3);
/*
Создаёт вектор (2, 3)
*/

```

## ivec2 & operator/= ( int v )

- *int* **v** - Скалярное значение.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp

a /= 2;
/*
Исходное значение вектора a:
	a (6, 10)

	a /= 2;
Вектор a после операции:
	a (3, 5)
*/

```

```cpp

	a (6, 10)
	b (2, 6)

	a /= b;
Вектор a после операции:
	a (3, 1)

```
