# Unigine::Concave Class (CPP)

**Header:** #include <UnigineMathLibConcave.h>


Этот класс создаёт вогнутые формы на основе вершин с использованием подмножества выпуклых форм.


## Concave Class

### Методы класса

---

## static ConcavePtr create ( )

Конструктор. Инициализирует новую вогнутую форму, очищая данные предыдущей вогнутой формы.
## static ConcavePtr create ( const Concave& concave )

Конструктор. Инициализирует новую вогнутую форму с использованием заданной формы.
### Аргументы

- *const Concave&* **concave** - Входная вогнутая форма.

## Concave & operator= ( const Concave& concave )

Задаёт вогнутую форму равной заданной вогнутой форме.
### Аргументы

- *const Concave&* **concave** - Вогнутая форма.

### Возвращаемое значение

Результирующая вогнутая форма.
## void clear ( )

Очищает данные предыдущей вогнутой формы.
## bool create ( const vec3* vertex_ , int num_vertex_ , int depth_ = 4 , float error_ = 0.01f , float threshold_ = 0.01f )

Создаёт вогнутую форму с использованием заданных вершин.
### Аргументы

- *const vec3** **vertex_** - Вершины.
- *int* **num_vertex_** - Количество вершин.
- *int* **depth_** - Глубина рекурсии.
- *float* **error_** - Погрешность выпуклости.
- *float* **threshold_** - Порог слияния.

### Возвращаемое значение

true, если форма была успешно создана; иначе false.
## float getError ( ) const

Возвращает погрешность выпуклости.
## float getThreshold ( ) const

Возвращает порог слияния.
## int getNumConvexes ( ) const

Возвращает количество выпуклых оболочек, использованных для создания этой вогнутой формы.
### Возвращаемое значение

Количество выпуклых оболочек.
## const Convex * getConvex ( int num ) const

Возвращает выпуклую форму, являющуюся частью данной вогнутой формы.
### Аргументы

- *int* **num** - Номер выпуклой формы.

### Возвращаемое значение

Выпуклая форма.
