# Unigine::Convex Class (CPP)

**Header:** #include <UnigineMathLibConvex.h>


Этот класс создаёт выпуклые формы.


## Convex Class

### Методы класса

---

## static ConvexPtr create ( )

Конструктор. Инициализирует новую выпуклую форму, очищая данные предыдущей формы.
## static ConvexPtr create ( const Convex& convex )

Конструктор. Инициализирует новую выпуклую форму с использованием заданной формы.
### Аргументы

- *const Convex&* **convex** - Входная выпуклая форма.

## Convex & operator= ( const Convex& convex )

Задаёт выпуклую форму равной заданной выпуклой форме.
### Аргументы

- *const Convex&* **convex** - Выпуклая форма.

### Возвращаемое значение

Результирующая выпуклая форма.
## void clear ( )

Очищает данные предыдущей выпуклой формы.
## bool create ( const vec3* v , int num_vertex , float error = 0.01f )

Создаёт выпуклую форму с использованием заданных вершин.
### Аргументы

- *const vec3** **v** - Вершины.
- *int* **num_vertex** - Количество вершин.
- *float* **error** - Погрешность аппроксимации (значение в диапазоне **[0..1]**, чем выше значение, тем меньше вершин). Это значение позволяет уменьшить количество вершин созданной формы. Выпуклые оболочки с меньшим числом вершин обрабатываются быстрее.

### Возвращаемое значение

true, если форма была успешно создана; иначе false.
## bool create ( const dvec3* v , int num_vertex , float error = 0.01f )

Создаёт выпуклую форму с использованием заданных вершин.
### Аргументы

- *const dvec3** **v** - Вершины.
- *int* **num_vertex** - Количество вершин.
- *float* **error** - Погрешность аппроксимации (значение в диапазоне **[0..1]**, чем выше значение, тем меньше вершин). Это значение позволяет уменьшить количество вершин созданной формы. Выпуклые оболочки с меньшим числом вершин обрабатываются быстрее.

### Возвращаемое значение

true, если форма была успешно создана; иначе false.

### Возвращаемое значение

## void getBoundBox ( dvec3& min , dvec3& max ) const

Вычисляет ограничивающий прямоугольник (bounding box) выпуклой формы (минимальную и максимальную вершины).
### Аргументы

- *dvec3&* **min** - Минимальная вершина формы.
- *dvec3&* **max** - Максимальная вершина формы.
