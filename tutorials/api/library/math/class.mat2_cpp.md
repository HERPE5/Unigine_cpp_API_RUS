# Unigine::Math::mat2 Struct (CPP)

**Header:** #include <UnigineMathLibMat2.h>


Этот класс представляет матрицу из четырёх (2x2) компонентов типа float.


## mat2 Struct

### Методы класса

---

## mat2 ( )

Конструктор по умолчанию. Создаёт единичную матрицу.
## mat2 ( const mat2& m )

Конструктор. Инициализирует матрицу путём копирования заданной исходной матрицы.
### Аргументы

- *const mat2&* **m** - Исходная матрица.

## mat2 ( float v )

Конструктор. Инициализирует матрицу с использованием заданного скалярного значения.
```cpp
mat2(2.0);

/* Создаёт матрицу
| 2.0	2.0	|
| 2.0	2.0	|
*/

```


### Аргументы

- *float* **v** - Скалярное значение.

## mat2 ( const mat3& m )

Конструктор. Инициализирует матрицу с использованием заданной исходной матрицы [mat3](../../../api/library/math/class.mat3_cpp.md) (3x3). Элементы матрицы заполняются соответствующими элементами исходной матрицы.
### Аргументы

- *const mat3&* **m** - Исходная матрица (3x3).

## mat2 ( const mat4& m )

Конструктор. Инициализирует матрицу с использованием заданной исходной матрицы [mat4](../../../api/library/math/class.mat4_cpp.md) (4x4). Элементы матрицы заполняются соответствующими элементами исходной матрицы.
### Аргументы

- *const mat4&* **m** - Исходная матрица (4x4).

## mat2 ( const dmat4& m )

Конструктор. Инициализирует матрицу с использованием заданной исходной матрицы [dmat4](../../../api/library/math/class.dmat4_cpp.md) (3x4). Элементы матрицы заполняются соответствующими элементами исходной матрицы.
### Аргументы

- *const dmat4&* **m** - Исходная матрица (3x4).

## mat2 ( const vec2& col0 , const vec2& col1 )

Конструктор. Инициализирует матрицу двумя заданными векторами [vec2](../../../api/library/math/class.vec2_cpp.md).
```text
Результирующая матрица:
    | col0.x   	 col1.x |
M=  | col0.y     col1.y |

```


### Аргументы

- *const vec2&* **col0** - Исходный вектор для первого столбца.
- *const vec2&* **col1** - Исходный вектор для второго столбца.

## mat2 ( float m00_ , float m10_ , float m01_ , float m11_ )
