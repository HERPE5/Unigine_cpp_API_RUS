## mat4 composeRotationXYZ ( const vec3 & r )


Составляет матрицу вращения из соответствующих углов Эйлера. Углы Эйлера задаются в последовательности вращения по осям - **XYZ**. Это порядок колец в трёхосевом карданном подвесе: ось **X** используется как внешнее кольцо (независимое кольцо), в то время как ось **Z** является внутренним (его вращение зависит от двух других колец).


Когда мы говорим об осях в UNIGINE, мы подразумеваем, что:

- Ось **X** направлена *вправо*, задавая угол **тангажа** (pitch).
- Ось **Y** направлена *вперёд*, задавая угол **крена** (roll).
- Ось **Z** направлена *вверх*, задавая угол **рыскания** (yaw, курс).


> **Примечание:** У игроков (Players) другая система координат:
> - Ось **X** направлена *вправо*, задавая угол **тангажа** (pitch).
> - Ось **Y** направлена *вверх*, задавая угол **рыскания** (yaw, курс).
> - Ось **Z** направлена *назад*, задавая угол **-крена** (-roll).


### Аргументы

- *const [vec3](../../../api/library/math/class.vec3_cpp.md) &* **r** - Вектор, содержащий углы Эйлера, в градусах - (yaw, roll, pitch).

### Возвращаемое значение

Составленная матрица вращения.

## mat4 cubeTransform ( int face )

Возвращает матрицу трансформации (матрицу обзора куба) для заданной грани кубической карты. Кубические карты часто используются в рендеринге для отображения окружения, отражений или скайбоксов. Каждая грань кубической карты соответствует одному из шести направлений: положительной и отрицательной осям X, Y и Z.
### Аргументы

- *int* **face** - Номер грани, одно из следующих значений: 0 (X+), 1 (X-), 2 (Y+), 3 (Y-), 4 (Z+), 5 (Z-).

### Возвращаемое значение

Матрица обзора куба.

## vec3 decomposeRotationZXY ( const mat3 & t )


Разлагает заданную матрицу вращения на соответствующие углы Эйлера. Углы Эйлера задаются в последовательности вращения по осям - **ZXY**. Это порядок колец в трёхосевом карданном подвесе: ось **Z** используется как внешнее кольцо (независимое кольцо), в то время как ось **Y** является внутренним (его вращение зависит от двух других колец).


Когда мы говорим об осях в UNIGINE, мы подразумеваем, что:

- Ось **X** направлена *вправо*, задавая угол **тангажа** (pitch).
- Ось **Y** направлена *вперёд*, задавая угол **крена** (roll).
- Ось **Z** направлена *вверх*, задавая угол **рыскания** (yaw, курс).


> **Примечание:** У игроков (Players) другая система координат:
> - Ось **X** направлена *вправо*, задавая угол **тангажа** (pitch).
> - Ось **Y** направлена *вверх*, задавая угол **рыскания** (yaw, курс).
> - Ось **Z** направлена *назад*, задавая угол **-крена** (-roll).

## mat4 frustum ( float left , float right , float bottom , float top , float znear , float zfar )

Возвращает матрицу перспективной проекции:
| 2.0 * znear / (right - left) | 0.0 | (right + left) / (right - left) | 0.0 |
|---|---|---|---|
| 0.0 | 2.0 * znear / (top - bottom) | (top + bottom) / (top - bottom) | 0.0 |
| 0.0 | 0.0 | -(zfar + znear) / (zfar - znear) | -2.0 * zfar * znear / (zfar - znear) |
| 0.0 | 0.0 | -1.0 | 0.0 |


Координаты top, left, right, bottom задаются относительно центральной точки плоскости znear.


![](frustum_desc.png)


На рисунке выше показаны две различные точки (A и B). Поскольку top, left, right, bottom - это координаты относительно центральной точки плоскости znear, координаты точки A должны быть *A(left, bottom, znear)*. Координаты точки B - *B(k * left, k * bottom, zfar)*, где *k = zfar/znear.*


### Аргументы

- *float* **left** - Левая координата ближней плоскости отсечения относительно центра.
- *float* **right** - Правая координата ближней плоскости отсечения относительно центра.
- *float* **bottom** - Нижняя координата ближней плоскости отсечения относительно центра.
- *float* **top** - Верхняя координата ближней плоскости отсечения относительно центра.
- *float* **znear** - Расстояние до ближней плоскости отсечения по глубине.
- *float* **zfar** - Расстояние до дальней плоскости отсечения по глубине.

### Возвращаемое значение

Матрица перспективной проекции.

## dmat4 setTo ( const dvec3 & position , const dvec3 & target , const vec3 & up , int axis = AXIS_NZ )

Возвращает матрицу трансформации, которая помещает объект в заданную позицию и задаёт его ориентацию на заданную целевую точку. Вектор направления взгляда ориентирован вдоль заданной оси (*отрицательная Z*, по умолчанию). Эта функция похожа на функцию [lookAt()](#lookAt_constdvec3n_constdvec3n_constvec3n_int), но вместо создания матрицы вида для камеры она создаёт матрицу модели для позиционирования и ориентации объекта. Это можно использовать для позиционирования объектов в мировом пространстве, выравнивая их так, чтобы они "смотрели" на цель, сохраняя при этом определённую ориентацию относительно направления "вверх".
### Аргументы

- *const [dvec3](../../../api/library/math/class.dvec3_cpp.md) &* **position** - Координаты позиции точки наблюдателя.
- *const [dvec3](../../../api/library/math/class.dvec3_cpp.md) &* **target** - Координаты позиции целевой точки.
- *const [vec3](../../../api/library/math/class.vec3_cpp.md) &* **up** - Направление вектора "вверх".
- *int* **axis** - Ось, вдоль которой ориентирован вектор направления взгляда (какая ось должна быть направлена на цель). Одно из значений [AXIS_*](../../../api/library/math/math.common_cpp.md#AXIS) (по умолчанию AXIS_NZ).

## mat4 symmetryProjection ( const mat4 & projection )

Возвращает симметричную матрицу проекции для заданной входной матрицы проекции. Симметричная проекция гарантирует, что усечённая пирамида вида симметрична относительно осей x и y, исходя из исходных размеров усечённой пирамиды. Это может быть полезно в случаях, когда асимметрия матрицы проекции может вызвать проблемы, такие как искажение отображаемой сцены или при выполнении определённых визуальных эффектов (например, зеркальное отражение или выравнивание видов). В результате получается матрица проекции, которая сохраняет то же поведение, связанное с глубиной, что и исходная, но обеспечивает симметрию по направлениям x и y.
### Аргументы

- *const [mat4](../../../api/library/math/class.mat4_cpp.md) &* **projection** - Входная матрица проекции.

### Возвращаемое значение

Симметричная матрица проекции.
