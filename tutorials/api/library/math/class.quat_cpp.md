# Unigine::Math::quat Struct (CPP)

**Header:** #include <UnigineMathLibQuat.h>


Этот класс представляет тип кватерниона. Кватернионы представляют вращение. Обычно они используются для плавной интерполяции между двумя углами, а также для избежания проблемы gimbal lock, которая может возникнуть при использовании углов Эйлера.


Кватернионы добавляют четвёртый элемент к значениям [x, y, z], определяющим вектор, в результате получаются произвольные 4-мерные векторы. Следующий пример иллюстрирует, как каждый элемент единичного кватерниона связан с вращением вокруг оси на заданный угол, где q представляет единичный кватернион (x, y, z, w), ось нормализована, а theta - желаемый угол вращения против часовой стрелки (CCW) вокруг оси:

- q.x = sin(theta/2) * axis.x
- q.y = sin(theta/2) * axis.y
- q.z = sin(theta/2) * axis.z
- q.w = cos(theta/2)


### Пример использования


Следующий пример создаёт кватернион для вращения узла: 45 градусов в секунду вокруг оси X.


> **Notice:** Предполагается, что вы уже создали экземпляр [node](../../../api/library/nodes/class.node_cpp.md) для вращения.


```cpp
// файл AppWorldLogic.cpp

// объявление указателя на узел источника света World
NodePtr node;

int AppWorldLogic::init()
{
	/* ... */

	// попытка найти источник World Node в текущем мире
	node = World::getNodeByType(Node::LIGHT_WORLD);

	return 1;
}

int AppWorldLogic::update()
{
	/* ... */

	// получение значения дельты времени
	float delta_time = Game::getIFps();

	// создание кватерниона для вращения 45 градусов в секунду вокруг оси X
	Unigine::Math::quat rotation_delta = Unigine::Math::quat(1.0f, 0.0f, 0.0f, 45.0f * delta_time);

	// вращение узла, если он существует
	if (node)
		node->worldRotate(rotation_delta);

	/* ... */
}

```


В приведённом выше примере кватернион был инициализирован с использованием четырёх значений: 3 компонента оси (*x,y,z*) и угол (компонент *w* кватерниона). Значение **1** компонента оси X показывает, что вращение будет выполняться вокруг оси X.

## mat3 getMat3 ( ) const

Возвращает матрицу вращения для кватерниона.
```text
Для кватерниона (x, y, z, w) соответствующая матрица вращения M определяется следующим образом:
    | 1 - 2y² - 2z²    2xy + 2wz      	2xz - 2wy     |
M=  | 2xy - 2wz        1 - 2x² - 2z²    2yz + 2wx     |
    | 2xz + 2wy        2yz - 2wx        1 - 2x² - 2y² |

```


### Возвращаемое значение

Матрица вращения для кватерниона.

## quat & normalizeValid ( )

Нормализует кватернион, приводя его величину к 1. При нормализации кватернион сохраняет то же направление, но его длина становится равной 1. Выполняется проверка на нулевой кватернион: если аргумент является нулевым кватернионом, возвращается нулевой кватернион.

Нормализованный кватернион.
