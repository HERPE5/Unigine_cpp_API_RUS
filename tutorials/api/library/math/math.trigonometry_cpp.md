# Тригонометрические математические функции (CPP)

**Header:** #include <UnigineMathLib.h>


Этот класс содержит основные и обратные тригонометрические функции.


> **Notice:** Тригонометрические математические функции являются членами пространства имён **Unigine::Math**.


## Класс Math

### Методы класса

---

## float acos ( float v )

Возвращает арккосинус заданного аргумента - угол в радианах, косинус которого равен аргументу. a == cos(acos(a)) для любого значения a, входящего в диапазон acos().
### Аргументы

- *float* **v** - Аргумент.

### Возвращаемое значение

Арккосинус аргумента, в радианах.

## float atan2 ( float y , float x )

Возвращает арктангенс двух аргументов (**x** и **y**). Это похоже на вычисление арктангенса **y / x**, за исключением того, что знаки обоих аргументов используются для определения квадранта результата.
### Аргументы

- *float* **y** - Первый аргумент.
- *float* **x** - Второй аргумент.

### Возвращаемое значение

Результат в радианах, находящийся в диапазоне между **-PI** и **PI** (включительно).

## void sincos ( float angle , float & s , float & c )

Вычисляет значения синуса и косинуса для заданного значения угла в радианах и записывает их в **out_sin** и **out_cos**.
### Аргументы

- *float* **angle** - Угол, в радианах.
- *float &* **s** - Переменная, в которую будет записано вычисленное значение синуса.
- *float &* **c** - Переменная, в которую будет записано вычисленное значение косинуса.
