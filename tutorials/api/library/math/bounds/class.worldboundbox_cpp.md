# Unigine::WorldBoundBox Struct (CPP)

**Header:** #include <UnigineMathLibBounds.h>


Эта структура служит для построения ограничивающего параллелепипеда в координатах двойной точности.


Ограничивающие параллелепипеды обладают более высокой точностью, но требуют больше времени на вычисление по сравнению с ограничивающими сферами.


Используя эту структуру, можно легко найти общий ограничивающий параллелепипед для нескольких объектов путём его расширения.

> **Notice:** Метод не проверяет, является ли ограничивающий параллелепипед допустимым (имеет положительный радиус).


### Аргументы

- *const [WorldBoundBox](../../../../api/library/math/bounds/class.worldboundbox_cpp.md) &* **bb** - Ограничивающий параллелепипед.

### Возвращаемое значение

**1**, если весь заданный ограничивающий параллелепипед находится внутри ограничивающего параллелепипеда; иначе **0**.
## bool insideAllValid ( const Math::Vec3* points , int num_points ) const

Проверяет, находятся ли все заданные точки внутри текущего ограничивающего параллелепипеда.
> **Notice:** Метод не проверяет, являются ли минимальные и максимальные координаты текущего ограничивающего параллелепипеда допустимыми.


### Аргументы

- *const  Math::Vec3** **points** - Массив проверяемых точек.
- *int* **num_points** - Количество проверяемых точек.

### Возвращаемое значение

**true**, если все заданные точки находятся внутри ограничивающего параллелепипеда; иначе **false**.

### Возвращаемое значение
