# Unigine::BoundBox Struct (CPP)

**Header:** #include <UnigineMathLibBounds.h>


Эта структура служит для построения ограничивающего параллелепипеда (bounding box) в координатах одинарной точности.

> **Notice:** Экземпляры этой структуры автоматически удаляются, когда это необходимо.


В случае координат двойной точности ограничивающий параллелепипед следует строить с использованием структуры **[WorldBoundBox](../../../../api/library/math/bounds/class.worldboundbox_cpp.md)**. Она включает те же функции, что и структура *BoundBox*, но её функции работают с координатами двойной точности.


> **Notice:** Для поддержки как сборок с одинарной, так и с двойной точностью можно использовать только структуру *WorldBoundBox*. Движок автоматически заменит её на *BoundBox*, если это потребуется.

> **Notice:** Метод не проверяет, являются ли минимальные и максимальные координаты текущего ограничивающего параллелепипеда допустимыми.


### Аргументы

- *const [BoundBox](../../../../api/library/math/bounds/class.boundbox_cpp.md) &* **bb** - Ограничивающий параллелепипед.

### Возвращаемое значение

**true**, если весь ограничивающий параллелепипед находится внутри ограничивающего параллелепипеда; иначе **false**.
