# Unigine::Math::dvec2 Struct (CPP)

**Header:** #include <UnigineMathLibDVec2.h>


Этот класс представляет вектор из 2 компонентов типа double.


## dvec2 Struct

### Методы класса

---

## dvec2 ( const __m128d& v )

Конструктор. Инициализирует вектор заданной 128-битной переменной в качестве источника.
> **Notice:** Не рекомендуется использовать этот метод, если у вас нет чёткого понимания SSE2.


### Аргументы

- *const __m128d&* **v** - 128-битная переменная.

## dvec2 ( double x , double y )

Конструктор. Инициализирует вектор заданными значениями типа double.
### Аргументы

- *double* **x** - Компонент X вектора.
- *double* **y** - Компонент Y вектора.

### Примеры


```cpp
dvec2(2.0, 3.0);
/*
Создаёт вектор (2.0, 3.0)
*/

```

## dvec2 & operator/= ( double v )

Выполняет покомпонентное деление вектора на скаляр. Реализовано с использованием вычисления обратного скалярного значения с последующим покомпонентным умножением.
### Аргументы

- *double* **v** - Скалярное значение.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
dvec2 a = dvec2(6.0, 10.0);
a /= 2.0;
/*
Начальное значение вектора a:
	a (6.0, 10.0)

	a /= 2.0;
Вектор a после операции:
	a (3.0, 5.0)
*/

```


## dvec2 & operator/= ( const dvec2& v )

Выполняет покомпонентное деление векторов.
### Аргументы

- *const dvec2&* **v** - Vector.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
dvec2 a, b;
a = dvec2(6.0, 10.0);
b = dvec2(2.0, 5.0);
a /= b;
/*
Начальные значения векторов a и b:
	a (6.0, 10.0)
	b (2.0, 5.0)

	a /= b;
Вектор a после операции:
	a (3.0, 2.0)
*/

```
