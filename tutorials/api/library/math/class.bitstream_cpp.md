# Unigine::BitStream Class (CPP)

**Header:** #include <UnigineMathLibCommon.h>


Этот класс представляет собой вспомогательную структуру для буфера фиксированного размера и его битовых операций чтения/записи. Вы можете задать размер структуры (шаблонный класс). Размер по умолчанию — 128 бит.


## BitStream Class

### Методы класса

---

## static BitStreamPtr create ( )

Конструктор. Инициализирует битовый буфер.
## const unsigned char * get ( ) const

Возвращает указатель на константный битовый буфер.
### Возвращаемое значение

Указатель на константный битовый буфер.
## unsigned char * get ( )

Возвращает указатель на битовый буфер.
### Возвращаемое значение

Указатель на битовый буфер.
## int size ( ) const

Возвращает размер структуры в байтах.
### Возвращаемое значение

Размер структуры в байтах.
## void clear ( )

Очищает буфер.
## void align ( )

Выравнивает буфер.
## int readUBits ( int num )

Возвращает беззнаковые данные из буфера.
### Аргументы

- *int* **num** - Количество бит для возврата.

### Возвращаемое значение

Беззнаковые данные.
## void writeUBits ( int value , int num )

Записывает беззнаковые данные в буфер.
### Аргументы

- *int* **value** - Данные для записи.
- *int* **num** - Количество бит для записи.

## int readBits ( int num )

Возвращает знаковые данные из буфера.
### Аргументы

- *int* **num** - Количество бит для возврата.

### Возвращаемое значение

Знаковые данные.
## void writeBits ( int value , int num )

Записывает знаковые данные в буфер.
### Аргументы

- *int* **value** - Данные для записи.
- *int* **num** - Количество бит для записи.
