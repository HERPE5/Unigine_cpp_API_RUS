# Unigine::Math::dvec3 Struct (CPP)

**Header:** #include <UnigineMathLibDVec3.h>


Этот класс представляет вектор из 3 компонентов типа double.

> **Warning:** Не используйте четвёртый компонент структуры (*align*), так как он может быть неявно изменён операциями структуры.

## dvec3 & operator/= ( const dvec3& v )

Выполняет покомпонентное деление векторов.
### Аргументы

- *const dvec3&* **v** - Вектор.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
dvec3 a, b;
a = dvec3(6.0, 10.0, 12.0);
b = dvec3(2.0, 5.0, 6.0);
a /= b;
/*
Начальные значения векторов a и b:
	a (6.0, 10.0, 12.0)
	b (2.0, 5.0, 6.0)

	a /= b;
Вектор a после операции:
	a (3.0, 2.0, 2.0)
*/

```


## dvec3 & operator/= ( double v )

Выполняет покомпонентное деление вектора на скаляр. Реализовано с использованием вычисления обратного скалярного значения с последующим покомпонентным умножением.
### Аргументы

- *double* **v** - Скалярное значение.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
dvec3 a = dvec3(6.0, 10.0, 12.0);
a /= 2.0;
/*
Начальное значение вектора a:
	a (6.0, 10.0, 12.0)

	a /= 2.0;
Вектор a после операции:
	a (3.0, 5.0, 6.0)
*/

```
