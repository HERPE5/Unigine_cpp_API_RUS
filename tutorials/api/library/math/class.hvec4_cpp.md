# Unigine::Math::hvec4 Struct (CPP)

**Header:** #include <UnigineMathLibHVec4.h>


Этот класс представляет вектор из 4 компонентов типа [half](../../../api/library/math/class.half_cpp.md) (16-битное число с плавающей точкой).


## hvec4 Struct

### Методы класса

---

## hvec4 ( )

Конструктор по умолчанию. Создаёт нулевой вектор.
## hvec4 ( const hvec4& v )

Конструктор. Инициализирует вектор путём копирования заданного исходного вектора.
### Аргументы

- *const hvec4&* **v** - Исходный вектор.

## hvec4 ( half x , half y , half z , half w )

Конструктор. Инициализирует вектор заданными значениями типа [half](../../../api/library/math/class.half_cpp.md).
### Аргументы

- *[half](../../../api/library/math/class.half_cpp.md)* **x** - Компонент X вектора.
- *[half](../../../api/library/math/class.half_cpp.md)* **y** - Компонент Y вектора.
- *[half](../../../api/library/math/class.half_cpp.md)* **z** - Компонент Z вектора.
- *[half](../../../api/library/math/class.half_cpp.md)* **w** - Компонент W вектора.

### Примеры


```cpp
hvec4(2.0, 3.0, 1.0, 4.0);
/*
Создаёт вектор (2.0, 3.0, 1.0, 4.0)
*/

```


## hvec4 ( half v )

Конструктор. Инициализирует вектор заданным значением типа [half](../../../api/library/math/class.half_cpp.md).
