# Unigine::Math::vec3 Struct (CPP)

**Header:** #include <UnigineMathLibVec3.h>


Этот класс представляет вектор из 3 компонентов типа float.

## vec3 & normalizeValid ( )

Нормализует вектор, приводя его величину к 1. При нормализации вектор сохраняет то же направление, но его длина становится равной 1. Выполняется проверка на нулевой вектор: если аргумент является нулевым вектором, возвращается нулевой вектор.
### Возвращаемое значение

Нормализованный вектор.

## vec3 & operator/= ( const vec3& v )

Выполняет покомпонентное деление векторов.
### Аргументы

- *const vec3&* **v** - Вектор.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
vec3 a, b;
a = vec3(6.0, 10.0, 12.0);
b = vec3(2.0, 5.0, 6.0);
a /= b;
/*
Начальные значения векторов a и b:
	a (6.0, 10.0, 12.0)
	b (2.0, 5.0, 6.0)

	a /= b;
Вектор a после операции:
	a (3.0, 2.0, 2.0)
*/

```

```cpp

	a (6.0, 10.0, 12.0)

```
