# Unigine::Bits Class (CPP)

**Header:** #include <UnigineMathLibCommon.h>


Этот класс представляет вспомогательную структуру для хранения данных в битовом формате независимо от исходного типа данных (шаблонный класс). Данные копируются в структуру побитово.


## Bits Class

### Методы класса

---

## static BitsPtr create ( )

Конструктор. Инициализирует битовую структуру.
## static BitsPtr create ( Type data_ )

Конструктор. Инициализирует битовую структуру данными указанного типа.
### Аргументы

- *Type* **data_** - Данные конкретного типа, используемые для инициализации.

## void set ( int index , int value )

Задаёт значение биту с заданным индексом.
### Аргументы

- *int* **index** - Индекс бита.
- *int* **value** - Устанавливаемое значение.

## void set ( int index , bool value )

Задаёт значение биту с заданным индексом.
### Аргументы

- *int* **index** - Индекс бита.
- *bool* **value** - Устанавливаемое значение.

## bool get ( int index ) const

Возвращает значение бита с заданным индексом.
### Аргументы

- *int* **index** - Индекс бита.

### Возвращаемое значение

Значение бита.
## bool operator[] ( int index ) const

Возвращает значение бита с заданным индексом.
### Аргументы

- *int* **index** - Индекс бита.

### Возвращаемое значение

Значение бита.
## void set ( Type mask )

Задаёт битовую структуру с использованием указанной маски.
### Аргументы

- *Type* **mask** - Любое значение, используемое в качестве битовой маски.

## Type get ( ) const

Возвращает битовую структуру в виде переменной исходного типа.
### Возвращаемое значение

Переменная исходного типа.
## int size ( ) const

Возвращает ёмкость структуры в битах.
### Возвращаемое значение

Ёмкость структуры.
## void clear ( )

Очищает структуру.
