# Unigine::Math::hvec3 Struct (CPP)

**Header:** #include <UnigineMathLibHVec3.h>


Этот класс представляет вектор из 3 компонентов типа [half](../../../api/library/math/class.half_cpp.md) (16-битное число с плавающей точкой).

> **Warning:** Не используйте четвёртый компонент структуры (*align*), так как он может быть неявно изменён операциями структуры.


## hvec3 Struct

### Методы класса

---

## hvec3 ( )

Конструктор по умолчанию. Создаёт нулевой вектор.
## hvec3 ( const hvec3& v )

Конструктор. Инициализирует вектор путём копирования заданного исходного вектора.
### Аргументы

- *const hvec3&* **v** - Исходный вектор.

## hvec3 ( half x , half y , half z )

Конструктор. Инициализирует вектор заданными значениями типа [half](../../../api/library/math/class.half_cpp.md).
### Аргументы

- *[half](../../../api/library/math/class.half_cpp.md)* **x** - Первый компонент вектора hvec3.
- *[half](../../../api/library/math/class.half_cpp.md)* **y** - Второй компонент вектора hvec3.
- *[half](../../../api/library/math/class.half_cpp.md)* **z** - Третий компонент вектора hvec3.

### Примеры


```cpp
hvec3(2.0, 3.0, 1.0);
/*
Создаёт вектор (2.0, 3.0, 1.0)
*/

```
