# Unigine::Math::dvec4 Struct (CPP)

**Header:** #include <UnigineMathLibDVec4.h>


Этот класс представляет вектор из 4 компонентов типа double.


## dvec4 Struct

### Методы класса

---

## dvec4 ( const hvec4& v )

### Аргументы

- *const hvec4&* **v** - Исходный вектор.

## dvec4 ( )

Конструктор по умолчанию. Создаёт нулевой вектор.
## dvec4 ( const dvec4& v )

Конструктор. Инициализирует вектор путём копирования заданного исходного вектора.
### Аргументы

- *const dvec4&* **v** - Исходный вектор.

## dvec4 ( const dvec2& v , double z , double w )

Конструктор. Инициализирует вектор заданным двухкомпонентным исходным вектором [dvec2](../../../api/library/math/class.dvec2_cpp.md) и двумя скалярами.
### Аргументы

- *const dvec2&* **v** - Двухкомпонентный исходный вектор.
- *double* **z** - Компонент Z вектора.
- *double* **w** - Компонент W вектора.

## dvec4 ( const dvec3& v , double w )

Конструктор. Инициализирует вектор заданным трёхкомпонентным исходным вектором [dvec3](../../../api/library/math/class.dvec3_cpp.md) и скаляром.
### Аргументы

- *const dvec3&* **v** - Трёхкомпонентный исходный вектор.
- *double* **w** - Компонент W вектора.

## dvec4 ( double x , double y , double z , double w )

Конструктор. Инициализирует вектор заданными значениями типа double.
### Аргументы

- *double* **x** - Компонент X вектора.
- *double* **y** - Компонент Y вектора.
- *double* **z** - Компонент Z вектора.
- *double* **w** - Компонент W вектора.

### Примеры


```cpp
dvec4(1.0, 2.0, 3.0, 4.5);
/*
Создаёт вектор (1.0, 2.0, 3.0, 4.5)
*/

```

## dvec4 & operator/= ( const dvec4& v )

Выполняет покомпонентное деление векторов.
### Аргументы

- *const dvec4&* **v** - Vector.

### Возвращаемое значение

Resulting vector.
### Примеры


```cpp
dvec4 a, b;
a = dvec4(6.0, 10.0, 12.0, 25.0);
b = dvec4(2.0, 5.0, 6.0, 5.0);
a /= b;
/*
Начальные значения векторов a и b:
	a (6.0, 10.0, 12.0, 25.0)
	b (2.0, 5.0, 6.0, 5.0)

	a /= b;
Вектор a после операции:
	a (3.0, 2.0, 2.0, 5.0)
*/

```


## dvec4 & operator/= ( double v )

Выполняет покомпонентное деление вектора на скаляр. Реализовано с использованием вычисления обратного скалярного значения с последующим покомпонентным умножением.
### Аргументы

- *double* **v** - Scalar value.

### Возвращаемое значение

Resulting vector.
### Примеры


```cpp
dvec4 a = dvec4(6.0, 10.0, 12.0, 25.0);
a /= 2.0;
/*
Начальное значение вектора a:
	a (6.0, 10.0, 12.0, 25.0)

	a /= 2.0;
Вектор a после операции:
	a (3.0, 5.0, 6.0, 12.5)
*/

```
