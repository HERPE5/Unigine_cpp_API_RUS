# Unigine::Math::ivec3 Struct (CPP)

**Header:** #include <UnigineMathLibIVec3.h>


Этот класс представляет вектор из 3 целочисленных компонентов.

> **Warning:** Не используйте четвёртый компонент структуры (*align*), так как он может быть неявно изменён операциями структуры.


## ivec3 Struct

### Методы класса

---

## ivec3 ( const __m128i& v )

Конструктор. Инициализирует вектор заданной 128-битной переменной в качестве источника.
> **Notice:** Не рекомендуется использовать этот метод, если у вас нет чёткого понимания SSE2.


### Аргументы

- *const __m128i&* **v** - 128-битная переменная

## ivec3 ( )

Конструктор по умолчанию. Создаёт нулевой вектор.
## ivec3 ( const ivec3& v )

Конструктор. Инициализирует вектор путём копирования заданного исходного вектора.
### Аргументы

- *const ivec3&* **v** - Исходный вектор.

## ivec3 ( int x , int y , int z )

Конструктор. Инициализирует вектор заданными целочисленными значениями.
### Аргументы

- *int* **x** - Компонент X вектора.
- *int* **y** - Компонент Y вектора.
- *int* **z** - Компонент Z вектора.

### Примеры


```cpp
ivec2(2, 3, 4);
/*
Создаёт вектор (2, 3, 4)
*/

```

## ivec3 & operator/= ( int v )

Выполняет покомпонентное целочисленное деление вектора на скаляр.
### Аргументы

- *int* **v** - Скалярное значение.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
ivec3 a = ivec3(6, 10, 11);
a /= 2;
/*
Начальное значение вектора a:
	a (6, 10, 11)

	a /= 2;
Вектор a после операции:
	a (3, 5, 5)
*/

```


## ivec3 & operator/= ( const ivec3& v )

Выполняет покомпонентное целочисленное деление векторов.
### Аргументы

- *const ivec3&* **v** - Vector.

### Возвращаемое значение

Resulting vector.
### Примеры


```cpp
ivec3 a, b;
a = ivec3(6, 10, 12);
b = ivec3(2, 6, 5);
a /= b;
/*
Начальные значения векторов a и b:
	a (6, 10, 12)
	b (2, 6, 5)

	a /= b;
Вектор a после операции:
	a (3, 1, 2)

```
