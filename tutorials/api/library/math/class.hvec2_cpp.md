# Unigine::Math::hvec2 Struct (CPP)

**Header:** #include <UnigineMathLibHVec2.h>


Этот класс представляет вектор из 2 компонентов типа [half](../../../api/library/math/class.half_cpp.md) (16-битное число с плавающей точкой).


## hvec2 Struct

### Методы класса

---

## hvec2 ( )

Конструктор по умолчанию. Создаёт нулевой вектор.
## hvec2 ( const hvec2& v )

Конструктор. Инициализирует вектор путём копирования заданного исходного вектора.
### Аргументы

- *const hvec2&* **v** - Исходный вектор.

## hvec2 ( half x , half y )

Конструктор. Инициализирует вектор заданными значениями типа [half](../../../api/library/math/class.half_cpp.md).
### Аргументы

- *[half](../../../api/library/math/class.half_cpp.md)* **x** - Компонент X вектора.
- *[half](../../../api/library/math/class.half_cpp.md)* **y** - Компонент Y вектора.

### Примеры


```cpp
hvec2(2.0, 3.0);
/*
Создаёт вектор (2.0, 3.0)
*/

```
