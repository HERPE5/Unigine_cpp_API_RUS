# Unigine::Math::ivec4 Struct (CPP)

**Header:** #include <UnigineMathLibIVec4.h>


Этот класс представляет вектор из 4 целочисленных компонентов.


## ivec4 Struct

### Методы класса

## ivec4 ( const __m128i& v )

Конструктор. Инициализирует вектор переменной [__m128i](https://docs.microsoft.com/en-us/cpp/cpp/m128i?view=msvc-160).
> **Notice:** Не рекомендуется использовать этот метод, если у вас нет чёткого понимания SSE2.

### Аргументы

- *const __m128i&* **v** - Все компоненты вектора в формате *__m128d*

## ivec4 & operator/= ( int v )

Выполняет покомпонентное целочисленное деление вектора на скаляр.
### Аргументы

- *int* **v** - Скалярное значение.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
ivec4 a = ivec4(6, 10, 11, 4);
a /= 2;
/*
Начальное значение вектора a:
	a (6, 10, 11, 4)

	a /= 2;
Вектор a после операции:
	a (3, 5, 5, 2)
*/

```


## ivec4 & operator/= ( const ivec4& v )

Выполняет покомпонентное целочисленное деление векторов.
### Аргументы

- *const ivec4&* **v** - Вектор.

### Возвращаемое значение

Результирующий вектор.
### Примеры


```cpp
ivec4 a, b;
a = ivec4(6, 10, 12, 3);
b = ivec4(2, 6, 5, 2);
a /= b;
/*
Начальные значения векторов a и b:
	a (6, 10, 12, 3)
	b (2, 6, 5, 2)

	a /= b;
Вектор a после операции:
	a (3, 1, 2, 1)

```
