# Unigine.VR Class (CPP)

**Header:** #include <UnigineVR.h>

> **Notice:** Этот класс является синглтоном.


Базовый класс для управления виртуальной реальностью в UNIGINE.


### Инициализация VR


По умолчанию VR не инициализируется. Чтобы запустить движок с поддержкой VR, необходимо указать опцию командной строки [*-vr_app*](../../../vr_development/index.md#which_backend) при запуске приложения.


### Поддерживаемые графические API


Следующие графические API поддерживаются "из коробки":


- DirectX 12
- Vulkan

## void setPeripheralRenderingBorderWidth ( float width = 0.2f )

***Консоль*:**`vr_peripheral_rendering_border_width`Задаёт новую ширину переходной границы между фовеальной (фокусной) и контекстной зонами рендеринга. Значение 1.0 означает, что весь вьюпорт имеет широкий, плавный переход. Очень малое значение (близкое к эпсилон) означает, что переход будет чрезвычайно узким и почти незаметным. Этот параметр хранится в следующем конфигурационном файле: **[*.boot](../../../code/configuration_file_cpp.md#boot)**.
### Аргументы

- *float* **width** - Ширина переходной границы между фовеальной (фокусной) и контекстной зонами рендеринга. Значение 1.0 означает, что весь вьюпорт имеет широкий, плавный переход. Очень малое значение (близкое к эпсилон) означает, что переход будет чрезвычайно узким и почти незаметным. Диапазон значений: **[eps, 1.0f]**. Значение по умолчанию: **0.2f**.

## static Event<bool> getEventRenderModelsVisibility () const

Событие, генерируемое при изменении видимости render-моделей. Вы можете подписываться на события через *connect()* и отписываться через *disconnect()*. Также для удобства можно использовать классы *[EventConnection](../../../api/library/common/events/class.eventconnection_cpp.md)* и *[EventConnections](../../../api/library/common/events/class.eventconnections_cpp.md)* (см. примеры ниже).

> **Notice:** Подробнее см. статью [Event Handling](../../../code/fundamentals/events/index_cpp.md).

 Сигнатура обработчика события выглядит следующим образом: *myhandler(**visible**)*
<details>
<summary>Показать пример | Скрыть</summary>

**Пример использования**

```cpp
// реализация обработчика события RenderModelsVisibility
void rendermodelsvisibility_event_handler(visible)
{
	Log::message("\Обработка события RenderModelsVisibility\n");
}

//////////////////////////////////////////////////////////////////////////////
//  1. Несколько подписок можно связать с экземпляром класса EventConnections,
//  который затем можно использовать для отмены всех этих подписок сразу
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnections
EventConnections rendermodelsvisibility_event_connections;

// связываем с этим экземпляром при подписке на событие (можно связывать подписки на разные события)
VR::getEventRenderModelsVisibility().connect(rendermodelsvisibility_event_connections, rendermodelsvisibility_event_handler);

// другие подписки также связаны с этим экземпляром EventConnections
// (например, можно подписываться с помощью лямбда-функций)
VR::getEventRenderModelsVisibility().connect(rendermodelsvisibility_event_connections, [](visible) {
		Log::message("\Обработка события RenderModelsVisibility (лямбда).\n");
	}
);

// ...

// позже все эти связанные подписки можно удалить одной строкой
rendermodelsvisibility_event_connections.disconnectAll();

//////////////////////////////////////////////////////////////////////////////
//  2. Можно подписываться и отписываться через экземпляр класса EventConnection.
//  А также включать и отключать это конкретное соединение при необходимости.
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnection
EventConnection rendermodelsvisibility_event_connection;

// подписываемся на событие RenderModelsVisibility с функцией-обработчиком, сохраняя соединение
VR::getEventRenderModelsVisibility().connect(rendermodelsvisibility_event_connection, rendermodelsvisibility_event_handler);

// ...

// можно временно отключить конкретное соединение события для выполнения определённых действий
rendermodelsvisibility_event_connection.setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
rendermodelsvisibility_event_connection.setEnabled(true);

// ...

// удаляем подписку на событие RenderModelsVisibility через соединение
rendermodelsvisibility_event_connection.disconnect();

//////////////////////////////////////////////////////////////////////////////
//  3. Можно добавить экземпляр EventConnection/EventConnections как член класса,
//  обрабатывающего событие. В этом случае все связанные подписки будут
//  автоматически удалены при вызове деструктора класса

// Класс, обрабатывающий событие
class SomeClass
{
public:
	// экземпляр класса EventConnections как член класса
	EventConnections e_connections;

	// Обработчик события RenderModelsVisibility, реализованный как член класса
	void event_handler(visible)
	{
		Log::message("\Обработка события RenderModelsVisibility\n");
		// ...
	}
};

SomeClass *sc = new SomeClass();

// экземпляр класса-обработчика удаляется, а все его подписки автоматически отменяются

EventConnections e_connections;

// определяем идентификатор соединения, который будет использован для отписки позже
EventConnectionId rendermodelsvisibility_handler_id;

// подписываемся на событие RenderModelsVisibility с лямбда-обработчиком, сохраняя идентификатор соединения
rendermodelsvisibility_handler_id = VR::getEventRenderModelsVisibility().connect(e_connections, [](visible) {
		Log::message("\Обработка события RenderModelsVisibility (лямбда).\n");
	}
);

VR::getEventRenderModelsVisibility().disconnect(rendermodelsvisibility_handler_id);
```

## static Event<int> getEventDeviceRenderModelChanged () const

Событие, генерируемое при изменении render-модели VR-устройства. Вы можете подписываться на события через *connect()* и отписываться через *disconnect()*. Также для удобства можно использовать классы *[EventConnection](../../../api/library/common/events/class.eventconnection_cpp.md)* и *[EventConnections](../../../api/library/common/events/class.eventconnections_cpp.md)* (см. примеры ниже).

> **Notice:** Подробнее см. статью [Event Handling](../../../code/fundamentals/events/index_cpp.md).

 Сигнатура обработчика события выглядит следующим образом: *myhandler(**vr_device_number**)*
<details>
<summary>Показать пример | Скрыть</summary>

**Пример использования**

```cpp

{
	Log::message("\Обработка события DeviceRenderModelChanged\n");
}

//////////////////////////////////////////////////////////////////////////////
//  1. Несколько подписок можно связать с экземпляром класса EventConnections,
//  который затем можно использовать для отмены всех этих подписок сразу
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnections
EventConnections devicerendermodelchanged_event_connections;

// связываем с этим экземпляром при подписке на событие (можно связывать подписки на разные события)
VR::getEventDeviceRenderModelChanged().connect(devicerendermodelchanged_event_connections, devicerendermodelchanged_event_handler);

// другие подписки также связаны с этим экземпляром EventConnections
// (например, можно подписываться с помощью лямбда-функций)
VR::getEventDeviceRenderModelChanged().connect(devicerendermodelchanged_event_connections, [](vr_device_number) {
		Log::message("\Обработка события DeviceRenderModelChanged (лямбда).\n");
	}
);

// ...

// позже все эти связанные подписки можно удалить одной строкой
devicerendermodelchanged_event_connections.disconnectAll();

//////////////////////////////////////////////////////////////////////////////
//  2. Можно подписываться и отписываться через экземпляр класса EventConnection.
//  А также включать и отключать это конкретное соединение при необходимости.
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnection

// ...

devicerendermodelchanged_event_connection.disconnect();

//////////////////////////////////////////////////////////////////////////////
//  3. Можно добавить экземпляр EventConnection/EventConnections как член класса,
//  обрабатывающего событие. В этом случае все связанные подписки будут
//  автоматически удалены при вызове деструктора класса

public:

	{
		Log::message("\Обработка события DeviceRenderModelChanged\n");
		// ...
	}
```
