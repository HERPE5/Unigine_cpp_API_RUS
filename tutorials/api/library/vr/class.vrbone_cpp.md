### Методы класса

## const char * getName () const

Возвращает текущее имя кости руки.
### Возвращаемое значение

Текущее имя кости руки.
## VRBone::TYPE getType () const

Возвращает текущий тип кости руки.
### Возвращаемое значение

Текущий тип кости руки, одно из значений [VRBone::TYPE](#TYPE_PALM).
## Ptr < VRHand > getHand () const

Возвращает текущую руку, содержащую эту кость.
### Возвращаемое значение

Текущая рука, содержащая эту кость.
## bool isTransformValid () const

Возвращает текущее значение, указывающее, действительна ли трансформация кости.
### Возвращаемое значение

**true**, если трансформация кости действительна; иначе **false**.
## bool isVelocityValid () const

Возвращает текущее значение, указывающее, действительна ли скорость кости.
### Возвращаемое значение

**true**, если скорость кости действительна; иначе **false**.
## Math:: mat4 getTransform () const

Возвращает текущую трансформацию кости в локальных координатах относительно родительского узла.
### Возвращаемое значение

Текущая локальная трансформация кости.
## Math:: Mat4 getWorldTransform () const

Возвращает текущую трансформацию кости в мировых координатах.
### Возвращаемое значение

Текущая мировая трансформация кости.
## Math:: vec3 getWorldLinearVelocity () const

Возвращает текущую линейную скорость кости.
### Возвращаемое значение

Текущая линейная скорость кости.
## Math:: vec3 getWorldAngularVelocity () const

Возвращает текущую угловую скорость кости.
### Возвращаемое значение

Текущая угловая скорость кости.
## Math:: vec3 getWorldAngularAcceleration () const

Возвращает текущее угловое ускорение кости.
### Возвращаемое значение

Текущее угловое ускорение кости.
## float getRadius () const

Возвращает текущий радиус кости.
### Возвращаемое значение

Текущий радиус кости.
## Ptr < VRBone > getParent () const

Возвращает текущий родительский элемент кости.
### Возвращаемое значение

Текущий родительский элемент кости.
## int getNumChildren () const

Возвращает текущее общее количество дочерних элементов кости.
### Возвращаемое значение

Текущее общее количество дочерних элементов кости.
---

## Ptr < VRBone > getChild ( int i )

Возвращает дочернюю кость руки по её индексу.
### Аргументы

- *int* **i** - Индекс дочернего элемента.

### Возвращаемое значение

Кость руки.
## void renderBasis ( ) const

Включает визуализатор базиса каждой кости руки. Эта опция требует включения [bone visualizer](#renderVisualizer_vec4_void).
## void renderVelocity ( ) const

Включает визуализатор векторов скорости каждой кости руки. Эта опция требует включения [bone visualizer](#renderVisualizer_vec4_void).
## void renderVisualizer ( const Math:: vec4 & color ) const

Включает визуализатор костей. Эта опция требует включения [visualizer mode](../../../code/console/index.md).
### Аргументы

- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md) &* **color** - Цвет визуализатора.
