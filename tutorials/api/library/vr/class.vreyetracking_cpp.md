# Unigine.VREyeTracking Class (CPP)

**Header:** #include <UnigineVREyeTracking.h>

> **Notice:** Этот класс является синглтоном.


Класс используется для управления айтрекингом на устройствах Varjo.


## VREyeTracking Class

### Перечисления

## STATUS

| Name | Description |
|---|---|
| **STATUS_INVALID** = 0 | Данные недоступны, пользователь не надел устройство, или глаза не обнаружены. |
| **STATUS_ADJUST** = 1 | Пользователь надел устройство, но отслеживание взгляда находится в процессе калибровки. |
| **STATUS_VALID** = 2 | Данные действительны. |

## EYE_STATUS

| Name | Description |
|---|---|
| **EYE_STATUS_INVALID** = 0 | Глаз не отслеживается и не виден (например, глаз закрыт). |
| **EYE_STATUS_VISIBLE** = 1 | Глаз виден, но не отслеживается надёжно (например, саккада или моргание). |
| **EYE_STATUS_COMPENSATED** = 2 | Глаз отслеживается, но качество снижено (например, шлем сместился после калибровки). |
| **EYE_STATUS_TRACKED** = 3 | Глаз отслеживается. |

### Методы класса

## bool isAvailable () const

Возвращает текущее значение, указывающее, доступен ли айтрекинг на активном VR-устройстве и поддерживается ли он во время выполнения.
### Возвращаемое значение

**true**, если айтрекинг доступен; иначе **false**.
## bool isValid () const

Возвращает текущее значение, указывающее, действителен ли айтрекинг.
### Возвращаемое значение

**true**, если айтрекинг действителен; иначе **false**.
## Math:: Vec3 getFocusWorldPosition () const

Возвращает текущую позицию точки фокуса глаз в мировых координатах.
### Возвращаемое значение

Текущая мировая позиция точки фокуса глаз.
## Math:: vec3 getGazeWorldDirection () const

Возвращает текущий вектор направления взгляда, являющийся комбинированным значением для обоих глаз, в мировых координатах.
### Возвращаемое значение

Текущий вектор направления для обоих глаз
## Math:: Vec3 getLeftEyeWorldPosition () const

Возвращает текущую позицию левого глаза в мировых координатах.
### Возвращаемое значение

Текущая мировая позиция левого глаза.
## Math:: vec3 getLeftEyeWorldDirection () const

Возвращает текущий вектор направления левого глаза в мировых координатах.
### Возвращаемое значение

Текущий вектор направления левого глаза.
## float getLeftPupilDiameter () const

Возвращает текущий оценочный диаметр левого зрачка. Функция возвращает 0.0f, если зрачок не отслеживается или оценка недоступна.
### Возвращаемое значение

Текущий диаметр левого зрачка, в миллиметрах.
## getLeftPupilIrisDiameterRatio () const

Возвращает текущее отношение оценки диаметра левого зрачка к оценочному диаметру левой радужки. Если одна из оценок недоступна, что не позволяет вычислить отношение, функция возвращает 0.0f.
### Возвращаемое значение

Текущее отношение оценки диаметра левого зрачка к оценочному диаметру левой радужки.
## float getLeftIrisDiameter () const

Возвращает текущий оценочный диаметр левой радужки. Функция возвращает 0.0f, если оценка недоступна.
### Возвращаемое значение

Текущий диаметр левой радужки, в миллиметрах.
## float getLeftOpenness () const

Возвращает текущий оценочный коэффициент открытости левого глаза. 1.0f соответствует полностью открытому глазу, 0.0f - полностью закрытому.
### Возвращаемое значение

Текущий оценочный коэффициент открытости левого глаза в диапазоне [0.0f;1.0f].
## VREyeTracking::EYE_STATUS getLeftStatus () const

Возвращает текущий статус левого глаза.
### Возвращаемое значение

Текущий статус левого глаза.
