# Unigine.VRHandTracking Class (CPP)

**Header:** #include <UnigineVRHandTracking.h>

> **Notice:** Этот класс является синглтоном.


Этот класс управляет функцией отслеживания рук в VR. Он позволяет визуализировать базис, скорость и размер костей для проверки и настройки конфигурации рук.


> **Notice:** Отслеживание рук нативно поддерживается только при использовании бэкенда OpenXR. Это включает **любое VR-устройство, поддерживающее отслеживание рук OpenXR** (например, Quest, Varjo, Vive с соответствующими рантаймами). Для бэкендов *varjo* и *openvr* отслеживание рук требует дополнительного **[Ultraleap Plugin](../../../code/plugins/ultraleap/index_cpp.md)**.
>
>
> См. [this article](../../../vr_development/vr_hand_tracking.md), чтобы правильно настроить отслеживание рук в вашем проекте и выбрать нужный бэкенд.


## VRHandTracking Class

### Методы класса

## bool isAvailable () const

Возвращает текущее значение, указывающее, доступно ли отслеживание рук на активном VR-устройстве и поддерживается ли оно во время выполнения.
### Возвращаемое значение

**true**, если отслеживание рук доступно; иначе **false**.
## Ptr < VRHand > getHandLeft () const

Возвращает текущую левую руку.
### Возвращаемое значение

Текущая левая рука.
## Ptr < VRHand > getHandRight () const

Возвращает текущую правую руку.
### Возвращаемое значение

Текущая правая рука.
## void setVisualizerEnabled ( bool enabled = 0 )

***Консоль*:**`vr_hand_tracking_visualizer_enabled`Задаёт новое значение, указывающее, включён ли визуализатор рук. При значении 1 движок будет рисовать простой отладочный скелет рук, показывая только кости. Эта опция требует включения [Visualizer](../../../code/console/index.md#show_visualizer).
![](../../../../../../../../../en/docs/future/api/library/vr/ht_command_visualizer.png)

 Этот параметр хранится в следующем конфигурационном файле: **[*.boot](../../../code/configuration_file_cpp.md#boot)**.
### Аргументы

- *bool* **enabled** - **true**, чтобы включить визуализатор рук; **false** - чтобы отключить его. Значение по умолчанию - **false**.
