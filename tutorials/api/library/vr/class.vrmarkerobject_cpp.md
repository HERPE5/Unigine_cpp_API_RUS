# Unigine.VRMarkerObject Class (CPP)

**Header:** #include <UnigineVRMixedReality.h>


Класс используется для управления объектным маркером Varjo. Маркеры Varjo обычно используются в приложениях смешанной реальности, но также могут применяться без сквозного видеорендеринга в приложениях виртуальной реальности для совмещения виртуальных объектов сцены с физическими объектами реального мира.


Объектные маркеры используются для отслеживания статических или динамических объектов в окружении пользователя. Объектные маркеры можно использовать как в XR, так и в VR приложениях. Каждый маркер имеет уникальный ID, и не следует использовать один и тот же маркер более одного раза в рамках одного окружения. Для повышения точности приложение может использовать несколько маркеров для отслеживания одного объекта. Например, можно отслеживать монитор, разместив маркер на каждом углу.


Чтобы получить объект маркера и извлечь из него информацию, используйте методы *[getMarkerObject()](../../../api/library/vr/class.vrmixedreality_cpp.md#getMarkerObject_short_VRMarkerObject)* или *[getMarkerObjectByID()](../../../api/library/vr/class.vrmixedreality_cpp.md#getMarkerObjectByID_short_VRMarkerObject)* класса **[VRMixedReality](../../../api/library/vr/class.vrmixedreality_cpp.md)**.


## VRMarkerObject Class

### Методы класса

## int getID () const

Возвращает текущий уникальный ID объекта маркера.
### Возвращаемое значение

Текущий ID объекта маркера.
## Math:: mat4 getTransform () const

Возвращает текущую трансформацию позы маркера.
### Возвращаемое значение

Текущая трансформация позы.
## Math:: Mat4 getWorldTransform () const

Возвращает текущую трансформацию позы маркера в глобальном пространстве.
### Возвращаемое значение

Текущая трансформация позы в глобальном пространстве.
## Math:: Vec3 getSize () const

Возвращает текущий размер маркера.
### Возвращаемое значение

Текущий размер, в метрах.
## Math:: Vec3 getVelocity () const

Возвращает текущую линейную скорость.
### Возвращаемое значение

Текущая линейная скорость, в метрах в секунду.
## Math:: Vec3 getAngularVelocity () const

Возвращает текущую угловую скорость.
### Возвращаемое значение

Текущая угловая скорость, в радианах в секунду.
## Math:: Vec3 getAcceleration () const

Возвращает текущее ускорение.
### Возвращаемое значение

Текущее ускорение, в м/с2.
## long long getRawTimestamp () const

Возвращает текущую метку времени позы. Она представляет момент времени, до которого была экстраполирована поза.
### Возвращаемое значение

Текущая метка времени позы, в наносекундах.
## double getConfidence () const

Возвращает текущую достоверность трекера.
### Возвращаемое значение

Текущая достоверность трекера в диапазоне [0.0, 1.0].
## int getPoseFlags () const

Возвращает текущее значение битового поля, описывающего позу.
### Возвращаемое значение

Текущее значение битового поля, описывающего позу. Одно из значений [*MARKER_POSE_FLAGS_**](#MARKER_POSE_FLAGS_TRACING_OK)
## void setDynamic ( bool dynamic )

Задаёт новое значение, указывающее, отслеживается ли маркер как динамический (поза маркера предсказывается).
### Аргументы

- *bool* **dynamic** - **true**, чтобы маркер отслеживался как динамический; **false** - чтобы отключить это.

## bool isDynamic () const

Возвращает текущее значение, указывающее, отслеживается ли маркер как динамический (поза маркера предсказывается).
### Возвращаемое значение

**true**, если отслеживание маркера как динамического включено; иначе **false**.
## void setLifetime ( float lifetime )

Задаёт новое время жизни маркера.
### Аргументы

- *float* **lifetime** - Время жизни маркера.

## float getLifetime () const

Возвращает текущее время жизни маркера.
### Возвращаемое значение

Текущее время жизни маркера.
