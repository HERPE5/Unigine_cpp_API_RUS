# AnimScript Class (CPP)

**Header:** #include <UnigineAnimation.h>


Этот класс предоставляет интерфейс уровня кода для взаимодействия с графами анимации во время выполнения. Графы анимации — это визуальные, узловые ресурсы (файлы `*.agraph`), созданные в редакторе, которые определяют сложную логику анимации — конечные автоматы, деревья блендинга и переходы.


Класс AnimScript служит контроллером экземпляра графа во время выполнения: он позволяет читать и записывать параметры графа для управления анимацией из игровой логики (например, установка параметра скорости для управления блендингом ходьбы/бега или булева флага для запуска состояния прыжка). Он также предоставляет доступ к данным root motion для перемещения персонажа на основе физики.


Экземпляр AnimScript получается из узла [NodeSkeletonPose](../../../../api/library/nodes/class.nodeskeletonpose_cpp.md) через [getAnimScript()](../../../../api/library/nodes/class.nodeskeletonpose_cpp.md#getAnimScript_AnimScript).


## AnimScript Class

### Перечисления

## PARAM_TYPE

Идентификатор типа параметра, используемый для различения типов значений параметров графа анимации.
| Имя | Описание |
|---|---|
| **PARAM_TYPE_UNKNOWN** = 0 | Неизвестный или неинициализированный тип параметра. |
| **PARAM_TYPE_INT** = 1 | Целочисленный параметр. |
| **PARAM_TYPE_FLOAT** = 2 | Параметр с плавающей точкой. |
| **PARAM_TYPE_BOOL** = 3 | Булев параметр. |
| **PARAM_TYPE_QUAT** = 4 | Параметр вращения-кватерниона. |
| **PARAM_TYPE_VEC2** = 5 | Параметр 2-компонентного вектора с плавающей точкой. |
| **PARAM_TYPE_VEC3** = 6 | Параметр 3-компонентного вектора с плавающей точкой. |
| **PARAM_TYPE_VEC4** = 7 | Параметр 4-компонентного вектора с плавающей точкой. |
| **PARAM_TYPE_IVEC2** = 8 | Параметр 2-компонентного целочисленного вектора. |
| **PARAM_TYPE_IVEC3** = 9 | Параметр 3-компонентного целочисленного вектора. |
| **PARAM_TYPE_IVEC4** = 10 | Параметр 4-компонентного целочисленного вектора. |
| **PARAM_TYPE_MAT3** = 11 | Параметр матрицы 3x3. |
| **PARAM_TYPE_MAT4** = 12 | Параметр матрицы 4x4. |
| **PARAM_TYPE_ANIM_ASSET** = 13 | Параметр ссылки на ресурс анимации (GUID). |
| **PARAM_TYPE_TRIGGER** = 14 | Параметр-триггер. Триггер — это булеподобный параметр, который автоматически сбрасывается в false после обработки графом анимации. |
| **NUM_PARAM_TYPES** = 15 | Общее количество типов параметров. |

### Методы класса

## isInit () const

Возвращает текущее значение, указывающее, инициализирован ли граф анимации и готов ли он к использованию.
### Возвращаемое значение

Инициализирован ли граф анимации в данный момент.
## getFileGUID () const

Возвращает текущий GUID исходного файла ресурса графа анимации.
### Возвращаемое значение

Текущий GUID файла графа анимации.
## const char * getFilePath () const

Возвращает текущий путь к файлу исходного ресурса графа анимации.
### Возвращаемое значение

Текущий путь к файлу графа анимации.
## getNumParams () const

Возвращает текущее общее количество параметров, определённых в графе анимации.
### Возвращаемое значение

Текущее количество параметров.
## isActiveRootMotion () const

Возвращает текущее значение, указывающее, активно ли в данный момент извлечение root motion в графе анимации.
### Возвращаемое значение

Активен ли в данный момент root motion.
## Math::Transform Math::Transform getRootMotionDelta () const

Возвращает текущую дельта-трансформацию root motion, накопленную во время последнего обновления графа, представляющую перемещение и поворот персонажа, извлечённые из анимации.
### Возвращаемое значение

Текущая дельта-трансформация root motion.
