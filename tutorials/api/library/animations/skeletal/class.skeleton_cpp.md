# Skeleton Class (CPP)

**Header:** #include <UnigineSkeleton.h>


Этот класс представляет скелет — иерархическую конструкцию суставов, используемую для деформации скиновых мешей. Скелет определяет иерархию суставов (имена, отношения родитель-потомок), трансформации бинд-позы, маски блендинга для частичного смешивания анимации, профили времени и веса блендинга, а также данные ретаргетинга для переноса анимаций между различными скелетами.


Единый файл `*.skeleton` выступает в роли общего ресурса: несколько файлов `*.mesh_skinned` и `*.anim` могут ссылаться на один и тот же скелет, если их риги совместимы.


## Skeleton Class

### Перечисления

## RETARGET_MODE

Режим ретаргетинга трансляции для сустава, определяющий, как перемещения суставов передаются между различными скелетами.
| Имя | Описание |
|---|---|
| **RETARGET_MODE_POSE** = 0 | Использовать перемещение сустава из позы анимации как есть. |
| **RETARGET_MODE_BIND** = 1 | Использовать перемещение бинд-позы целевого скелета, игнорируя перемещение исходной анимации. |
| **RETARGET_MODE_PROPORTION** = 2 | Масштабировать перемещение пропорционально на основе соотношения длины кости между исходным и целевым скелетами. |

## void beginEditingHierarchy ( )

Начинает редактирование иерархии суставов. Во время редактирования суставы можно добавлять, удалять и менять их родителей. Вызовите [endEditingHierarchy()](#endEditingHierarchy_void) по завершении, чтобы применить изменения.
## void endEditingHierarchy ( Vector <int> & OUT_old_to_new_joint )

Завершает редактирование иерархии суставов и выводит таблицу переотображения старых индексов суставов в новые. Используйте эту перегрузку, когда требуется обновить внешние ссылки на суставы после изменений иерархии.
### Аргументы

- *[Vector](../../../../api/library/containers/vector/class.vector_cpp.md)<int> &* **OUT_old_to_new_joint** - Выходной массив, получающий отображение старых индексов суставов в новые индексы суставов после реорганизации иерархии. > **Notice:** Этот выходной буфер заполняется Движком в результате выполнения метода.

## void endEditingHierarchy ( )

- *Math::Transform &* **transform** - Трансформация бинд-позы в локальном (относительно родителя) пространстве сустава.
