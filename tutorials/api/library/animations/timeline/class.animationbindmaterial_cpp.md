# Unigine::AnimationBindMaterial Class (CPP)

**Header:** #include <UnigineAnimation.h>

**Inherits from:** AnimationBind


Этот класс используется для управления привязками материалов [bindings](../../../../principles/animations/index.md#animation_binding) у [animation objects](../../../../principles/animations/index.md#animation_object) из кода. Объекты анимации служат прокси в последовательностях анимации и привязываются к конкретным объектам (материалам, узлам, параметрам свойств или runtime-объектам, таким как виджеты и окна) на этапе воспроизведения.


Привязки используются для хранения, поиска и получения реальных объектов движка, которые фактически анимируются.


Материал, который будет анимироваться, может быть привязан либо через ассет материала, либо через поверхность объекта, которой этот материал назначен, в зависимости от указанного режима доступа [access mode](#setAccess_int_void). В случае доступа к материалу через поверхность будет получен дочерний материал, унаследованный от материала, назначенного этой поверхности.


## AnimationBindMaterial Class

### Перечисления

## ACCESS

Режим доступа. Определяет способ получения анимируемого материала.
| Имя | Описание |
|---|---|
| **ACCESS_FROM_ASSET** = 0 | Анимируемый материал получается из ассета материала (`.mat`). |
| **ACCESS_FROM_SURFACE** = 1 | Анимируемый материал получается из поверхности объекта. В этом случае будет получен дочерний материал, унаследованный от материала, назначенного поверхности. |

### Аргументы

## void setMaterialDescription ( const UGUID & guid , const UGUID & file_guid )

Устанавливает параметры описания анимируемого материала. Этот метод используется, если режим доступа [access mode](#setAccess_int_void) установлен в *[ACCESS_FROM_ASSET](../../../...md#ACCESS_FROM_ASSET)*
### Аргументы

- *const [UGUID](../../../../api/library/filesystem/class.uguid_cpp.md) &* **guid** - GUID анимируемого материала.
- *const [UGUID](../../../../api/library/filesystem/class.uguid_cpp.md) &* **file_guid** - GUID файла, описывающего анимируемый материал.

## void setObjectDescription ( int id , const char * name )

Устанавливает параметры описания объекта, которому принадлежит поверхность с анимируемым материалом. Этот метод используется, если режим доступа [access mode](#setAccess_int_void) установлен в *[ACCESS_FROM_SURFACE](../../../...md#ACCESS_FROM_SURFACE)*.
### Аргументы

- *int* **id** - ID объекта, которому принадлежит поверхность с анимируемым материалом.
- *const char ** **name** - Имя объекта, которому принадлежит поверхность с анимируемым материалом.

## void setSurfaceDescription ( const char * name , int index )

Устанавливает параметры описания поверхности, которой назначен анимируемый материал. Этот метод используется, если режим доступа [access mode](#setAccess_int_void) установлен в *[ACCESS_FROM_SURFACE](../../../...md#ACCESS_FROM_SURFACE)*
### Аргументы

- *const char ** **name** - Имя поверхности, которой назначен анимируемый материал.
- *int* **index** - Номер поверхности, которой назначен анимируемый материал.
