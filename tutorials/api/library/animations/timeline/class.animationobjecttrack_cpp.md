# Unigine::AnimationObjectTrack Class (CPP)

**Header:** #include <UnigineAnimation.h>

**Inherits from:** AnimationObject


Этот класс позволяет управлять прокси-[animation objects](../../../../principles/animations/index.md#animation_object), используемыми для управления треками анимации. Привязка к конкретному треку анимации в рамках конкретного [playback](../../../../principles/animations/index.md#animation_playback) выполняется по имени трека.


## AnimationObjectTrack Class

---

## AnimationObjectTrack ( const char * name )

Конструктор. Создаёт новый объект анимации трека с указанным именем.
### Аргументы

- *const char ** **name** - Имя объекта анимации трека.
