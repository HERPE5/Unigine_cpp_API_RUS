# Unigine::AnimationBindPropertyParameter Class (CPP)

**Header:** #include <UnigineAnimation.h>

**Inherits from:** AnimationBind


Этот класс используется для управления привязками параметров свойств [bindings](../../../../principles/animations/index.md#animation_binding) у [animation objects](../../../../principles/animations/index.md#animation_object) из кода. Объекты анимации служат прокси в последовательностях анимации и привязываются к конкретным объектам (материалам, узлам, параметрам свойств или runtime-объектам, таким как виджеты и окна) на этапе воспроизведения.


Привязки используются для хранения, поиска и получения реальных объектов движка, которые фактически анимируются.


Анимируемый параметр свойства может быть привязан либо через ассет свойства, либо через узел, либо через поверхность объекта, которой назначено свойство с анимируемым параметром, в зависимости от указанного режима доступа [access mode](#setAccess_int_void). В случае доступа к параметру свойства через поверхность будет получено дочернее свойство, унаследованное от свойства, назначенного этой поверхности.


## AnimationBindPropertyParameter Class

### Перечисления

## ACCESS

Режим доступа. Определяет способ получения анимируемого материала.
| Имя | Описание |
|---|---|
| **ACCESS_FROM_ASSET** = 0 | Анимируемый материал получается из ассета материала (`.mat`). |
| **ACCESS_FROM_NODE** = 1 | Анимируемый материал получается из узла. |
| **ACCESS_FROM_SURFACE** = 2 | Анимируемый материал получается из поверхности объекта. В этом случае будет получено дочернее свойство, унаследованное от свойства, назначенного поверхности. |
