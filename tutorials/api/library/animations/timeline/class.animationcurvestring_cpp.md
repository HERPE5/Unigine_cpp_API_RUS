# Unigine::AnimationCurveString Class (CPP)

**Header:** #include <UnigineAnimation.h>

**Inherits from:** AnimationCurve


Этот класс представляет интерфейс, позволяющий создавать и управлять кривыми анимации, содержащими строковые значения.


## AnimationCurveString Class

### Методы класса

## const char * getDefaultKeyValue () const

Возвращает текущее значение по умолчанию для всех ключей кривой.
### Возвращаемое значение

Текущее значение по умолчанию для всех ключей кривой.
## getNumKeys () const

Возвращает текущее общее количество ключевых точек в кривой.
### Возвращаемое значение

Текущее общее количество ключевых точек в кривой.
## getMinTime () const

Возвращает текущую точку общей временной шкалы анимации, с которой начинает применяться эта кривая, в единицах.
### Возвращаемое значение

Текущая точка общей временной шкалы анимации, с которой начинает применяться эта кривая, в единицах.
## getMaxTime () const

Возвращает текущую точку общей временной шкалы анимации, до которой применяется эта кривая, в единицах.
### Возвращаемое значение

Текущая точка общей временной шкалы анимации, до которой применяется эта кривая, в единицах.

## AnimationCurveString ( )

Конструктор. Создаёт новый экземпляр кривой анимации, содержащей строковые значения.
## void copy ( const Ptr < AnimationCurveString > & curve )

Копирует все данные (ключевые точки и касательные) из указанной исходной кривой.
### Аргументы

- *const [Ptr](../../../../api/library/common/class.ptr_cpp.md)<[AnimationCurveString](../../../../api/library/animations/timeline/class.animationcurvestring_cpp.md)> &* **curve** - Исходная кривая.

## int addKey ( float time , const char * value )

Добавляет в кривую новую ключевую точку с указанным значением в указанной точке временной шкалы.
### Аргументы

- *float* **time** - Время ключа на временной шкале, в секундах.
- *const char ** **value** - Строковое значение ключа.

### Возвращаемое значение

Индекс добавленной ключевой точки.
## void removeKey ( int index )

Удаляет из кривой ключевую точку с указанным индексом.
### Аргументы

- *int* **index** - Номер ключевой точки в диапазоне от 0 до [total number of key points](#getNumKeys_int) в кривой.

## int moveKey ( int index , float new_time )

Перемещает ключевую точку с указанным номером на новую временную позицию (с сохранением касательных). Индекс ключевой точки будет автоматически обновлён. Этот метод можно использовать для реализации перетаскивания ключей на кривой.
### Аргументы

- *int* **index** - Номер ключевой точки в диапазоне от 0 до [total number of key points](#getNumKeys_int) в кривой.
- *float* **new_time** - Время ключа на временной шкале, в секундах.

### Возвращаемое значение

Новый индекс ключа.
## float getKeyTime ( int index ) const

Возвращает текущее время ключевой точки с указанным индексом.
### Аргументы

- *int* **index** - Номер ключевой точки в диапазоне от 0 до [total number of key points](#getNumKeys_int) в кривой.

### Возвращаемое значение

Время указанной ключевой точки на временной шкале, в секундах.

### Аргументы

### Возвращаемое значение
