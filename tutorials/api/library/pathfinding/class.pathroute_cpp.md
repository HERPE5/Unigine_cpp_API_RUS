# Unigine::PathRoute Class (CPP)

**Header:** #include <UniginePathFinding.h>


> **Warning:** - Функция 3D-навигации является экспериментальной и не рекомендуется для использования в production.
> - Между функциями класса *PathRoute* и функциями класса *Path* нет связи.


Этот класс рассчитывает кратчайший 2D- или 3D-маршрут в обход препятствий в пределах связанных областей навигации и задаёт размер и скорость точки, перемещающейся по этому маршруту.


- В случае маршрута **2D** точка перемещается в нижней плоскости области навигации. Координата Z не учитывается при расчёте 2D-маршрута. Значения высоты и радиуса, заданные для точки через *[*setHeight()*](#setHeight_float_void)* и *[*setRadius()*](#setRadius_float_void)*, используются для проверки того, может ли область навигации участвовать в поиске пути: если высота или радиус, заданные для точки, превышают размер области навигации, такая область навигации будет отброшена. Если разница высот между связанными областями превышает [maximum height](#setMaxHeight_float_void), область навигации также исключается из расчётов.
- В случае маршрута **3D** (доступен только для [navigation sectors](../../../api/library/pathfinding/class.navigationsector_cpp.md)) точка перемещается в трёх измерениях. Радиус, заданный для точки через *[*setRadius()*](#setRadius_float_void)*, используется для проверки того, может ли navigation sector участвовать в поиске пути: если радиус, заданный для точки, превышает размер navigation sector, он будет отброшен. Также точка не может подняться выше [maximum height](#setMaxHeight_float_void), заданной для navigation sector.


Функции класса PathRoute позволяют игнорировать указанные [navigation areas](#setExcludeNavigations_VECNode_void) и [obstacles](#setExcludeObstacles_VECNode_void).


Также можно ограничить [maximum time](#setMaxTime_float_void), допустимое для достижения конечной точки, и [maximum danger](#setMaxDangerous_float_void) factor.


> **Notice:** Для выбора между областями навигации используется алгоритм A*.

## PathRoute Class

### Методы класса

## void setVelocity ( float velocity )

Задаёт новую скорость точки, перемещающейся по маршруту.
### Аргументы

- *float* **velocity** - Скорость точки, перемещающейся по маршруту.

## float getVelocity () const

Возвращает текущую скорость точки, перемещающейся по маршруту.
### Возвращаемое значение

Текущая скорость точки, перемещающейся по маршруту.
## void setRadius ( float radius )

Задаёт новый радиус, необходимый для перемещения точки по маршруту внутри области навигации. Если указанный радиус превышает размер области навигации, точка не будет перемещаться внутри неё.
### Аргументы

- *float* **radius** - Радиус, необходимый для перемещения точки по маршруту внутри области навигации. Если указано отрицательное значение, вместо него используется **0**.

## float getRadius () const

Возвращает текущий радиус, необходимый для перемещения точки по маршруту внутри области навигации. Если указанный радиус превышает размер области навигации, точка не будет перемещаться внутри неё.
### Возвращаемое значение

Текущий радиус, необходимый для перемещения точки по маршруту внутри области навигации. Если указано отрицательное значение, вместо него используется **0**.
## void setObstacleMask ( int mask )

Задаёт новую маску препятствий. Препятствие учитывается, если его маска препятствий [matches](../../../principles/bit_masking/index.md) с маской препятствий маршрута.
### Аргументы

- *int* **mask** - Целочисленное значение, каждый бит которого используется для задания маски.

## int getObstacleMask () const

Возвращает текущую маску препятствий. Препятствие учитывается, если его маска препятствий [matches](../../../principles/bit_masking/index.md) с маской препятствий маршрута.
### Возвращаемое значение

Текущее целочисленное значение, каждый бит которого используется для задания маски.
## int getNumPoints () const

Возвращает текущее количество поворотных точек на маршруте.
### Возвращаемое значение

Текущее количество поворотных точек на маршруте.
## void setNavigationMask ( int mask )

Задаёт новую маску навигации. Маска навигации области навигации должна [match](../../../principles/bit_masking/index.md) с маской навигации маршрута, рассчитываемого в её пределах. В противном случае область не будет участвовать в поиске пути.
### Аргументы

- *int* **mask** - Целочисленное значение, каждый бит которого используется для задания маски.

## int getNavigationMask () const

Возвращает текущую маску навигации. Маска навигации области навигации должна [match](../../../principles/bit_masking/index.md) с маской навигации маршрута, рассчитываемого в её пределах. В противном случае область не будет участвовать в поиске пути.
### Возвращаемое значение

Текущее целочисленное значение, каждый бит которого используется для задания маски.
## void setMaxTime ( float time )

Задаёт новое максимальное время для достижения конечной точки. Если маршрут занимает больше времени, точка не будет перемещаться по нему.
### Аргументы

- *float* **time** - Максимальное время перемещения.

## float getMaxTime () const

Возвращает текущее максимальное время для достижения конечной точки. Если маршрут занимает больше времени, точка не будет перемещаться по нему.
### Возвращаемое значение

Текущее максимальное время перемещения.
## void setMaxHeight ( float height )

Задаёт новую максимально допустимую разницу высот между связанными областями навигации при поиске 2D-маршрута. В случае 3D-маршрута это максимальная высота, на которую может подняться точка.
### Аргументы

- *float* **height** - Максимальная высота.

## float getMaxHeight () const

Возвращает текущую максимально допустимую разницу высот между связанными областями навигации при поиске 2D-маршрута. В случае 3D-маршрута это максимальная высота, на которую может подняться точка.
### Возвращаемое значение

Текущая максимальная высота.
## void setMaxDangerous ( float dangerous )

Задаёт новый максимально допустимый фактор опасности для перемещения по этому маршруту. Если области навигации имеют более высокий фактор опасности, точка не будет перемещаться по маршруту.
### Аргументы

- *float* **dangerous** - Максимальный фактор опасности.

## float getMaxDangerous () const

Возвращает текущий максимально допустимый фактор опасности для перемещения по этому маршруту. Если области навигации имеют более высокий фактор опасности, точка не будет перемещаться по маршруту.
### Возвращаемое значение

Текущий максимальный фактор опасности.

### Аргументы

## float getMaxAngle () const
