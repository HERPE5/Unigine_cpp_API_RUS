# Unigine::Plugins::Geodetics::Transformer Class (CPP)

**Header:** #include <plugins/Unigine/Geodetics/UnigineGeodetics.h>


Этот класс предоставляет низкоуровневые преобразования геодезических координат между геодезическими координатами (**широта, долгота и высота**) и 3D-позициями и ориентациями в мировом пространстве. Он использует библиотеку **GDAL** для работы с системами координат и поддерживает два способа задания проекции:


- По **коду EPSG** — числовому идентификатору из геодезического реестра EPSG (например, 32637 для зоны UTM 37N).
- По **строке WKT2** — полному описанию системы координат проекции в формате OpenGIS Well-Known Text.


После установки проекции Transformer вычисляет внутреннее **начало координат в пространстве проекции**, преобразуя предоставленное геодезическое начало координат сцены в координаты проекции. Все последующие преобразования из мировых координат в геодезические и обратно применяют это смещение, так что начало координат 3D-сцены соответствует указанной реальной геодезической локации.


Метод *[geodeticToWorld()](../../../...md#geodeticToWorld_const_dvec3_ref_bool_dmat4)* возвращает полную матрицу трансформации **dmat4**, оси которой выровнены по локальной системе координат **East-North-Up (ENU)** в указанной точке: ось X указывает на восток, ось Y указывает на север, а ось Z указывает вверх. Ориентация вычисляется путём численного дифференцирования проекции в запрашиваемой точке, что даёт точные оси локальной системы координат даже для неконформных проекций. Когда нужна только позиция, *[geodeticToWorldPosition()](../../../...md#geodeticToWorldPosition_const_dvec3_ref_bool_dvec3)* предоставляет более лёгкую альтернативу, пропускающую вычисление ориентации.


Для высокоуровневого преобразования координат, которое также обрабатывает узлы *[GeodeticPivot](../../../../api/library/geodetics/class.geodeticpivot_cpp.md)*, автоматическое определение террейна, преобразования углов Эйлера между мировым пространством и локальной геодезической системой координат, а также преобразования геоцентрических (ECEF) координат, используйте связанный класс [Converter](../../../../api/library/geodetics/geodetics_plugin/class.converter_cpp.md), доступный через *[getConverter()](../../../...md#getConverter_Converter)*.


> **Notice:** Геодезические преобразования доступны **только** если загружен [Geodetics Plugin](../../../../code/plugins/geodetics/index.md).


## Transformer Class

### Методы класса

## Math:: dvec3 getOriginProjectionSpace () const

Возвращает текущее начало координат сцены, выраженное в системе координат проекции (например, в метрах UTM). Это значение вычисляется один раз при установке проекции через **[setProjectionEpsg()](../../../...md#setProjectionEpsg_int_dvec3_cstr_bool_int)** или **[setProjectionWkt()](../../../...md#setProjectionWkt_cstr_dvec3_cstr_bool_int)** путём преобразования предоставленного геодезического начала координат в пространство проекции. Оно используется как смещение, применяемое при всех преобразованиях из мировых координат в проекцию и обратно.
### Возвращаемое значение

Текущее начало координат сцены, выраженное в системе координат проекции (например, в метрах UTM).

## int setProjectionWkt ( const char * projection_cs_wkt_string , const Math:: dvec3 & world_origin_geo_coords , const char * geodetic_cs_string = WGS84 , bool geodetic_cs_is_well_known = true )

Устанавливает проекцию по описанию WKT, которая используется как проекция мировых координат, и определяет геодезическую систему координат. Также вычисляет и сохраняет начало координат в пространстве проекции, преобразуя предоставленные координаты геодезического начала координат. При сбое всё внутреннее состояние проекции очищается.
### Аргументы

- *const char ** **projection_cs_wkt_string** - Описание проекции в формате OpenGIS WKT.
- *const  Math::[dvec3](../../../../api/library/math/class.dvec3_cpp.md) &* **world_origin_geo_coords** - Начало координат сцены в геодезических координатах (широта, долгота, высота).
- *const char ** **geodetic_cs_string** - Описание геодезической системы координат.
- *bool* **geodetic_cs_is_well_known** - true или false. Если установлено в **1**, в качестве аргумента **geodetic_cs_string** используется общеизвестное описание системы координат. Поддерживаются следующие общеизвестные текстовые значения: Если установлено в false, используется подробное описание WKT.

  - WGS84 — то же, что *EPSG:4326*, но не зависит от файлов данных EPSG.
  - WGS72 — то же, что *EPSG:4322*, но не зависит от файлов данных EPSG.
  - NAD27 — то же, что *EPSG:4267*, но не зависит от файлов данных EPSG.
  - NAD83 — то же, что *EPSG:4269*, но не зависит от файлов данных EPSG.
  - EPSG:n — *n* — это код GCS из таблицы горизонтальных систем координат.

### Возвращаемое значение

**1** при успехе; иначе **0**.
## int setProjectionEpsg ( int projection_cs_epsg_code , const Math:: dvec3 & world_origin_geo_coords , const char * geodetic_cs_string = WGS84 , bool geodetic_cs_is_well_known = true )

Устанавливает проекцию по коду EPSG, которая используется как проекция мировых координат, и определяет геодезическую систему координат. При сбое всё внутреннее состояние проекции очищается.

Поддерживаются следующие общеизвестные текстовые значения: Если установлено в false, используется подробное описание WKT.

  - WGS84 — то же, что *EPSG:4326*, но не зависит от файлов данных EPSG.
  - WGS72 — то же, что *EPSG:4322*, но не зависит от файлов данных EPSG.
  - NAD27 — то же, что *EPSG:4267*, но не зависит от файлов данных EPSG.
  - NAD83 — то же, что *EPSG:4269*, но не зависит от файлов данных EPSG.
  - EPSG:n — *n* — это код GCS из таблицы горизонтальных систем координат.

### Возвращаемое значение

**1** при успехе; иначе **0**.
## Math:: dmat4 geodeticToWorld ( const Math:: dvec3 & geo_coords , bool rotate_to_en = false ) const

Преобразует геодезические координаты выбранной системы координат в 3D-мировые координаты: позицию и вращение (ось Y направлена на север, ось X — на восток, ось Z — вверх). Ориентация вычисляется путём численного дифференцирования проекции в указанной точке для получения точных локальных векторов севера и востока. Возвращает единичную матрицу, если проекция не установлена.
### Аргументы

- *const  Math::[dvec3](../../../../api/library/math/class.dvec3_cpp.md) &* **geo_coords** - Геодезические координаты (широта, долгота, высота).
- *bool* **rotate_to_en** - true, чтобы повернуть данные следующим образом: восток => X, север => Y (ENU и похожие системы); false, если источник данных использует другое выравнивание (например, NED).

### Возвращаемое значение

Мировая позиция и ориентация.
## Math:: dvec3 geodeticToWorldPosition ( const Math:: dvec3 & geo_coords , bool rotate_to_en = false ) const

Преобразует геодезические координаты выбранной системы координат в 3D-мировые координаты (только позицию, без ориентации). Более эффективен, чем **geodeticToWorld()**, когда нужна только позиция. Возвращает нулевой вектор, если проекция не установлена.
### Аргументы

- *const  Math::[dvec3](../../../../api/library/math/class.dvec3_cpp.md) &* **geo_coords** - Геодезические координаты (широта, долгота, высота).
- *bool* **rotate_to_en** - true, чтобы повернуть данные следующим образом: восток => X, север => Y (ENU и похожие системы); false, если источник данных использует другое выравнивание (например, NED).

### Возвращаемое значение

Мировая позиция.
## Math:: dvec3 worldToGeodetic ( const Math:: dvec3 & world_position , bool rotate_to_en = false ) const

Преобразует 3D-мировые координаты в геодезические координаты выбранной системы координат. Мировая позиция сначала смещается на величину смещения начала координат в пространстве проекции, затем преобразуется через обратное преобразование координат (из проекции в геодезические). Возвращает нулевой вектор, если проекция не установлена.
### Аргументы

- *const  Math::[dvec3](../../../../api/library/math/class.dvec3_cpp.md) &* **world_position** - Мировая позиция.
- *bool* **rotate_to_en** - true, чтобы повернуть данные следующим образом: восток => X, север => Y (ENU и похожие системы); false, если источник данных использует другое выравнивание (например, NED).

### Возвращаемое значение

Геодезические координаты (широта, долгота, высота).
## Converter * getConverter ( ) const

Возвращает экземпляр **[Converter](../../../../api/library/geodetics/geodetics_plugin/class.converter_cpp.md)**, связанный с этим *Transformer*. *Converter* предоставляет высокоуровневые преобразования из геодезических координат в мировые, которые также обрабатывают узлы *[GeodeticPivot](../../../../api/library/geodetics/class.geodeticpivot_cpp.md)*, определение террейна, преобразования углов Эйлера и преобразования геоцентрических координат.
### Возвращаемое значение

Связанный экземпляр **[Converter](../../../../api/library/geodetics/geodetics_plugin/class.converter_cpp.md)**.
