# Unigine.LightProj Class (CPP)

**Header:** #include <UnigineLights.h>

**Inherits from:** Light


Этот класс используется для создания [projected light sources](../../../objects/lights/proj/index.md), излучающих свет из одной точки и создающих конус света. Свет от таких источников можно модулировать текстурой.


### Пример


Следующий код показывает, как создать проекционный источник света и задать его параметры.


```cpp
#include <UnigineLights.h>
using namespace Unigine;

/* .. */

// создание проекционного источника света с белым цветом, расстоянием затухания 10 единиц и углом FOV 60 градусов
LightProjPtr projector = LightProj::create(Math::vec4(1.0f, 1.0f, 0.5f, 1.0f), 10.0f, 60.0f, "");

// установка позиции источника света
projector->setWorldPosition(Math::Vec3(2.5f, 2.5f, 3.0f));

// установка имени источника света
projector->setName("projector");

// установка вращения источника света
projector->setWorldRotation(Math::quat(-45.0f, 45.0f, 0.0f));

// установка коэффициента полутени
projector->setPenumbra(0.425f);

// установка текстуры "mytexture.tga" для модуляции света
projector->setTextureFilePath("mytexture.tga");

// установка интенсивности света
projector->setIntensity(1.0f);

```

### Аргументы

- *bool* **fov** - Значение **true** включает масштабирование текстуры IES; **false** - отключает его.

## static LightProjPtr create ( const Math:: vec4 & color , float attenuation_distance , float fov , const char * name = 0 )

### Аргументы

- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md) &* **color** - Цвет нового источника света.
- *float* **attenuation_distance** - Расстояние от формы источника света, на котором источник света ничего не освещает.
- *float* **fov** - Угол обзора нового источника света.
- *const char ** **name** - Путь к текстуре нового источника света.

## int setTextureImage ( const Ptr < Image > & image , bool dynamic = 0 )

Задаёт заданный экземпляр Image в качестве текстуры изображения света. Если нужно задать текстуру для всех источников света в сцене, установите флаг dynamic в 1.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Image](../../../api/library/common/class.image_cpp.md)> &* **image** - Image.
- *bool* **dynamic** - Флаг динамической текстуры.

  - Если установлено в 0, изменение текстуры экземпляра источника света также повлияет на все источники света в сцене.
  - Если установлено в 1, изображение будет успешно задано только для текущего экземпляра источника света.

### Возвращаемое значение

Возвращает 1, если текстура успешно задана; иначе 0.

### Возвращаемое значение

Возвращает 1, если текстура успешно считана; иначе 0.
