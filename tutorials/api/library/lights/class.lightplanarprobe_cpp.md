# Unigine::LightPlanarProbe Class (CPP)

**Header:** #include <UnigineLights.h>

**Inherits from:** Light


Этот класс используется для создания и управления [Planar Reflection Probes](../../../objects/lights/planar/index.md), реализующими функциональность плоских отражений (используется для создания зеркал и т.д.). Проба захватывает отражение и требует поверхность, на которую это отражение будет проецироваться. Существует набор параметров, позволяющих настроить внешний вид отражений и оптимизировать нагрузку на рендеринг (ограничивая расстояние видимости, [reflections rendering distance](#setReflectionDistance_float_void) и т.д.).


### Пример использования


В примере ниже *Planar Reflection Probe* создаётся вместе с плоским примитивом. Поверхность примитива служит для проецирования отражения, захваченного пробой (отражение проецируется только в области пересечения пробы и поверхности). Также настраиваются некоторые параметры материала, назначенного отражающей поверхности, чтобы получить желаемый эффект и соответствовать диапазону [roughness](#setReflectionVisibilityRoughnessMin_float_void) (что позволяет рендерить отражения в зависимости от шероховатости поверхности).


[Create](../../../principles/component_system/component_system_cpp/index.md#workflow) новый класс с именем **PlanarReflector** и скопируйте содержимое **.h** и **.cpp** в соответствующие файлы класса. Затем [assign](../../../principles/component_system/component_system_cpp/index.md#workflow) сгенерированное для вашего компонента свойство любому нужному узлу типа *Object*, чтобы увидеть, как его текстура альбедо заменяется новым созданным изображением.

<details>
<summary>PlanarReflector.cpp | Закрыть</summary>

```cpp
#include "PlanarReflector.h"
#include <UniginePrimitives.h>
#include <UnigineObjects.h>
#include <UnigineLights.h>
REGISTER_COMPONENT(PlanarReflector);

using namespace Unigine;

void PlanarReflector::init()
{
	// создание отражающей плоскости, на которую проба будет проецировать отражение
	plane = Primitives::createPlane(20, 20, 1);

	// создание planar reflection probe такого же размера
	planar_probe = LightPlanarProbe::create();
	planar_probe->setProjectionSize(Math::vec3(20, 20, 1));
	plane->rotate(-90.0f, 0.0f, 0.0f);
	plane->translate(0.0f, 5.0f, -5.0f);

	// размещение planar probe так, чтобы она покрывала отражающую поверхность
	planar_probe->setTransform(plane->getTransform());

	// наследование нового материала от материала, назначенного
	// поверхности по умолчанию, чтобы настроить его
	// и задать значения metalness и roughness (металлический и полированный)
	MaterialPtr plane_mat = plane->getMaterialInherit(0);
	plane_mat->setParameterFloat("metalness", 1.0f);
	plane_mat->setParameterFloat("roughness", 0.0f);

	// установка расстояния от камеры, до которого
	// будет видно плоское отражение
	planar_probe->setVisibleDistance(5.0f);
}

```

## LightPlanarProbe Class

### Перечисления

## REFLECTION_RESOLUTION

| Имя | Описание |
|---|---|
| **REFLECTION_RESOLUTION_MODE_HEIGHT** = 0 | Размер текстуры отражения равен разрешению по высоте viewport. |
| **REFLECTION_RESOLUTION_MODE_HALF_HEIGHT** = 1 | Размер текстуры отражения равен половине разрешения по высоте viewport. |
| **REFLECTION_RESOLUTION_MODE_QUART_HEIGHT** = 2 | Размер текстуры отражения равен четверти разрешения по высоте viewport. |
| **REFLECTION_RESOLUTION_MODE_128** = 3 | Размер текстуры отражения равен 128x128 пикселей. |
| **REFLECTION_RESOLUTION_MODE_256** = 4 | Размер текстуры отражения равен 256x256 пикселей. |
| **REFLECTION_RESOLUTION_MODE_512** = 5 | Размер текстуры отражения равен 512x512 пикселей. |
| **REFLECTION_RESOLUTION_MODE_1024** = 6 | Размер текстуры отражения равен 1024x1024 пикселей. |
| **REFLECTION_RESOLUTION_MODE_2048** = 7 | Размер текстуры отражения равен 2048x2048 пикселей. |
| **REFLECTION_RESOLUTION_MODE_4096** = 8 | Размер текстуры отражения равен 4096x4096 пикселей. |

### Методы класса

## void setProjectionSize ( const Math:: vec3 & size )

Задаёт новый размер Light Planar Probe. Определяет объём влияния в форме бокса вокруг пробы, в единицах, в пределах которого отражающие поверхности (с соответствующими значениями шероховатости) будут использовать результаты, захваченные пробой.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md)&* **size** - Размер по осям X, Y и Z. Значение по умолчанию - (2.0f, 2.0f, 0.1f).

## Math:: vec3 getProjectionSize () const

Возвращает текущий размер Light Planar Probe. Определяет объём влияния в форме бокса вокруг пробы, в единицах, в пределах которого отражающие поверхности (с соответствующими значениями шероховатости) будут использовать результаты, захваченные пробой.
### Возвращаемое значение

Текущий размер по осям X, Y и Z. Значение по умолчанию - (2.0f, 2.0f, 0.1f).
## void setAttenuationDistance ( const Math:: vec3 & distance )

Задаёт новое расстояние затухания, определяющее, как далеко проекция может достигать любых поверхностей от позиции пробы. Оно также определяет область затухания вокруг пробы, в которой проекция начинает угасать с заданной скоростью.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md)&* **distance** - Расстояние затухания. Значение по умолчанию - (0.1f, 0.1f, 0.1f).

## Math:: vec3 getAttenuationDistance () const

Возвращает текущее расстояние затухания, определяющее, как далеко проекция может достигать любых поверхностей от позиции пробы. Оно также определяет область затухания вокруг пробы, в которой проекция начинает угасать с заданной скоростью.
### Возвращаемое значение

Текущее расстояние затухания. Значение по умолчанию - (0.1f, 0.1f, 0.1f).
