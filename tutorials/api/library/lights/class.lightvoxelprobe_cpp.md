# Unigine::LightVoxelProbe Class (CPP)

**Header:** #include <UnigineLights.h>

**Inherits from:** Light


Этот класс позволяет создавать источники *[Voxel Probe](../../../objects/lights/voxelprobe/index.md)* и управлять ими.


## LightVoxelProbe Class

### Перечисления

## BAKE_INTERNAL_VOLUME

| Имя | Описание |
|---|---|
| **BAKE_INTERNAL_VOLUME_HALF** = 0 | Запекать внутренний объём (воксели, не касающиеся геометрии) в половинном разрешении. |
| **BAKE_INTERNAL_VOLUME_FULL** = 1 | Запекать внутренний объём (воксели, не касающиеся геометрии) в полном разрешении. |

## BAKE_QUALITY

Пресет качества запекания освещения для *Voxel Probe*. Каждый пресет включает рекомендуемые общие настройки качества запекания, такие как количество симулируемых лучей света и качество сэмплирования, влияющие на время запекания освещения и итоговое качество.
| Имя | Описание |
|---|---|
| **BAKE_QUALITY_DRAFT** = 0 | Наименьшее качество сэмплирования и количество симулируемых лучей, но наивысшая итеративность. |
| **BAKE_QUALITY_LOW** = 1 | Низкое качество сэмплирования и количество симулируемых лучей света. |
| **BAKE_QUALITY_MEDIUM** = 2 | Стабильный уровень качества, подходящий для большинства случаев. |
| **BAKE_QUALITY_HIGH** = 3 | Высокое качество сэмплирования и количество симулируемых лучей света, вполне достаточное для релизного продакшена. |
| **BAKE_QUALITY_ULTRA** = 4 | Максимальное качество запекания может быть полезно для устранения небольших несоответствий в релизном продакшене. |

## BLEND

| Имя | Описание |
|---|---|
| **BLEND_ALPHA_BLEND** = 0 | Режим смешивания света alpha blend. |
| **BLEND_ADDITIVE** = 1 | Аддитивный режим смешивания света. Эта опция обеспечивает большую гибкость в управлении освещением. Её можно использовать для смешивания освещения нескольких *Voxel Probe* вместе и управления ими по отдельности (например, создать отдельную *Voxel Probe* для внутреннего источника света emission и смешать её с другой *Voxel Probe* с освещением, запечённым от неба, с возможностью включать и отключать их по отдельности). > **Notice:** Voxel probe с включённым аддитивным смешиванием нельзя использовать для добавления деталей освещения (например, создания небольшой высокодетализированной *Voxel Probe* внутри большой низкодетализированной). Такие пробы не заменяют друг друга, а смешиваются. |
| **BLEND_MULTIPLICATIVE** = 2 | Мультипликативный режим смешивания света. |

## void setBakeVisibilityEnvironmentProbe ( bool probe )

Задаёт новое значение, указывающее, выполняется ли запекание источников света environment probe в *Voxel Probe*. Эту опцию можно использовать вместе с [additive blending](#BLEND_ADDITIVE) для большей гибкости в [light baking](../../../editor2/lighting/gi/bake_lighting/index.md). Таким образом, можно сделать *Voxel Probe* независимыми друг от друга и комбинировать их для получения своего рода динамического эффекта GI.

## long long getVideoMemoryUsage ( )

Возвращает значение, определяющее, сколько памяти занимает текстура света в соответствии с её размером. Память рассчитывается по следующей формуле: ***Memory** = **SizeX** × **SizeY** × **SizeZ** × **Sides** × **FormatMemory***
- **SizeX, SizeY, SizeZ** - размеры 3D-текстуры света, в вокселях.
- **Sides** - количество сторон каждого вокселя, равное 6.
- **FormatMemory** - объём используемой памяти для текстуры в формате RGBA16, равный 8.


### Возвращаемое значение

Объём используемой памяти текстуры, в байтах.
