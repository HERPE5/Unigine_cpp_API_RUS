# Unigine.LightOmni Class (CPP)

**Header:** #include <UnigineLights.h>

**Inherits from:** Light


Этот класс используется для создания [omni directional light sources](../../../objects/lights/omni/index.md). Свет от точечных источников можно модулировать текстурой.


### Пример


Следующий код показывает, как создать точечный источник света и задать его параметры.


```cpp
#include <UnigineLights.h>
using namespace Unigine;

/* .. */

// создание точечного источника света с белым цветом и расстоянием затухания 10 единиц
LightOmniPtr light_omni = LightOmni::create(Math::vec4(1.0f, 1.0f, 1.0f, 1.0f), 10.0f, "");

// установка имени источника света
light_omni->setName("omni");

// установка позиции источника света
light_omni->setWorldPosition(Math::Vec3(0.0f, 0.0f, 5.0f));

// установка текстуры "mytexture.tga" для модуляции света
projector->setTextureFilePath("mytexture.tga");

// установка интенсивности света
light_omni->setIntensity(0.1f);

```

## Math:: vec3 getSize () const

Возвращает текущий размер области, освещаемой источником света. В зависимости от [shape type](#setShapeType_int_void) размер варьируется:
- Если источник точечный, каждый компонент вектора будет равен [*attenuation distance*](#setAttenuationDistance_float_void): ```cpp vec3(attenuation_distance) ```
- Если источник сферический, каждый компонент вектора будет равен [*attenuation distance*](#setAttenuationDistance_float_void) *+* [*sphere radius*](#setShapeRadius_float_void): ```cpp vec3(attenuation_distance + sphere_radius) ```
- Если источник в форме капсулы, 1-й компонент вектора будет равен [*attenuation distance*](#setAttenuationDistance_float_void) *+* [*capsule length*](#setShapeLength_float_void): ```cpp vec3(attenuation_distance + capsule_length,attenuation_distance,attenuation_distance) ```
- Если источник прямоугольный, 2-й компонент вектора будет равен [*attenuation distance*](#setAttenuationDistance_float_void) *+* [*rectangle height*](#setShapeHeight_float_void): ```cpp vec3(attenuation_distance,attenuation_distance + rectangle_height,attenuation_distance) ```


### Возвращаемое значение

Текущий размер освещаемой области.

## int setTextureImage ( const Ptr < Image > & image , bool dynamic = 0 )

Задаёт заданный экземпляр Image в качестве текстуры изображения света. Если нужно задать текстуру для всех источников света в сцене, установите флаг dynamic в 1.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Image](../../../api/library/common/class.image_cpp.md)> &* **image** - Устанавливаемая новая текстура.
- *bool* **dynamic** - Флаг динамической текстуры.

  - Если установлено в 0, изменение текстуры экземпляра источника света также повлияет на все источники света в сцене.
  - Если установлено в 1, изображение будет успешно задано только для текущего экземпляра источника света.

### Возвращаемое значение

Возвращает 1, если текстура успешно задана; иначе 0.

## void setShadowSideEnabled ( int side , int enable )

Включает или отключает тени для указанной стороны кубической карты точечного источника света. По умолчанию источник света отбрасывает тени во всех направлениях.
### Аргументы

- *int* **side** - Номер стороны точечного источника света, для которой включаются или отключаются тени. Одно из следующих значений:

  - 0 - положительная X
  - 1 - отрицательная X
  - 2 - положительная Y
  - 3 - отрицательная Y
  - 4 - положительная Z
  - 5 - отрицательная Z
- *int* **enable** - 1 включает тени для указанной стороны точечного источника света, 0 - отключает.

## int isShadowSideEnabled ( int side ) const

Возвращает значение, указывающее, отбрасываются ли тени для указанной стороны точечного источника света. По умолчанию источник света отбрасывает тени во всех направлениях.
### Аргументы

- *int* **side** - Номер стороны точечного источника света, для которой включаются или отключаются тени. Одно из следующих значений:

  - 0 - положительная X
  - 1 - отрицательная X
  - 2 - положительная Y
  - 3 - отрицательная Y
  - 4 - положительная Z
  - 5 - отрицательная Z

### Возвращаемое значение

1, если тени отбрасываются для указанной стороны точечного источника света; иначе 0.
