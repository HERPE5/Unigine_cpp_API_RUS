# Unigine.Light Class (CPP)

**Header:** #include <UnigineLights.h>

**Inherits from:** Node


Этот базовый класс используется для создания источников света и теней от них. Источники света могут рендериться как упрощённое отложенное освещение.

## SHADOW_MODE

| Имя | Описание |
|---|---|
| **SHADOW_MODE_MIXED** = 0 | Режим теней для точечных и проекционных источников света со включённым статическим режимом освещения для рендеринга как статических, так и динамических теней. |
| **SHADOW_MODE_STATIC** = 1 | Статический режим теней для точечных и проекционных источников света со включённым статическим режимом освещения. |

## SHADOW_COLOR_MODE

| Имя | Описание |
|---|---|
| **SHADOW_COLOR_MODE_IES** = 0 | Распределение света определяется профилем IES. |
| **SHADOW_COLOR_MODE_SIMPLE** = 1 | На сцену проецируется произвольная 2D-текстура. |

## MODE

| Имя | Описание |
|---|---|
| **MODE_DYNAMIC** = 0 | Режим рендеринга света в реальном времени. Источник света с этим режимом отключается во время расчёта запекания освещения. Объекты, освещённые таким источником, отбрасывают только динамические тени. |
| **MODE_STATIC** = 1 | Смешанный режим рендеринга света. Источник света с этим режимом освещения участвует в запекании освещения и остаётся включённым всё время, обеспечивая прямое освещение в реальном времени. Объекты, освещённые таким источником, могут отбрасывать статические или динамические тени в зависимости от режима теней, заданного для источника и поверхности объекта. |

## SHAPE

| Имя | Описание |
|---|---|
| **SHAPE_DEFAULT** = -1 | Точечный источник света (свет излучается бесконечно малой точкой), заданный по умолчанию. |
| **SHAPE_POINT** = DEFAULT + 1 | Точечный источник света (свет излучается бесконечно малой точкой). |
| **SHAPE_SPHERE** = POINT + 1 | Источник света в форме сферы. |
| **SHAPE_CAPSULE** = SPHERE + 1 | Источник света в форме капсулы. |
| **SHAPE_RECTANGLE** = CAPSULE + 1 | Прямоугольный источник света. Такой источник света создаёт свет и блик в форме скруглённого прямоугольника. |

## void setShadowScreenSpaceSoftness ( float softness = 0.4 )

Задаёт новое значение мягкости экранных теней для источника света. Более высокие значения обеспечивают более мягкие тени.
> **Notice:** Экранные тени должны быть включены, см. метод [setShadowScreenSpace()](#setShadowScreenSpace_int_void).


### Аргументы

- *float* **softness** - Мягкость экранных теней.

## void setShadowScreenSpaceThresholdNear ( float near = 1.0 )

Задаёт новое пороговое значение, используемое для расчёта экранных теней для источника света ([close distance range](#setShadowScreenSpaceThresholdNearDistance_float_void)). Можно задавать разные значения Step Size и Threshold для объектов, расположенных близко к камере и далеко от неё. Таким образом, для крупных объектов, расположенных далеко, будут отрисованы полномасштабные тени, а в диапазоне малых расстояний будут отрисованы только тени от небольших объектов. Эта возможность особенно полезна для локаций, где требуется детализация как на близких, так и на дальних дистанциях.
> **Notice:** Экранные тени должны быть включены, см. метод [setShadowScreenSpace()](#setShadowScreenSpace_int_void).


### Аргументы

- *float* **near** - [threshold for close distance range](../../../objects/lights/parameters/index.md#near_threshold) экранных теней.

## void setShadowPenumbraMode ( Light::SHADOW_PENUMBRA mode = SHADOW_PENUMBRA_GLOBAL )
