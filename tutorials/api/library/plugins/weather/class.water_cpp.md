## BEAUFORT_CHANGE_TYPE

Режим перехода между текущим и целевым уровнями силы ветра по шкале Бофорта.
| Name | Description |
|---|---|
| **BEAUFORT_CHANGE_TYPE_DISCRETE** = 0 | Уровни силы ветра по шкале Бофорта переключаются дискретно от текущего к целевому. |
| **BEAUFORT_CHANGE_TYPE_CONTINUOUS** = 1 | Включён плавный переход силы ветра между текущим и целевым уровнями по шкале Бофорта. |

## void setSeaLevelSmoothBySpeed ( double unit_per_sec )

Задаёт режим плавного постепенного изменения [height of the sea level](#setSeaLevel_double_void) с указанной скоростью (в метрах в секунду). Высота уровня моря постепенно изменяется от текущего к целевому значению на указанную величину каждую секунду, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Этот метод лучше всего подходит, когда разница между целевым и текущим значением либо слишком велика (например, изменение дальности видимости с 10 м до 1 км), либо слишком мала (например, с 1 м до 1.05 м), избегая слишком быстрых или слишком медленных изменений. Для других случаев можно также выбрать другой режим "по времени", чтобы изменить значение от текущего к целевому в течение указанного интервала времени через *[setSeaLevelSmoothByTime()](#setSeaLevelSmoothByTime_float_void)*.
### Аргументы

- *double* **unit_per_sec** - Постоянная скорость (в метрах в секунду), с которой значение постепенно изменяется от текущего к целевому.

## void setSeaLevelSmoothByTime ( float sec )

Задаёт режим плавного постепенного изменения [height of the sea level](#setSeaLevel_double_void) в течение указанного интервала времени. Атмосферное давление постепенно изменяется от текущего к целевому значению в течение этого интервала, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Если задано значение 0, изменение происходит мгновенно. Если разница между целевым и текущим значением слишком велика (например, изменение дальности видимости с 10 м до 1 км), изменения в этом режиме могут быть слишком быстрыми и заметными, или наоборот, слишком медленными, если разница слишком мала (например, с 1 м до 1.05 м). В этом случае можно выбрать другой режим для изменения значения с заданной скоростью через *[setSeaLevelSmoothBySpeed()](#setSeaLevelSmoothBySpeed_double_void)*.
### Аргументы

- *float* **sec** - Интервал времени (в секундах), в течение которого значение изменяется от текущего к целевому.
