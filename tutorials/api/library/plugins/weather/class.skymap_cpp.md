# Unigine::Plugins::Weather::SkyMap Class (CPP)

**Header:** #include <plugins/Unigine/Weather/UnigineWeather.h>


Этот класс используется для управления Солнцем, Луной, звёздами, циклом дня/ночи для IG.

> **Notice:** Плагин Weather должен быть загружен.


Свойство [**Celestial**](../../../../ig/weather/settings.md#celestial) используется для задания Солнца и Луны.


## SkyMap Class

### Методы класса

---

## void setTimezone ( float timezone )

Задаёт часовой пояс, используемый для симуляции, в формате UTC. По умолчанию генератор изображения настроен на использование Гринвичского часового пояса.
### Аргументы

- *float* **timezone** - Значение часового пояса UTC.

## float getTimezone ( ) const

Возвращает часовой пояс, используемый в данный момент для симуляции, в формате UTC.
### Возвращаемое значение

Значение часового пояса UTC.
## void setDateTime ( long long time_posix , bool UTC = false )

Задаёт время симуляции.
### Аргументы

- *long long* **time_posix** - Задаваемое время симуляции, количество секунд с 1 января 1970 года
- *bool* **UTC** - true, чтобы задать это время как всемирное координированное время (UTC +0), false — чтобы задать это время как текущее местное время.

## void setDateTime ( int sec , int min , int hour , int day , int month , int year , bool UTC = false )

Задаёт текущую дату и время.
### Аргументы

- *int* **sec** - Целое число от 0 до 59 для задания в качестве значения секунд.
- *int* **min** - Целое число от 0 до 59 для задания в качестве значения минут.
- *int* **hour** - Целое число от 0 (полночь) до 23 (23:00) по местному времени для задания в качестве значения часов.
- *int* **day** - Целое число от 1 до 31 для задания в качестве значения дня.
- *int* **month** - Целое число от 1 до 12 для задания в качестве значения месяца.
- *int* **year** - Целое число для задания в качестве значения года.
- *bool* **UTC** - true, чтобы задать это время как всемирное координированное время (UTC +0), false — чтобы задать это время как текущее местное время.

## long long getDateTime ( bool UTC = false ) const

Возвращает текущее время симуляции.
### Аргументы

- *bool* **UTC** - true, чтобы вернуть это время как всемирное координированное время (UTC +0), false — чтобы вернуть это время как текущее местное время.

## void setContinuousTime ( bool enable )

Включает или отключает непрерывное время суток. Если включено, генератор изображения будет непрерывно обновлять время суток. Иначе однажды заданные время и дата останутся неизменными.
### Аргументы

- *bool* **enable** - true, чтобы включить непрерывное время суток; false - чтобы использовать статичное время.

## bool isContinuousTime ( ) const

Возвращает значение, указывающее, обновляется ли время суток непрерывно генератором изображения, или остаётся статичным.
### Возвращаемое значение

true, если время суток непрерывно обновляется генератором изображения; иначе false.

## void forceRefresh ( )

Обновляет sky map в соответствии с его текущими настройками. Этот метод следует вызывать после задания параметров sky map, чтобы применить их. При обновлении вызываются [Sky map change callbacks](#addOnTimeChangedCallback_CallbackBase_ptr_void).
## void * addOnTimeChangedCallback ( Unigine:: CallbackBase * func )

Добавляет функцию callback, вызываемую при изменении состояния sky map. Эта функция может использоваться для определения конкретных действий, выполняемых при изменении состояния sky map. Сигнатура функции callback должна быть следующей:
```cpp
void(void);
```


Функцию callback можно задать следующим образом:


```cpp
addOnTimeChangedCallback(MakeCallback(time_changed_callback_function_name));
```


**Пример:** Задание callback изменения времени при изменении состояния sky map.


```cpp
/// функция callback, вызываемая при изменении состояния sky map
void SomeClass::my_callback()
{
	// указатель на узел вашего солнца (не забудьте его инициализировать)
	NodePtr sun;

	// вычисляем зенитный угол, чтобы определить, ночное ли сейчас время
	float zenith = getAngle(vec3_up, sun->getDirection(AXIS_Z));
	bool night = zenith > sun_zenit_threshold;

	// переключаем освещение
	for (auto & it : lights)
	{
		it.data.setEnable(night);
	}

	// переключаем состояние излучения для эмиссивных материалов
	for (auto & it : emissive_materials)
	{
		it->setState("emission",night);
	}
}

// ...
// где-то в коде
void SomeClass::init()
{
	// добавляем "my_callback" для вызова при изменении состояния sky map
	ig_manager->getSkyMap()->addOnTimeChangedCallback(this, Unigine::MakeCallback(this, &SomeClass::my_callback ) );
}

```


### Аргументы

- *Unigine::[CallbackBase](../../../../api/library/common/callbacks/class.callbackbase_cpp.md) ** **func** - Функция callback.

### Возвращаемое значение

ID последнего добавленного callback изменения времени, если callback был успешно добавлен; иначе **nullptr**. Этот ID можно использовать для [remove](#removeOnTimeChangedCallback_void_ptr_bool) этого callback при необходимости.
## bool removeOnTimeChangedCallback ( void * id )

Удаляет указанный callback из списка callback изменения времени.
### Аргументы

- *void ** **id** - ID callback изменения времени, полученный при его [adding](#addOnTimeChangedCallback_CallbackBase_ptr_void).

### Возвращаемое значение

True, если callback изменения времени с указанным ID был успешно удалён; иначе false.
## void clearOnTimeChangedCallbacks ( )

Очищает все [added](#addOnTimeChangedCallback_CallbackBase_ptr_void) callback изменения времени.
