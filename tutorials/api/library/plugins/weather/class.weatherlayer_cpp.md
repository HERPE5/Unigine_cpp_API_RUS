# Unigine::Plugins::Weather::WeatherLayer Class (CPP)

**Header:** #include <plugins/Unigine/Weather/UnigineWeather.h>


Это базовый класс для weather layers. Слои составляют вертикальный профиль [weather region](../../../../api/library/plugins/weather/class.region_cpp.md). Различные слои облаков или осадков могут существовать на разных высотах. Доступны три типа слоёв:


- **Base Layer** - слой без визуального представления, задаёт параметры погоды, такие как [visibility range](#setVisibility_float_void), [temperature](#setTemperature_float_void), [humidity](#setHumidity_float_void).
- **Cloud Layer** - слой, управляющий облаками в пределах региона (через класс [WeatherLayerCloud](../../../../api/library/plugins/weather/class.weatherlayercloud_cpp.md)).
- **Precipitation Layer** - слой, управляющий осадками в пределах региона (через класс [WeatherLayerPrecipitation](../../../../api/library/plugins/weather/class.weatherlayerprecipitation_cpp.md)).

| **WEATHER_LAYER_TYPE_CLOUD** = 1 | **Cloud Layer** - слой, управляющий облаками в пределах региона (через класс [WeatherLayerCloud](../../../../api/library/plugins/weather/class.weatherlayercloud_cpp.md)). |
| **WEATHER_LAYER_TYPE_PRECIPITATION** = 2 | **Precipitation Layer** - слой, управляющий осадками в пределах региона (через класс [WeatherLayerPrecipitation](../../../../api/library/plugins/weather/class.weatherlayerprecipitation_cpp.md)). |

## void setElevationSmoothBySpeed ( double unit_per_sec )

Задаёт режим плавного постепенного изменения [weather layer elevation](#setElevation_double_void) с указанной скоростью (в единицах в секунду). Высота weather layer постепенно изменяется от текущего к целевому значению на указанную величину каждую секунду, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Этот метод лучше всего подходит, когда разница между целевым и текущим значением либо слишком велика (например, изменение дальности видимости с 10 м до 1 км), либо слишком мала (например, с 1 м до 1.05 м), избегая слишком быстрых или слишком медленных изменений. Для других случаев можно также выбрать другой режим "по времени", чтобы изменить значение от текущего к целевому в течение указанного интервала времени через *[setElevationSmoothByTime()](#setElevationSmoothByTime_float_void)*.
### Аргументы

- *double* **unit_per_sec** - Постоянная скорость (в единицах в секунду), с которой значение постепенно изменяется от текущего к целевому.

## void setElevationSmoothByTime ( float sec )

Задаёт режим плавного постепенного изменения [weather layer elevation](#setElevation_double_void) в течение указанного интервала времени. Высота weather layer постепенно изменяется от текущего к целевому значению в течение этого интервала, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Если задано значение 0, изменение происходит мгновенно. Если разница между целевым и текущим значением слишком велика (например, изменение дальности видимости с 10 м до 1 км), изменения в этом режиме могут быть слишком быстрыми и заметными, или наоборот, слишком медленными, если разница слишком мала (например, с 1 м до 1.05 м). В этом случае можно выбрать другой режим для изменения значения с заданной скоростью через *[setElevationSmoothBySpeed()](#setElevationSmoothBySpeed_double_void)*.
### Аргументы

- *float* **sec** - Интервал времени (в секундах), в течение которого значение изменяется от текущего к целевому.

## void setVisibilitySmoothBySpeed ( float unit_per_sec )

Задаёт режим плавного постепенного изменения [visibility](#setVisibility_float_void) с указанной скоростью (в единицах в секунду). Видимость постепенно изменяется от текущего к целевому значению на указанную величину каждую секунду, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Этот метод лучше всего подходит, когда разница между целевым и текущим значением либо слишком велика (например, изменение дальности видимости с 10 м до 1 км), либо слишком мала (например, с 1 м до 1.05 м), избегая слишком быстрых или слишком медленных изменений. Для других случаев можно также выбрать другой режим "по времени", чтобы изменить значение от текущего к целевому в течение указанного интервала времени через *[setVisibilitySmoothByTime()](#setVisibilitySmoothByTime_float_void)*.
### Аргументы

- *float* **unit_per_sec** - Постоянная скорость (в единицах в секунду), с которой значение постепенно изменяется от текущего к целевому.
