# Unigine::Plugins::Weather::WeatherLayerPrecipitation Class (CPP)

**Header:** #include <plugins/Unigine/Weather/UnigineWeather.h>

**Inherits from:** WeatherLayer


Этот класс используется для представления слоя осадков в пределах [weather region](../../../../api/library/plugins/weather/class.region_cpp.md). Он позволяет задать тип осадков (дождь, снег и т.д.), узел (*[ObjectParticles](../../../../objects/effects/particles/index.md)*), используемый для визуализации эффекта осадков, и управлять размером частиц, представляющих снежинки или капли.

## void setParticlesSizeSmoothBySpeed ( float unit_per_sec )

Задаёт режим плавного постепенного изменения [particles size](#setParticlesSize_float_void) с указанной скоростью (в единицах в секунду). Размер частиц постепенно изменяется от текущего к целевому значению на указанную величину каждую секунду, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Этот метод лучше всего подходит, когда разница между целевым и текущим значением либо слишком велика (например, изменение дальности видимости с 10 м до 1 км), либо слишком мала (например, с 1 м до 1.05 м), избегая слишком быстрых или слишком медленных изменений. Для других случаев можно также выбрать другой режим "по времени", чтобы изменить значение от текущего к целевому в течение указанного интервала времени через *[setParticlesSizeSmoothByTime()](#setParticlesSizeSmoothByTime_float_void)*.
### Аргументы

- *float* **unit_per_sec** - Постоянная скорость (в единицах в секунду), с которой значение постепенно изменяется от текущего к целевому.

## void setParticlesSizeSmoothByTime ( float sec )

Задаёт режим плавного постепенного изменения [particles size](#setParticlesSize_float_void) в течение указанного интервала времени. Размер частиц постепенно изменяется от текущего к целевому значению в течение этого интервала, такое сглаживание выполняется для более реалистичных изменений. Более того, каждое значение можно изменять со своей скоростью (дождь начинается быстро при медленно меняющейся облачности). Если задано значение 0, изменение происходит мгновенно. Если разница между целевым и текущим значением слишком велика (например, изменение дальности видимости с 10 м до 1 км), изменения в этом режиме могут быть слишком быстрыми и заметными, или наоборот, слишком медленными, если разница слишком мала (например, с 1 м до 1.05 м). В этом случае можно выбрать другой режим для изменения значения с заданной скоростью через *[setParticlesSizeSmoothBySpeed()](#setParticlesSizeSmoothBySpeed_float_void)*.
### Аргументы

- *float* **sec** - Интервал времени (в секундах), в течение которого значение изменяется от текущего к целевому.
