# Unigine::Plugins::PDFRender::PDFFile Class (CPP)

**Header:** #include <plugins/Unigine/PDFRender/UniginePDFRender.h>


## PDFFile Class

### Перечисления

## RENDER_FLAG

| Name | Description |
|---|---|
| **RENDER_FLAG_ANNOT** = 0x01 | Включить отрисовку аннотаций. |
| **RENDER_FLAG_LCD_TEXT** = 0x02 | Включить отрисовку текста, оптимизированную для ЖК-дисплеев. > **Notice:** Этот флаг действует только при включённом сглаживании текста. |
| **RENDER_FLAG_NO_NATIVETEXT** = 0x04 | Отключить нативный вывод текста на платформах, где он доступен. |
| **RENDER_FLAG_GRAYSCALE** = 0x08 | Отрисовывать вывод в оттенках серого. |
| **RENDER_FLAG_NO_SMOOTHTEXT** = 0x1000 | Отключить сглаживание текста. > **Notice:** Этот флаг также отключает оптимизацию текста для ЖК-дисплеев. |
| **RENDER_FLAG_NO_SMOOTHIMAGE** = 0x2000 | Отключить сглаживание изображений. |
| **RENDER_FLAG_NO_SMOOTHPATH** = 0x4000 | Отключить сглаживание путей. |

### Методы класса

## bool isValid () const

Возвращает текущее значение, указывающее, загружен ли файл PDF.
### Возвращаемое значение

**true**, если файл PDF загружен; иначе **false**.
## int getPageCount () const

Возвращает текущее общее количество страниц PDF-документа.
### Возвращаемое значение

Текущее общее количество страниц PDF-документа.

## float getPageHeight ( int pageIndex ) const

Возвращает высоту указанной страницы PDF, в единицах. Одна единица равна 1/72 дюйма (около 0.3528 мм).
### Аргументы

- *int* **pageIndex** - индекс целевой страницы.

### Возвращаемое значение

Высота страницы, в единицах. Одна единица равна 1/72 дюйма (около 0.3528 мм).
## float getPageWidth ( int pageIndex ) const

Возвращает ширину указанной страницы PDF, в единицах. Одна единица равна 1/72 дюйма (около 0.3528 мм).
### Аргументы

- *int* **pageIndex** - индекс целевой страницы.

### Возвращаемое значение

Ширина страницы, в единицах. Одна единица равна 1/72 дюйма (около 0.3528 мм).
## Ptr < Image > renderPage ( int pageIndex , int width , int height , int render_flags = 0 ) const

Отрисовывает указанную страницу PDF в новый объект *[Image](../../../../api/library/common/class.image_cpp.md)* с заданными шириной, высотой и [render flags](#RENDER_FLAG).
### Аргументы

- *int* **pageIndex** - индекс целевой страницы.
- *int* **width** - ширина целевого изображения, в единицах. Одна единица равна 1/72 дюйма (около 0.3528 мм).
- *int* **height** - высота целевого изображения, в единицах. Одна единица равна 1/72 дюйма (около 0.3528 мм).
- *int* **render_flags** - [render flag](#RENDER_FLAG).

### Возвращаемое значение

Изображение, содержащее данные отрисованной страницы PDF.
