# Unigine::Plugins::IG::ArticulatedPart Class (CPP)

**Header:** #include <plugins/Unigine/IG/UnigineIG.h>


Этот класс представляет интерфейс Articulated Part IG.

> **Notice:** Плагин IG должен быть загружен.


## ArticulatedPart Class

### Методы класса

---

## int getID ( ) const

Возвращает ID сочленённой части.
### Возвращаемое значение

ID сочленённой части.
## int getNumNodes ( ) const

Возвращает общее количество узлов, представляющих сочленённую часть.
### Возвращаемое значение

Количество узлов, представляющих сочленённую часть.
## Ptr < Node > getNode ( int num ) const

Возвращает указанный узел из массива узлов, представляющих сочленённую часть.
### Аргументы

- *int* **num** - Номер узла.

### Возвращаемое значение

Узел.
## void setEnabled ( bool enable )

Задаёт значение, указывающее, включена ли сочленённая часть.
### Аргументы

- *bool* **enable** - true, чтобы включить сочленённую часть; false - чтобы отключить её.

## int isEnabled ( ) const

Возвращает значение, указывающее, включена ли сочленённая часть.
### Возвращаемое значение

true, если сочленённая часть включена; иначе false.
## void setPosition ( const Math::vec3& offset )

Задаёт смещение сочленённой части в системе координат субмодели (SCS).
### Аргументы

- *const  Math::vec3&* **offset** - Задаваемые координаты смещения сочленённой части (X - назад, Y - влево, Z - вниз).

## Math:: vec3 getPosition ( ) const

Возвращает текущее смещение сочленённой части в системе координат субмодели (SCS).
### Возвращаемое значение

Координаты смещения сочленённой части (X - назад, Y - влево, Z - вниз).
## void setRotationEuler ( const Math::vec3& rotation_euler )

Задаёт поворот сочленённой части в системе координат субмодели (SCS).
### Аргументы

- *const  Math::vec3&* **rotation_euler** - Задаваемые углы Эйлера поворота сочленённой части.

## Math:: vec3 getRotationEuler ( ) const

Возвращает поворот сочленённой части в системе координат субмодели (SCS).
### Возвращаемое значение

Углы Эйлера поворота сочленённой части.
## void setLinearRate ( const Math::vec3& rate )

Задаёт скорость линейного перемещения сочленённой части.
### Аргументы

- *const  Math::vec3&* **rate** - Вектор скоростей линейного перемещения, задаваемых для соответствующих осей (результат автоматически преобразуется для текущей [coordinate system](../../../../../api/library/plugins/ig/api/class.nedconverter_cpp.md#TARGET_COORDINATE_SYSTEM)).

## Math:: vec3 getLinearRate ( ) const

Возвращает текущую скорость линейного перемещения сочленённой части.
### Возвращаемое значение

Вектор скоростей линейного перемещения для соответствующих осей (результат автоматически преобразуется для текущей [coordinate system](../../../../../api/library/plugins/ig/api/class.nedconverter_cpp.md#TARGET_COORDINATE_SYSTEM)).
## void setAngularRate ( const Math::vec3& rate )

Задаёт скорость углового перемещения сочленённой части.
### Аргументы

- *const  Math::vec3&* **rate** - Вектор скоростей углового перемещения, задаваемых для соответствующих осей (результат автоматически преобразуется для текущей [coordinate system](../../../../../api/library/plugins/ig/api/class.nedconverter_cpp.md#TARGET_COORDINATE_SYSTEM)).

## Math:: vec3 getAngularRate ( ) const

Возвращает текущую скорость углового перемещения сочленённой части.
### Возвращаемое значение

Вектор скоростей углового перемещения для соответствующих осей (результат автоматически преобразуется для текущей [coordinate system](../../../../../api/library/plugins/ig/api/class.nedconverter_cpp.md#TARGET_COORDINATE_SYSTEM)).
