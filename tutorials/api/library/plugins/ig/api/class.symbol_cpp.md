# Unigine::Plugins::IG::Symbol Class (CPP)

**Header:** #include <plugins/Unigine/IG/UnigineIG.h>


Этот класс представляет интерфейс Symbol IG. Символ — это единичный примитив рисования или группа примитивов рисования, которые могут быть отрисованы на [symbol surface (plane)](../../../../../api/library/plugins/ig/api/class.symbolsplane_cpp.md) в рамках определённого [view](../../../../../api/library/plugins/ig/api/class.view_cpp.md), либо размещены относительно определённой [entity](../../../../../api/library/plugins/ig/api/class.entity_cpp.md).

> **Notice:** Плагин IG должен быть загружен.

## void setFlashProgram ( const Unigine:: Vector <float> & data )

Задаёт программу мигания для символа. Программа использует последовательность указанных периодов времени в секундах для последовательного включения и отключения символа, начиная с состояния Enabled. Например, последовательность 0.3;0.05;0.1 означает, что символ включён 0.3 секунды, затем отключён 0.05 секунды, включён 0.1 секунды, а затем снова включён на 0.3 секунды и т.д. Чтобы отключить программу, массив должен быть пустым.
### Аргументы

- *const  Unigine::[Vector](../../../../../api/library/containers/vector/class.vector_cpp.md)<float> &* **data** - Программа мигания для символа.

## void resetFlashProgram ( )

Запускает программу мигания заново.
