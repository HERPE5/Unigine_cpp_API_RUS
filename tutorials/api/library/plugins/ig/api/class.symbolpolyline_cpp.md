# Unigine::Plugins::IG::SymbolPolyline Class (CPP)

**Header:** #include <plugins/Unigine/IG/UnigineIG.h>


## SymbolPolyline Class

### Методы класса

---

## void addPoint ( float x , float y )

Задаёт точку в координатах плоскости.
### Аргументы

- *float* **x** - Горизонтальное смещение от начала координат плоскости.
- *float* **y** - Вертикальное смещение от начала координат плоскости.

## void setFill ( bool value )

Включает или отключает заливку фигуры, образованной линиями.
### Аргументы

- *bool* **value** - true, чтобы сделать фигуру залитой, иначе false.

## void setClosed ( bool value )

Включает и отключает соединение последней точки с первой, что делает линию замкнутой.
### Аргументы

- *bool* **value** - true, чтобы сделать фигуру замкнутой, иначе false.

## void setVertexOrderStrip ( bool value )

Включает и отключает создание полосы треугольников — связанной серии залитых треугольников, образованных из упорядоченного набора вершин. Первый треугольник образуется из первых трёх вершин. Каждый следующий треугольник образуется из последних двух вершин и следующей вершины в наборе.
### Аргументы

- *bool* **value** - true, чтобы включить полосу треугольников, false, чтобы отключить.
