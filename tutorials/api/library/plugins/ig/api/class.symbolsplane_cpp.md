# Unigine::Plugins::IG::SymbolsPlane Class (CPP)

**Header:** #include <plugins/Unigine/IG/UnigineIG.h>


Этот класс представляет интерфейс SymbolsPlane IG. Поверхность символов (плоскость) — это прямоугольная двумерная область рисования на виртуальной плоскости, на которой могут отрисовываться [symbols](../../../../../api/library/plugins/ig/api/class.symbol_cpp.md). Такая плоскость размещается в 3D-пространстве относительно определённой сущности либо совпадает с ближней плоскостью отсечения определённого view.

> **Notice:** Плагин IG должен быть загружен.


## SymbolsPlane Class

### Перечисления

## SYMBOLS_PLANE_TYPE

| Name | Description |
|---|---|
| **SYMBOLS_PLANE_TYPE_ENTITY** = 0 | Плоскость символов размещается относительно определённой сущности. |
| **SYMBOLS_PLANE_TYPE_VIEW** = 1 | Плоскость символов совпадает с ближней плоскостью отсечения определённого view. |

### Методы класса

---

## int getID ( ) const

Возвращает идентификатор плоскости.
### Возвращаемое значение

Идентификатор плоскости.
## void addSymbol ( Symbol * symbol )

Добавляет указанный [symbol](../../../../../api/library/plugins/ig/api/class.symbol_cpp.md) на плоскость.
### Аргументы

- *[Symbol](../../../../../api/library/plugins/ig/api/class.symbol_cpp.md) ** **symbol** - Добавляемый символ.

## void setBillboard ( bool enable , bool fixed_scale )

Включает и отключает ориентацию плоскости на наблюдателя и фиксацию размера плоскости независимо от расстояния до неё.
### Аргументы

- *bool* **enable** - true, чтобы сделать плоскость биллбордом (всегда ориентированным на наблюдателя), false, чтобы отключить ориентацию на наблюдателя.
- *bool* **fixed_scale** - true, чтобы размер биллборда оставался неизменным независимо от расстояния до наблюдателя, false — чтобы отключить.

## bool isBillboard ( ) const

Проверяет, является ли узел биллбордом (всегда ориентированным на наблюдателя).
### Возвращаемое значение

true, если узел является биллбордом, иначе false.
## bool isFixedBillboardScale ( ) const

Проверяет, зафиксирован ли размер биллборда относительно наблюдателя независимо от расстояния.
### Возвращаемое значение

true, если масштаб биллборда зафиксирован, иначе false.
## void setPosition ( const Math:: vec3 & value )

Задаёт положение плоскости относительно сущности, если у плоскости есть родительская сущность.
### Аргументы

- *const  Math::[vec3](../../../../../api/library/math/class.vec3_cpp.md) &* **value** - Положение в системе координат родительской сущности.

## void setRotation ( const Math:: quat & rotate )

Задаёт поворот плоскости относительно родительской сущности. Метод неприменим к биллбордам.
### Аргументы

- *const  Math::[quat](../../../../../api/library/math/class.quat_cpp.md) &* **rotate** - Кватернион поворота плоскости

## void setPhysicalSize ( float width , float height )

Задаёт размер плоскости для плоскостей, имеющих родительскую сущность.
### Аргументы

- *float* **width** - Ширина плоскости символов, в единицах
- *float* **height** - Высота плоскости символов, в единицах

## vec2 getPhysicalSize ( ) const

Возвращает физический размер плоскости символов, в единицах.
### Возвращаемое значение

Вектор, содержащий физический размер плоскости символов (ширина, высота), в единицах.
## void setUVSize ( float minU , float minV , float maxU , float maxV )

Задаёт 2D-систему координат поверхности символов.
### Аргументы

- *float* **minU** - Минимальное значение U поверхности символов.
- *float* **minV** - Минимальное значение V поверхности символов.
- *float* **maxU** - Максимальное значение U поверхности символов.
- *float* **maxV** - Максимальное значение V поверхности символов.

## vec4 getUVSize ( ) const

Возвращает текущую 2D-систему координат поверхности символов.
### Возвращаемое значение

Вектор, содержащий следующие значения: (минимум U, минимум V, максимум U, максимум V).
## void setScreenSize ( float width , float height , float offsetX , float offsetY )

Задаёт разрешение и смещение экранной плоскости, в пикселях.
### Аргументы

- *float* **width** - Ширина экранной плоскости, в пикселях.
- *float* **height** - Высота экранной плоскости, в пикселях.
- *float* **offsetX** - Горизонтальное смещение экранной плоскости.
- *float* **offsetY** - Вертикальное смещение экранной плоскости.

## vec4 getScreenSize ( ) const

Возвращает разрешение и смещение экранной плоскости, в пикселях.
### Возвращаемое значение

Вектор, содержащий экранные размеры плоскости символов (screen_width, screen_height, offset_z, offset_y), в пикселях.
