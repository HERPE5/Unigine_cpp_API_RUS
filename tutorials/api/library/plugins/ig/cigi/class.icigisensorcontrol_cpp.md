# CigiSensorControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiSensorControl Class

### Методы класса

---

## int getViewID ( ) const

Возвращает view ID, указанный в пакете.
### Возвращаемое значение

View ID.
## int getSensorID ( ) const

Возвращает ID сенсора, указанный в пакете.
### Возвращаемое значение

ID сенсора.
## int getSensorEnabled ( ) const

Возвращает значение параметра **Sensor On/Off**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Sensor On/Off**: 1, если сенсор включён; иначе 0.
## int getPolarity ( ) const

Возвращает значение параметра **Polarity**, указанное в пакете. Определяет, отображает ли сенсор режим white hot или black hot.
### Возвращаемое значение

Значение параметра **Polarity**. Поддерживаются следующие значения:
- 0 - White hot
- 1 - Red hot


## int getDropoutEnabled ( ) const

Возвращает значение параметра **Line-by-Line Dropout Enable**, указанное в пакете. Этот эффект предназначен для симуляции горизонтальных полос, вызванных кратковременной потерей видеоинформации.
### Возвращаемое значение

Значение параметра **Line-by-Line Dropout Enable**: 1, если построчное выпадение включено; иначе 0.
## int getAutomaticGain ( ) const

Возвращает значение параметра **Automatic Gain**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Automatic Gain**: 1, если сенсор автоматически регулирует значение усиления для оптимизации яркости и контрастности изображения сенсора; иначе 0.
## int getTrackColor ( ) const

Возвращает значение параметра **Track White/Black**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Track White/Black**: 1 - если сенсор отслеживает чёрный цвет; 0 - если сенсор отслеживает белый цвет.
## int getTrackMode ( ) const

Возвращает значение параметра **Track Mode**, указанное в пакете. Определяет, какой режим слежения будет использовать сенсор.
### Возвращаемое значение

Значение параметра **Track Mode**. Поддерживаются следующие значения:
- 0 - Выключено
- 1 - Force Correlate. Поведение слежения аналогично применяемому в ракете Maverick.
- 2 - Scene. Поведение слежения аналогично применяемому в FLIR (Forward Looking Infrared).
- 3 - Target. Для захвата конкретной области цели используется контрастное слежение.
- 4 - Ship. Используется контрастное слежение с корректировкой точки слежения таким образом, чтобы оружие поражало цель вблизи ватерлинии.
- 5-7 - Определяется IG


## int getResponse ( ) const

Возвращает значение параметра **Response Type**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Response Type**: 1 - Extended (положение gate и цели), IG вернёт [Sensor Extended Response packet](../../../../../api/library/plugins/ig/cigi/class.icigisensorextresponse_cpp.md); 0 - Normal (положение gate), IG вернёт [Sensor Response packet](../../../../../api/library/plugins/ig/cigi/class.icigisensorresponse_cpp.md).
> **Notice:** IG должен возвращать один из двух пакетов ответа сенсора каждый кадр, пока выполняются следующие два условия:
> 1. Sensor On/Off установлен в On (1).
> 2. Track Mode не установлен в Off (0).


## float getGain ( ) const

Возвращает значение параметра **Gain**, указанное в пакете. Определяет контрастность изображения сенсора.
### Возвращаемое значение

Значение параметра **Gain** в диапазоне [0.0; 1.0].
## float getLevel ( ) const

Возвращает значение параметра **Level**, указанное в пакете. Определяет яркость изображения сенсора.
### Возвращаемое значение

Значение параметра **Level** в диапазоне [0.0; 1.0].
## float getCoupling ( ) const

Возвращает значение параметра **AC Coupling**, указанное в пакете. Определяет постоянную затухания AC-связи для изображения сенсора.
### Возвращаемое значение

Значение параметра **AC Coupling**.
## float getNoise ( ) const

Возвращает значение параметра **Noise**, указанное в пакете. Определяет уровень шума детектора сенсора.
### Возвращаемое значение

Значение параметра **Noise** в диапазоне [0.0; 1.0].
