### Методы класса

---

## int getEntityID ( ) const

Возвращает ID сущности, указанный в пакете.
### Возвращаемое значение

ID сущности.
## int getSegmentID ( ) const

Возвращает ID сегмента, указанный в пакете.
### Возвращаемое значение

ID сегмента.
## int getSegmentEnabled ( ) const

Возвращает значение параметра **Segment Enable**, указанное в пакете.
### Возвращаемое значение

Параметр **Segment Enable**: 1 - сегмент будет учитываться при проверке столкновений; иначе 0.
## unsigned int getMaterialMask ( ) const

Возвращает значение параметра **Material Mask**, указанное в пакете. Определяет природные и антропогенные объекты, учитываемые или исключаемые при проверке столкновений.
### Возвращаемое значение

Значение параметра **Material Mask**. Каждый бит представляет диапазон значений кода материала. Установка этого бита в 1 приведёт к тому, что IG будет регистрировать попадания в материалы в соответствующем диапазоне. Установка этого поля в 0h отключает проверку столкновений для этого сегмента.
