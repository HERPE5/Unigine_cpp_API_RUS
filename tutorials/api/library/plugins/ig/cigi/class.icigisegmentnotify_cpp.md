# CigiSegmentNotify Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>


## CigiSegmentNotify Class

### Методы класса

---

## void setEntityID ( int id )

Задаёт ID сущности, которой принадлежит сегмент обнаружения столкновений.
### Аргументы

- *int* **id** - ID сущности, которой принадлежит сегмент обнаружения столкновений.

## void setSegmentID ( int id )

Задаёт ID сегмента обнаружения столкновений, вдоль которого произошло столкновение. Этот параметр вместе с [Entity ID](#setEntityID_int_void) позволяет Host сопоставить этот ответ с соответствующим запросом.
### Аргументы

- *int* **id** - ID сегмента обнаружения столкновений, вдоль которого произошло столкновение.

## void setContactEntityID ( int id )

Задаёт сущность, с которой произошло столкновение. Если [Collision Type](#setCollisionType_int_void) установлен в Non-entity (0), этот параметр игнорируется.
### Аргументы

- *int* **id** - ID сущности, с которой произошёл контакт.

## void setCollisionType ( int type )

Этот параметр указывает, произошло ли столкновение с другой сущностью или с объектом, не являющимся сущностью, например, с ландшафтом.
### Аргументы

- *int* **type** - Тип столкновения. Доступные значения:

  - 0 — для столкновений с объектом, не являющимся сущностью.
  - 1 — для столкновений с другими сущностями.

## void setMaterialCode ( unsigned int code )

Задаёт код материала поверхности в точке столкновения.
### Аргументы

- *unsigned int* **code** - Код материала поверхности в точке столкновения.

## void setDistance ( float d )

Задаёт расстояние вдоль тестового вектора столкновения от исходной конечной точки ([first point](../../../../../api/library/plugins/ig/cigi/class.icigisegmentdef_cpp.md#getPoint1_vec3) сегмента столкновения) до точки пересечения.
### Аргументы

- *float* **d** - Длина вдоль сегмента от исходной конечной точки, в метрах.
