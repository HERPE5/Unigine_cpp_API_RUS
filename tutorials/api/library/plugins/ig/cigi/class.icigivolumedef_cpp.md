# CigiVolumeDef Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiVolumeDef Class

### Методы класса

---

## int getEntityID ( ) const

Возвращает ID сущности, указанный в пакете.
### Возвращаемое значение

ID сущности.
## int getVolumeID ( ) const

Возвращает ID объёма, указанный в пакете.
### Возвращаемое значение

ID объёма.
## int getVolumeEnabled ( ) const

Возвращает значение параметра **Volume Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Volume Enable**: 1 - объём будет учитываться при проверке столкновений; иначе 0.
## int getVolumeType ( ) const

Возвращает значение параметра **Volume Type**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Volume Type**. Поддерживаются следующие значения:
- 0 - Sphere
- 1 - Cuboid


## Math:: vec3 getCenter ( ) const

Возвращает координаты смещения центра объёма столкновения, указанного в пакете.
### Возвращаемое значение

Смещение центра объёма столкновения.
> **Notice:** Измеряется относительно системы координат сущности, указанной параметром [Entity ID](#getEntityID_int)


## Math:: vec3 getSize ( ) const

Возвращает размер объёма столкновения, указанный в пакете.
### Возвращаемое значение

Размеры объёма столкновения: (height, width, depth).
> **Notice:** Для сферических объёмов учитывается только первый компонент вектора — он интерпретируется как радиус.


## Math:: vec3 getRotation ( ) const

Возвращает углы Эйлера поворота объёма столкновения, указанного в пакете.
### Возвращаемое значение

Углы Эйлера поворота объёма столкновения (roll, pitch, yaw).
## float getRadius ( ) const

Возвращает радиус сферического объёма столкновения, указанного в пакете.
### Возвращаемое значение

Радиус объёма столкновения.
