# CigiSymbolCircleDef Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiSymbolCircleDef Class

### Методы класса

---

## int getSymbolID ( ) const

Возвращает **Symbol ID**, указанный в пакете.
### Возвращаемое значение

Symbol ID.
## int getDrawStyle ( ) const

Возвращает значение параметра **Drawing Style**, указанное в пакете. Определяет, заданы ли окружности и дуги в этом пакете как кривые линии или как залитые объёмы.
### Возвращаемое значение

Значение параметра Draw Style. Поддерживаются следующие значения:
- 0 - Line.
- 1 - Fill.


## int getStipplePattern ( ) const

Возвращает значение параметра **Stipple Pattern**, указанное в пакете. Определяет узор штриховой линии, используемый при отрисовке кривой линии окружности или дуги.
### Возвращаемое значение

Значение параметра **Stipple Pattern**.
> **Notice:** Если значение этого параметра равно 0xFFFF, IG рисует сплошную линию. Если значение равно 0x00, IG не рисует линию.


## float getPatternLength ( ) const

Возвращает значение параметра **Stipple Pattern Length**, указанное в пакете. Определяет длину одного полного повторения узора штриховой линии.
### Возвращаемое значение

Параметр Stipple Pattern Length, в единицах поверхности символов.
## float getLineWidth ( ) const

Возвращает значение параметра **Line Width**, указанное в пакете. Определяет толщину линии, используемую IG при отрисовке окружностей и дуг, заданных в этом пакете.
### Возвращаемое значение

Значение параметра Line Width, в единицах поверхности символов.
## int getNumCircles ( ) const

Возвращает количество окружностей в экземпляре.
### Возвращаемое значение

Количество окружностей.
## Math:: vec3 getCenter ( int num ) const

Возвращает трёхкомпонентный вектор с UV-координатами центра указанной окружности. Этот вектор объединяет значения параметров **Center U** и **Center V**, указанных в пакете.
### Аргументы

- *int* **num** - Индекс окружности.

### Возвращаемое значение

Трёхкомпонентный вектор с UV-координатами центра указанной окружности **(Center U, Center V, Z)**.
> **Notice:** Третий компонент вектора игнорируется.


## float getOuterRadius ( int num ) const

Возвращает значение параметра **Radius**, указанное в пакете. Определяет радиус внешней окружности указанной окружности или дуги.
### Аргументы

- *int* **num** - Индекс окружности.

### Возвращаемое значение

Значение параметра Radius, которое больше значения параметра InnerRadius.
## float getInnerRadius ( int num ) const

Возвращает значение параметра **Inner Radius**, указанное в пакете. Определяет внутренний радиус указанной залитой окружности или дуги.
### Аргументы

- *int* **num** - Индекс окружности.

### Возвращаемое значение

Значение параметра Inner Radius, которое больше 0.
## float getStartAngle ( int num ) const

Возвращает значение параметра **Start Angle**, указанное в пакете. Определяет начальный угол указанной дуги.
### Аргументы

- *int* **num** - Индекс окружности.

### Возвращаемое значение

Значение параметра Start Angle.
## float getEndAngle ( int num ) const

Возвращает значение параметра **End Angle**, указанное в пакете. Определяет конечный угол указанной дуги.
### Аргументы

- *int* **num** - Индекс окружности.

### Возвращаемое значение

Значение параметра **End Angle**.
