# CigiSymbolControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiSymbolControl Class

### Методы класса

---

## int getSymbolID ( ) const

Возвращает **Symbol ID**, указанный в пакете. Определяет символ, к которому применяется этот пакет.
### Возвращаемое значение

Symbol ID.
## int getParentID ( ) const

Возвращает **Parent Symbol ID**, указанный в пакете. Определяет родителя, к которому IG присоединит символ.
### Возвращаемое значение

Parent ID.
## int getSurfaceID ( ) const

Возвращает **Surface ID**, указанный в пакете. Определяет поверхность символов, на которой IG отрисует символ.
### Возвращаемое значение

Surface ID.
## int getSymbolState ( ) const

Возвращает значение параметра **Symbol State**, указанное в пакете. Определяет, скрыт ли символ, видим или уничтожен.
### Возвращаемое значение

Параметр Symbol State. Поддерживаются следующие значения:
- 0 - Скрыт.
- 1 - Видим.
- 2 - Уничтожен.


## int getAttachState ( ) const

Возвращает значение параметра **Attach State**, указанное в пакете. Определяет, будет ли символ присоединён как дочерний к родительскому символу.
### Возвращаемое значение

Значение параметра Attach State: 1, если символ должен быть присоединён к родителю; иначе 0.
## int getFlashControl ( ) const

Returns the value of the **Flash Control** parameter specified in the packet. Determines whether the IG shall continue the symbol’s flash cycle from its present state or restart it from the beginning.
### Возвращаемое значение

Значение параметра Flash Control. Одно из следующих значений:
- 0 - продолжить
- 1 - перезапустить


## int getInheritColor ( ) const

Возвращает значение параметра **Inherit Color**, указанное в пакете. Определяет, наследует ли символ свой цвет от символа, к которому он присоединён.
### Возвращаемое значение

Значение параметра Inherit Color: 1, если цвет наследуется; иначе 0.
## int getLayer ( ) const

Возвращает значение параметра **Layer**, указанное в пакете. Определяет слой, к которому назначается символ.
### Возвращаемое значение

Значение параметра Layer в диапазоне [0 - 255].
## int getFlashDuty ( ) const

Возвращает значение параметра **Flash Duty Cycle Percentage**, указанное в пакете. Определяет коэффициент заполнения для мигающего символа, измеряемый в процентах от периода мигания.
### Возвращаемое значение

Значение параметра Flash Duty в диапазоне [0 - 100].
## float getFlashPeriod ( ) const

Возвращает значение параметра **Flash Period**, указанное в пакете. Этот параметр определяет длительность одного цикла мигания. IG делает символ видимым на протяжении периода коэффициента заполнения и невидимым на оставшуюся часть периода мигания.
### Возвращаемое значение

Значение параметра Flash Period.
## float getRotation ( ) const

Возвращает значение параметра **Rotation**, указанное в пакете. Определяет контрастность изображения сенсора.
### Возвращаемое значение

Значение параметра Rotation в диапазоне [0.0; 1.0].
## Math:: vec3 getPosition ( ) const

Возвращает UV-положение символа в виде трёхкомпонентного вектора, объединяющего значения параметров **Position U и Position V**, указанных в пакете.
### Возвращаемое значение

UV-положение символа. Первые два компонента задают положение символа вдоль осей U и V. Третий компонент игнорируется.
> **Notice:** For top-level (non-child) symbols, the IG defines position of the symbol with respect to the symbol surface’s 2D coordinate system.
>
>
> For child symbols - with respect to the parent symbol’s local coordinate system.


## Math:: vec3 getScale ( ) const

Возвращает вектор масштаба символа в виде трёхкомпонентного вектора, объединяющего значения параметров **Scale U и Scale V**, указанных в пакете.
### Возвращаемое значение

Вектор **Scale** символа. Первые два компонента задают коэффициенты масштабирования символа вдоль его локальных осей U и V. Третий компонент игнорируется.
## Math:: vec4 getColor ( ) const

Возвращает цвет символа в виде четырёхкомпонентного вектора, объединяющего значения параметров **Red, Green, Blue и Alpha**, указанных в пакете.
### Возвращаемое значение

Четырёхкомпонентный вектор, представляющий цвет символа (Red, Green, Blue, Alpha).
