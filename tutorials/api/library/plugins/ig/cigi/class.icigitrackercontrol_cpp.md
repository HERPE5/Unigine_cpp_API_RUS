# CigiTrackerControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiTrackerControl Class

### Методы класса

---

## int getViewID ( ) const

Возвращает view ID, указанный в пакете.
### Возвращаемое значение

View ID.
## int getTrackerID ( ) const

Возвращает ID трекера, указанный в пакете.
### Возвращаемое значение

ID трекера.
## int getTrackerEnabled ( ) const

Возвращает значение параметра **Tracker Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Tracker Enable**: 1, если отслеживающее устройство включено; иначе 0.
## int getBoresightEnabled ( ) const

Возвращает значение параметра **Boresight Enable**, указанное в пакете. Режим Boresight Enable используется для повторного установления «центрального» положения трекера в текущем положении и ориентации.
### Возвращаемое значение

Значение параметра **Boresight Enable**: 1, если состояние boresight отслеживающего устройства включено; иначе 0.
> **Notice:** При включении Host должен отправить пакет Motion Tracker Control с Boresight Enable, установленным в Disable (0), чтобы вернуть трекер к обычной работе. IG будет продолжать обновлять положение boresight каждый кадр, пока это не произойдёт.


## int getGroupSelect ( ) const

Возвращает значение параметра **View/View Group Select**, указанное в пакете.
### Возвращаемое значение

Значение параметра **View/View Group Select**: 1, если отслеживающее устройство присоединено к группе view; 0 - если отслеживающее устройство присоединено к отдельному view.
## Math:: ivec3 getPositionEnabled ( ) const

Возвращает трёхкомпонентный вектор, задающий координаты **X, Y и Z**.
### Возвращаемое значение

Вектор из трёх целочисленных значений. Каждое значение определяет соответствующую координату (X, Y, Z).
## Math:: ivec3 getRotationEnabled ( ) const

Возвращает трёхкомпонентный вектор, объединяющий значения **Roll/Pitch/Yaw Enable**, указанные в пакете. Каждое значение определяет, включён ли поворот вокруг соответствующей оси (roll, pitch, yaw).
### Возвращаемое значение

Вектор из трёх целочисленных значений. Каждое значение определяет, включён ли поворот вокруг соответствующей оси (Roll, Pitch, Yaw): 1 - включено; 0 - отключено.
