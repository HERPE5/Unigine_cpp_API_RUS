## CigiViewDef Class

### Методы класса

---

## int getViewID ( ) const

Возвращает view ID, указанный в пакете.
### Возвращаемое значение

View ID.
## int getGroupID ( ) const

Возвращает ID группы view, указанный в пакете.
### Возвращаемое значение

ID группы view.
> **Notice:** 0 - означает, что view не является членом ни одной группы.


## int getNearEnabled ( ) const

Возвращает значение параметра **Near Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Near Enable**: 1 - использовать указанный параметр [Near](#getNear_float) для установки ближней плоскости отсечения view; иначе 0.

## int getViewType ( ) const

Возвращает значение параметра **View Type**, указанное в пакете.
### Возвращаемое значение

Значение параметра **View Type**. Тип view, определённый в IG.
## int getReorder ( ) const

Возвращает значение параметра **Reorder**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Reorder**: 1 - view будет перемещён поверх любых перекрывающих его view; 0 - без переупорядочивания.
> **Notice:** В случаях, когда несколько перекрывающихся view перемещаются наверх, приоритет имеет последний указанный view.
