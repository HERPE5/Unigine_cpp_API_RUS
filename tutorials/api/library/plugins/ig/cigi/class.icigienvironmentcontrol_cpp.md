# CigiEnvironmentControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiEnvironmentControl Class

### Методы класса

---

## int getRegionID ( ) const

Возвращает ID экологического региона, указанный в пакете.
### Возвращаемое значение

ID экологического региона.
## int getRegionState ( ) const

Возвращает состояние экологического региона, указанное в пакете.
### Возвращаемое значение

Состояние экологического региона. Поддерживаются следующие значения:
- 0 - Неактивен
- 1 - Активен
- 2 - Уничтожен


## int getMergeWeather ( ) const

Возвращает значение параметра **Merge Weather Properties**, указанное в пакете. Определяет, будут ли атмосферные условия в этом регионе объединены с условиями других регионов в областях перекрытия.
### Возвращаемое значение

Значение параметра **Merge Weather Properties**. Поддерживаются следующие значения:
- 1 - объединить
- 0 - использовать данные из последнего пакета Weather Control.


## int getMergeAerosol ( ) const

Возвращает значение параметра **Merge Aerosol Concentrations**, указанное в пакете. Определяет, будут ли атмосферные условия в этом регионе объединены с условиями других регионов в областях перекрытия.
### Возвращаемое значение

Значение параметра **Merge Aerosol Concentrations**. Поддерживаются следующие значения:
- 1 - объединить
- 0 - использовать данные из последнего пакета Weather Control.


## int getMergeMaritime ( ) const

Возвращает значение параметра **Merge Maritime Surface Conditions**, указанное в пакете. Определяет, будут ли морские поверхностные условия в этом регионе объединены с условиями других регионов в областях перекрытия.
### Возвращаемое значение

Значение параметра **Merge Maritime Surface Conditions**. Поддерживаются следующие значения:
- 1 - объединить
- 0 - использовать данные из последнего пакета Maritime Surface Conditions Control.


## int getMergeTerrestrial ( ) const

Возвращает значение параметра **Merge Terrestrial Surface Conditions**, указанное в пакете. Определяет, будут ли наземные поверхностные условия в этом регионе объединены с условиями других регионов в областях перекрытия.

Возвращает значение параметра **Latitude**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Latitude**.
## double getLongitude ( ) const

Возвращает значение параметра **Longitude**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Longitude**.
## float getSizeX ( ) const

Возвращает значение параметра **Size X**, указанное в пакете. Определяет длину экологического региона вдоль его оси X на поверхности геоида.
> **Notice:** Эта длина не включает ширину переходного периметра.


### Возвращаемое значение

Значение параметра **Size X**.
## float getSizeY ( ) const

Возвращает значение параметра **Size Y**, указанное в пакете. Определяет длину экологического региона вдоль его оси Y на поверхности геоида.
> **Notice:** Эта длина не включает ширину переходного периметра.


### Возвращаемое значение

Значение параметра **Size Y**.
## float getRadius ( ) const

Возвращает значение параметра **Corner Radius**, указанное в пакете. Определяет радиус скругления угла прямоугольника. Чем меньше радиус, тем «острее» угол.
### Возвращаемое значение

Значение параметра **Corner Radius**.
## float getRotation ( ) const

Возвращает значение параметра **Rotation**, указанное в пакете. Определяет угол yaw прямоугольника со скруглёнными углами.
### Возвращаемое значение

Значение параметра **Rotation**.
## float getTransition ( ) const

Возвращает значение параметра **Transition Perimeter**, указанное в пакете. Определяет переходный периметр вокруг экологического региона. Этот периметр представляет собой область, в которой погодные условия интерполируются между условиями внутри экологического региона и условиями непосредственно за пределами периметра.
### Возвращаемое значение

Значение параметра **Transition Perimeter**.
