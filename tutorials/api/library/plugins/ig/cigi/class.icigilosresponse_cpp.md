# CigiLosResponse Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>


## CigiLosResponse Class

### Методы класса

---

## void setLosID ( int id )

Задаёт значение параметра **LOS ID**, указываемое в пакете.
### Аргументы

- *int* **id** - Значение параметра **LOS ID**.

## void setEntityID ( int id )

Задаёт значение параметра **Entity ID**, указываемое в пакете.
### Аргументы

- *int* **id** - Значение параметра **Entity ID**.

## void setEntityValid ( int valid )

Задаёт значение параметра **Entity Valid**, указываемое в пакете.
### Аргументы

- *int* **valid** - Значение параметра **Entity ID Valid**. Поддерживаются следующие значения:

  - 0 - недействительно (если пересечённый полигон не был частью сущности)
  - 1 - действительно (если пересечённый полигон был частью сущности)

## void setResponseValid ( int valid )

Задаёт значение параметра **Response Valid**, указываемое в пакете.
### Аргументы

- *int* **valid** - Значение параметра **Valid**. Поддерживаются следующие значения:

  - 0 - недействительно (пересечение не произошло)
  - 1 - действительно (произошло одно или несколько пересечений)

## void setResponseCount ( int count )

Задаёт значение параметра **Response Count**, указываемое в пакете. Этот параметр указывает общее количество пакетов Line of Sight Response, которые IG вернёт для соответствующего запроса.
### Аргументы

- *int* **count** - Значение параметра **Response Count**.

## void setVisible ( int v )

Задаёт значение параметра **Visible**, указываемое в пакете.
### Аргументы

- *int* **v** - Значение параметра **Visible**. Поддерживаются следующие значения:

  - 0 - скрыто (не видно)
  - 1 - видно

## void setRange ( double range )

Задаёт значение параметра **Range**, указываемое в пакете.
### Аргументы

- *double* **range** - Значение параметра **Range**.
