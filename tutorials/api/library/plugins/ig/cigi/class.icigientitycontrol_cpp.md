# CigiEntityControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiEntityControl Class

### Перечисления

## CIGI_ENTITY

| Name | Description |
|---|---|
| **CIGI_ENTITY_NO_CLAMP** = 0 | Привязка высоты для сущности отключена. |
| **CIGI_ENTITY_NON_CONFORMAL** = 1 | Параметр высоты задаёт смещение сущности над уровнем земли. |
| **CIGI_ENTITY_CONFORMAL** = 2 | Параметр высоты задаёт смещение сущности над уровнем моря. |

## CIGI_ANIMATION

| Name | Description |
|---|---|
| **CIGI_ANIMATION_STOP** = 0 | Остановить воспроизведение анимации сущности. |
| **CIGI_ANIMATION_PAUSE** = 1 | Приостановить воспроизведение анимации сущности. |
| **CIGI_ANIMATION_PLAY** = 2 | Запустить воспроизведение анимации сущности. |
| **CIGI_ANIMATION_CONTINUE** = 3 | Возобновить воспроизведение анимации сущности. |

### Методы класса

---

## int getEntityID ( ) const

Возвращает ID сущности.
### Возвращаемое значение

ID сущности.
## int getParentID ( ) const

Возвращает ID родителя сущности.
### Возвращаемое значение

ID родителя сущности.
## int getEntityType ( ) const

Возвращает текущий тип сущности.
### Возвращаемое значение

Тип сущности.
## int getEntityState ( ) const

Возвращает текущее состояние сущности.
### Возвращаемое значение

Текущее состояние сущности. Одно из значений [CIGI_STATE_*](../../../../../api/library/plugins/ig/cigi/class.cigi_connector_cpp.md#CIGI_STATE_DISABLED).
## int getAttachState ( ) const

Возвращает значение параметра **Attach State**. Оно указывает, присоединена ли сущность как дочерняя к [parent](#getParentID_int).
### Возвращаемое значение

Значение параметра **Attach State**. 1 - сущность должна быть или остаться присоединённой к сущности, указанной [Parent ID parameter](#getParentID_int); 0 - сущность должна быть отсоединена от родителя.
## int getCollision ( ) const

Возвращает значение, указывающее, должно ли быть включено обнаружение столкновений для сущности.
### Возвращаемое значение

Значение параметра **Collision Detection Enable**. 1 - обнаружение столкновений для сущности должно быть включено; 0 - обнаружение столкновений для сущности должно быть отключено.
## int getInheritAlpha ( ) const

Возвращает значение, указывающее, использует ли сущность значение alpha своего [parent](#getParentID_int).
### Возвращаемое значение

1, если сущность использует значение alpha своего [parent](#getParentID_int); иначе 0.
## int getGroundClamp ( ) const

Возвращает значение параметра **Ground/Ocean Clamp**.
### Возвращаемое значение

Значение параметра **Ground/Ocean Clamp**. Одно из значений [CIGI_ENTITY_*](#CIGI_ENTITY_NO_CLAMP).
## int getAnimationBack ( ) const

Возвращает текущее направление воспроизведения анимации сущности.
### Возвращаемое значение

Направление воспроизведения анимации сущности (вперёд или назад).
## int getAnimationLoop ( ) const

Возвращает текущий режим воспроизведения анимации сущности.
### Возвращаемое значение

Режим воспроизведения анимации сущности (однократный или циклический).
## int getAnimationState ( ) const

Возвращает текущее состояние воспроизведения анимации сущности.
### Возвращаемое значение

Состояние воспроизведения анимации сущности. Одно из значений [CIGI_ANIMATION_*](#CIGI_ANIMATION_STOP).
## int getInterpolation ( ) const

Возвращает значение, указывающее, включены ли интерполяция и экстраполяция.
### Возвращаемое значение

1, если интерполяция и экстраполяция включены; иначе 0.
## int getAlpha ( ) const

Возвращает текущее значение alpha, определяющее прозрачность геометрии сущности.
### Возвращаемое значение

Значение alpha.
## Math:: vec3 getRotation ( ) const

Возвращает текущие углы Эйлера поворота сущности.
### Возвращаемое значение

Углы Эйлера поворота сущности (roll, pitch, yaw).
## Math:: vec3 getPosition ( ) const

Возвращает текущее положение сущности.
### Возвращаемое значение

Координаты положения сущности.
> **Notice:** Геокоординаты будут возвращены, если родительская сущность не назначена, иначе будут возвращены локальные координаты.
