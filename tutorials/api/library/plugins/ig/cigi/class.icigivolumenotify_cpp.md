# CigiVolumeNotify Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>


## CigiVolumeNotify Class

### Методы класса

---

## void setEntityID ( int id )

Задаёт ID сущности, которой принадлежит объём обнаружения столкновений.
### Аргументы

- *int* **id** - ID сущности, которой принадлежит объём обнаружения столкновений.

## void setVolumeID ( int id )

Задаёт ID объёма обнаружения столкновений, внутри которого произошло столкновение. Этот параметр вместе с [Entity ID](#setEntityID_int_void) позволяет Host сопоставить этот ответ с соответствующим запросом.
### Аргументы

- *int* **id** - ID объёма обнаружения столкновений, внутри которого произошло столкновение.

## void setContactEntityID ( int id )

Задаёт сущность, с которой произошло столкновение. Если [Collision Type](#setCollisionType_int_void) установлен в Non-entity (0), этот параметр игнорируется.
### Аргументы

- *int* **id** - ID сущности, с которой произошёл контакт.

## void setContactVolumeID ( int id )

Задаёт ID объёма обнаружения столкновений, с которым произошло столкновение.
### Аргументы

- *int* **id** - ID объёма обнаружения столкновений, с которым произошло столкновение.

## void setCollisionType ( int type )

Этот параметр указывает, произошло ли столкновение с другой сущностью или с объектом, не являющимся сущностью, например, с ландшафтом.
### Аргументы

- *int* **type** - Тип столкновения. Доступные значения:

  - 0 — для столкновений с объектом, не являющимся сущностью.
  - 1 — для столкновений с другими сущностями.
