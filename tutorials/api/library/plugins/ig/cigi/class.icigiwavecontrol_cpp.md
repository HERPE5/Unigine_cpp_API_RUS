## CigiWaveControl Class

### Методы класса

---

## int getRegionID ( ) const

Возвращает ID экологического региона, указанный в пакете.
### Возвращаемое значение


- **Entity ID**, если [Scope](#getScope_int) установлен в Entity (2).
- **Region ID**, если [Scope](#getScope_int) установлен в Regional (1).


> **Notice:** Это значение будет игнорироваться, если [Scope](#getScope_int) установлен в Global (0).


## int getWaveID ( ) const

Возвращает значение **Wave ID**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Wave ID**.
## int getWaveEnabled ( ) const

Возвращает значение параметра **Wave Enable**, указанное в пакете.
### Возвращаемое значение

Параметр **Wave Enable**: 1 - волна включена и будет влиять на форму поверхности воды; иначе 0.
## int getScope ( ) const

Возвращает значение параметра **Scope**, указанное в пакете. Определяет, задана ли волна для глобальных, региональных или управляемых сущностью морских поверхностных условий.
### Возвращаемое значение

Значение параметра **Scope**. Поддерживаются следующие значения:
- 0 - Глобальная
- 1 - Региональная
- 2 - Сущности


## int getBreaker ( ) const

Возвращает значение параметра **Breaker Type**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Breaker Type**. Поддерживаются следующие значения:
- 0 - Plunging. Ныряющие волны нарастают, пока волна не образует вертикальную стену, после чего гребень движется быстрее основания буруна. Затем волна резко обрушивается в подошву волны.
- 1 - Spilling. Разливающиеся буруны разрушаются постепенно на большом расстоянии. Над гребнем образуется белая пена, стекающая вниз по фронту буруна.
- 2 - Surging. Набегающие буруны продвигаются к берегу в виде вертикальных стен воды. В отличие от ныряющих и разливающихся бурунов, гребень не обрушивается на переднюю часть волны.
