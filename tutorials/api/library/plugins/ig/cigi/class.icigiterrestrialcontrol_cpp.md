# CigiTerrestrialControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiTerrestrialControl Class

### Методы класса

---

## int getRegionID ( ) const

Возвращает ID экологического региона, указанный в пакете.
### Возвращаемое значение


- **Entity ID**, если [Scope](#getScope_int) установлен в Entity (2).
- **Region ID**, если [Scope](#getScope_int) установлен в Regional (1).


> **Notice:** Это значение будет игнорироваться, если [Scope](#getScope_int) установлен в Global (0).


## int getSurfaceID ( ) const

Возвращает значение параметра **Surface Condition ID**, указанное в пакете. Определяет поверхностное условие или загрязнение.
> **Notice:** Можно задать несколько условий, отправив несколько пакетов Terrestrial Surface Conditions Control.


### Возвращаемое значение

Значение параметра **Surface Condition ID**. Поддерживаются следующие значения:
- **0** - Dry (сброс).
- **> 0** - Определяется IG.


> **Notice:** Когда этот параметр установлен в Dry (0), все существующие поверхностные условия будут удалены в указанной области действия.


## int getSurfaceEnabled ( ) const

Возвращает значение параметра **Surface Condition Enable**, указанное в пакете.
### Возвращаемое значение

Параметр **Surface Condition Enable**: 1 - атрибут поверхностного условия, идентифицированный параметром [Surface Condition ID](#getSurfaceID_int), должен быть включён; иначе 0.
## int getScope ( ) const

Возвращает значение параметра **Scope**, указанное в пакете. Определяет, применяются ли поверхностные условия глобально, регионально или к экологической сущности.
### Возвращаемое значение

Значение параметра **Scope**. Поддерживаются следующие значения:
- 0 - Глобальная
- 1 - Региональная
- 2 - Сущности


## int getSeverity ( ) const

Возвращает значение параметра **Severity**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Severity**: 0 – 31 (от наименее к наиболее выраженному).
## int getCoverage ( ) const

Возвращает значение параметра **Coverage**, указанное в пакете. Определяет степень покрытия указанным поверхностным загрязнением.
### Возвращаемое значение

Значение параметра **Coverage** в диапазоне [0; 100].
