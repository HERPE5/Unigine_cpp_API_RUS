# CigiArticulatedControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiArticulatedControl Class

### Методы класса

---

## int getEntityID ( ) const

Возвращает ID сущности, указанный в пакете.
### Возвращаемое значение

ID сущности.
## int getPartID ( ) const

Возвращает ID сочленённой части, указанный в пакете.
### Возвращаемое значение

ID сочленённой части.
## int getPartEnabled ( ) const

Возвращает значение параметра **Articulated Part Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Articulated Part Enable**: 1, если сочленённая часть включена; иначе 0.
## Math:: ivec3 getOffsetEnabled ( ) const

Возвращает трёхкомпонентный вектор, объединяющий значения **Offset Enable**, указанные в пакете. Каждое значение определяет, включено ли смещение по соответствующей оси (X - назад, Y - влево, Z - вниз).
### Возвращаемое значение

Вектор из трёх целочисленных значений. Каждое значение определяет, включено ли смещение по соответствующей оси (X - назад, Y - влево, Z - вниз): 1 - включено; 0 - отключено.
## Math:: ivec3 getRotationEnabled ( ) const

Возвращает трёхкомпонентный вектор, объединяющий значения **Roll/Pitch/Yaw Enable**, указанные в пакете. Каждое значение определяет, включён ли поворот вокруг соответствующей оси (roll, pitch, yaw).
### Возвращаемое значение

Вектор из трёх целочисленных значений. Каждое значение определяет, включён ли поворот по соответствующей оси (X - назад, Y - влево, Z - вниз): 1 - включено; 0 - отключено.
## Math:: vec3 getOffset ( ) const

Возвращает смещение сочленённой части в системе координат субмодели (SCS), указанное в пакете.
### Возвращаемое значение

Координаты смещения сочленённой части (X - назад, Y - влево, Z - вниз).
## Math:: vec3 getRotation ( ) const

Возвращает поворот сочленённой части в системе координат субмодели (SCS), указанный в пакете.
### Возвращаемое значение

Углы Эйлера поворота сочленённой части.
