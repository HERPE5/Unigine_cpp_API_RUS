# CigiCelestialControl Class (CPP)

**Header:** #include <plugins/Unigine/CIGIConnector/UnigineCIGIConnector.h>

**Inherits from:** CigiHostPacket


## CigiCelestialControl Class

### Методы класса

---

## int getHour ( ) const

Возвращает значение параметра **Hour**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Hour** в диапазоне [0; 23].
## int getMinute ( ) const

Возвращает значение параметра **Minute**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Minute** в диапазоне [0; 59].
## unsigned int getDate ( ) const

Возвращает значение параметра **Date**, указанное в пакете. Задаёт текущую дату в симуляции.
### Возвращаемое значение

Значение параметра **Date**. Дата представляется семи- или восьмизначным десятичным целым числом в следующем формате: **MMDDYYYY = (месяц × 1000000) + (день × 10000) + год**
## int getTimeValid ( ) const

Возвращает значение параметра **Date/Time Valid**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Date/Time Valid**: 1, если параметры Hour, Minute и Date действительны; иначе 0.
## int getContinuous ( ) const

Возвращает значение параметра **Ephemeris Model Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Ephemeris Model Enable**. Поддерживаются следующие значения:
- 0 - Статичное время суток
- 1 - Непрерывное время суток


## int getSunEnabled ( ) const

Возвращает значение параметра **Sun Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Sun Enable**: 1, если солнце включено; иначе 0.
> **Notice:** Значение этого параметра вместе с соответствующим временем суток и положением на глобусе определяет, видно ли солнце на небе.


## int getMoonEnabled ( ) const

Возвращает значение параметра **Moon Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Moon Enable**: 1, если луна включена; иначе 0.
> **Notice:** Значение этого параметра вместе с соответствующим временем суток и положением на глобусе определяет, видна ли луна на небе.


## int getStarsEnabled ( ) const

Возвращает значение параметра **Star Field Enable**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Star Field Enable**: 1, если звёзды включены; иначе 0.
> **Notice:** Значение этого параметра вместе с соответствующим временем суток и положением на глобусе определяет, видны ли звёзды на небе.


## float getStarsIntensity ( ) const

Возвращает значение параметра **Star Field Intensity**, указанное в пакете.
### Возвращаемое значение

Значение параметра **Star Field Intensity** в диапазоне [0; 1].
