# Unigine::Plugins::MediaPlayer::VideoSource Class (CPP)

**Header:** #include <plugins/Unigine/MediaPlayer/UnigineMediaPlayer.h>


**VideoSource** представляет отдельный экземпляр воспроизведения медиа. Он предоставляет полный контроль над воспроизведением видео, включая play/pause/stop, перемотку, управление громкостью и доступ к текстуре видео для отрисовки в сцене.


Экземпляры VideoSource создаются через *[MediaPlayer::Manager::load()](../../../../api/library/plugins/mediaplayer/class.mediaplayer_manager_cpp.md#load_cstr_int_VideoSourcePtr)* и должны быть освобождены с помощью *[MediaPlayer::Manager::unload()](../../../../api/library/plugins/mediaplayer/class.mediaplayer_manager_cpp.md#unload_VideoSourcePtr_void)*, когда они больше не нужны.


Видео декодируется в текстуру RGBA, которую можно применить к любому материалу в сцене:


```cpp
auto *manager = MediaPlayer::Manager::get();
auto *player = manager->load(manager->getFileURL("video.mp4"));
player->play();

// Применение текстуры к материалу
material->setTexture("albedo", player->getTexture());

// Управление воспроизведением
player->setVolume(80);
player->setLoop(true);

// Перемотка к 50% видео
player->setPosition(0.5f);

```


```cpp
//-------------------------------------------------------------
// 1.  Использование текстуры, сгенерированной VLC, для декали
//-------------------------------------------------------------
// Создание ортографической декали, настройка её параметров и положения
Unigine::DecalOrthoPtr decal = Unigine::DecalOrtho::create();
decal->setRadius(10.0f);
decal->setWidth(2.0f);
decal->setHeight(2.0f);
decal->setWorldPosition(Math::Vec3(0.0f, 0.0f, 5.0f));

// Преобразование локального пути к файлу в URL для загрузки менеджером
Unigine::String url = Unigine::Plugins::MediaPlayer::Manager::get()->getFileURL("video.mp4");

// Создание нового источника видео и загрузка файла по URL
Unigine::Plugins::MediaPlayer::VideoSource* video_source = Unigine::Plugins::MediaPlayer::Manager::get()->load(url);

// Запуск воспроизведения
video_source->play();

// Создание экземпляра материала декали для его настройки
Unigine::MaterialPtr material = decal->getMaterialInherit();

// Задание текстуры, создаваемой источником видео, в качестве текстуры albedo
material->setTexture("albedo", video_source->getTexture());

//-------------------------------------------------------------
// 2. Использование той же текстуры, сгенерированной VLC, для виджета Sprite
//-------------------------------------------------------------
// Получение указателя на системный GUI
GuiPtr gui = Gui::get();

// Создание виджета Sprite
Unigine::WidgetSpritePtr sprite = WidgetSprite::create();

// Задание текстуры, создаваемой источником видео, для использования спрайтом
sprite->setRender(video_source->getTexture());

// Добавление виджета Sprite в системный GUI
gui->addChild(sprite, Gui::ALIGN_OVERLAP | Gui::ALIGN_FIXED);

```

 Лучшая практикаДля упрощённого управления воспроизведением видео используйте готовый **[VideoSourceComponent](../../../../api/library/plugins/mediaplayer/class.videosourcecomponent_cpp.md)**. Он позволяет добавить видео на объект сцены без написания кода — достаточно указать путь к файлу или URL, выбрать поверхность объекта и задать слот текстуры в материале. Компонент автоматически загружает видео, применяет текстуру и запускает воспроизведение при инициализации.

## bool isValid () const

Возвращает текущее значение, указывающее, действителен ли источник видео и готов ли он к воспроизведению.
### Возвращаемое значение

## void setRate ( float rate )
