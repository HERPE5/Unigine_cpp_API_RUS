# Unigine::Plugins::DataBridge::DataBridgeUI Class (CPP)

**Header:** #include <plugins/Unigine/DataBridge/UnigineDataBridge.h>


Этот класс управляет отрисовкой списка всех переменных, доступных в приложении, вместе с их типами и текущими значениями.


![](../../../../code/plugins/databridge/databridgeui.png)


## DataBridgeUI Class

### Методы класса

---

## void setVisible ( bool v )

Задаёт значение, указывающее, отрисовывается ли DataBridge UI в viewport.
### Аргументы

- *bool* **v** - true, чтобы включить отрисовку DataBridge UI, false, чтобы отключить её.

## bool isVisible ( )

Возвращает значение, указывающее, отрисовывается ли DataBridge UI в viewport.
### Возвращаемое значение

true, если DataBridge UI видим, иначе false.
