# Unigine::Plugins::DataBridge::DBVariable Class (CPP)

**Header:** #include <plugins/Unigine/DataBridge/UnigineDataBridge.h>


Этот класс предоставляет доступ к переменной и её методам.


## DBVariable Class

### Перечисления

## Type

| Name | Description |
|---|---|
| **Empty** = 0 | Пустое значение. |
| **Bool** = 1 | Булево значение. |
| **Int32** = 2 | Целочисленное значение. |
| **UInt32** = 3 | Беззнаковое целочисленное значение. |
| **Float32** = 4 | Значение с плавающей точкой. |
| **Float64** = 5 | Значение double. |
| **Int64** = 6 | Значение long long. |
| **UInt64** = 7 | Значение unsigned long long. |
| **String** = 8 | Строковое значение. |
| **Blob** = 9 | Значение blob. |
| **Directory** = 10 | Каталог. Эта переменная не имеет собственного значения и хранит другие переменные. |
