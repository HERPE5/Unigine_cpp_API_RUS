# Unigine::Plugins::SteamLeaderboard Class (CPP)

**Header:** #include <plugins/Unigine/Steam/UnigineSteam.h>


## SteamLeaderboard Class

### Перечисления

## DATA_REQUEST

| Name | Description |
|---|---|
| **DATA_REQUEST_GLOBAL** = 0 | Используется для запроса последовательного диапазона записей таблицы лидеров по рангу. Параметры start и end управляют запрашиваемым диапазоном. Например, можно отобразить топ 10 таблицы лидеров вашей игры, задав start равным 1, а end равным 10. |
| **DATA_REQUEST_GLOBAL_AROUND_USER** = 1 | Используется для получения записей таблицы лидеров относительно записи пользователя. Параметр start — это количество записей, получаемых перед записью текущего пользователя, а параметр end — количество записей после неё. Запись текущего пользователя всегда включается. Например, если текущий пользователь занимает 5-е место в таблице лидеров, задание start равным -2, а end равным 2, вернёт 5 записей: ранги с 3-го по 7-й. Если записей до или после записи пользователя недостаточно, Steam скорректирует диапазон, стараясь вернуть запрошенное количество записей. Например, если пользователь занимает 1-е место в таблице лидеров, а start задан равным -2, end равным 2, Steam вернёт первые 5 записей таблицы лидеров. |
| **DATA_REQUEST_FRIENDS** = 2 | Используется для получения всех записей таблицы лидеров для друзей текущего пользователя. Параметры start и end игнорируются. |
| **DATA_REQUEST_USERS** = 3 | Используется внутренне. |

## DISPLAY_TYPE

| Name | Description |
|---|---|
| **DISPLAY_TYPE_NONE** = 0 | Используется только когда таблица лидеров недействительна, никогда не задавайте это значение самостоятельно. |
| **DISPLAY_TYPE_NUMERIC** = 1 | Счёт представляет собой простое числовое значение. |
| **DISPLAY_TYPE_TIME_SECONDS** = 2 | Счёт представляет собой время в секундах. |
| **DISPLAY_TYPE_TIME_MILLISECONDS** = 3 | Счёт представляет собой время в миллисекундах. |

## SORT_METHOD

| Name | Description |
|---|---|
| **SORT_METHOD_NONE** = 0 | Используется только когда таблица лидеров недействительна, никогда не задавайте это значение самостоятельно. |
| **SORT_METHOD_ASCENDING** = 1 | Лучший результат — самое низкое число. |
| **SORT_METHOD_DESCENDING** = 2 | Лучший результат — самое высокое число. |

## int getID ( ) const

Возвращает ID таблицы лидеров.
### Возвращаемое значение

ID таблицы лидеров.
## const char * getName ( ) const

Возвращает имя таблицы лидеров.
### Возвращаемое значение

Имя таблицы лидеров.
## bool isFound ( ) const

Возвращает значение, указывающее, была ли найдена таблица лидеров.
### Возвращаемое значение

true, если таблица лидеров найдена; иначе false.
## bool find ( )

Возвращает значение, указывающее, была ли создана таблица лидеров.
### Возвращаемое значение

true, если таблица лидеров создана; иначе false.
## bool findOrCreate ( SteamLeaderboard::SORT_METHOD sort_method , SteamLeaderboard::DISPLAY_TYPE display_type )

Проверяет, создана ли таблица лидеров, и создаёт её, если она ещё не создана.
### Аргументы

- *[SteamLeaderboard::SORT_METHOD](../../../../api/library/plugins/steam/class.steamleaderboard_cpp.md#SORT_METHOD)* **sort_method** - Порядок сортировки новой таблицы лидеров, если она будет создана.
- *[SteamLeaderboard::DISPLAY_TYPE](../../../../api/library/plugins/steam/class.steamleaderboard_cpp.md#DISPLAY_TYPE)* **display_type** - Тип отображения (используется веб-сайтом Steam Community) новой таблицы лидеров, если она будет создана.

### Возвращаемое значение

true, если таблица лидеров создана; иначе false.
## bool uploadScore ( int score , bool forced = false )

Загружает результат пользователя в текущую таблицу лидеров.
### Аргументы

- *int* **score** - Значение для сохранения в текущей таблице лидеров.
- *bool* **forced** - Если задано true, таблица лидеров всегда будет заменять счёт на указанный; если задано false, таблица лидеров сохранит лучший счёт пользователя.

### Возвращаемое значение

true, если ; иначе false.
## bool downloadScores ( SteamLeaderboard::DATA_REQUEST request , int num_before , int num_after )

Загружает набор записей из текущей таблицы лидеров.
### Аргументы

- *[SteamLeaderboard::DATA_REQUEST](../../../../api/library/plugins/steam/class.steamleaderboard_cpp.md#DATA_REQUEST)* **request** - Тип запрашиваемых данных, одно из значений [DATA_REQUEST](#DATA_REQUEST_GLOBAL).
- *int* **num_before** - Количество записей перед текущим пользователем.
- *int* **num_after** - Количество записей после текущего пользователя.

### Возвращаемое значение

false, если таблица лидеров ещё не выбрана; иначе true.

## int getEntryRank ( int num ) const

- *int* **num** - Номер записи в таблице лидеров.

### Возвращаемое значение

Необработанный счёт, заданный в таблице лидеров.
