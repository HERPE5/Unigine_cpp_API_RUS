## OPTIMIZE_MODE

| Name | Description |
|---|---|
| **OPTIMIZE_MODE_DISABLED** = 0 | Оптимизация трекинга отключена. |
| **OPTIMIZE_MODE_AUTO** = 1 | Оптимизация трекинга задана автоматической. |

## void setBackgroundUpdate ( bool update )

Задаёт значение, указывающее, разрешено ли приложению получать кадры в фоновом режиме. По умолчанию ваше приложение UNIGINE прекращает отрисовку кадров и обновление своего главного окна, когда окно теряет фокус (например, пользователь переключается на другое окно). Включение режима фонового обновления позволяет вести постоянную отрисовку независимо от того, находится ли окно приложения в фокусе или в фоне.
### Аргументы

- *bool* **update** - Режим обновления окна: true для постоянно повторяющегося цикла обновления (т.е. приложение обновляется, даже если окно скрыто или не в фокусе); иначе false.

## bool isBackgroundUpdate ( ) const

Возвращает значение, указывающее, разрешено ли приложению получать кадры в фоновом режиме.
### Возвращаемое значение

**true**, если цикл обновления постоянно повторяется (т.е. приложение обновляется, даже если окно скрыто или не в фокусе); иначе **false**.

## void setTrackingOffsetDefault ( const Math::Vec3& val )

Задаёт стандартное смещение для вновь подключённого устройства. Значение Y задаёт смещение от глаз до плоскости фронтальной камеры, в метрах, а значение Z — смещение от уровня глаз до уровня камеры, в метрах. Значение X должно быть задано равным 0. Эти настройки могут использоваться для соответствия физическому положению и ориентации трекинг-оборудования на отслеживаемом устройстве, на которое оно установлено (например, VR-гарнитура).
### Аргументы

- *const  Math::Vec3&* **val** - Стандартное смещение для вновь подключённого устройства. Значение Y задаёт смещение от глаз до плоскости фронтальной камеры, в метрах, а значение Z — смещение от уровня глаз до уровня камеры, в метрах. Значение X должно быть задано равным 0. Эти настройки могут использоваться для соответствия физическому положению и ориентации трекинг-оборудования на отслеживаемом устройстве, на которое оно установлено (например, VR-гарнитура).

## long long getLeapNow ( ) const

Считывает значение универсальных часов, используемых системой для проставления временных меток кадров изображений и трекинга. Возвращаемое значение счётчика указано в микросекундах с начала эпохи. Используемые для самого счётчика часы определяются реализацией, но в целом это глобальные, монотонные часы, использующие наиболее точный высокопроизводительный счётчик, доступный в системе.
### Возвращаемое значение

Время, в микросекундах с неопределённого начала эпохи.
