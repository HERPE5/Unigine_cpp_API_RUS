# Unigine::Plugins::UltraleapHand Class (CPP)

**Header:** #include <plugins/Unigine/Ultraleap/UnigineUltraleap.h>


> **Notice:** Плагин [Ultraleap](../../../../code/plugins/ultraleap/index_cpp.md) должен быть загружен.


[Hands](../../../../code/plugins/ultraleap/index_cpp.md#hands) (руки/кисти) являются основной сущностью, отслеживаемой контроллером Ultraleap. Контроллер поддерживает внутреннюю модель человеческой руки и сверяет данные от своих сенсоров с этой моделью. Это позволяет контроллеру отслеживать положения пальцев, даже когда палец не полностью виден.


> **Notice:** Движение или изменения позиции могут быть потеряны, когда палец находится за рукой или непосредственно перед ней (с точки зрения контроллера).


Программное обеспечение Ultraleap сопоставляет внутреннюю модель с имеющимися данными. В некоторых случаях программное обеспечение может выполнить неверное сопоставление — например, определить правую руку как левую.


Класс Hand представляет физическую руку, обнаруженную устройством Leap, и предоставляет доступ к её атрибутам, описывающим позицию, ориентацию и движение руки.

| Name | Description |

## float getPinchDistance ( ) const

Возвращает расстояние между большим и указательным пальцами позы "щипок". Расстояние вычисляется по кратчайшему расстоянию между последними 2 фалангами большого пальца и указательного пальца. Это измерение щипка учитывает только большой и указательный пальцы.
### Возвращаемое значение

Расстояние между большим и указательным пальцами позы "щипок".
## float getPinchStrength ( ) const

Возвращает силу удержания позы "щипок". Сила равна нулю для открытой ладони и плавно достигает единицы при распознавании позы "щипок". Щипок может выполняться между большим пальцем и любым другим пальцем той же руки.
### Возвращаемое значение

Сила удержания позы "щипок": 0 для открытой ладони, плавно достигает 1 при распознавании позы "щипок".
## float getGrabStrength ( ) const

Сила позы "захват". Сила равна нулю для открытой ладони и плавно достигает единицы при распознавании позы "захват".
### Возвращаемое значение

Сила позы "захват": 0 для открытой ладони, плавно достигает 1 при распознавании позы "захват".
## float getGrabAngle ( ) const

Угол между пальцами и рукой позы "захват". Угол вычисляется по углу между направлением 4 пальцев и направлением руки. Большой палец не учитывается при вычислении угла. Угол равен 0 радиан для открытой ладони и достигает π радиан, когда поза представляет собой сжатый кулак.
### Возвращаемое значение

Угол между пальцами и рукой позы "захват": 0 радиан для открытой ладони, достигает π радиан, когда поза представляет собой сжатый кулак.
## double getPalmWidth ( ) const

### Возвращаемое значение

Ширина ладони, когда рука находится в плоском положении, в метрах.

## Math:: Vec3 getPalmStabilizedPosition ( ) const

Возвращает изменённую позицию ладони с применённым дополнительным сглаживанием и стабилизацией. Сглаживание и стабилизация выполняются для того, чтобы сделать это значение более подходящим для взаимодействия с 2D-контентом. Стабилизированная позиция отстаёт от позиции ладони на переменную величину, зависящую в первую очередь от скорости движения.
### Возвращаемое значение

Координаты изменённой позиции ладони с применённым дополнительным сглаживанием и стабилизацией.

### Возвращаемое значение

## Math:: vec3 getPalmNormal ( ) const

Возвращает координаты вектора нормали к ладони. Если рука плоская, этот вектор будет направлен вниз, или "наружу" от передней поверхности ладони.
### Возвращаемое значение

Координаты вектора нормали к ладони.
