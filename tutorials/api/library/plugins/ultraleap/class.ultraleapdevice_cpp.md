# Unigine::Plugins::UltraleapDevice Class (CPP)

**Header:** #include <plugins/Unigine/Ultraleap/UnigineUltraleap.h>


## UltraleapDevice Class

### Перечисления

## HARDWARE_TYPE

| Name | Description |
|---|---|
| **HARDWARE_TYPE_UNKNOWN** = 0x0000 | Неизвестное устройство, совместимое с программным обеспечением трекинга. |
| **HARDWARE_TYPE_PERIPHERAL** = 0x0003 | Контроллер Leap Motion (первое потребительское периферийное устройство). |
| **HARDWARE_TYPE_DRAGONFLY** = 0x1102 | Внутренний исследовательский продукт с кодовым названием "Dragonfly". |
| **HARDWARE_TYPE_NIGHTCRAWLER** = 0x1201 | Внутренний исследовательский продукт с кодовым названием "Nightcrawler". |
| **HARDWARE_TYPE_RIGEL** = 0x1202 | Исследовательский продукт с кодовым названием "Rigel". |
| **HARDWARE_TYPE_SIR170** = 0x1203 | Модуль трекинга рук Ultraleap Stereo IR 170 (SIR170). |
| **HARDWARE_TYPE__3DI** = 0x1204 | Камера трекинга рук Ultraleap 3Di. |
| **HARDWARE_TYPE_INVALID** = -1 | Недействительный тип устройства. |

## TRANSFORM_MODE

| Name | Description |
|---|---|
| **TRANSFORM_MODE_HMD_VARJO** = 0 | Для трансформации используются HMD Pose от AppVarjo и [IModelView](../../../../api/library/rendering/class.camera_cpp.md#getIModelview_Mat4) от [Game::getPlayer()](../../../../api/library/engine/class.game_cpp.md#getPlayer_Player). |
| **TRANSFORM_MODE_MANUAL** = 1 | Пользователь вручную [sets the transform matrix](#setTransform_Mat4_void), как описано для [Ultraleap Coordinate System](../../../../code/plugins/ultraleap/index_cpp.md#coordinate_system). |

## void setTrackingOffset ( const Math::Vec3& offset )

Задаёт стандартное смещение для вновь подключённого устройства. Значение Y задаёт смещение от глаз до плоскости фронтальной камеры, в метрах, а значение Z — смещение от уровня глаз до уровня камеры, в метрах. Значение X должно быть задано равным 0. Эти настройки могут использоваться для соответствия физическому положению и ориентации трекинг-оборудования на отслеживаемом устройстве, на которое оно установлено (например, VR-гарнитура).
### Аргументы

- *const  Math::Vec3&* **offset** - Стандартное смещение для вновь подключённого устройства. Значение Y задаёт смещение от глаз до плоскости фронтальной камеры, в метрах, а значение Z — смещение от уровня глаз до уровня камеры, в метрах. Значение X должно быть задано равным 0.

## Math:: Vec3 getTrackingOffset ( ) const

Возвращает текущее виртуальное смещение трекинг-устройства. Значение Y задаёт смещение от глаз до плоскости фронтальной камеры, в метрах, а значение Z — смещение от уровня глаз до уровня камеры, в метрах.
### Возвращаемое значение

Стандартное смещение для вновь подключённого устройства. Значение Y задаёт смещение от глаз до плоскости фронтальной камеры, в метрах, а значение Z — смещение от уровня глаз до уровня камеры, в метрах. Значение X должно быть задано равным 0.
