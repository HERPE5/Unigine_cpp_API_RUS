# Unigine::Plugins::GPUMonitorPlugin Class (CPP)

**Header:** #include <plugins/Unigine/GPUMonitor/UnigineGPUMonitor.h>

> **Notice:** Этот класс является синглтоном.


## GPUMonitorPlugin Class

### Методы класса

---

## int getUpdateRate ( int num ) const

Возвращает количество обновлений в секунду для выбранного монитора.
### Аргументы

- *int* **num** - Порядковый номер, обозначающий монитор. Минимальное значение этого параметра — 0, максимальное значение — на единицу меньше значения, возвращаемого [getNumMonitors()](#getNumMonitors_int).

### Возвращаемое значение

Количество обновлений в секунду для выбранного монитора.
## void setUpdateRate ( int rate )

Задаёт количество обновлений в секунду.
### Аргументы

- *int* **rate** - Количество обновлений в секунду

## int getNumMonitors ( ) const

Возвращает количество мониторов.
### Возвращаемое значение

Количество мониторов.
## GPUMonitor * getMonitor ( int num ) const

Возвращает интерфейс выбранного GPUMonitor.
### Аргументы

- *int* **num** - Порядковый номер, обозначающий монитор. Минимальное значение этого параметра — 0, максимальное значение — на единицу меньше значения, возвращаемого [getNumMonitors()](#getNumMonitors_int).

### Возвращаемое значение

Интерфейс выбранного GPUMonitor
