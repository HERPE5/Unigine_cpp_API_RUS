### Методы класса

---

## const char * getName ( ) const

Возвращает имя используемого в данный момент GPU.
### Возвращаемое значение

Имя используемого в данный момент GPU
## int getNumAdapters ( ) const

Возвращает количество адаптеров в системе.
### Возвращаемое значение

Количество адаптеров
## const char * getAdapterName ( int num ) const

Возвращает имя видеоадаптера по его порядковому номеру.
### Аргументы

- *int* **num** - Порядковый номер, обозначающий видеоадаптер. Минимальное значение этого параметра — 0, максимальное значение — на единицу меньше значения, возвращаемого [getNumAdapters()](#getNumAdapters_int).

### Возвращаемое значение

Имя видеоадаптера
## float getCoreClock ( int num ) const

Возвращает тактовую частоту ядра выбранного адаптера.
### Аргументы

- *int* **num** - Порядковый номер, обозначающий видеоадаптер. Минимальное значение этого параметра — 0, максимальное значение — на единицу меньше значения, возвращаемого [getNumAdapters()](#getNumAdapters_int).

### Возвращаемое значение

Тактовая частота ядра, т.е. частота, на которой работает GPU.
