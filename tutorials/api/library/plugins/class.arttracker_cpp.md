# Unigine::Plugins::ARTTracker Class (CPP)

**Header:** #include <plugins/Unigine/ARTTracker/UnigineARTTracker.h>

> **Notice:** Этот класс является синглтоном.


## ARTTracker Class

### Перечисления

## ERROR

| Name | Description |
|---|---|
| **ERROR_NONE** = 0 | Нет ошибки. |
| **ERROR_TIMEOUT** = 1 | Таймаут при получении данных. |
| **ERROR_NET** = 2 | Ошибка получения UDP. |
| **ERROR_PARSE** = 3 | Ошибка в UDP-пакете. |

## DTRACKSDK

| Name | Description |
|---|---|
| **DTRACKSDK_FLYSTICK_MAX_BUTTON** = 16 | Данные FlyStick: максимальное количество кнопок. |
| **DTRACKSDK_FLYSTICK_MAX_JOYSTICK** = 8 | Данные FlyStick: максимальное количество значений джойстика. |
| **DTRACKSDK_MEATOOL_MAX_BUTTON** = 16 | Данные измерительного инструмента: максимальное количество кнопок. |
| **DTRACKSDK_HAND_MAX_FINGER** = 5 | Данные отслеживания пальцев руки: максимальное количество пальцев. |
| **DTRACKSDK_HUMAN_MAX_JOINTS** = 200 | Модель человека A.R.T (максимальное количество суставов + отслеживание пальцев). |

### Методы класса

## bool receive ( )

Принимает и обрабатывает один пакет данных DTrack.
### Возвращаемое значение

true, если пакет данных DTrack успешно получен, иначе false.
## int getFrameCounter ( ) const

Возвращает счётчик кадров (подсчёт с частотой синхронизации).
## double getTimeStamp ( ) const

Возвращает время измерения текущего кадра, т.е. время срабатывания инфракрасной вспышки камер. Временная метка использует внутренние часы контроллера, возвращая количество секунд (с точностью 1 мкс) с 00:00 UTC (полночь). Это означает, что значение временной метки сбрасывается в ноль при переходе через полночь (UTC).
### Возвращаемое значение

Время измерения текущего кадра.
## int init ( const char * ip = "192.168.1.100" , int port = 5000 )

Инициализирует связь с DTrack.
### Аргументы

- *const char ** **ip** - IP-адрес DTrack.
- *int* **port** - UDP-порт DTrack.

### Возвращаемое значение

1, если инициализация прошла успешно, иначе 0.
## bool start ( )

Запускает связь с DTrack.
### Возвращаемое значение

true, если связь успешно запущена, иначе false.
## bool stop ( )

Останавливает связь с DTrack.
### Возвращаемое значение

true, если связь успешно остановлена, иначе false.

## double getInertialError ( int index )

Возвращает текущую оценку ошибки дрейфа, в градусах; оценка возрастает на 10 градусов в минуту при инерциальном отслеживании.

- *int* **index** - Индекс стандартного тела 6DOF.

### Возвращаемое значение


- Для [inertial state](#getInertialState_int_int) 1: текущая оценка ошибки дрейфа, в градусах [0;360].
- Для [inertial states](#getInertialState_int_int) 0 и 2: 0.
