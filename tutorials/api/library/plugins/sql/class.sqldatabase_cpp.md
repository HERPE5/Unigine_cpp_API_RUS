# Unigine::Plugins::Sql::SqlDatabase Class (CPP)

**Header:** #include <plugins/Unigine/Sql/UnigineSql.h>


Этот класс управляет операциями с SQL-базами данных.


## SqlDatabase Class

### Методы класса

## bool isOpen () const

Возвращает текущее значение, указывающее, открыто ли в данный момент соединение с базой данных.
### Возвращаемое значение

**true**, если соединение с базой данных в данный момент открыто; иначе **false**.
## bool isOpenError () const

Возвращает текущее значение, указывающее, произошла ли ошибка при открытии соединения с базой данных. Информацию об ошибке можно получить с помощью [*getLastError()*](#getLastError_String).
### Возвращаемое значение

**true**, если при открытии соединения с базой данных произошла ошибка; иначе **false**.
## String getLastError () const

Возвращает текущую информацию о последней ошибке, произошедшей в базе данных.
### Возвращаемое значение

Текущая информация о последней ошибке, произошедшей в базе данных.
## bool isValid () const

Возвращает текущее значение, указывающее, есть ли у базы данных корректный драйвер.
### Возвращаемое значение

**true**, если у базы данных есть корректный драйвер; иначе **false**.

## bool open ( )

Открывает соединение с базой данных, используя текущие значения соединения. В случае сбоя информацию об ошибке можно получить с помощью [*getLastError()*](#getLastError_String).
### Возвращаемое значение

true, если соединение с базой данных открыто; иначе false.
## void close ( )

Закрывает соединение с базой данных, освобождая все занятые ресурсы и делая недействительными все существующие запросы, используемые с этой базой данных.
## bool transaction ( )

Начинает транзакцию в базе данных, если драйвер поддерживает транзакции.
### Возвращаемое значение

true, если операция выполнена успешно; иначе false.
## bool commit ( )

Фиксирует транзакцию в базе данных, если драйвер поддерживает транзакции и [transaction has been started](#transaction_int).
### Возвращаемое значение

true, если операция выполнена успешно; иначе false.
## bool rollback ( )

Откатывает транзакцию в базе данных, если драйвер поддерживает транзакции и [transaction has been started](#transaction_int).
### Возвращаемое значение

true, если операция выполнена успешно; иначе false.

## SqlResponse * execAsync ( SqlRequest * request )

Асинхронно выполняет SQL-запрос и возвращает полученные данные в виде SQL-ответа.

### Аргументы

### Возвращаемое значение
