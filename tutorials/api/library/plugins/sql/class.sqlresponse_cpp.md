# Unigine::Plugins::Sql::SqlResponse Class (CPP)

**Header:** #include <plugins/Unigine/Sql/UnigineSql.h>


Этот класс управляет ответом от SQL-базы данных.


## SqlResponse Class

### Методы класса

## String getExecutedQuery () const

Возвращает текущий запрос, который был фактически выполнен. Он может отличаться от переданного запроса, например, если с подготовленным запросом использовались привязанные значения, а используемая база данных не поддерживает подготовленные запросы.
### Возвращаемое значение

Текущий запрос, который был фактически выполнен.
## bool isReady () const

Возвращает текущее значение, указывающее, были ли запрошены данные (был выполнен метод [*execAsync()*](../../../../api/library/plugins/sql/class.sqldatabase_cpp.md#execAsync_SqlRequest_SqlResponse)).
### Возвращаемое значение

**true**, если данные были запрошены; иначе **false**.
## bool isDataReady () const

Возвращает текущее значение, указывающее, что запрошенные данные были загружены в ответ.
### Возвращаемое значение

**true**, если ответ получен; иначе **false**.
## bool isSuccess () const

Возвращает текущее значение, указывающее, что при получении ответа не произошло ошибок. Если возвращается false, используйте [*getError()*](#getError_String), чтобы узнать ошибку.
### Возвращаемое значение

**true**, если ответ был получен без ошибок; иначе **false**.
## String getError () const

Возвращает текущую строку, содержащую ошибку.
### Возвращаемое значение

Текущая строка, содержащая ошибку.
## int getNumRows () const

Возвращает текущее количество строк в полученном SQL-ответе.
### Возвращаемое значение

Текущее количество строк в полученном SQL-ответе.
## int getNumColumns () const

Возвращает текущее количество столбцов в полученном SQL-ответе.
### Возвращаемое значение

Текущее количество столбцов в полученном SQL-ответе.
---

## void next ( unsigned int maxRows = 20 )

Запрашивает указанное количество следующих строк. Этот метод может быть вызван только после метода [*execAsync()*](../../../../api/library/plugins/sql/class.sqldatabase_cpp.md#execAsync_SqlRequest_SqlResponse), иначе это вызовет сбой.
### Аргументы

- *unsigned int* **maxRows** - Максимальное количество строк базы данных в запросе, которые должны быть получены.

## String getColumnName ( int column ) const

Возвращает имя столбца базы данных по его индексу.
### Аргументы

- *int* **column** - Столбец базы данных.

### Возвращаемое значение

Имя столбца.
## Variable getData ( int row , int column ) const

Возвращает данные в указанной ячейке базы данных.
### Аргументы

- *int* **row** - Индекс строки базы данных.
- *int* **column** - Индекс столбца базы данных.

### Возвращаемое значение

Переменная базы данных.
