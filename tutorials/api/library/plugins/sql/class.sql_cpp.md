# Unigine::Plugins::Sql::Sql Class (CPP)

**Header:** #include <plugins/Unigine/Sql/UnigineSql.h>

> **Notice:** Этот класс является одиночкой (singleton).


Этот класс предназначен для создания и удаления SQL-баз данных и проверки доступных драйверов.


## Sql Class

### Перечисления

## TABLE_TYPE

| Name | Description |
|---|---|
| **TABLES** = 0x01 | Все таблицы, видимые пользователю. |
| **SYSTEM_TABLES** = 0x02 | Внутренние таблицы, используемые базой данных. |
| **VIEWS** = 0x04 | Все представления, видимые пользователю. |
| **ALL_TABLES** = 0xff | Всё вышеперечисленное. |

## NUMERICAL_PRECISION_POLICY

| Name | Description |
|---|---|
| **LOW_PRECISION_INT32** = 0x01 | Принудительно использовать 32-битные целочисленные значения. В случае чисел с плавающей точкой дробная часть отбрасывается без предупреждения. |
| **LOW_PRECISION_INT64** = 0x02 | Принудительно использовать 64-битные целочисленные значения. В случае чисел с плавающей точкой дробная часть отбрасывается без предупреждения. |
| **LOW_PRECISION_DOUBLE** = 0x04 | Принудительно использовать значения double. Это политика по умолчанию. |
| **HIGH_PECISION** = 0 | Для сохранения точности будут использоваться строки. |

## BATCH_EXECUTION_MODE

| Name | Description |
|---|---|
| **VALUES_AS_ROWS** = 0 | Пакетный режим выполнения. Каждая запись в запросе трактуется как значение для обновления следующей строки. Обновляет несколько строк. |
| **VALUES_AS_COLUMNS** = 1 | Пакетный режим выполнения. Каждая запись в запросе трактуется как одно значение типа массив. Обновляет одну строку. |

## void getDrivers ( Vector < String > & OUT_drivers ) const

Возвращает список всех доступных драйверов баз данных.
### Аргументы

- *[Vector](../../../../api/library/containers/vector/class.vector_cpp.md)<[String](../../../../api/library/common/class.string_cpp.md)> &* **OUT_drivers** - Выходной буфер для списка драйверов баз данных. > **Notice:** Этот выходной буфер должен быть заполнен движком в результате выполнения метода.

## SqlDatabase * createDatabase ( const char * type , const char * connectionName )

Добавляет базу данных в список соединений с базами данных, используя тип драйвера и имя соединения. Перед использованием соединение должно быть инициализировано, например, вызовом некоторых или всех методов setDatabaseName(), setUserName(), setPassword(), setHostName(), setPort() и setConnectOptions(), и, наконец, open().
### Аргументы

- *const char ** **type** - Тип драйвера.
- *const char ** **connectionName** - Имя соединения с базой данных. Если добавить соединение с тем же именем, что и у существующего соединения, новое соединение заменит старое. Если connectionName не указано, новое соединение становится соединением по умолчанию для приложения, и последующие вызовы database() без аргумента имени соединения будут возвращать соединение по умолчанию.

### Возвращаемое значение

Вновь добавленное соединение с базой данных.
## void deleteDatabase ( SqlDatabase * database )

Удаляет указанное соединение с базой данных.
### Аргументы

- *[SqlDatabase](../../../../api/library/plugins/sql/class.sqldatabase_cpp.md) ** **database** - Соединение с базой данных, которое нужно удалить.
