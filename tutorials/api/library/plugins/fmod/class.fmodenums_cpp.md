## FMODEnums Class

### Перечисления

## FMOD_MODE

| Name | Description |
|---|---|
| **DEFAULT** = 0x00000000 | Значение по умолчанию для всех режимов, перечисленных ниже. [LOOP_OFF](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#LOOP_OFF), [_2D](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#_2D), [_3D_WORLDRELATIVE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#_3D_WORLDRELATIVE), [_3D_INVERSEROLLOFF](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#_3D_INVERSEROLLOFF). |
| **LOOP_OFF** = 0x00000001 | Для незацикленных звуков (по умолчанию). Переопределяет [LOOP_NORMAL](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#LOOP_NORMAL) / [LOOP_BIDI](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#LOOP_BIDI). |
| **LOOP_NORMAL** = 0x00000002 | Для звуков, зацикленных вперёд. |
| **LOOP_BIDI** = 0x00000004 | Для двунаправленных зацикленных звуков (работает только для программно микшируемых статических звуков). |
| **_2D** = 0x00000008 | Игнорирует любую 3D-обработку (по умолчанию). |
| **_3D** = 0x00000010 | Делает звук позиционируемым в 3D. Переопределяет [_2D](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#_2D). |
| **CREATESTREAM** = 0x00000080 | Декомпрессия во время выполнения, потоковая передача из указанного источника (например, с диска). Переопределяет [CREATESAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATESAMPLE) и [CREATECOMPRESSEDSAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATESAMPLE). Обратите внимание: поток можно воспроизводить только один раз одновременно, поскольку у него есть только один буфер потока и дескриптор файла. Откройте несколько потоков, чтобы воспроизводить их одновременно. |
| **CREATESAMPLE** = 0x00000100 | Декомпрессия при загрузке, распаковка или декодирование всего файла в память в целевом формате сэмпла (например, PCM). Самый быстрый вариант для воспроизведения и наиболее гибкий. |
| **CREATECOMPRESSEDSAMPLE** = 0x00000200 | Загружает MP2/MP3/FADPCM/IMAADPCM/Vorbis/AT9 или XMA в память, оставляя данные сжатыми. Кодирование Vorbis/AT9/FADPCM поддерживается только в контейнерном формате .FSB. Во время воспроизведения программный микшер FMOD декодирует данные в реальном времени как 'сжатый сэмпл'. Переопределяет [CREATESAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATESAMPLE). Если данные звука не соответствуют одному из поддерживаемых форматов, они будут обработаны так, как если бы были созданы с [CREATESAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATESAMPLE), с декодированием звука в PCM. |
| **OPENUSER** = 0x00000400 | Открывает статический сэмпл или поток, созданные пользователем. |
| **OPENMEMORY** = 0x00000800 | "name_or_data" будет интерпретироваться как указатель на память вместо имени файла при создании звуков. При использовании с [CREATESAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATESAMPLE) или [CREATECOMPRESSEDSAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATECOMPRESSEDSAMPLE), FMOD дублирует память в собственные буферы. При использовании с [CREATESTREAM](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATESTREAM), FMOD будет транслировать данные из переданного вами буфера. В этом случае собственный буфер не следует освобождать, пока не завершена работа с потоком и он не освобождён. |
| **OPENMEMORY_POINT** = 0x10000000 | "name_or_data" будет интерпретироваться как указатель на память вместо имени файла при создании звуков. Отличается от [OPENMEMORY](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#OPENMEMORY) тем, что использует память как есть, без дублирования в собственные буферы. Не будет работать, если данные сжаты и не используется [CREATECOMPRESSEDSAMPLE](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#CREATECOMPRESSEDSAMPLE). |
| **OPENRAW** = 0x00001000 | Игнорирует формат файла и обрабатывает данные как сырой PCM. |
| **OPENONLY** = 0x00002000 | Просто открывает файл без предварительной буферизации или чтения. Подходит для быстрого открытия ради получения информации. |
| **ACCURATETIME** = 0x00004000 | Для точного Sound::getLength / Channel::setPosition при работе с VBR MP3 и файлами MOD/S3M/XM/IT/MIDI. Сначала сканирует файл, поэтому открытие занимает больше времени. [OPENONLY](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#OPENONLY) не влияет на это поведение. |
| **MPEGSEARCH** = 0x00008000 | Для повреждённых / некорректных файлов MP3. Выполняет поиск по всему файлу, пока не найдёт корректный заголовок MPEG. Обычно поиск ограничен 4 КБ. |
| **NONBLOCKING** = 0x00010000 | Для асинхронного открытия звуков и получения потоковых подзвуков (перемотка). |
| **UNIQUE** = 0x00020000 | Уникальный звук, может воспроизводиться только один экземпляр одновременно. |
| **_3D_HEADRELATIVE** = 0x00040000 | Делает положение, скорость и ориентацию звука относительными к слушателю. |
| **_3D_WORLDRELATIVE** = 0x00080000 | Делает положение, скорость и ориентацию звука абсолютными (относительно мира) (по умолчанию). |
| **_3D_INVERSEROLLOFF** = 0x00100000 | Этот звук будет следовать модели обратного затухания, где mindistance = полная громкость, maxdistance = точка, где звук перестаёт затухать, а затухание фиксировано согласно глобальному коэффициенту затухания (по умолчанию). |
| **_3D_LINEARROLLOFF** = 0x00200000 | Этот звук будет следовать линейной модели затухания, где mindistance = полная громкость, maxdistance = тишина. |
| **_3D_LINEARSQUAREROLLOFF** = 0x00400000 | Этот звук будет следовать линейно-квадратичной модели затухания, где mindistance = полная громкость, maxdistance = тишина. |
| **_3D_INVERSETAPEREDROLLOFF** = 0x00800000 | Этот звук будет следовать модели обратного затухания на расстояниях, близких к mindistance, и линейно-квадратичному затуханию вблизи maxdistance. |
| **_3D_CUSTOMROLLOFF** = 0x04000000 | Этот звук будет следовать пользовательской модели затухания. |
| **_3D_IGNOREGEOMETRY** = 0x40000000 | Не подвержен окклюзии геометрией. |
| **IGNORETAGS** = 0x02000000 | Пропускает проверки тегов id3v2/asf и т.д. при открытии звука, чтобы уменьшить накладные расходы на поиск/чтение при открытии файлов. |
| **LOWMEM** = 0x08000000 | Отключает некоторые возможности сэмплов для снижения затрат памяти. |

## INIT_FLAGS

| Name | Description |
|---|---|
| **NORMAL** = 0x00000000 | Обычная инициализация. |
| **STREAM_FROM_UPDATE** = 0x00000001 | Внутренний поток для стриминга не создаётся. В основном используется с выходами не в реальном времени. |
| **MIX_FROM_UPDATE** = 0x00000002 | Внутренний поток микшера не создаётся. |
| **_3D_RIGHTHANDED** = 0x00000004 | 3D-вычисления будут выполняться в правосторонней системе координат. |
| **CHANNEL_LOWPASS** = 0x00000100 | Включает использование ChannelControl::setLowPassGain, ChannelControl::set3DOcclusion или автоматическое использование Geometry API. Все голоса добавят эффект программного ФНЧ-фильтра в цепочку DSP, который простаивает, если не используется одна из перечисленных функций/возможностей. |
| **CHANNEL_DISTANCEFILTER** = 0x00000200 | Все голоса на основе [_3D](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#_3D) добавят эффект программного ФНЧ- и ФВЧ-фильтра в цепочку DSP, который будет действовать как автоматизированный по расстоянию полосовой фильтр. |
| **PROFILE_ENABLE** = 0x00010000 | Включает хост на основе TCP/IP, к которому могут подключаться FMOD Studio или FMOD Profiler для просмотра памяти, ЦП и графа сети DSP в реальном времени. |
| **VOL0_BECOMES_VIRTUAL** = 0x00020000 | Любые звуки с нулевой громкостью станут виртуальными и не будут обрабатываться, кроме виртуального обновления их позиций. |
| **GEOMETRY_USECLOSEST** = 0x00040000 | При использовании движка геометрии обрабатывается только ближайший полигон, а не накапливаются все полигоны, которые пересекает линия от звука к слушателю. |
| **PREFER_DOLBY_DOWNMIX** = 0x00080000 | Использует алгоритм даунмикса Dolby Pro Logic II вместо стандартного алгоритма стереодаунмикса. |
| **THREAD_UNSAFE** = 0x00100000 | Отключает потокобезопасность вызовов API. Используйте это только если FMOD вызывается из одного потока и не используется Studio API! |
| **PROFILE_METER_ALL** = 0x00200000 | Медленнее, но добавляет измерение уровня для каждого DSP-модуля в графе. |
| **MEMORY_TRACKING** = 0x00400000 | Включает отслеживание выделения памяти. В настоящее время полезно только при использовании Studio API. Увеличивает объём используемой памяти и снижает производительность. |

## TIME_UNIT

| Name | Description |
|---|---|
| **MS** = 0x00000001 | Миллисекунды. |
| **PCM** = 0x00000002 | Сэмплы PCM, связаны через миллисекунды * частоту дискретизации / 1000. |
| **PCMBYTES** = 0x00000004 | Байты, связаны через сэмплы PCM * количество каналов * ширину данных (например, 16 бит = 2 байта). |
| **RAWBYTES** = 0x00000008 | Сырые байты файла (сжатых) данных звука (без учёта заголовков). Используется только [Sound::getLength](../../../../api/library/plugins/fmod/class.fmod_sound_cpp.md#getLength_int_uint) и [Channel::getPositionTimeLine](../../../../api/library/plugins/fmod/class.channel_cpp.md#getPositionTimeLine_uint_int_void). |
| **PCMFRACTION** = 0x00000010 | Доли одного сэмпла PCM. Диапазон unsigned int от 0 до 0xFFFFFFFF. Используется для субсэмпловой точности в целях DSP. |
| **MODORDER** = 0x00000100 | MOD/S3M/XM/IT. Порядок в секвенированном формате модуля. |
| **MODROW** = 0x00000200 | MOD/S3M/XM/IT. Текущая строка в секвенированном формате модуля. Нельзя использовать с [Channel::setPositionTimeLine](../../../../api/library/plugins/fmod/class.channel_cpp.md#setPositionTimeLine_uint_int_void). [Sound::getLength](../../../../api/library/plugins/fmod/class.fmod_sound_cpp.md#getLength_int_uint) вернёт количество строк в текущем воспроизводимом или выбранном паттерне. |
| **MODPATTERN** = 0x00000400 | MOD/S3M/XM/IT. Текущий паттерн в секвенированном формате модуля. Нельзя использовать с [Channel::setPositionTimeLine](../../../../api/library/plugins/fmod/class.channel_cpp.md#setPositionTimeLine_uint_int_void). [Sound::getLength](../../../../api/library/plugins/fmod/class.fmod_sound_cpp.md#getLength_int_uint) вернёт количество паттернов в композиции, а [Channel::getPositionTimeLine](../../../../api/library/plugins/fmod/class.channel_cpp.md#getPositionTimeLine_uint_int_void) вернёт текущий воспроизводимый паттерн. |
