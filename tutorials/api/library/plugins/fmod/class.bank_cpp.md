# Unigine::Plugins::FMOD::Bank Class (CPP)

**Header:** #include <plugins/Unigine/FMOD/UnigineFMOD.h>


> **Notice:** Этот набор функций доступен, если загружен плагин [FMOD](../../../../code/plugins/fmod/index.md).


Банки FMOD Studio содержат метаданные и данные аудиосэмплов, необходимые для микширования и воспроизведения в реальном времени. Данные аудиосэмплов могут быть упакованы в тот же банк, что и ссылающиеся на них события, либо в отдельные банки.


## Bank Class

### Методы класса

## bool isUnloading () const

Возвращает текущее значение, указывающее, выгружается ли банк.
### Возвращаемое значение

**true**, если банк выгружается; иначе **false**.
## bool isUnloaded () const

Возвращает текущее значение, указывающее, выгружен ли банк.
### Возвращаемое значение

**true**, если банк выгружен; иначе **false**.
## bool isLoading () const

Возвращает текущее значение, указывающее, загружается ли банк.
### Возвращаемое значение

**true**, если банк загружается; иначе **false**.
## bool isLoaded () const

Возвращает текущее значение, указывающее, загружен ли банк.
### Возвращаемое значение

**true**, если банк загружен; иначе **false**.
## bool isError () const

Возвращает текущее значение, указывающее, произошла ли ошибка.
### Возвращаемое значение

**true**, если произошла ошибка; иначе **false**.
## bool isValid () const

Возвращает текущее значение, указывающее, действительна ли ссылка на банк.
### Возвращаемое значение

**true**, если ссылка на банк действительна; иначе **false**.

## EventDescription * getEventDescription ( int index )

Возвращает описание события по указанному индексу. Вспомогательная функция, не должна использоваться напрямую.
### Аргументы

- *int* **index** - Индекс события.

### Возвращаемое значение

Описание события по указанному индексу.
## Bus * getBus ( int index )

Возвращает шину по её индексу. Вспомогательная функция, не должна использоваться напрямую.
### Аргументы

- *int* **index** - Индекс шины.

### Возвращаемое значение

Объект шины.
## VCA * getVCA ( int index )

Возвращает VCA по его индексу. Вспомогательная функция, не должна использоваться напрямую.
### Аргументы

- *int* **index** - Индекс VCA.

### Возвращаемое значение

Объект VCA.
