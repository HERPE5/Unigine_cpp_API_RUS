# Unigine::Plugins::FMOD::DSP Class (CPP)

**Header:** #include <plugins/Unigine/FMOD/UnigineFMOD.h>


> **Notice:** Этот набор функций доступен, если загружен плагин [FMOD](../../../../code/plugins/fmod/index.md).


Цифровой сигнальный процессор преобразует входные аудиосигналы в выходной поток.


## DSP Class

### Методы класса

## bool isIdle () const

Возвращает текущее значение, указывающее, включено ли состояние простоя. DSP считается простаивающим, когда он перестаёт получать входной сигнал и вся внутренняя обработка сохранённого ввода исчерпана. Каждый тип DSP может по-разному переходить в состояние простоя в зависимости от типа эффекта. Реверберация или эхо могут переходить в простой дольше после прекращения получения корректного сигнала, чем эффект с более коротким хвостом затухания, например, EQ-фильтр.
### Возвращаемое значение

**true**, если состояние простоя включено; иначе **false**.
## void setBypass ( bool bypass )

Задаёт новое состояние обхода обработки. Если обход включён, обработка этого модуля пропускается, но он продолжает обрабатывать свои входы.
### Аргументы

- *bool* **bypass** - Установите **true**, чтобы включить обход обработки; **false** - чтобы отключить его.

## bool isBypass () const

Возвращает текущее состояние обхода обработки. Если обход включён, обработка этого модуля пропускается, но он продолжает обрабатывать свои входы.
### Возвращаемое значение

**true**, если обход обработки включён; иначе **false**.
## void setActive ( bool active )

Задаёт новое активное состояние обработки. Если активное состояние отключено, обработка этого модуля и его входов останавливается. При создании DSP неактивен. Если используется [addDSP](../../../../api/library/plugins/fmod/class.channelgroup_cpp.md#addDSP_int_int_DSP), он будет активирован автоматически, иначе его нужно активировать вручную.
### Аргументы

- *bool* **active** - Установите **true**, чтобы включить активное состояние; **false** - чтобы отключить его.

## bool isActive () const

Возвращает текущее активное состояние обработки. Если активное состояние отключено, обработка этого модуля и его входов останавливается. При создании DSP неактивен. Если используется [addDSP](../../../../api/library/plugins/fmod/class.channelgroup_cpp.md#addDSP_int_int_DSP), он будет активирован автоматически, иначе его нужно активировать вручную.
### Возвращаемое значение

**true**, если активное состояние включено; иначе **false**.

## void getInfo ( char * name , unsigned int * version , int * channels , int * configwidth , int * configheight )

Получает информацию об этом DSP-модуле.
### Аргументы

- *char ** **name** - Имя этого модуля будет записано (с завершающим нулём) в предоставленный 32-байтовый буфер (строка UTF-8).
- *unsigned int ** **version** - Номер версии этого модуля, обычно в шестнадцатеричном формате AAAABBBB, где AAAA — основной номер версии, BBBB — дополнительный номер версии.
- *int ** **channels** - Количество каналов, обрабатываемых этим модулем, где 0 означает "любое количество".
- *int ** **configwidth** - Ширина диалогового окна конфигурации, где 0 означает "без диалогового окна".
- *int ** **configheight** - Высота диалогового окна конфигурации, где 0 означает "без диалогового окна".

## void setWetDryMix ( float prewet = 1 , float postwet = 1 , float dry = 1 )

Задаёт масштаб компонентов wet и dry сигнала.
### Аргументы

- *float* **prewet** - Уровень микса 'Dry' (необработанного сигнала), обрабатываемого DSP. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
- *float* **postwet** - Уровень микса 'Wet' (обработанного сигнала) на выходе. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
- *float* **dry** - Уровень микса 'Dry' (необработанного сигнала) на выходе. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.

## void getWetDryMix ( float prewet = 1 , float postwet = 1 , float dry = 1 )

Возвращает масштаб компонентов wet и dry сигнала.
### Аргументы

- *float* **prewet** - Уровень микса 'Dry' (необработанного сигнала), обрабатываемого DSP. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
- *float* **postwet** - Уровень микса 'Wet' (обработанного сигнала) на выходе. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
- *float* **dry** - Уровень микса 'Dry' (необработанного сигнала) на выходе. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
