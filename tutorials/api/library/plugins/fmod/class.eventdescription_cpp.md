# Unigine::Plugins::FMOD::EventDescription Class (CPP)

**Header:** #include <plugins/Unigine/FMOD/UnigineFMOD.h>


> **Notice:** Этот набор функций доступен, если загружен плагин [FMOD](../../../../code/plugins/fmod/index.md).


Описание события FMOD Studio.


Описания событий принадлежат банкам и могут быть запрошены после загрузки соответствующего банка. Описания событий можно получить по пути или GUID, либо путём перечисления всех описаний в банке.


## EventDescription Class

### Методы класса

## bool isSampleUnloading () const

Возвращает текущее состояние выгрузки данных сэмплов.
### Возвращаемое значение

**true**, если сэмпл выгружается; иначе **false**.
## bool isSampleUnloaded () const

Возвращает текущее состояние выгрузки данных сэмплов.
### Возвращаемое значение

**true**, если сэмпл выгружен; иначе **false**.
## bool isSampleLoading () const

Возвращает текущее состояние загрузки данных сэмплов.
### Возвращаемое значение

**true**, если сэмпл загружается; иначе **false**.
## bool isSampleLoaded () const

Возвращает текущее состояние загрузки данных сэмплов.
### Возвращаемое значение

**true**, если сэмпл загружен; иначе **false**.
## bool isSampleError () const

Возвращает текущее значение, указывающее, произошёл ли сбой загрузки сэмпла.
### Возвращаемое значение

**true**, если произошёл сбой загрузки сэмпла; иначе **false**.
## bool isValid () const

Возвращает текущее значение, указывающее, действительно ли описание события.
### Возвращаемое значение

**true**, если описание события действительно; иначе **false**.
## int getLength () const

Возвращает текущую длину временной шкалы.
### Возвращаемое значение

Текущая длина временной шкалы.
## bool isDopplerEnabled () const

Возвращает текущее значение, указывающее, включён ли эффект Доплера.
### Возвращаемое значение

**true**, если эффект Доплера включён; иначе **false**.
## bool isOneShot () const

Возвращает текущее значение, указывающее, является ли событие однократным (oneshot).
### Возвращаемое значение

**true**, если событие является однократным (oneshot); иначе **false**.
---

## EventInstance * createEvent ( )

Создаёт воспроизводимый экземпляр.
### Возвращаемое значение

Объект EventInstance.
## void releaseAllEvents ( )

Освобождает все экземпляры.
## void loadSampleData ( )

Загружает все непотоковые данные сэмплов.
## void unloadSampleData ( )

Выгружает все непотоковые данные сэмплов. Данные сэмплов не будут выгружены, пока не будут освобождены все экземпляры события.
## void release ( )

Помечает экземпляр события для освобождения. Экземпляры событий, помеченные для освобождения, уничтожаются при асинхронном обновлении, когда они находятся в остановленном состоянии.
## void releaseFromStudio ( )

Вспомогательная функция, не должна использоваться напрямую.
## void update ( )

Обновляет положение экземпляра события в мировом пространстве.
## String getPath ( ) const

Возвращает путь к описанию события.
### Возвращаемое значение

Путь.
