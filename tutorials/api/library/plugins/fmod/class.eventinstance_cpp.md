## void setPitch ( float pitch )

Задаёт новое значение высоты тона. Диапазон: [0; inf]. По умолчанию: 1. Множитель высоты тона можно задать любым значением, большим или равным нулю, но итоговая объединённая высота тона ограничивается диапазоном [0; 100] перед применением.
### Аргументы

- *float* **pitch** - Множитель высоты тона. Диапазон: [0; inf]. По умолчанию: 1. Множитель высоты тона можно задать любым значением, большим или равным нулю, но итоговая объединённая высота тона ограничивается диапазоном [0; 100] перед применением.

## float getPitch () const

Возвращает текущее значение высоты тона. Диапазон: [0; inf]. По умолчанию: 1. Множитель высоты тона можно задать любым значением, большим или равным нулю, но итоговая объединённая высота тона ограничивается диапазоном [0; 100] перед применением.
### Возвращаемое значение

Текущий множитель высоты тона. Диапазон: [0; inf]. По умолчанию: 1. Множитель высоты тона можно задать любым значением, большим или равным нулю, но итоговая объединённая высота тона ограничивается диапазоном [0; 100] перед применением.

## void set3DAttributes ( const Math:: Vec3 & position , const Math:: Vec3 & up , const Math:: Vec3 & forward , const Math:: Vec3 & velocity )

Задаёт положение, скорость и ориентацию события, используемые для вычисления 3D-панорамирования, эффекта Доплера и значений автоматических параметров расстояния и угла.
### Аргументы

- *const  Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **position** - Положение в мировом пространстве, используемое для панорамирования и затухания.
- *const  Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **up** - Ориентация вверх, должна иметь единичную длину (1.0) и быть перпендикулярна forward.
- *const  Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **forward** - Ориентация вперёд, должна иметь единичную длину (1.0) и быть перпендикулярна up.
- *const  Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **velocity** - Скорость в мировом пространстве, используемая для эффекта Доплера, в единицах расстояния в секунду.

## void get3DAttributes ( Math:: Vec3 & position , Math:: Vec3 & up , Math:: Vec3 & forward , Math:: Vec3 & velocity )

Возвращает положение, скорость и ориентацию события.
### Аргументы

- *Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **position** - Положение в мировом пространстве.
- *Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **up** - Ориентация вверх.
- *Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **forward** - Ориентация вперёд.
- *Math::[Vec3](../../../../api/library/math/class.vec3_cpp.md) &* **velocity** - Скорость в мировом пространстве.
