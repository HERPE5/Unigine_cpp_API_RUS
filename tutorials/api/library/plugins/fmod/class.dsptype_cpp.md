# Unigine::Plugins::FMOD::DSPType Class (CPP)

**Header:** #include <plugins/Unigine/FMOD/UnigineFMOD.h>


> **Notice:** Этот набор функций доступен, если загружен плагин [FMOD](../../../../code/plugins/fmod/index.md).


Предопределённые типы зарегистрированных DSP-модулей FMOD.


## DSPType Class

### Перечисления

## TYPE

| Name | Description |
|---|---|
| **UNKNOWN** = 0 | Создан не через плагин FMOD и имеет неизвестное назначение. |
| **MIXER** = 1 | Не обрабатывает сигнал, служит только для микширования входов. |
| **OSCILLATOR** = 2 | Генерирует синусоидальные/прямоугольные/пилообразные/треугольные или шумовые тона. |
| **LOWPASS** = 3 | Фильтрует звук с помощью высококачественного резонансного ФНЧ-алгоритма, но потребляет больше процессорного времени. Устарел и будет удалён в будущих версиях. |
| **ITLOWPASS** = 4 | Фильтрует звук с помощью резонансного ФНЧ-алгоритма, используемого в Impulse Tracker, но с ограниченным диапазоном частоты среза (от 0 до 8060 Гц). |
| **HIGHPASS** = 5 | Фильтрует звук с помощью резонансного ФВЧ-алгоритма. Устарел и будет удалён в будущих версиях. |
| **ECHO** = 6 | Создаёт эхо-эффект на звуке и затухает с заданной скоростью. |
| **FADER** = 7 | Панорамирует и масштабирует громкость сигнала. |
| **FLANGE** = 8 | Создаёт эффект флэнжера на звуке. |
| **DISTORTION** = 9 | Искажает звук. |
| **NORMALIZE** = 10 | Нормализует или усиливает звук до определённого уровня. |
| **LIMITER** = 11 | Ограничивает звук определённым уровнем. |
| **PARAMEQ** = 12 | Ослабляет или усиливает выбранный диапазон частот. Устарел и будет удалён в будущих версиях. |
| **PITCHSHIFT** = 13 | Изменяет высоту тона звука без изменения скорости воспроизведения. |
| **CHORUS** = 14 | Создаёт эффект хоруса на звуке. |
| **VSTPLUGIN** = 15 | Позволяет использовать плагины Steinberg VST. |
| **WINAMPPLUGIN** = 16 | Позволяет использовать плагины Nullsoft Winamp. |
| **ITECHO** = 17 | Создаёт эхо-эффект на звуке и затухает с заданной скоростью, как это реализовано в Impulse Tracker. |
| **COMPRESSOR** = 18 | Динамическая компрессия (связанная/несвязанная многоканальная, широкополосная). |
| **SFXREVERB** = 19 | Эффект реверберации I3DL2. |
| **LOWPASS_SIMPLE** = 20 | Фильтрует звук с помощью простого ФНЧ без резонанса, с гибкой настройкой частоты среза и высокой скоростью работы. Устарел и будет удалён в будущих версиях. |
| **DELAY** = 21 | Создаёт различные задержки на отдельных каналах звука. |
| **TREMOLO** = 22 | Создаёт эффект тремоло / chopper на звуке. |
| **LADSPAPLUGIN** = 23 | Не поддерживается / устарел. |
| **SEND** = 24 | Отправляет копию сигнала на return DSP в любом месте дерева DSP. |
| **RETURN** = 25 | Принимает сигналы от нескольких send DSP. |
| **HIGHPASS_SIMPLE** = 26 | Фильтрует звук с помощью простого ФВЧ без резонанса, с гибкой настройкой частоты среза и высокой скоростью работы. Устарел и будет удалён в будущих версиях. |
| **PAN** = 27 | Панорамирует сигнал в 2D или 3D, возможно, также выполняя апмиксинг или даунмиксинг. |
| **THREE_EQ** = 28 | Трёхполосный эквалайзер. |
| **FFT** = 29 | Анализирует сигнал и предоставляет информацию о спектре через getParameter. |
| **LOUDNESS_METER** = 30 | Анализирует громкость и истинный пик сигнала. |
| **ENVELOPEFOLLOWER** = 31 | Отслеживает огибающую входного/sidechain-сигнала. Устарел и будет удалён в будущих версиях. |
| **CONVOLUTIONREVERB** = 32 | Конволюционная реверберация. |
| **CHANNELMIX** = 33 | Предоставляет усиление по каналам, группировку каналов входного сигнала, которая также задаёт формат динамиков для выходного сигнала, и настраиваемую маршрутизацию каналов входа в выход. |
| **TRANSCEIVER** = 34 | 'Отправляет' и 'принимает' из набора до 32 различных слотов. Похож на send/return, но использует глобальные слоты вместо return в качестве назначения. Несколько transceiver могут принимать от одного канала, либо несколько transceiver могут отправлять на один канал, либо возможна комбинация обоих вариантов. |
| **OBJECTPAN** = 35 | Пространственно располагает входной сигнал, передавая его во внешний объектный микшер. |
| **MULTIBAND_EQ** = 36 | Пятиполосный параметрический эквалайзер. |
| **MAX** = 37 | Максимальное количество предопределённых типов DSP. |
