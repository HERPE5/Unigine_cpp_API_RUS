# Unigine::Plugins::FMOD::VCA Class (CPP)

**Header:** #include <plugins/Unigine/FMOD/UnigineFMOD.h>


> **Notice:** Этот набор функций доступен, если загружен плагин [FMOD](../../../../code/plugins/fmod/index.md).


Представляет глобальный VCA микшера.


## VCA Class

### Методы класса

## void setVolume ( float volume )

Задаёт новый уровень громкости. Отрицательное значение инвертирует сигнал. Диапазон: [-inf, -inf]. По умолчанию: 1.
### Аргументы

- *float* **volume** - Уровень громкости. Отрицательное значение инвертирует сигнал. Диапазон: [-inf, -inf]. По умолчанию: 1.

## float getVolume () const

Возвращает текущий уровень громкости. Отрицательное значение инвертирует сигнал. Диапазон: [-inf, -inf]. По умолчанию: 1.
### Возвращаемое значение

Текущий уровень громкости. Отрицательное значение инвертирует сигнал. Диапазон: [-inf, -inf]. По умолчанию: 1.
## bool isValid () const

Возвращает текущее значение, указывающее, действительна ли ссылка на VCA.
### Возвращаемое значение

**true**, если ссылка на VCA действительна; иначе **false**.

Путь объекта.
