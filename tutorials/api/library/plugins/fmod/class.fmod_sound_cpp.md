## unsigned int getLength ( FMODEnums::TIME_UNIT time_unit )

Возвращает длину в указанных единицах времени. Значение длины 0xFFFFFFFF означает неограниченную длину, например, для интернет-радиопотока или файла MOD/S3M/XM/IT, который может зацикливаться бесконечно.


Использование источника VBR (переменный битрейт) без метаданных, содержащих точную длину (например, MP3 без тегов или MOD/S3M/XM/IT), может вернуть неточные значения длины. Для таких форматов используйте [ACCURATETIME](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#ACCURATETIME) при создании звука. Это вызовет небольшую задержку и увеличение расхода памяти, так как FMOD просканирует весь файл при создании для определения корректной длины. Этот флаг также создаёт таблицу перемотки для точной посэмпловой перемотки.

### Аргументы

- *[FMODEnums::TIME_UNIT](../../../../api/library/plugins/fmod/class.fmodenums_cpp.md#TIME_UNIT)* **time_unit** - Тип единицы измерения времени.

### Возвращаемое значение

Длина звука.
