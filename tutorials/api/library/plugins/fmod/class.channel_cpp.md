# Unigine::Plugins::FMOD::Channel Class (CPP)

**Header:** #include <plugins/Unigine/FMOD/UnigineFMOD.h>


> **Notice:** Этот набор функций доступен, если загружен плагин [FMOD](../../../../code/plugins/fmod/index.md).


Источник аудиосигнала, подключающийся к иерархии микширования ChannelGroup.


## Channel Class

### Методы класса

## void setPitch ( float pitch )

Задаёт новую относительную высоту тона или скорость воспроизведения. Масштабирует частоту воспроизведения объекта Channel. Значение pitch 0.5f представляет половинную высоту тона (на октаву ниже), 1.0f — неизменённую высоту тона, 2.0f — удвоенную высоту тона (на октаву выше).
### Аргументы

- *float* **pitch** - Значение высоты тона: 0.5f представляет половинную высоту тона (на октаву ниже), 1.0f — неизменённую высоту тона, 2.0f — удвоенную высоту тона (на октаву выше).

## float getPitch () const

Возвращает текущую относительную высоту тона или скорость воспроизведения. Масштабирует частоту воспроизведения объекта Channel. Значение pitch 0.5f представляет половинную высоту тона (на октаву ниже), 1.0f — неизменённую высоту тона, 2.0f — удвоенную высоту тона (на октаву выше).
### Возвращаемое значение

Текущее значение высоты тона: 0.5f представляет половинную высоту тона (на октаву ниже), 1.0f — неизменённую высоту тона, 2.0f — удвоенную высоту тона (на октаву выше).

## void setPriority ( int priority )

Задаёт новый приоритет, используемый для упорядочивания виртуальных голосов. 0 означает *самый важный*, 256 означает *наименее важный*. Приоритет используется как грубый механизм управления системой виртуальных голосов. Каналы с более низким приоритетом всегда будут вытеснены раньше каналов с более высоким приоритетом. Для каналов с одинаковым приоритетом первыми будут вытеснены те, у которых наименьшее значение слышимости.
### Аргументы

- *int* **priority** - Приоритет, используемый для упорядочивания виртуальных голосов: 0 означает *самый важный*, 256 означает *наименее важный*.

## int getPriority () const

Возвращает текущий приоритет, используемый для упорядочивания виртуальных голосов. 0 означает *самый важный*, 256 означает *наименее важный*. Приоритет используется как грубый механизм управления системой виртуальных голосов. Каналы с более низким приоритетом всегда будут вытеснены раньше каналов с более высоким приоритетом. Для каналов с одинаковым приоритетом первыми будут вытеснены те, у которых наименьшее значение слышимости.
### Возвращаемое значение

Текущий приоритет, используемый для упорядочивания виртуальных голосов: 0 означает *самый важный*, 256 означает *наименее важный*.
## void setMute ( bool mute )

### Аргументы

- *bool* **mute** - Установите **true**, чтобы включить состояние отключения звука (тишины); **false** - чтобы отключить его.

## bool isMute () const

Возвращает текущее состояние отключения звука. Отключение звука — это дополнительный элемент управления громкостью, эффект которого эквивалентен установке громкости в ноль.
### Возвращаемое значение

**true**, если состояние отключения звука (тишины) включено; иначе **false**.
## void setLoopCount ( int count )

## void setVolume ( float volume )

Задаёт новый уровень громкости. Диапазон [-inf; inf]. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
### Аргументы

- *float* **volume** - Уровень громкости в диапазоне [-inf; inf]. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.

## float getVolume () const

Возвращает текущий уровень громкости. Диапазон [-inf; inf]. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
### Возвращаемое значение

Текущий уровень громкости в диапазоне [-inf; inf]. 0 = тишина, 1 = полная громкость. Отрицательное значение инвертирует сигнал. Значения больше 1 усиливают сигнал.
## void setVolumeRamp ( bool ramp )

Задаёт новое значение, указывающее, изменяется ли громкость плавно или мгновенно. Если воспроизведение не приостановлено, изменения громкости плавно приближаются к целевому значению, чтобы избежать щелчка. Эта функция позволяет переопределить эту настройку и применять изменения громкости немедленно.
### Аргументы

- *bool* **ramp** - Установите **true**, чтобы включить плавное изменение громкости; **false** - чтобы отключить его.

## bool isVolumeRamp () const

Возвращает текущее значение, указывающее, изменяется ли громкость плавно или мгновенно. Если воспроизведение не приостановлено, изменения громкости плавно приближаются к целевому значению, чтобы избежать щелчка. Эта функция позволяет переопределить эту настройку и применять изменения громкости немедленно.
### Возвращаемое значение

**true**, если плавное изменение громкости включено; иначе **false**.
## bool isPlaying () const

### Возвращаемое значение

## float getAudibility () const

Возвращает текущую оценку выходной громкости. Оценочная громкость вычисляется на основе 3D-пространственного расположения, окклюзии, уровней громкости API и используемых DSP. Это значение используется для определения, какие каналы должны быть слышимыми, а какие — виртуализированы при ограниченных ресурсах.
### Возвращаемое значение

Текущая оценочная слышимость.
## bool isVirtual () const

Возвращает текущее значение, указывающее, эмулируется ли канал системой виртуальных голосов. True означает *беззвучный* / *эмулируемый*, false означает *слышимый* / *реальный*.
### Возвращаемое значение

**true**, если виртуальное состояние беззвучное/эмулируемое; иначе **false**.

## void setMinMaxDistance ( float min , float max )

Задаёт минимальное и максимальное расстояния, используемые для вычисления затухания 3D rolloff.
### Аргументы

- *float* **min** - Расстояние от источника, на котором начинается затухание. Диапазон: [0; max]. По умолчанию: 1
- *float* **max** - Расстояние от источника, на котором заканчивается затухание. Диапазон: [min; inf]. По умолчанию: 10000.
