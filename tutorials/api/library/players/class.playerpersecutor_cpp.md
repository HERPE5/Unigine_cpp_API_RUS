# Unigine.PlayerPersecutor Class (CPP)

**Header:** #include <UniginePlayers.h>

**Inherits from:** Player


Этот класс используется для создания свободно летающей камеры без физического тела, следующей за [target node](#setTarget_Node_void) на заданном [distance](#setDistance_float_void). Точная точка цели, за которой она следует, называется [anchor](#setAnchor_vec3_void). Persecutor может либо вращаться вокруг своей цели, либо иметь [fixed](#setFixed_int_void) направление взгляда. Как и [PlayerSpectator](../../../api/library/players/class.playerspectator_cpp.md), он аппроксимируется сферой, что позволяет ему [collide](#setCollision_int_void) с объектами (но не толкать их и не взаимодействовать с ними иным образом).

## void setFixed ( bool fixed )

Задаёт значение, указывающее, может ли persecutor свободно вращаться вокруг своей цели, или он ориентирован строго в одном направлении. Фиксированное направление взгляда — это то же направление, в котором persecutor смотрел на момент вызова этой функции, хотя впоследствии его можно сбросить на другое.
### Аргументы

- *bool* **fixed** - true, чтобы ориентировать player строго в одном направлении, **false** — чтобы позволить ему свободно вращаться.

## bool isFixed ( ) const

Возвращает значение, указывающее, может ли persecutor свободно вращаться вокруг своей цели, или он ориентирован строго в одном направлении. Фиксированное направление взгляда — это то же направление, в котором persecutor смотрел на момент вызова функции [setFixed()](#setFixed_int_void), хотя впоследствии его можно сбросить на другое.
### Возвращаемое значение

true, если persecutor ориентирован строго в одном направлении; иначе **false**.

## void setThetaAngle ( float angle )

Задаёт угол theta player (зенитный угол, также известный как угол pitch). Этот угол определяет вертикальное направление взгляда, т.е. вверх и вниз. Значение будет ограничено между минимальным и максимальным углом theta.
### Аргументы

- *float* **angle** - Новый угол, в градусах, в диапазоне [-90;90]. Если указано положительное значение, player будет смотреть вверх; если указано отрицательное значение, player будет смотреть вниз.

## float getThetaAngle ( ) const

Возвращает угол theta (зенитный угол, также известный как угол pitch). Этот угол определяет вертикальное направление взгляда, т.е. вверх или вниз. Если возвращается положительное значение, player смотрит вверх; если отрицательное — вниз. Значение ограничено между [minimum](#setMinThetaAngle_float_void) и [maximum](#setMaxThetaAngle_float_void) углом theta.
### Возвращаемое значение

Угол, в градусах.
