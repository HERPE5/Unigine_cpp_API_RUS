## static PlayerSpectatorPtr create ( )

Конструктор. Создаёт новый spectator со свойствами по умолчанию.
## void setAcceleration ( float acceleration )

Задаёт ускорение spectator.
### Аргументы

- *float* **acceleration** - Новое ускорение, в единицах в секунду в квадрате. Если указано отрицательное значение, вместо него используется 0.

## float getAcceleration ( ) const

Возвращает текущее ускорение spectator.
### Возвращаемое значение

Ускорение, в единицах в секунду в квадрате.
## void setCollision ( int collision )

Обновляет значение, указывающее, следует ли учитывать столкновения со сферой spectator.
### Аргументы

- *int* **collision** - 1, чтобы включить столкновения, 0, чтобы позволить spectator пролетать сквозь объекты.

## int getCollision ( ) const

Возвращает значение, указывающее, учитываются ли столкновения со сферой spectator.
### Возвращаемое значение

1, если столкновения учитываются; иначе 0.

### Аргументы

- *int* **mask** - Целочисленное значение, каждый бит которого используется для задания битовой маски.

## int getCollisionMask ( ) const

Возвращает маску столкновений коллизионной сферы spectator. Два объекта сталкиваются, если у обоих совпадающие маски.
### Возвращаемое значение

Целочисленное значение, каждый бит которого используется для задания битовой маски.

## void setMaxThetaAngle ( float angle )

Задаёт максимальный угол theta (зенитный угол, также известный как угол pitch), определяющий, насколько далеко вниз может смотреть player.
### Аргументы

- *float* **angle** - Новый максимальный угол, в градусах, в диапазоне [0;90]. Чем выше значение, тем дальше вниз может смотреть player.

### Возвращаемое значение

Текущий максимальный угол theta, в градусах.

## void setPhiAngle ( float angle )

Задаёт угол phi (азимутальный угол, также известный как угол yaw). Этот угол определяет горизонтальное направление взгляда, т.е. влево или вправо.
### Аргументы

- *float* **angle** - Новый угол, в градусах. Положительные значения поворачивают player вправо; отрицательные — влево.

## float getPhiAngle ( ) const

Возвращает угол phi (азимутальный угол, также известный как угол yaw). Этот угол определяет горизонтальное направление взгляда, т.е. влево или вправо. Положительные значения поворачивают player вправо; отрицательные — влево.
### Возвращаемое значение

Значение угла phi.
## void setThetaAngle ( float angle )

Задаёт угол theta player (зенитный угол, также известный как угол pitch). Этот угол определяет вертикальное направление взгляда, т.е. вверх и вниз. Значение будет ограничено между минимальным и максимальным углом theta.
### Аргументы

- *float* **angle** - Новый угол, в градусах, в диапазоне [-90;90]. Если указано положительное значение, player будет смотреть вверх; если указано отрицательное значение, player будет смотреть вниз.

## float getThetaAngle ( ) const

Возвращает угол theta (зенитный угол, также известный как угол pitch). Этот угол определяет вертикальное направление взгляда, т.е. вверх или вниз. Если возвращается положительное значение, player смотрит вверх; если отрицательное — вниз. Значение ограничено между минимальным и максимальным углом theta.
### Возвращаемое значение

Значение угла theta.
