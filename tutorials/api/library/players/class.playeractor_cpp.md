## void setCollision ( int collision )

Задаёт значение, указывающее, следует ли учитывать столкновения с капсулой player. Этот метод действителен только когда setPhysical() установлен в 0 и не обрабатывает столкновения автоматически.
### Аргументы

- *int* **collision** - 1, чтобы включить столкновения, 0 — не обрабатывать столкновения с actor.

## int getCollision ( ) const

Возвращает значение, указывающее, учитываются ли столкновения с капсулой player. Этот метод действителен только когда setPhysical() установлен в 0 и не обрабатывает столкновения автоматически.
### Возвращаемое значение

1, если столкновения учитываются; иначе 0.

## void setThetaAngle ( float angle )

Задаёт угол theta player (зенитный угол, также известный как угол pitch). Этот угол определяет вертикальное направление взгляда, т.е. вверх и вниз. Значение будет ограничено между минимальным и максимальным углом theta.
### Аргументы

- *float* **angle** - Новый угол, в градусах, в диапазоне [-90;90]. Если указано положительное значение, player будет смотреть вверх; если указано отрицательное значение, player будет смотреть вниз.

## float getThetaAngle ( ) const

Возвращает угол theta (зенитный угол, также известный как угол pitch). Этот угол определяет вертикальное направление взгляда, т.е. вверх или вниз. Если возвращается положительное значение, player смотрит вверх; если отрицательное — вниз. Значение ограничено между минимальным и максимальным углом theta.
### Возвращаемое значение

Угол, в градусах.
