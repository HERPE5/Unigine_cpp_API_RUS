## void setFilter ( float filter )

Устанавливает значение фильтра, используемое для коррекции текущего состояния аналоговой оси относительно предыдущего. Состояния осей интерполируются для стиков и триггеров.
### Аргументы

- *float* **filter** - Значение фильтра для интерполяции между состояниями осей. Указанное значение ограничивается диапазоном [0;1].

  - Значение фильтра 0 означает отсутствие интерполяции — текущее значение не корректируется.
  - Значение фильтра 1 означает, что вместо текущего состояния используется предыдущее.

## float getFilter ( ) const

Значение фильтра, используемое для коррекции текущего состояния аналоговой оси (стиков и триггеров) относительно предыдущего:
- Значение фильтра 0 означает отсутствие интерполяции — текущее значение не корректируется.
- Значение фильтра 1 означает, что вместо текущего состояния используется предыдущее.


### Возвращаемое значение

Фильтр геймпада.
## Math:: vec2 getAxesLeft ( ) const

Возвращает вектор осей левого стика. Когда стик находится в центральном положении, это значение равно [0,0]. Значения соответствуют следующим позициям стика:
- **Первое значение** соответствует оси **X**. Отрицательные значения означают положение слева; положительные — справа.
- **Второе значение** соответствует оси **Y**. Отрицательные значения означают положение снизу; положительные — сверху.


### Возвращаемое значение

Вектор из двух значений в диапазоне [-1;1].
## Math:: vec2 getAxesLeftDelta ( ) const

Возвращает вектор дельта-значений [left thumbstick axes](../../../api/library/controls/class.inputgamepad_cpp.md#getAxesLeft_vec2) — разницу между значениями в предыдущем и текущем кадрах.
### Возвращаемое значение

Вектор дельта-осей.
## Math:: vec2 getAxesRight ( ) const

- **Первое значение** соответствует оси **X**. Отрицательные значения означают положение слева; положительные — справа.
- **Второе значение** соответствует оси **Y**. Отрицательные значения означают положение снизу; положительные — сверху.


### Возвращаемое значение

## void setVibration ( float low_frequency , float high_frequency , float duration_ms = 100.0f )

Устанавливает величину вибрации для правого (высокочастотного) и левого (низкочастотного) моторов на период времени, указанный в миллисекундах.
### Аргументы

- *float* **low_frequency** - Значение вибрации в диапазоне [0.0f; 1.0f] для левого (низкочастотного) мотора.
- *float* **high_frequency** - Значение вибрации в диапазоне [0.0f; 1.0f] для правого (высокочастотного) мотора.
- *float* **duration_ms** - Продолжительность периода вибрации, в миллисекундах.

## int getPlayerIndex ( ) const

Возвращает индекс игрока для геймпада. Некоторые устройства поддерживают подключение нескольких игроков (например, XBox 360 поддерживает до четырёх игроков, подключённых через геймпады XBox 360). Этот метод позволяет получить этот индекс.
### Возвращаемое значение

Индекс игрока для геймпада.

## const char * getGuid ( ) const

Возвращает GUID, созданный на основе идентификаторов производителя и продукта, а также номера версии продукта. Он позволяет идентифицировать модель устройства (*Controller XBox One* и т.д.), однако будет одинаковым для двух идентичных моделей.
### Возвращаемое значение

GUID модели устройства.
