# Unigine::InputJoystick Class (CPP)

**Заголовочный файл:** #include <UnigineInput.h>


Этот класс обрабатывает ввод с джойстика. Обычные джойстики поддерживают горячее подключение. Таким образом, вы можете подключить свой джойстик до или после создания экземпляра этого класса.


Класс *InputJoystick* предоставляет доступ к следующему вводу с контроллера:


- **Оси (Axes)** определяют движение вдоль осей X и Y (если джойстик двухосный, что является наиболее типичным случаем) и вдоль оси Z (если он трёхосный). Двухосные джойстики настроены таким образом, что движение стика слева направо соответствует движению вдоль оси X, а движение назад-вперёд (вниз-вверх) указывает на движение вдоль оси Y. В случае 3D-джойстика поворот стика влево (против часовой стрелки) или вправо (по часовой стрелке) соответствует движению вдоль оси Z. Состояния осей запрашиваются через *[getAxis()](#getAxis_uint_float)*. Для обеспечения плавной интерполяции между кадрами и во избежание рывков значения осей можно фильтровать через *[setFilter()](#setFilter_float_void)*.
- **Кнопки (Buttons)** соответствуют кнопкам контроллера и могут быть либо нажаты, либо отпущены в текущем кадре, либо непрерывно удерживаться нажатыми в течение нескольких кадров подряд, включая текущий.
- **POV-переключатели (Point-Of-View hat switches)** указывают направление обзора и поддерживают ряд положений, таких как влево, вправо, вверх и вниз (аналогично D-pad).

## void setFilter ( float filter )

Задаёт значение фильтра, используемое для коррекции текущего состояния оси джойстика относительно предыдущего.
### Аргументы

- *float* **filter** - Значение фильтра для интерполяции между состояниями осей. Предоставленное значение ограничивается диапазоном **[0;1]**.

  - Значение фильтра **0** означает, что интерполяции нет, и текущее значение не корректируется.
  - Значение фильтра **1** означает, что вместо текущего значения используется предыдущее состояние.

## float getFilter ( ) const

Возвращает значение фильтра, используемое для коррекции текущего состояния оси джойстика относительно предыдущего:
- Значение фильтра **0** означает, что интерполяции нет, и текущее значение не корректируется.
- Значение фильтра **1** означает, что вместо текущего значения используется предыдущее состояние.


### Возвращаемое значение

Значение фильтра для интерполяции между состояниями осей.

## float getAxis ( unsigned int axis ) const

Возвращает значение состояния оси с указанным номером. Оно включает позицию джойстика вдоль следующих осей: X, Y (двухосный джойстик) и Z (трёхосный джойстик). Когда джойстик находится в центральном положении, значения осей X и Y равны нулю. Отрицательные значения означают влево или вниз; положительные значения означают вправо или вверх.
### Аргументы

- *unsigned int* **axis** - Номер оси.

### Возвращаемое значение

Значение в диапазоне **[-1; 1]**.

## void playForceFeedbackEffectConstant ( float force )

Применяет к джойстику эффект постоянной силовой обратной связи с указанными параметрами. Сила применяется на постоянном уровне в течение всей продолжительности эффекта.
### Аргументы

- *float* **force** - Величина силы, применяемой эффектом силовой обратной связи. Значение в диапазоне [-1, 1]. Отрицательные значения означают, что начальное направление эффекта силовой обратной связи - влево, положительные значения - вправо.

## void playForceFeedbackEffectRamp ( float force , unsigned long long duration_us )

Применяет к джойстику эффект силовой обратной связи типа "рампа" с указанными параметрами. Сила применяется постепенно, увеличиваясь или уменьшаясь в течение продолжительности эффекта.
### Аргументы

- *float* **force** - Величина силы, применяемой эффектом силовой обратной связи. Значение в диапазоне [-1, 1]. Отрицательные значения означают, что начальное направление эффекта силовой обратной связи - влево, положительные значения - вправо.
- *unsigned long long* **duration_us** - Продолжительность эффекта силовой обратной связи, в микросекундах.

## void playForceFeedbackEffectSpring ( float force )

Применяет к джойстику пружинный эффект силовой обратной связи с указанной силой. Сила применяется в противодействие заданному состоянию.
### Аргументы

- *float* **force** - Величина силы, применяемой эффектом силовой обратной связи. Значение в диапазоне [-1, 1]. Отрицательные значения означают, что начальное направление эффекта силовой обратной связи - влево, положительные значения - вправо.

## void playForceFeedbackEffectSpring ( float left_force , float left_saturation , float right_force , float right_saturation , float offset , float deadband )

Применяет к джойстику пружинный эффект силовой обратной связи с указанными параметрами. Сила применяется в противодействие заданному состоянию.
### Аргументы

- *float* **left_force** - Сила эффекта силовой обратной связи, возникающего при повороте влево. Значение в диапазоне [0, 1].
- *float* **left_saturation** - Максимально возможная сила для эффекта силовой обратной связи при повороте влево. Значение в диапазоне [0, 1]. Не все устройства поддерживают насыщение.
- *float* **right_force** - Сила эффекта силовой обратной связи, возникающего при повороте вправо. Значение в диапазоне [0, 1].
- *float* **right_saturation** - Максимально возможная сила для эффекта силовой обратной связи при повороте вправо. Значение в диапазоне [0, 1]. Не все устройства поддерживают насыщение.
- *float* **offset** - Смещение от нулевого показания соответствующего значения датчика, при котором начинает применяться условие. Для пружинного эффекта нейтральная точка - то есть точка на оси, в которой пружина считалась бы в состоянии покоя - определяется смещением для условия.
- *float* **deadband** - Зона вокруг смещения оси, в которой условие не активно. В случае пружины, находящейся в состоянии покоя в середине оси, мёртвая зона увеличивает эту область покоя. Не все устройства поддерживают мёртвую зону.
