# Unigine::InputVRDevice Class (CPP)

**Header:** #include <UnigineInput.h>


Базовый класс для VR-устройств. Он предоставляет доступ к свойствам и настройкам, которые есть у всех VR-устройств. Например, вы можете получить имя устройства, проверить, есть ли у него батарея, дрейфует ли оно в определённом направлении, и так далее.


Кроме того, функциональность класса позволяет получить модель VR-устройства. Например, вы можете использовать её для отрисовки контроллера:


1. Получите контроллер для отрисовки с помощью соответствующих методов класса *[Input](../../../api/library/controls/class.input_cpp.md)*. Например, чтобы получить левый контроллер, вызовите *[getVRControllerLeft()](../../../api/library/controls/class.input_cpp.md)*.
2. Проверьте, что он существует.
3. Получите количество его моделей через *[getNumModels()](#getNumModels_int).*
4. Загрузите его [meshes](#getModelMesh_int_Mesh) и [textures](#getModelTexture_int_Texture) по отдельности, один за другим, либо получите [the whole mesh](#getCombinedModelMesh_Mesh) сразу. Обратите внимание, что во время процесса загрузки может возникнуть задержка.
5. Отрисуйте загруженные мэши с текстурами.

## TRANSFORM_TYPE

| Name | Description |
|---|---|
| **TRANSFORM_TYPE_AIM** = 0 | (только OpenXR) Поза, позволяющая приложениям указывать направление в мире с помощью источника ввода, согласно соглашениям платформы для прицеливания этим типом источника. Поза прицеливания определяется следующим образом: - Для отслеживаемых рук: Луч, следующий соглашениям платформы о том, как пользователь наводится на объекты в мире всей рукой, с +Y вверх, +X вправо и -Z вперёд. Выбранный луч зависит от рантайма, часто это луч, исходящий из руки в точку, на которую указывает предплечье. - Для ручных контроллеров движения: Луч, следующий соглашениям платформы о том, как пользователь наводится на объекты в мире с помощью контроллера движения, с +Y вверх, +X вправо и -Z вперёд. Обычно это используется для приложений, отрисовывающих модель, соответствующую физическому контроллеру, так как приложение, отрисовывающее виртуальный объект в руке пользователя, вероятно, предпочитает указывать направление на основе геометрии этого виртуального объекта. Выбранный луч зависит от рантайма, хотя часто он исходит из передней части контроллера движения. |
| **TRANSFORM_TYPE_GRIP** = 1 | Поза, позволяющая приложениям надёжно отрисовывать виртуальный объект, удерживаемый в руке пользователя, независимо от того, отслеживается ли она напрямую или с помощью контроллера движения. Поза захвата определяется следующим образом: - Позиция захвата: - Для отслеживаемых рук: Центроид ладони пользователя при сжатии кулака, на поверхности ладони. - Для ручных контроллеров движения: Фиксированная позиция внутри контроллера, которая обычно совпадает с центроидом ладони при удержании рукой в нейтральном положении. Эта позиция должна корректироваться влево или вправо для центрирования позиции в захвате контроллера. - Ось +X ориентации захвата: Когда вы полностью открываете руку, образуя плоскую позу с 5 пальцами, луч, перпендикулярный ладони пользователя (от ладони в левой руке, в ладонь в правой руке). - Ось -Z ориентации захвата: Когда вы частично сжимаете руку (как будто держите контроллер), луч, проходящий через центр трубки, образованной пальцами, кроме большого, в направлении от мизинца к большому пальцу. - Ось +Y ориентации захвата: ортогональна +Z и +X по правилу правой руки. |
| **TRANSFORM_TYPE_MESH** = 2 | Поза ([grip_surface](https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#semantic-paths-standard-pose-identifiers)), позволяющая приложениям надёжно привязывать визуальный контент относительно физической руки пользователя, независимо от того, отслеживается ли рука напрямую или её позиция и ориентация определяются физическим контроллером. Поза grip_surface определяется следующим образом: - Позиция grip_surface: Центроид физической ладони пользователя, на поверхности ладони. Во избежание сомнений, ладонь не включает пальцы. - Ось +X ориентации grip_surface: Когда пользователь держит контроллер и выпрямляет указательный палец вперёд, луч, нормальный (перпендикулярный) ладони пользователя (от ладони в левой руке, в ладонь в правой руке). - Ось -Z ориентации grip_surface: Когда пользователь держит контроллер и выпрямляет указательный палец, луч, параллельный направлению указания пальца. - Ось +Y ориентации grip_surface: ортогональна +Z и +X по правилу правой руки. |
| **TRANSFORM_TYPE_PINCH** = 3 | [Поза щипка](https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#_pinch_pose), предназначенная для взаимодействия с небольшим объектом в пределах досягаемости руки с помощью пальца и большого пальца жестом "щипок". Например, поворот ключа для открытия замка или перемещение ручки на слайдере — это взаимодействия, подходящие для позы "щипок". |
| **TRANSFORM_TYPE_POKE** = 4 | [Поза тыка](https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#_poke_pose), предназначенная для взаимодействий с использованием кончика пальца для касания и нажатия небольшого объекта. Например, нажатие кнопки кончиком пальца, свайп для прокрутки в браузере или набор текста на виртуальной клавиатуре — это взаимодействия, подходящие для позы "тык". |
| **TRANSFORM_TYPE_GAZE** = 5 | [Поза взгляда](https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html#_eye_gaze_input) представляет направление взгляда пользователя и предназначена для взаимодействий на основе отслеживания глаз пользователя в реальном времени. Поза взгляда обычно используется для таких взаимодействий, как указание, выбор объекта, наведение на UI и взаимодействие на основе внимания. Она предоставляет естественный способ определения намерений пользователя на основе того, на что он в данный момент смотрит в сцене. Поза взгляда определяется следующим образом: - Позиция взгляда: Центральная точка между глазами пользователя (когда отслеживание глаз активно), или предполагаемая точка между глазами на основе отслеживания головы. - Ось -Z ориентации взгляда: Направление, в котором смотрит пользователь. Когда отслеживание глаз доступно, это отражает фактическую линию взгляда пользователя; иначе выравнивается с направлением вперёд головы. - Ось +Y ориентации взгляда: Обычно направлена вверх от лица пользователя. - Ось +X ориентации взгляда: Вправо с точки зрения пользователя, образуя правостороннюю систему координат. > **Notice:** Эта функция доступна только для устройств OpenXR. |
| **NUM_TRANSFORM_TYPES** = 6 | Общее количество типов трансформации. |
