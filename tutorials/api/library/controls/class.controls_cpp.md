## void setState ( int state , int value )

Переключает состояние заданного элемента управления вкл/выкл.
### Аргументы

- *int* **state** - Номер состояния элемента управления для обновления. Возможные значения находятся в диапазоне [STATE_FORWARD;NUM_STATES]. Полный список доступных элементов управления см. в перечислении Unigine::Controls::.
- *int* **value** - Значение состояния: положительное значение — "нажать" элемент управления; 0 — отпустить его.

## int getState ( int state ) const

Возвращает состояние заданного элемента управления (нажат или не нажат).
### Аргументы

- *int* **state** - Номер состояния элемента управления. Возможные значения находятся в диапазоне [STATE_FORWARD;NUM_STATES]. Полный список доступных элементов управления см. в перечислении Unigine::Controls::.

### Возвращаемое значение

**1**, если элемент управления нажат; иначе **0**.

## int clearState ( int state )

Возвращает состояние элемента управления и сбрасывает его в **0** (не нажато). Эта функция позволяет обработать элемент управления только один раз, даже если он удерживается нажатым в течение нескольких кадров подряд.
### Аргументы

- *int* **state** - Номер состояния элемента управления. Возможные значения находятся в диапазоне [STATE_FORWARD;NUM_STATES]. Полный список доступных элементов управления см. в перечислении Unigine::Controls::.

### Возвращаемое значение

Возвращает состояние заданного элемента управления: 1, если элемент управления нажат; иначе 0.
## bool saveState ( const Ptr < Stream > & stream ) const

Сохраняет настройки элементов управления в поток.
**Пример** использования методов saveState() и [restoreState()](#restoreState_Stream_int):


```cpp
// Получаем экземпляр стандартных элементов управления движка и устанавливаем его состояние
controls = Engine::getControls();
controls->setMouseDX(5.0f);

// сохраняем состояние
BlobPtr blob_state = Blob::create();
controls->saveState(blob_state);

// изменяем состояние
controls->setMouseDX(1.0f);

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем каретку в начало blob'а
controls->restoreState(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель на Stream.

### Возвращаемое значение

**true**, если настройки элементов управления успешно сохранены; иначе **false**.
## bool restoreState ( const Ptr < Stream > & stream )

Восстанавливает настройки элементов управления из потока.
**Пример** использования методов [saveState()](#saveState_Stream_int) и restoreState():


```cpp
// Получаем экземпляр стандартных элементов управления движка и устанавливаем его состояние
controls = Engine::getControls();
controls->setMouseDX(5.0f);

// сохраняем состояние
BlobPtr blob_state = Blob::create();
controls->saveState(blob_state);

// изменяем состояние
controls->setMouseDX(1.0f);

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем каретку в начало blob'а
controls->restoreState(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель на Stream.

### Возвращаемое значение

**true**, если настройки элементов управления успешно восстановлены; иначе **false**.
