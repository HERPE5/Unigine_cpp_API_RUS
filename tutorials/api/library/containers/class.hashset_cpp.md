# Unigine::HashSet Class (CPP)

**Header:** #include <UnigineHashSet.h>


Шаблон контейнера хеш-множества. Хеш-множество хранит ключи в *неопределённом* порядке. Оно обеспечивает быстрый поиск ключей. Например, вы можете реализовать быстрый поиск узлов по их идентификаторам.


Данные хранятся в памяти линейно, то есть как вектор:


![](hashset_data_storage.png)


> **Notice:** Адреса Key и Value могут изменяться на протяжении существования хеш-мапы. Такой способ хранения данных хеш-множества более производителен, но если вам нужно, чтобы адрес хеш-множества оставался неизменным, используйте класс *[BucketHashSet](../../../api/library/containers/class.buckethashset_cpp.md)*.


Чтобы создать новое хеш-множество, вы можете использовать [default constructor](#HashSet) или один из следующих способов:


- Создать хеш-множество с помощью списка инициализации: ```cpp // конструктор, принимающий список инициализации const HashSet<int> hashSet{ 4,7,2 }; // проверяем результат for (const auto &it : hashSet) Log::message("%d ", it.key); ```
- Создать хеш-множество с помощью конструктора копирования: ```cpp // конструктор, принимающий список инициализации const HashSet<String> initial{ "a", "e" }; // конструктор копирования const HashSet<String> copied(initial); // проверяем результат for (const auto &it : copied) Log::message("%s ", it.key.get()); ```
- Создать новое хеш-множество, добавив в него вектор ключей с помощью функции *[fromKeys()](#fromKeys_Vector_ref_HashSet)*: ```cpp // создаём вектор ключей Vector<String> keys{ "1", "2", "3" }; // добавляем ключи в пустое хеш-множество HashSet<String> hashSet = HashSet<String>::fromKeys(keys); // проверяем результат for (const auto &it : hashSet) Log::message("%s ", it.key.get()); ```


Вы можете изменять созданное хеш-множество с помощью функций-членов класса, описанных в этой статье. Рассмотрите некоторые примеры использования:


- Чтобы добавить ключи в текущее хеш-множество, вы можете использовать одну из функций *[append()](#append_Key_rvref_void)* или *[insert()](#insert_Key_rvref_void)*: ```cpp // создаём хеш-множества с помощью списков инициализации HashSet<String> initial{ "a", "b", "c", "d", "e" }; HashSet<String> to_add{ "m", "n", "o" }; // добавляем ключи хеш-множества "to_add" в хеш-множество "initial" initial.append(to_add); // вставляем ключ в хеш-множество "initial" initial.insert("s"); // проверяем результат for (const auto &it : initial) Log::message("%s ", it.key.get()); ``` Также можно вставлять ключи с помощью *[operator+=](#operator_addassign_const_Key_ref_HashSet_ref)*: ```cpp // создаём хеш-множества с помощью списков инициализации HashSet<String> initial{ "a", "e" }; const HashSet<String> to_add{ "b", "c", "d" }; const HashSet<String> expected{ "a", "b", "c", "d", "e" }; // добавляем одно хеш-множество к другому initial += to_add; // проверяем результат if (initial == expected) Log::message("The hash set has been added successfully\n"); ``` > **Notice:** Если ключ уже существует в хеш-множестве, он не будет добавлен. ```cpp // создаём хеш-множество HashSet<String> set{ "s" }; // присваиваем одно хеш-множество другому const HashSet<String> original = set; // вставляем хеш-множество в то же самое хеш-множество set.insert(set); // проверяем результат - хеш-множество остаётся тем же самым if (set == original) Log::message("Sets are equal\n"); ``` ```cpp // создаём пустое хеш-множество HashSet<String> set; // создаём две одинаковые строки const char *initial_str = "aaa"; const String aaa0(initial_str), aaa1(initial_str); // добавляем одну из строк как ключ в хеш-множество set.insert(aaa0); // проверяем результат if (set.contains(initial_str)) Log::message("The hash set contains the recently added key\n"); Log::message("The size is %d\n", set.size()); // добавляем дублирующую строку как ключ в хеш-множество set.insert(aaa1); // проверяем результат - размер хеш-множества остаётся тем же Log::message("The size is %d\n", set.size()); ```
- Чтобы удалить ключи из хеш-множества, вы можете использовать функцию *[subtract()](#subtract_const_HashSet_ref_void)* или *[remove()](#remove_const_HashSet_ref_void)*: ```cpp // создаём хеш-множества HashSet<String> initial{ "a", "b", "c", "d", "e" }; const HashSet<String> to_subtract{ "a", "c", "e" }; const HashSet<String> expected{ "b", "d" }; // удаляем ключи одного хеш-множества из другого initial.subtract(to_subtract); // проверяем, равны ли хеш-множества if (initial == expected)  Log::message("Sets are equal\n"); ``` ```cpp // создаём хеш-множества HashSet<String> set{ "1", "2", "3", "4", "5" }; HashSet<String> to_remove{ "3", "5" }; // удаляем ключи одного хеш-множества из другого set.remove(to_remove); // проверяем результат for (const auto &it : set) Log::message("%s ", it.key.get()); ``` Также можно использовать *[operator-=](#operator_subassign_const_Key_ref_HashSet_ref)*: ```cpp // создаём хеш-множества HashSet<String> initial{ "a", "b", "c", "d", "e" }; const HashSet<String> to_subtract{ "a", "c", "e" }; const HashSet<String> expected{ "b", "d" }; // удаляем ключи одного хеш-множества из другого initial -= to_subtract; // проверяем, равны ли хеш-множества if (initial == expected)  Log::message("Sets are equal\n"); ```
- Чтобы очистить хеш-множество, используйте функцию *[clear()](#clear_void)*: ```cpp // создаём хеш-множество HashSet<String> set{ "1", "2", "3", "4", "5" }; // удаляем все ключи из хеш-множества set.clear(); // проверяем, пусто ли множество if (set.empty()) Log::message("The set is empty\n"); ```
