# Unigine::HashMap Class (CPP)

**Header:** #include <UnigineHashMap.h>


Шаблонный контейнер хеш-map. Хеш-map хранит элементы, представленные парами ключ-значение, в *неопределённом* порядке. Данные хранятся в памяти линейно, то есть как вектор:


![](hashmap_data_storage.png)


> **Notice:** Адрес Key и Value может изменяться на протяжении существования хеш-map. Такой способ хранения данных хеш-map более производителен, но если вам нужно, чтобы адрес хеш-map оставался неизменным, используйте класс *[BucketHashMap](../../../api/library/containers/class.buckethashmap_cpp.md)*.


Хеш-map можно использовать, например, для поиска среди узлов по их именам.


Чтобы создать новый хеш-map, вы можете использовать [default constructor](#HashMap) или один из следующих способов:


- Создать хеш-map с помощью списка инициализации: ```cpp // создаём хеш-map с помощью списка инициализации const HashMap<String, int> hashMap_0{ { "a", 1 },	{ "b", 2 },	{ "c", 3 },	}; // проверяем результат for (const auto &k : hashMap_0) Log::message("%s : %d \n", k.key.get(), k.data); ``` Хеш-map, хранящий значения пользовательского типа, можно создать следующим образом: ```cpp // объявляем перечисление enum class MyEnum { One, Two, Three, }; // создаём хеш-map с помощью списка инициализации const HashMap<String, MyEnum> hashMap_1 { { "One", MyEnum::One }, { "Two", MyEnum::Two }, { "Three", MyEnum::Three }, }; // проверяем результат for (const auto &k : hashMap_1) Log::message("%s : %d \n", k.key.get(), k.data); ```
- Создать хеш-множество с помощью конструктора копирования: ```cpp // создаём хеш-map с помощью списка инициализации const HashMap<String, int> initial{ { "a", 1 },{ "b", 2 },{ "c", 3 },{ "d", 4 }, }; // конструктор копирования HashMap<String, int> copied(initial); // проверяем результат for (const auto &k : copied) Log::message("%s : %d \n", k.key.get(), k.data); ```


Вы можете изменять созданный хеш-map, используя функции-члены класса, описанные в данной статье. Рассмотрите некоторые примеры использования:


- Чтобы добавить элементы в текущий хеш-map, вы можете использовать одну из функций *[append()](#append_const_HashMap_ref_void)* или *[insert()](#insert_const_HashMap_ref_void)*: ```cpp // создаём хеш-map с помощью списков инициализации HashMap<String, int> initial{ { "a", 1 }, { "b", 2 }, { "c", 3 }, }; const HashMap<String, int> to_append{ { "m", 7 }, { "n", 8 }, { "o", 9 }, }; // добавляем элементы одного хеш-map в другой initial.append(to_append); // вставляем элемент в хеш-map "initial" initial.insert("s", 10); // проверяем результат for (const auto &k : initial) Log::message("%s : %d \n", k.key.get(), k.data); ```
- Получить значение по ключу из хеш-map и вставить элемент, если такого ключа нет: ```cpp // создаём пустой хеш-map HashMap<int, int> hashMap{ { 1, 10 } }; // пытаемся получить значения по заданным ключам Log::message("Value %d\n", hashMap[1]); // если такого ключа нет, он будет добавлен в хеш-map со значением по умолчанию Log::message("Value %d\n", hashMap[2]); // проверяем результат - новый элемент со значением по умолчанию добавлен в хеш-map for (const auto &k: hashMap) Log::message("%d : %d \n", k.key, k.data); ```
- Извлечь элемент из хеш-map: ```cpp // создаём хеш-map HashMap<int, int> hashMap { {1, 1}, {2, 2}, {3, 3}, }; // объявляем ключ и значение const int key = 0; const int value = 4; // добавляем новый элемент в хеш-map hashMap.append(key,value); // получаем итератор элемента по его ключу auto it = hashMap.find(key); // извлекаем элемент из хеш-map int c = hashMap.take(it); // проверяем результат - извлечённый элемент удалён из хеш-map for (const auto &k : hashMap) Log::message("%d : %d \n", k.key, k.data); ```
- Удалить элемент из хеш-map: ```cpp // создаём хеш-map HashMap<int, int> hashMap{ { 1, 1 },{ 2, 2 },{ 3, 3 }, }; // получаем итератор элемента по его ключу auto it = hashMap.find(2); // удаляем элемент из хеш-map hashMap.remove(it); // проверяем результат for (const auto &k: hashMap) Log::message("%d : %d \n", k.key, k.data); ```
- Получить элементы по значениям из хеш-map: ```cpp // создаём хеш-map HashMap<String, int> hashMap{ { "a", 1 }, { "b", 2 }, { "c", 3 }, }; // получаем итератор элемента по его значению auto it = hashMap.findData(2); // проверяем результат Log::message("%s \n", it->key.get()); ```
- Получить значение/значения из хеш-map: ```cpp // создаём хеш-map HashMap<String, int> hashMap{ { "a", 1 },{ "b", 2 },{ "c", 3 }, }; // получаем ключ по его значению Log::message("%d \n", hashMap.value("a")); // получаем вектор всех значений хеш-map Vector<int> ret = hashMap.values(); for (int i = 0; i < ret.size(); i++) Log::message("%d \n",ret[i]); ```
