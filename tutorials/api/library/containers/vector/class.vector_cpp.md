# Unigine::Vector Class (CPP)

**Header:** #include <UnigineVector.h>


Шаблон контейнера-вектора.


> **Warning:** В UnigineScript вектор — это последовательный контейнер, представляющий собой массив гибкого размера. Подробности см. в статье [Containers](../../../../code/uniginescript/language/containers/index.md#vector).

## Iterator back ( )

Возвращает ссылку на последний элемент вектора. В отличие от метода [end()](#end), который возвращает итератор, указывающий сразу за этим элементом, эта функция возвращает прямую ссылку.
### Возвращаемое значение

Конечный итератор.

Возвращает ссылку на последний элемент вектора. В отличие от метода [end()](#end), который возвращает итератор, указывающий сразу за этим элементом, эта функция возвращает прямую ссылку.

## Type value ( int index )

Возвращает элемент вектора, взятый по заданному индексу. Это безопасный метод, возвращающий значение по умолчанию, если индекс выходит за пределы вектора.
### Аргументы

- *int* **index** - Индекс значения.

### Возвращаемое значение

Элемент вектора.
## Type value ( int index , const Type & def )

Возвращает элемент вектора, взятый по заданному индексу.
### Аргументы

- *int* **index** - Индекс значения.
- *const Type &* **def** - Ссылка, возвращаемая, если индекс выходит за пределы вектора.

### Возвращаемое значение

Элемент вектора.
## const Type & valueRef ( int index , const Type & def )

Возвращает ссылку на элемент вектора, взятый по заданному индексу.
### Аргументы

- *int* **index** - Индекс значения.
- *const Type &* **def** - Ссылка, возвращаемая, если индекс выходит за пределы вектора.

### Возвращаемое значение

Ссылка на элемент вектора.
