# Unigine::BiMap Class (CPP)

**Header:** #include <UnigineBiMap.h>


Шаблонный контейнер двунаправленного отображения (bimap), содержащий пары *ключ-значение* с взаимно однозначным соответствием. Bimap обеспечивает быстрый двунаправленный поиск между ключами и значениями.
