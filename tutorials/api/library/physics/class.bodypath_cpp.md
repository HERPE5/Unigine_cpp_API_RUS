# Unigine::BodyPath Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Body


Этот класс представляет путь, вдоль которого может перемещаться произвольное твёрдое тело. Например, он позволяет создать физически симулируемый поезд, движущийся вдоль железнодорожного пути. BodyRigid и BodyPath должны быть соединены между собой с помощью JointPath.

> **Notice:** *Path* — это сплайн, вдоль которого может перемещаться объект.

## Math:: quat getClosestRotation ( const Math:: Vec3 & position )

Находит точку на пути, ближайшую к указанной опорной точке, и возвращает поворот, заданный путём в этой точке.
### Аргументы

- *const  Math::[Vec3](../../../api/library/math/class.vec3_cpp.md) &* **position** - Координаты опорной точки.

### Возвращаемое значение

Поворот, заданный путём в найденной точке, если путь существует; иначе возвращается кватернион (0 0 0 1).
## Ptr < Path > getPath ( )

Возвращает путь, вдоль которого перемещаются физические объекты. С помощью этой функции можно изменять скорость объектов, перемещающихся по пути, их трансформацию и т.д.
### Возвращаемое значение

Экземпляр класса [*Path*](../../../api/library/common/class.path_cpp.md).
## void setPathName ( const char * name , int unique = 0 )

Перезагружает внутреннюю трансформацию пути.
### Аргументы

- *const char ** **name** - Путь к файлу path, который нужно задать.
- *int* **unique** - Флаг динамичности:

  - **0** - Если перезагруженный путь изменяется во время выполнения, пути, загруженные из того же файла, также будут изменены.
  - **1** - Если перезагруженный путь изменяется во время выполнения, пути, загруженные из того же файла, изменены не будут.

## const char * getPathName ( )

Возвращает имя пути, вдоль которого перемещаются физические объекты.
### Возвращаемое значение

Путь к файлу path.
