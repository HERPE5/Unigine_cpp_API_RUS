# Unigine::BodyWater Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Body


Этот класс используется для симуляции [water body](../../../principles/physics/bodies/water/index.md), обеспечивающего плавучесть и волны от других физических тел. Симулируется как 2D-сетка с точечными частицами, расположенными в вершинах меша.

## static BodyWaterPtr create ( )

Конструктор. Создаёт water body со свойствами по умолчанию.
## static BodyWaterPtr create ( const Ptr < Object > & object )

Конструктор. Создаёт water body со свойствами по умолчанию для указанного объекта.

## void setAbsorption ( int absorption )

Обновляет значение, указывающее, должны ли волны рассеиваться по периметру меша.
### Аргументы

- *int* **absorption** - Положительное число, чтобы разрешить рассеивание волн, **0**, чтобы волны отражались.

## int getAbsorption ( )

Возвращает значение, указывающее, рассеиваются ли волны по периметру меша.
### Возвращаемое значение

Положительное значение, если волны рассеиваются по периметру меша; **0**, если они отражаются.

## void addParticleHeight ( const Math:: vec3 & position , float height )

Добавляет вертикальное смещение к воде. Соседние частицы воды, образующие плоскую сетку воды, соответствующим образом изменят свою высоту, симулируя круги на воде.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **position** - Локальные координаты точки (только по осям *X* и *Y*) вертикального смещения.
- *float* **height** - Высота вертикального смещения воды, в единицах.

## void addParticleVelocity ( const Math:: vec3 & position , const Math:: vec3 & velocity )

Прикладывает силу к воде. Соседним частицам воды, образующим плоскую сетку воды, будут переданы соответствующие значения скорости, симулируя кильватерный след от движущегося объекта.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **position** - Локальные координаты точки (только по осям *X* и *Y*) приложения силы.
- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **velocity** - Значение скорости.
