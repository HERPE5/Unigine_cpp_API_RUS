# Unigine::ShapeContact Class (CPP)

**Header:** #include <UniginePhysics.h>


Этот класс хранит результат физического контакта (координаты точки, длительность контакта, глубину проникновения, объект контакта, физические формы, участвующие в контакте, индекс поверхности контакта). Этот класс можно использовать для реализации собственной физики или собственного [player](../../../api/library/players/class.player_cpp.md).

## void setTime ( float time )

Задаёт время наступления контакта. При использовании CCD (для сфер или капсул) — это время от текущего тика симуляции физики до момента, когда должен произойти рассчитанный контакт. При непрерывном (non-continuous) обнаружении столкновений всегда равно 0.
### Аргументы

- *float* **time** - Время контакта, в миллисекундах.

## float getTime ( )

Возвращает время наступления контакта. При использовании CCD (для сфер или капсул) возвращает время от текущего тика симуляции физики до момента, когда должен произойти рассчитанный контакт. При непрерывном обнаружении столкновений всегда возвращается 0.
### Возвращаемое значение

Время контакта, в миллисекундах.
