# Unigine::Joint Class (CPP)

**Header:** #include <UniginePhysics.h>


Этот класс используется для симуляции различных типов [joints](../../../principles/physics/joints/index.md) и определения общих параметров, разделяемых всеми joints.

## void setAngularSoftness ( float softness )

Задаёт новую угловую мягкость (эластичность) joint. При скручивании joint угловая мягкость определяет, усредняются ли угловые скорости тел. Например:
- **0** означает, что joint жёсткий. Угловые скорости первого и второго тела независимы.
- **1** означает, что joint эластичный (желеобразный). Если первое тело изменяет свою скорость, скорость второго тела выравнивается с ней.


### Аргументы

- *float* **softness** - Угловая мягкость. Указанное значение будет ограничено диапазоном **[0;1]**.

## float getAngularSoftness () const

Возвращает текущую угловую мягкость (эластичность) joint. При скручивании joint угловая мягкость определяет, усредняются ли угловые скорости тел. Например:

## void setAngularRestitution ( float restitution )

Задаёт новую угловую упругость (жёсткость) joint. Угловая упругость определяет, насколько быстро joint компенсирует изменение угла между двумя телами. Когда тела поворачиваются относительно друг друга, упругость управляет величиной силы, прикладываемой к обоим телам, чтобы их точки крепления снова выровнялись. Например:
- **1** означает, что joint возвращает тела на место в течение 1 тика физики.
- **0.2** означает, что joint возвращает тела на место в течение 5 тиков физики.

Максимальное значение **1** может привести к дестабилизации физики (так как прикладываются слишком большие силы).
### Аргументы

- *float* **restitution** - Угловая упругость. Указанное значение будет ограничено диапазоном **[0;1]**.

## float getAngularRestitution () const

## Event<const Ptr < Joint > &> getEventBroken () const

Событие, срабатывающее при разрыве joint. Обработчик события должен получать *Joint* в качестве аргумента. Вы можете подписываться на события через *connect()* и отписываться через *disconnect()*. Также для удобства можно использовать классы *[EventConnection](../../../api/library/common/events/class.eventconnection_cpp.md)* и *[EventConnections](../../../api/library/common/events/class.eventconnections_cpp.md)* (см. примеры ниже).

> **Notice:** Подробнее см. статью [Event Handling](../../../code/fundamentals/events/index_cpp.md).

 Сигнатура обработчика события выглядит следующим образом: *myhandler(const Ptr<Joint> & **joint**)*

**Пример использования**

```cpp
// реализация обработчика события Broken
void broken_event_handler(const Ptr<Joint> & joint)
{
	Log::message("\Обработка события Broken\n");
}

//////////////////////////////////////////////////////////////////////////////
//  1. Несколько подписок можно связать с экземпляром класса EventConnections,
//  который затем можно использовать для отмены всех этих подписок сразу
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnections
EventConnections broken_event_connections;

// связываем с этим экземпляром при подписке на событие (можно связывать подписки на разные события)
publisher->getEventBroken().connect(broken_event_connections, broken_event_handler);

// другие подписки также связаны с этим экземпляром EventConnections
// (например, можно подписываться с помощью лямбда-функций)
publisher->getEventBroken().connect(broken_event_connections, [](const Ptr<Joint> & joint) {
		Log::message("\Обработка события Broken (лямбда).\n");
	}
);

// ...

// позже все эти связанные подписки можно удалить одной строкой
broken_event_connections.disconnectAll();

//////////////////////////////////////////////////////////////////////////////
//  2. Можно подписываться и отписываться через экземпляр класса EventConnection.
//  А также включать и отключать это конкретное соединение при необходимости.
//////////////////////////////////////////////////////////////////////////////

// создаём экземпляр класса EventConnection
EventConnection broken_event_connection;

// подписываемся на событие Broken с функцией-обработчиком, сохраняя соединение
publisher->getEventBroken().connect(broken_event_connection, broken_event_handler);

// ...

// можно временно отключить конкретное соединение события для выполнения определённых действий
broken_event_connection.setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
broken_event_connection.setEnabled(true);

// ...

// удаляем подписку на событие Broken через соединение
broken_event_connection.disconnect();

//////////////////////////////////////////////////////////////////////////////
//  3. Можно добавить экземпляр EventConnection/EventConnections как член класса,
//  обрабатывающего событие. В этом случае все связанные подписки будут
//  автоматически удалены при вызове деструктора класса
//////////////////////////////////////////////////////////////////////////////

// Класс, обрабатывающий событие
class SomeClass
{
public:
	// экземпляр класса EventConnections как член класса
	EventConnections e_connections;

	// Обработчик события Broken, реализованный как член класса
	void event_handler(const Ptr<Joint> & joint)
	{
		Log::message("\Обработка события Broken\n");
		// ...
	}
};

SomeClass *sc = new SomeClass();

// ...

// указываем экземпляр класса, если метод-обработчик принадлежит какому-либо классу
publisher->getEventBroken().connect(sc->e_connections, sc, &SomeClass::event_handler);

// ...

// экземпляр класса-обработчика удаляется, а все его подписки автоматически отменяются
delete sc;

//////////////////////////////////////////////////////////////////////////////
//   4. Подписка на событие с сохранением идентификатора соединения
//   и последующей отпиской по этому идентификатору
//////////////////////////////////////////////////////////////////////////////
// экземпляр класса EventConnections для управления соединениями событий
EventConnections e_connections;

// определяем идентификатор соединения, который будет использован для отписки позже
EventConnectionId broken_handler_id;

// подписываемся на событие Broken с лямбда-обработчиком, сохраняя идентификатор соединения
broken_handler_id = publisher->getEventBroken().connect(e_connections, [](const Ptr<Joint> & joint) {
		Log::message("\Обработка события Broken (лямбда).\n");
	}
);

// удаляем подписку позже, используя идентификатор
publisher->getEventBroken().disconnect(broken_handler_id);

//////////////////////////////////////////////////////////////////////////////
//   5. Игнорирование всех событий Broken при необходимости
//////////////////////////////////////////////////////////////////////////////

// можно временно отключить событие для выполнения определённых действий без его срабатывания
publisher->getEventBroken().setEnabled(false);

// ... выполняемые действия

// и снова включить его при необходимости
publisher->getEventBroken().setEnabled(true);
```

## int saveState ( const Ptr < Stream > & stream ) const

Сохраняет состояние указанного узла в двоичный поток.
- Если узел является родительским для других узлов, состояния этих дочерних узлов нужно сохранять вручную.
- Чтобы сохранить состояние из [buffer](../../../api/library/common/class.blob_cpp.md), [file](../../../api/library/filesystem/class.file_cpp.md) или сообщения из [socket](../../../api/library/networking/class.socket_cpp.md), убедитесь, что поток [opened](../../../api/library/common/class.stream_cpp.md#isOpened_int). Для буферов и файлов также необходимо задать правильную позицию для чтения.


**Пример** использования методов saveState() и [restoreState()](#restoreState_Stream_int):


```cpp
// задаём состояние joint
joint->setAngularRestitution(0.8f);

// сохраняем состояние
BlobPtr blob_state = Blob::create();
joint->saveState(blob_state);

// изменяем состояние
joint->setAngularRestitution(0.4f);

// восстанавливаем состояние
blob_state->seekSet(0);       // возвращаем каретку в начало blob'а
joint->restoreState(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Поток для сохранения данных состояния узла.

### Возвращаемое значение

true, если состояние узла успешно сохранено; иначе false.
## int restoreState ( const Ptr < Stream > & stream )

При необходимости для буферов и файлов можно задать позицию для записи.
