# Unigine::BodyRigid Class (CPP)

**Заголовочный файл:** #include <UniginePhysics.h>

**Наследуется от:** Body


Этот класс используется для симуляции [rigid bodies](../../../principles/physics/bodies/rigid/index.md), которые движутся согласно [rigid bodies dynamics](../../../principles/physics/bodies/index.md#rigid_bodies_dynamics).

## void setHighPriorityContacts ( bool contacts )

Задаёт новое значение, указывающее, имеет ли тело приоритет обработки обнаруженных контактов, в которых оно участвует. Контакт может обрабатываться любым из тел, участвующих в нём. То, какому телу назначается контакт, определяется случайным образом. Если контакт назначен телу и обрабатывается им, он называется *внутренним*, в противном случае — *внешним* (обрабатывается другим телом). Перебор внутренних контактов происходит значительно быстрее, чем внешних, поэтому этот метод можно использовать, если вы хотите, чтобы определённое тело обрабатывало большинство контактов, в которых оно участвует (т.е. они были внутренними), для повышения производительности.
> **Примечание:** Контакт между двумя телами с высоким приоритетом будет обработан одним из них, определённым случайным образом.


### Аргументы

- *bool* **contacts** - Установите **true**, чтобы включить высокий приоритет обработки обнаруженных контактов для тела; **false** - чтобы отключить его.

## void addForce ( const Math:: vec3 & force )


Прикладывает силу к центру масс тела.


В отличие от [impulses](#addImpulse_vec3_vec3_void), все силы сначала накапливаются, затем вычисляется результирующая сила и прикладывается к телу (на этапе симуляции физики, когда вызывается функция *update()* тела).


> **Примечание:** Эту функцию можно вызывать только из функции *[updatePhysics()](../../../code/fundamentals/execution_sequence/code_update.md#code_updatePhysics)* в скрипте мира. Не прикладывайте силы в функции *[update()](../../../code/fundamentals/execution_sequence/code_update.md#code_update)*, так как вы получите нестабильный результат, изменяющийся каждый кадр рендеринга.


### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **force** - Сила, которую нужно приложить, в мировых координатах.

## void addForce ( const Math:: vec3 & radius , const Math:: vec3 & force )


Прикладывает силу к точке, определяемой заданным радиус-вектором, указанным в локальных координатах. Эта функция вычисляет векторное произведение радиус-вектора и вектора силы. Она действует как рычаг, изменяющий и линейную, и угловую скорости тела.

## int createShapes ( int depth = 4 , float error = 0.01 , float threshold = 0.01 )

Удаляет все ранее созданные формы и создаёт одну или несколько [convex shapes](../../../api/library/physics/class.shapeconvex_cpp.md), аппроксимирующих меш.
### Аргументы

- *int* **depth** - Степень декомпозиции меша. Если задано **0** или отрицательное значение, будет создана только одна форма. Если задано положительное **n**, меш будет декомпозирован **n** раз. Этот параметр необязательный.
- *float* **error** - Погрешность аппроксимации, используемая для создания выпуклых оболочек. Этот параметр необязательный.
- *float* **threshold** - Порог, используемый для определения, могут ли две соседние выпуклые формы быть заменены одной большей формой. Пара форм заменяется большей формой, если их объёмы примерно равны. Это значение ограничивается диапазоном **[1 E-6; 1]**. Этот параметр необязательный.

### Возвращаемое значение

**1**, если выпуклые формы успешно созданы; иначе **0**.
