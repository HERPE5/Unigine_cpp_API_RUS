# Unigine::BodyRagdoll Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Body


Этот класс используется для управления [ragdoll body](../../../principles/physics/bodies/ragdoll/index.md), которое позволяет использовать [inverse kinematics](../../../principles/physics/bodies/ragdoll/index.md#combined) и процедурную анимацию последовательности смерти для [bone-animated](../../../objects/objects/mesh_skinned_legacy/index.md) персонажей.


Этот тип тела [automatically generates](#createBones_float_float_int_int) ragdoll [skeleton](../../../principles/physics/bodies/ragdoll/index.md#skeleton), т.е. иерархию костей персонажа (*[Object Dummy](../../../objects/objects/dummy/index.md)*), каждая из которых имеет коллизионную [shape](../../../api/library/physics/class.shape_cpp.md) и соединена с помощью [joints](../../../api/library/physics/class.joint_cpp.md).

## void setFrameBased ( bool based )

Задаёт новое значение, указывающее, какой подход используется для движения костей ragdoll: согласно анимации, записанной в файле, или на основе физики.
### Аргументы

- *bool* **based** - Установите **true**, чтобы включить движение костей согласно анимации, записанной в файле; **false** — чтобы отключить.

## bool isFrameBased () const

Возвращает текущее значение, указывающее, какой подход используется для движения костей ragdoll: согласно анимации, записанной в файле, или на основе физики.
### Возвращаемое значение

**true**, если движение костей согласно анимации, записанной в файле, включено; иначе **false**.
## void setRigidity ( float rigidity )

Задаёт новую жёсткость движения костей, т.е. насколько интерполированные линейная и угловая скорости всех костей влияют на скорости каждой отдельной кости.
### Аргументы

- *float* **rigidity** - Жёсткость движения костей. Указанное значение ограничивается диапазоном **[0;1]**:

  - При значении **0** кости независимы.
  - При значении **1** движение костей равномерно, так как интерполированная скорость значительно изменяет скорости каждой кости.

## float getRigidity () const

Возвращает текущую жёсткость движения костей, т.е. насколько интерполированные линейная и угловая скорости всех костей влияют на скорости каждой отдельной кости.
### Возвращаемое значение

Текущая жёсткость движения костей. Указанное значение ограничивается диапазоном **[0;1]**:
- При значении **0** кости независимы.
- При значении **1** движение костей равномерно, так как интерполированная скорость значительно изменяет скорости каждой кости.

## int createBones ( float error = 0.2 , float threshold = 0.01 , int capsule = 0 )

Автоматически генерирует упрощённый скелет из меша и его костей. Каждая кость аппроксимируется выпуклой оболочкой (convex hull) или капсулой в зависимости от указанных параметров.
### Аргументы

- *float* **error** - Допустимая погрешность, используемая при создании выпуклых оболочек. Это необязательный параметр.
- *float* **threshold** - Порог, используемый для обнаружения и отбрасывания слишком малых выпуклых оболочек. Выпуклая оболочка, объём которой меньше среднего объёма, умноженного на *threshold*, отбрасывается. Это необязательный параметр.
- *int* **capsule** - Форма аппроксимации. При значении **0** используется выпуклая оболочка; значение **1** задаёт аппроксимацию капсулой.

### Возвращаемое значение

Количество созданных костей.
