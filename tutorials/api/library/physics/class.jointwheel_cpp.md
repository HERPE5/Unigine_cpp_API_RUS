# Unigine::JointWheel Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Joint


Этот класс используется для создания [ray-cast](../../../principles/physics/joints/index.md#vehicles) колёс. Как рама, так и колесо являются [rigid bodies](../../../principles/physics/bodies/rigid/index.md). Назначать форму колесу не требуется: для обнаружения столкновения колеса с поверхностью используется трассировка луча (ray casting).


### Пример


Следующий код иллюстрирует соединение двух [rigid bodies](../../../api/library/physics/class.bodyrigid_cpp.md) (frame и wheel) с помощью wheel joint.


```cpp
include <UniginePhysics.h>

/* .. */

JointWheelPtr joint = JointWheel::create(frame, wheel);

// задаём координаты точки крепления joint
joint->setWorldAnchor(wheel->getObject()->getWorldTransform() * Vec3(0.0f));

// задаём координаты осей joint
joint->setWorldAxis0(vec3(0.0f,0.0f,1.0f));
joint->setWorldAxis1(vec3(0.0f,1.0f,0.0f));

// задаём линейное демпфирование и жёсткость пружины
joint->setLinearDamping(200.0f);
joint->setLinearSpring(100.0f);

// задаём нижний и верхний пределы хода подвески [-1.0; 0.0]
joint->setLinearLimitFrom(-1.0f);
joint->setLinearLimitTo(0.0f);

// задаём целевую высоту подвески
joint->setLinearDistance(0.5f);

// задаём максимальную угловую скорость и момент силы
joint->setAngularVelocity(-20.0f);
joint->setAngularTorque(10.0f);

// задаём параметры колеса
joint->setWheelRadius(0.5f);
joint->setWheelMass(4.0f);
joint->setWheelThreshold(0.1f);

// задаём параметры трения шины
joint->setTangentFriction(4.0f);
joint->setBinormalFriction(5.0f);

// задаём количество итераций
joint->setNumIterations(8);

```

## float getCurrentSlipRatio () const

Возвращает текущее отношение вращения колеса к скорости относительно земли.
### Возвращаемое значение

Текущий коэффициент проскальзывания, в процентах. **0** означает, что скорости равны. При нажатии газа значение будет положительным. При нажатии тормоза значение будет отрицательным.

## void setCanBeUnderTerrain ( bool val )

Задаёт значение, указывающее, должен ли *Wheel Joint* использоваться под поверхностью террейна (езда в подземном паркинге или туннеле). Этот флаг обеспечивает корректное поведение joint под землёй, иначе *Wheel Joint* будет стремиться всплыть на поверхность террейна над ним.
### Аргументы

- *bool* **val** - true, если *Wheel Joint* должен использоваться под поверхностью террейна; иначе false.
