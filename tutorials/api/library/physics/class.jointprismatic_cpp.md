# Unigine::JointPrismatic Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Joint


Этот класс используется для создания [prismatic joints](../../../principles/physics/joints/index.md#prismatic).


### Пример


Следующий код иллюстрирует соединение двух [bodies](../../../api/library/physics/class.body_cpp.md) (b0 и b1) с помощью призматического соединения.


```cpp
include <UniginePhysics.h>

/* .. */

JointPrismaticPtr joint = JointPrismatic::create(b0, b1);

// задаём координаты оси соединения
joint->setWorldAxis(vec3(0.0f, 0.0f, 1.0f));

// задаём общие параметры ограничений соединения
joint->setLinearRestitution(0.4f);
joint->setAngularRestitution(0.4f);
joint->setLinearSoftness(0.4f);
joint->setAngularSoftness(0.4f);

// задаём линейное демпфирование
joint->setLinearDamping(4.0f);

// задаём линейные пределы [-1.5; 1.5]
joint->setLinearLimitFrom(-1.5f);
joint->setLinearLimitTo(1.5f);

// задаём количество итераций
joint->setNumIterations(16);

```

## static JointPrismaticPtr create ( const Ptr < Body > & body0 , const Ptr < Body > & body1 )

Конструктор. Создаёт призматическое соединение, соединяющее два заданных тела. Точка привязки размещается между центрами масс тел.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Body](../../../api/library/physics/class.body_cpp.md)> &* **body0** - Первое тело, соединяемое с помощью соединения.
- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Body](../../../api/library/physics/class.body_cpp.md)> &* **body1** - Второе тело, соединяемое с помощью соединения.

Конструктор. Создаёт призматическое соединение, соединяющее два заданных тела с указанными координатами оси и точкой привязки, размещённой в указанных координатах.
### Аргументы
