# Unigine::JointHinge Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Joint


Этот класс используется для создания [hinge joints](../../../principles/physics/joints/index.md#hinge).


### Пример


Следующий код иллюстрирует соединение двух [bodies](../../../api/library/physics/class.body_cpp.md) (b0 и b1) с помощью шарнирного соединения.


```cpp
include <UniginePhysics.h>

/* .. */

JointHingePtr joint = JointHinge::create(b0, b1);

// задаём координаты оси соединения
joint->setWorldAxis(vec3(1.0f, 0.0f, 0.0f));

// задаём общие параметры ограничений соединения
joint->setLinearRestitution(0.4f);
joint->setAngularRestitution(0.4f);
joint->setLinearSoftness(0.4f);
joint->setAngularSoftness(0.4f);

// задаём угловое демпфирование
joint->setAngularDamping(8.0f);

// задаём угловые пределы, в градусах [-20; 20]
joint->setAngularLimitFrom(-20.0f);
joint->setAngularLimitTo(20.0f);

// задаём коэффициент жёсткости пружины
joint->setAngularSpring(8.0f);

// задаём количество итераций
joint->setNumIterations(16);

```

## JointHinge Class

### Методы класса

## float getCurrentAngularVelocity () const

Возвращает текущую скорость мотора, т.е. разницу между угловыми скоростями двух тел, соединённых шарниром, относительно оси шарнира.
> **Примечание:** Корректное значение скорости возвращается только если оба тела имеют тип [BodyRigid](../../../api/library/physics/class.bodyrigid_cpp.md). В противном случае возвращается **0**.


### Возвращаемое значение

Текущая скорость мотора, в радианах в секунду.
## float getCurrentAngularAngle () const

Возвращает текущий угол между телами.
### Возвращаемое значение

Текущий угол в градусах.

## void setAngularSpring ( float spring )

Устанавливает новый коэффициент жёсткости угловой пружины. **0** означает, что пружина не присоединена.
### Аргументы

- *float* **spring** - Коэффициент жёсткости. Если указано отрицательное значение, вместо него будет использовано **0**. **0** отсоединяет пружину.

## float getAngularSpring () const

- *float* **to** - Верхний предельный угол поворота в градусах. Указанное значение будет ограничено диапазоном **[-180; 180]**.

## static JointHingePtr create ( const Ptr < Body > & body0 , const Ptr < Body > & body1 )

Конструктор. Создаёт шарнирное соединение, соединяющее два заданных тела. Точка привязки размещается между центрами масс тел.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Body](../../../api/library/physics/class.body_cpp.md)> &* **body0** - Первое тело, соединяемое с помощью соединения.
- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Body](../../../api/library/physics/class.body_cpp.md)> &* **body1** - Второе тело, соединяемое с помощью соединения.

## static JointHingePtr create ( const Ptr < Body > & body0 , const Ptr < Body > & body1 , const Math:: Vec3 & anchor , const Math:: vec3 & axis )

Конструктор. Создаёт шарнирное соединение, соединяющее два заданных тела с указанными координатами оси и точкой привязки, размещённой в указанных координатах.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Body](../../../api/library/physics/class.body_cpp.md)> &* **body0** - Первое тело, соединяемое с помощью соединения.
- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Body](../../../api/library/physics/class.body_cpp.md)> &* **body1** - Второе тело, соединяемое с помощью соединения.
- *const  Math::[Vec3](../../../api/library/math/class.vec3_cpp.md) &* **anchor** - Координаты точки привязки.
- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **axis** - Координаты оси.
