# Unigine::JointCylindrical Class (CPP)

**Header:** #include <UniginePhysics.h>

**Inherits from:** Joint


Этот класс используется для создания [cylindrical joints](../../../principles/physics/joints/index.md#cylindrical).


### Пример


Следующий код иллюстрирует соединение двух [bodies](../../../api/library/physics/class.body_cpp.md) (b0 и b1) с помощью цилиндрического шарнира.


```cpp
include <UniginePhysics.h>

/* .. */

JointCylindricalPtr joint = JointCylindrical::create(b0, b1);

// задаём координаты оси шарнира
joint->setWorldAxis(vec3(0.0f, 0.0f, 1.0f));

// задаём общие параметры ограничений шарнира
joint->setLinearRestitution(0.4f);
joint->setAngularRestitution(0.4f);
joint->setLinearSoftness(0.4f);
joint->setAngularSoftness(0.4f);

// задаём линейное и угловое демпфирование
joint->setLinearDamping(4.0f);
joint->setAngularDamping(2.0f);

// задаём линейные пределы [-1.5; 1.5]
joint->setLinearLimitFrom(-1.5f);
joint->setLinearLimitTo(1.5f);

// задаём количество итераций
joint->setNumIterations(16);

```
