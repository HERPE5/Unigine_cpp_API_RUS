# Unigine.Decal Class (CPP)

**Header:** #include <UnigineDecals.h>

**Inherits from:** Node


Класс Decal используется для базовых операций с [decals](../../../objects/decals/index.md). Для создания, изменения или получения информации о специальных типах декалей используйте [Decal-Related Classes](../../../api/library/decals/index.md).


## Decal Class

### Методы класса

---

## Ptr < Material > getMaterialInherit ( ) const

Наследует материал для декали (т.е. создаёт экземпляр материала). Изменения, внесённые в новый экземпляр материала, не влияют на исходный материал.
> **Notice:** Дочерний материал будет создан только один раз, все последующие вызовы этого метода будут возвращать первый созданный дочерний материал.


### Возвращаемое значение

Умный указатель на унаследованный материал.
## int isMaterialInherited ( ) const

Возвращает значение, указывающее, является ли заданный материал унаследованным (инстанцированным). Изменения, внесённые в экземпляр материала, не влияют на исходный материал.
### Возвращаемое значение

1, если материал успешно унаследован; в противном случае 0.

## void setViewportMask ( int mask )

Задаёт битовую маску для рендеринга декали во вьюпорт. Декаль рендерится, если её маска совпадает с маской вьюпорта камеры и маской вьюпорта материала декали.
### Аргументы

- *int* **mask** - Целочисленное значение, каждый бит которого используется для задания маски.

## int getViewportMask ( ) const

Возвращает текущую битовую маску для рендеринга во вьюпорт. Декаль рендерится, если её маска совпадает с маской вьюпорта камеры и маской вьюпорта материала декали.
### Возвращаемое значение

## void setIntersectionMask ( int mask )

Задаёт новую маску пересечения для декали. Эта маска может использоваться для вырезания областей, пересекаемых декалью, из [grass](../../../api/library/objects/class.objectgrass_cpp.md#setCutoutIntersectionMask_int_void), [mesh clutter](../../../api/library/objects/class.objectmeshclutter_cpp.md#setCutoutIntersectionMask_int_void) и [world clutter](../../../api/library/worlds/class.worldclutter_cpp.md#setCutoutIntersectionMask_int_void) (например, для удаления травы или леса с поверхности дорог, спроецированных с помощью декалей).
> **Notice:** Области будут вырезаны только если маски пересечения травы и объектов clutter совпадают с этой маской (хотя бы один бит).


### Аргументы

- *int* **mask** - Целое число, каждый бит которого является маской.

> **Notice:** Области будут вырезаны только если маски пересечения травы и объектов clutter совпадают с этой маской (хотя бы один бит).


### Возвращаемое значение

## void setCastBakedGlobalIllumination ( bool illumination )

Задаёт значение, указывающее, следует ли игнорировать декаль при запекании *Global Illumination* (карт освещения и пробников). Если включено, декаль ведёт себя так же, как поверхности с выбранным *Dynamic Lighting Mode*: они невидимы для *Voxel Probes* и *Environment Probes* и не запекаются в карты освещения.
### Аргументы

- *bool* **illumination** - true, чтобы игнорировать декаль при запекании *Global Illumination* (карт освещения и пробников); false, чтобы запекать декаль в карты освещения и пробники.

## bool isCastBakedGlobalIllumination ( ) const

Возвращает значение, указывающее, следует ли игнорировать декаль при запекании *Global Illumination* (карт освещения и пробников). Если включено, декаль ведёт себя так же, как поверхности с выбранным *Dynamic Lighting Mode*: они невидимы для *Voxel Probes* и *Environment Probes* и не запекаются в карты освещения.
### Возвращаемое значение

true, если декаль следует игнорировать при запекании *Global Illumination* (карт освещения и пробников); в противном случае false.
