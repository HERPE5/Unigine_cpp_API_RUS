## static WorldSwitcherPtr create ( )

Конструктор. Создаёт переключатель мира.
## void setMaxDistance ( float distance )

Задаёт максимальное расстояние видимости. Если камера находится дальше от узла, чем это максимальное расстояние, узел не виден. Значение по умолчанию — inf.
### Аргументы

- *float* **distance** — максимальное расстояние видимости в единицах.

## float getMaxDistance ( ) const

Возвращает текущее максимальное расстояние видимости. Если камера находится дальше от узла, чем это максимальное расстояние, узел не виден. Значение по умолчанию — inf.
### Возвращаемое значение

Максимальное расстояние видимости в единицах.
## void setMinDistance ( float distance )

Задаёт минимальное расстояние видимости. Если камера находится ближе к узлу, чем это минимальное расстояние, узел не виден. Значение по умолчанию — -inf.
### Аргументы

- *float* **distance** — минимальное расстояние видимости в единицах.

## float getMinDistance ( ) const

Возвращает текущее минимальное расстояние видимости. Если камера находится ближе к узлу, чем это минимальное расстояние, узел не виден. Значение по умолчанию — -inf.
### Возвращаемое значение

Минимальное расстояние видимости в единицах.
