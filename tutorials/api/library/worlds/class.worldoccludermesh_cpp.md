# Unigine.WorldOccluderMesh Class (CPP)

**Header:** #include <UnigineWorlds.h>

**Inherits from:** Node


Этот класс используется для создания окклюдера на основе произвольного меша, который отсекает поверхности, чьи границы в данный момент скрыты за ним. Если хотя бы часть границы поверхности объекта видна за окклюдером, поверхность не будет отсечена. Поверхности объектов за окклюдером не отправляются на GPU, что экономит производительность.


Сам окклюдер визуализируется на CPU и хранится в отдельном буфере.


#### Использование


Для повышения производительности окклюдеры следует использовать разумно. Следующие заметки помогут вам решить, использовать окклюдер или нет:

- Окклюдеры могут быть весьма эффективны в сложных сценах, где много объектов перекрывают друг друга и дорого стоят в рендере (у них много полигонов и/или тяжёлые шейдеры).
- Эффективное отсечение возможно, если объекты не слишком большие, так как если видна хотя бы часть их поверхности, она не может быть отсечена. Если объекты большие и имеют мало поверхностей, вероятно, дополнительная нагрузка на производительность от окклюдера не окупится.
- Если сцена заполнена плоскими объектами или камера смотрит на сцену сверху вниз (например, в авиасимуляторах), лучше вообще не использовать окклюдеры или отключить их.

### Методы класса

## static WorldOccluderMeshPtr create ( )

Конструктор. Создаёт новый меш-окклюдер мира со значением расстояния по умолчанию.
## static WorldOccluderMeshPtr create ( const char * name )

Конструктор. Создаёт новый меш-окклюдер мира из заданного файла `*.mesh`.
### Аргументы

- *const char ** **name** - Имя файла меша.

## void setDistance ( float distance )

Обновляет расстояние между камерой и ограничивающим боксом меша-окклюдера, при котором этот меш-окклюдер становится отключённым (не обрабатывается на CPU и, следовательно, не рендерится). По умолчанию используется значение inf.
### Аргументы

- *float* **distance** - Расстояние, в единицах.

## float getDistance ( ) const

Возвращает текущее расстояние между камерой и ограничивающим боксом меша-окклюдера, при котором этот меш-окклюдер становится отключённым (не обрабатывается на CPU и, следовательно, не рендерится). По умолчанию используется значение inf.
### Возвращаемое значение

Расстояние, в единицах.
## bool setMesh ( const Ptr < Mesh > & mesh )

Позволяет реинициализировать меш-окклюдер: функция копирует заданный меш в текущий меш, используемый для меша-окклюдера.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Mesh](../../../api/library/rendering/class.mesh_cpp.md)> &* **mesh** - Меш для копирования.

### Возвращаемое значение

true, если меш успешно скопирован; иначе false.
## bool getMesh ( Ptr < Mesh > & mesh ) const

Копирует текущий меш, на котором основан меш-окклюдер, в целевой меш.
### Аргументы

- *[Ptr](../../../api/library/common/class.ptr_cpp.md)<[Mesh](../../../api/library/rendering/class.mesh_cpp.md)> &* **mesh** - Целевой меш.

### Возвращаемое значение

true, если меш успешно скопирован; иначе false.
## bool setMeshPath ( const char * name , bool force_load = false )

Задаёт новый путь для меша, на котором основан меш-окклюдер, и принудительно загружает меш по новому пути для текущего меша-окклюдера.
### Аргументы

- *const char ** **name** - Новый путь для меша.
- *bool* **force_load** - true, чтобы немедленно загрузить меш по новому пути, false, чтобы обновить только путь меша

### Возвращаемое значение

true, если:
- Текущий путь меша совпадает с новым путём.
- Меш по новому пути был успешно загружен.
- Флаг принудительной загрузки установлен в 0.

В остальных случаях - false.
## const char * getMeshPath ( ) const

Возвращает путь меша, на котором основан меш-окклюдер.
### Возвращаемое значение

Путь меша.
## bool loadMesh ( const char * name )

Загружает меш для текущего меша-окклюдера из файла. Эта функция не изменяет имя меша.
### Аргументы

- *const char ** **name** - Имя файла меша.

### Возвращаемое значение

true, если меш успешно загружен; иначе false.
## bool saveMesh ( const char * name ) const

Сохраняет меш, на котором основан меш-окклюдер, в файл.
### Аргументы

- *const char ** **name** - Имя файла меша.

### Возвращаемое значение

true, если меш успешно сохранён; иначе false.
