# Unigine.WorldClutter Class (CPP)

**Header:** #include <UnigineWorlds.h>

**Inherits from:** Node


Класс [WorldClutter](../../../objects/worlds/world_clutter/index.md) позволяет случайным образом размещать [reference nodes](../../../api/library/nodes/class.nodereference_cpp.md) в соответствии с [mask](#setMaskImageName_cstr_int_void) и используя указанный [seed](#setSeed_int_void). Для каждого узла задаётся [probability of appearing](#setReferenceProbability_int_float_void). Все узлы в world clutter отображаются видимыми только в пределах указанного [distance](#setVisibleDistance_float_void), а затем [fade out](#setFadeDistance_float_void). Так же, как и [ObjectGrass](../../../api/library/objects/class.objectgrass_cpp.md), world clutter рендерится по ячейкам.


Использование WorldClutter даёт два преимущества:

- Экземпляры узлов, находящиеся вне пирамиды видимости, не хранятся в памяти, что обеспечивает гораздо более эффективное использование памяти.
- Менее загруженное пространственное дерево, что позволяет, например, ускорить обнаружение столкновений.


Можно использовать [a mask](#setCutoutIntersectionMask_int_void) для вырезания объектов clutter в областях пересечения с другими объектами и декалями (например, чтобы удалить растительность под домами или с поверхности дорог, спроецированных с помощью декалей).

Задаёт новое значение, указывающее, рендерятся ли объекты clutter внутри или снаружи областей, определённых [cutout intersection mask](#setCutoutIntersectionMask_int_void).

## void setCutoutIntersectionMask ( int mask )

Задаёт новую маску пересечения для вырезания. Эта маска позволяет вырезать объекты clutter в областях пересечения с другими объектами и декалями (например, может использоваться для удаления растительности под домами или с поверхности дорог, спроецированных с помощью декалей). Объекты clutter будут вырезаны объектами и декалями, у которых маска пересечения совпадает с этой (хотя бы в одном бите).
> **Notice:** Для задания масок пересечения можно использовать следующие методы:
> - **для декалей** используйте *[getIntersectionMask()](../../../api/library/decals/class.decal_cpp.md#getIntersectionMask_int)*
> - **для объектов** используйте *[getIntersectionMask()](../../../api/library/objects/class.object_cpp.md#getIntersectionMask_int_int)*


### Аргументы

- *int* **mask** - Маска - целое число, каждый бит которого является маской.

## bool saveStateReferences ( const Ptr < Stream > & stream ) const

Сохраняет состояние всех reference nodes из world clutter в указанный поток.
**Пример** использования методов saveStateReferences() и [restoreStateReferences()](#restoreStateReferences_Stream_int):


```cpp
// инициализируем узел и задаём его состояние
WorldClutterPtr worldClutter = WorldClutter::create();
worldClutter->setSizeX(500.0f);
worldClutter->setSizeY(500.0f);

// сохраняем состояние
BlobPtr blob_state = Blob::create();
worldClutter->saveStateReferences(blob_state);

// изменяем состояние
worldClutter->setSizeY(700.0f);

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем каретку в начало blob
worldClutter->restoreStateReferences(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель на поток.

### Возвращаемое значение

true, если состояния всех reference nodes из world clutter были успешно сохранены в указанный поток; иначе false.

```cpp
// инициализируем узел и задаём его состояние
WorldClutterPtr worldClutter = WorldClutter::create();

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем каретку в начало blob
worldClutter->restoreStateReferences(blob_state);

```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель на поток.

true, если состояния всех reference nodes из world clutter были успешно восстановлены из указанного потока; иначе false.
