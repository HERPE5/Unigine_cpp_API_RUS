# Unigine::WorldTransformPath Class (CPP)

**Header:** #include <UnigineWorlds.h>

**Inherits from:** Node


Этот класс используется для создания покадровой последовательности трансформаций из загруженного пути. Чтобы другие узлы перемещались вместе с этими трансформациями, их следует назначить дочерними для *WorldTransformPath*.

> **Notice:** *Путь (path)* - это сплайн, вдоль которого может перемещаться объект.

### Методы класса

---

## static WorldTransformPathPtr create ( const char * name , int unique = 0 )

Конструктор. Создаёт трансформер, определённый путём, в мировых координатах.
### Аргументы

- *const char ** **name** - Путь к файлу `*.path`.
- *int* **unique** - Флаг динамичности:

  - **0** - Если путь изменяется во время выполнения, пути, загруженные из того же файла, также изменятся.
  - **1** - Если путь изменяется во время выполнения, пути, загруженные из того же файла, не изменятся

## void setLoop ( int loop )

Задаёт значение, указывающее, должна ли зацикливаться трансформация, определённая путём.
### Аргументы

- *int* **loop** - 1, чтобы зациклить трансформацию, определённую путём; 0, чтобы воспроизвести её только один раз.

## int getLoop ( ) const

Возвращает значение, указывающее, зациклена ли трансформация, определённая путём.
### Возвращаемое значение

1, если трансформация зациклена; иначе 0.
## void setOrientation ( int orientation )

Задаёт значение, указывающее, должен ли объект ориентироваться вдоль пути. Если эта опция включена, при вычислении промежуточной трансформации между кадрами учитывается полная матрица трансформации (позиция, поворот и масштаб). Если отключена - используется только промежуточная позиция между кадрами, при этом масштаб и поворот объекта сохраняются.
### Аргументы

- *int* **orientation** - 1, чтобы ориентировать объект вдоль пути; 0, чтобы сохранить исходную ориентацию объекта. Значение по умолчанию - 1.

## int getOrientation ( ) const

Возвращает значение, указывающее, ориентирован ли объект вдоль пути. Если эта опция включена, при вычислении промежуточной трансформации между кадрами учитывается полная матрица трансформации (позиция, поворот и масштаб). Если отключена - используется только промежуточная позиция между кадрами, при этом масштаб и поворот объекта сохраняются.
### Возвращаемое значение

1, если объект ориентирован вдоль пути; 0, если сохраняется исходная ориентация объекта. Значение по умолчанию - 1.
## Ptr < Path > getPath ( ) const

Возвращает путь, которым определяется трансформация. С помощью этой функции можно редактировать текущий путь или изменять скорость либо трансформацию объекта, движущегося по пути.
### Возвращаемое значение

Экземпляр класса [*Path*](../../../api/library/common/class.path_cpp.md).
## void setPathName ( const char * name , int unique = 0 )

Перезагружает внутреннюю трансформацию пути.
### Аргументы

- *const char ** **name** - Имя пути.
- *int* **unique** - Флаг динамичности:

  - **0** - Если перезагруженный путь изменяется, пути, загруженные из того же файла, также изменятся.
  - **1** - Если перезагруженный путь изменяется, пути, загруженные из того же файла, не изменятся.

## const char * getPathName ( ) const

Возвращает имя пути, которым определяется трансформация.
### Возвращаемое значение

Имя пути.
## bool isPlaying ( ) const

Возвращает значение, указывающее, воспроизводится ли трансформация, определённая путём.
### Возвращаемое значение

true, если трансформация воспроизводится; иначе false.
## void setSpeed ( float speed )

Задаёт скорость воспроизведения трансформации, определённой путём.
### Аргументы

- *float* **speed** - Скорость воспроизведения трансформации. Отрицательное значение управляет обратным воспроизведением.

## float getSpeed ( ) const

Возвращает скорость воспроизведения трансформации, определённой путём.
### Возвращаемое значение

Скорость воспроизведения.
## bool isStopped ( ) const

Возвращает значение, указывающее, остановлена ли трансформация, определённая путём.
### Возвращаемое значение

true, если трансформация остановлена; иначе false.
## void setTime ( float time )

Задаёт время, с которого начинается воспроизведение трансформации, определённой путём. Если объект [oriented](#getOrientation_int) вдоль пути, его трансформация будет соответствовать трансформации пути в указанное время. В противном случае изменится только позиция объекта.
### Аргументы

- *float* **time** - Время воспроизведения.

## float getTime ( ) const

Возвращает время, с которого начинается воспроизведение трансформации, определённой путём.
### Возвращаемое значение

Время воспроизведения.
## void play ( )

Продолжает воспроизведение трансформации, определённой путём, если оно приостановлено, или запускает воспроизведение, если оно остановлено.
## void stop ( )

Останавливает воспроизведение трансформации, определённой путём. Эта функция сохраняет позицию воспроизведения, чтобы воспроизведение трансформации, определённой путём, можно было возобновить с той же точки.
## static int type ( )

Возвращает тип узла.
### Возвращаемое значение

Идентификатор типа [World](../../../api/library/engine/class.world_cpp.md).

## float getUpdateDistanceLimit ( ) const

Возвращает расстояние от камеры, в пределах которого объект должен обновляться.
### Возвращаемое значение

Расстояние от камеры, в пределах которого объект должен обновляться.
