# Unigine.SplineGraph Class (CPP)

**Header:** #include <UnigineSplineGraph.h>


Этот класс используется для управления вершинами и сегментами графов сплайнов. Система 3D-сплайнов UNIGINE имеет широкий спектр применений, в частности процедурную генерацию контента (реки, дороги, трубопроводы и т.д.).


![](../../../code/formats/spline.png)


Граф сплайна определяется набором точек **p0, p 1, ... p n** и набором сегментов (кубических сплайнов Безье), соединяющих некоторые или все эти точки.


Каждый **сегмент** определяется индексами начальной (**pSTART**) и конечной (**pEND**) точек и координатами касательных векторов в этих точках, которые определяют форму сегмента (**tSTART** и **tEND** соответственно).


Дополнительно для каждой точки сегмента хранятся координаты **вектора "up"**. Этот вектор можно указать для определения ориентации геометрии или объектов, которые могут быть [stretched or tiled along the segments](../../../api/library/worlds/class.worldsplinegraph_cpp.md#intro) графа сплайна. По умолчанию этот вектор параллелен оси **Z**. Вектор "up" не влияет на форму сегмента сплайна.


Можно получить интерполированное значение для любой точки, принадлежащей сегменту, это можно использовать для различных целей (например, для изменения профиля дороги). Интерполированный вектор "up" можно вычислить следующим образом (псевдокод):

```cpp
vec3 lerpUpVector(vec3 start_up, vec3 end_up, float t) const
{
	float angle = acos(dot(start_up, end_up)) * RAD2DEG;
	vec3 rotation_axis = cross(start_up, end_up);

	return rotateAxisAngle(rotation_axis, angle * t) * start_up;
}

```

## void removePoint ( int index , bool merge = 0 )

Удаляет точку с заданным индексом из графа сплайна.
### Аргументы

- *int* **index** - Индекс точки.
- *bool* **merge** - Флаг объединения. Если к точке присоединены два сегмента, true объединяет эти сегменты в один; false удаляет все сегменты, присоединённые к точке (по умолчанию).

## void splitPoint ( int index )

Разделяет точку с указанным индексом на **N** точек, где **N** - количество сегментов, присоединённых к точке. Количество точек в графе увеличится на **N-1**. Все новые точки будут присоединены к соответствующим сегментам.
### Аргументы

- *int* **index** - Индекс точки.

## void weldPoints ( Vector < int > & OUT_indices )

Объединяет все точки с заданными индексами в одну.
> **Notice:** Все общие сегменты между этими точками будут удалены. Все точки с заданными индексами удаляются из графа, кроме точки с минимальным значением индекса, к которой будут присоединены все сегменты. Итоговая точка будет перемещена в позицию первой точки в заданном массиве.


### Аргументы

- *[Vector](../../../api/library/containers/vector/class.vector_cpp.md)< int > &* **OUT_indices** - Массив, содержащий индексы точек для объединения в одну. > **Notice:** Этот выходной буфер должен быть заполнен движком в результате выполнения метода.

## void removeSegment ( int index , bool with_points = 0 )

Удаляет сегмент с заданным индексом.
### Аргументы

- *int* **index** - Индекс сегмента.
- *bool* **with_points** - true удаляет сегмент вместе с его начальной и конечной точками, false удаляет только сегмент. > **Notice:** Точки будут удалены только в том случае, если они не принадлежат другим сегментам. После удаления последний элемент вектора сегментов графа сплайна будет перемещён на позицию удалённого.
