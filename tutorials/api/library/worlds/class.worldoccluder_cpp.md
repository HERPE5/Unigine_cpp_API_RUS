# Unigine.WorldOccluder Class (CPP)

**Заголовочный файл:** #include <UnigineWorlds.h>

**Наследуется от:** Node


Этот класс используется для создания окклюдера в форме коробки, который отсекает поверхности, чьи границы в данный момент скрыты за ним. Если хотя бы часть границы поверхности объекта видна за окклюдером, поверхность не будет отсечена. Поверхности объектов за окклюдером не отправляются на GPU, что экономит производительность.


Сам окклюдер визуализируется на CPU и хранится в отдельном буфере.


> **Примечание:** Для отсечения поверхностей используются передние или задние грани окклюдера. Подробности см. [here](../../../objects/worlds/world_occluders/occluder_object/index.md).


#### Использование


Для повышения производительности окклюдеры следует использовать разумно. Следующие заметки помогут вам решить, использовать окклюдер или нет:

- Окклюдеры могут быть весьма эффективны в сложных сценах, где много объектов перекрывают друг друга и дорого стоят в рендере (у них много полигонов и/или тяжёлые шейдеры).
- Эффективное отсечение возможно, если объекты не слишком большие, так как если видна хотя бы часть их поверхности, она не может быть отсечена. Если объекты большие и имеют мало поверхностей, вероятно, дополнительная нагрузка на производительность от окклюдера не окупится.
- Если сцена заполнена плоскими объектами или камера смотрит на сцену сверху вниз (например, в авиасимуляторах), лучше вообще не использовать окклюдеры или отключить их.

## WorldOccluder Class

### Методы класса

---

## static WorldOccluderPtr create ( const Math:: vec3 & size )

Конструктор. Создаёт новый мировой окклюдер с заданными размерами.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **size** — размер нового окклюдера.

## void setBackFace ( bool face )

Обновляет значение, указывающее, используются ли задние грани коробки окклюдера вместо передних граней для отсечения поверхностей объектов. По умолчанию используются передние грани.
### Аргументы

- *bool* **face** — true для использования задних граней окклюдера для отсечения поверхностей; false для использования передних.

## bool isBackFace ( ) const

Возвращает значение, указывающее, используются ли задние грани коробки окклюдера вместо передних граней для отсечения поверхностей объектов. По умолчанию используются передние грани.
### Возвращаемое значение

true, если для отсечения поверхностей используются задние грани окклюдера; в противном случае — false.
## void setDistance ( float distance )

Обновляет расстояние между камерой и ограничивающим боксом окклюдера, при котором окклюдер становится отключённым (не обрабатывается на CPU и, следовательно, не рендерится). По умолчанию используется значение inf.
### Аргументы

- *float* **distance** — расстояние в единицах.

## float getDistance ( ) const

Возвращает текущее расстояние между камерой и ограничивающим боксом окклюдера, при котором окклюдер становится отключённым (не обрабатывается на CPU и, следовательно, не рендерится). По умолчанию используется значение inf.
### Возвращаемое значение

Расстояние в единицах.
## void setSize ( const Math:: vec3 & size )

Обновляет текущие размеры коробки мирового окклюдера.
### Аргументы

- *const  Math::[vec3](../../../api/library/math/class.vec3_cpp.md) &* **size** — размеры окклюдера.

## Math:: vec3 getSize ( ) const

Возвращает текущие размеры коробки мирового окклюдера.
### Возвращаемое значение

Размеры окклюдера.
## static int type ( )
