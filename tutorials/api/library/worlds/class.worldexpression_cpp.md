# Unigine.WorldExpression Class (CPP)

**Заголовочный файл:** #include <UnigineWorlds.h>

**Наследуется от:** Node


Этот класс используется для создания [world expression](../../../objects/worlds/world_expression/index.md), которое выполняет произвольное выражение. Выражение может выполняться для других узлов, если они назначены дочерними узлами WorldExpression. Дочерние узлы наследуют трансформации (если есть) мирового выражения и будут трансформироваться относительно опорной точки WorldExpression.

## WorldExpression Class

### Методы класса

---

## static WorldExpressionPtr create ( )

Конструктор. Создаёт произвольное выражение для выполнения.
## bool isCompiled ( ) const

Возвращает значение, указывающее, было ли скомпилировано данное выражение. Автоматически вызывается при загрузке мира или после использования *[setExpression()](#setExpression_cstr_int)*.
### Возвращаемое значение

true, если выражение было скомпилировано; в противном случае — false.
## bool setExpression ( const char * src )

Задаёт произвольное выражение для выполнения.
> **Примечание:** Выражение, передаваемое в качестве аргумента, должно быть обёрнуто фигурными скобками {}, так как они определяют область видимости мирового выражения.


### Аргументы

- *const char ** **src** — исполняемое выражение.

### Возвращаемое значение

true, если выражение установлено успешно; в противном случае — false.
## const char * getExpression ( ) const

Возвращает исполняемое выражение.
### Возвращаемое значение

Исполняемое выражение.
## bool isFunction ( const char * name , int num_args ) const

Возвращает значение, указывающее, содержит ли данное мировое выражение функцию с указанным именем и количеством аргументов.
### Аргументы

- *const char ** **name** — имя функции.
- *int* **num_args** — количество аргументов.

### Возвращаемое значение

true, если выражение существует; в противном случае — false.
## void setIFps ( float ifps )

Задаёт постоянную длительность кадра, используемую для выполнения выражения. Может использоваться для снижения частоты кадров ради повышения производительности. 0 означает, что выражение выполняется с той же частотой кадров, что и главное окно приложения.
### Аргументы

- *float* **ifps** — длительность кадра (величина, обратная FPS) в секундах (*1/FPS*). Если указано слишком малое значение, вместо него будет использовано 1E-6.

## float getIFps ( ) const

Возвращает текущую постоянную длительность кадра, используемую для выполнения выражения. 0 означает, что выражение выполняется с той же частотой кадров, что и главное окно приложения.
### Возвращаемое значение

Длительность кадра (величина, обратная FPS) в секундах (*1/FPS*).
## static int type ( )

Возвращает тип узла.
### Возвращаемое значение

Идентификатор типа [World](../../../api/library/engine/class.world_cpp.md).
## bool setExpressionName ( const char * name )

Загружает выражение из указанного файла.
### Аргументы

- *const char ** **name** — имя файла выражения.

### Возвращаемое значение

true, если выражение успешно загружено из указанного файла; в противном случае — false.
## const char * getExpressionName ( ) const

Возвращает имя файла выражения.
### Возвращаемое значение

Имя файла выражения.

## float getUpdateDistanceLimit ( ) const
