# Unigine::SoundReverb Class (CPP)

**Header:** #include <UnigineSounds.h>

**Inherits from:** Node


Этот класс используется для создания [reverberation zones](../../../objects/sounds/sound_reverb.md) для [sound sources](../../../api/library/sounds/class.soundsource_cpp.md) с [reverberation flag](../../../api/library/sounds/class.soundsource_cpp.md#setReverbMask_int_void). Такой звук будет иметь начальные [reflections](../../../objects/sounds/sound_reverb.md#reflections), [reverberation](../../../objects/sounds/sound_reverb.md#reverb) и [echo](../../../objects/sounds/sound_reverb.md#echo). Он также может иметь [modified pitch](../../../objects/sounds/sound_reverb.md#pitch).


Если звук проходит через две зоны реверберации (например, одну зону реверберации вокруг player'а и другую вокруг источника звука), слышимый эффект реверберации будет вдвое сильнее.


### Создание зоны реверберации


Чтобы создать зону реверберации, сначала создайте [sound source](../../../api/library/sounds/class.soundsource_cpp.md#create), который будет реверберировать, затем создайте экземпляр класса SoundReverb и укажите все необходимые настройки:


```cpp
// создаём источник звука
SoundSourcePtr sound = SoundSource::create("static_mono_00.oga");
sound->setWorldTransform(translate(Vec3(10.0f)));
// отключаем приглушение звука при перекрытии
sound->setOcclusion(0);
// задаём расстояние, на котором звук становится чётким
sound->setMinDistance(1.0f);
// задаём расстояние, на котором звук выходит за пределы слышимости
sound->setMaxDistance(10.0f);
// задаём громкость, приводящую к затуханию в 6 дБ
sound->setGain(0.5f);
// зацикливаем звук
sound->setLoop(1);
// запускаем воспроизведение звукового сэмпла
sound->play();

// создаём зону реверберации
SoundReverbPtr reverb = SoundReverb::create(vec3(10.0f));
// задаём трансформацию
reverb->setWorldTransform(translate(Vec3(10.0f)));
// задаём размер порога, определяющий расстояние перехода от частичной к полной слышимости реверберации
reverb->setThreshold(vec3(1.0f, 1.0f, 1.0f));
// задаём остальные настройки зоны реверберации
reverb->setDensity(0.2f);
reverb->setDiffusion(0.5f);
reverb->setDecayTime(1.0f);
reverb->setReflectionGain(2.0f);
reverb->setLateReverbGain(8.0f);


```


Чтобы обновить настройки созданной зоны реверберации, можно просто вызвать соответствующие методы при необходимости.

## void setReverbMask ( int mask )

Задаёт новую битовую маску, определяющую, какие [reverberation zones](../../../api/library/sounds/class.soundreverb_cpp.md) могут быть услышаны. Чтобы звук реверберировал, хотя бы один бит этой маски должен совпадать с [player's reverberation mask](../../../api/library/players/class.player_cpp.md#setReverbMask_int_void). При этом [reverb mask of the sound source](../../../api/library/sounds/class.soundsource_cpp.md#setReverbMask_int_void) также должна совпадать с маской player'а (но не обязательно в том же бите, что и эта маска).
### Аргументы

- *int* **mask** - Целое число, каждый бит которого является маской для реверберирующих источников звука и зон реверберации.

## int getReverbMask () const

Возвращает текущую битовую маску, определяющую, какие [reverberation zones](../../../api/library/sounds/class.soundreverb_cpp.md) могут быть услышаны. Чтобы звук реверберировал, хотя бы один бит этой маски должен совпадать с [player's reverberation mask](../../../api/library/players/class.player_cpp.md#setReverbMask_int_void). При этом [reverb mask of the sound source](../../../api/library/sounds/class.soundsource_cpp.md#setReverbMask_int_void) также должна совпадать с маской player'а (но не обязательно в том же бите, что и эта маска).
### Возвращаемое значение

Текущее целое число, каждый бит которого является маской для реверберирующих источников звука и зон реверберации.
