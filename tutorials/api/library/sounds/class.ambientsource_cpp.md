# Unigine::AmbientSource Class (CPP)

**Header:** #include <UnigineSounds.h>


Этот класс используется для создания ненаправленного окружающего фонового звука.


### Создание источника окружающего звука


Чтобы создать источник окружающего звука, создайте экземпляр класса AmbientSource и укажите все необходимые настройки:


> **Notice:** Для воспроизведения источника окружающего звука всегда требуется [player](../../../api/library/players/index.md). Если источник окружающего звука должен воспроизводиться, когда не загружены ни мир, ни редактор, player, а также источник звука (см. код ниже), должны быть созданы в методе [*SystemLogic.init()*](../../../api/library/common/logic/class.systemlogic_cpp.md#init_int); в противном случае звук не будет слышен.


```cpp
// создаём player, чтобы источник окружающего звука воспроизводился
PlayerSpectatorPtr player = PlayerSpectator::create();
player->setPosition(Vec3(0.0f, -3.401f, 1.5f));
player->setViewDirection(vec3(0.0f, 1.0f, -0.4f));
Game::setPlayer(player);

// создаём источник окружающего звука
AmbientSourcePtr sound = AmbientSource::create("sound.mp3");
// задаём необходимые настройки звука
sound->setGain(0.5f);
sound->setPitch(1.0f);
sound->setLoop(1);
sound->play();


```


### Обновление существующего источника окружающего звука


Чтобы обновить настройки источника окружающего звука, можно просто вызвать соответствующие методы:


```cpp
// изменяем файл сэмпла воспроизводимого источника звука
if ((sound->isPlaying()) && (Input::isKeyDown(Input::KEY::KEY_C)))
{
	// увеличиваем высоту тона
	sound->setPitch(2.0f);
	// уменьшаем громкость
	sound->setGain(0.2f);
}


```


Поскольку звук имеет собственный поток, обновляющийся с частотой 30 FPS, изменения не применяются немедленно. Однако можно принудительно выполнить обновление с помощью метода *[renderWorld()](../../../api/library/engine/class.sound_cpp.md#renderWorld_int_void)*.


События звука, такие как *[play()](#play_void)* или *[stop()](#stop_void)*, также обновляются не сразу. Поэтому, когда требуется выполнить операции, требующие остановки воспроизведения (например, обновление времени, с которого должен воспроизводиться сэмпл, или имени сэмпла), необходимо принудительно обновить поток звука после остановки воспроизведения:


```cpp
// проверяем, воспроизводится ли звуковой сэмпл
if (sound->isPlaying())
{
	// останавливаем воспроизведение сэмпла
	sound->stop();
	// принудительно обновляем поток звука
	Sound::renderWorld(1);
	// обновляем время
	sound->setTime(0.0f);
	// воспроизводим сэмпл
	sound->play();
}


```

## AmbientSource Class

### Методы класса

## bool isStopped () const

Возвращает текущее значение, указывающее, остановлено ли воспроизведение.
### Возвращаемое значение

**true**, если сэмпл остановлен; иначе **false**.
## bool isPlaying () const

Возвращает текущее значение, указывающее, воспроизводится ли сэмпл.
### Возвращаемое значение

**true**, если сэмпл воспроизводится; иначе **false**.
## void setTime ( float time )

Задаёт новое время от начала сэмпла. Нельзя задать время, если сэмпл уже воспроизводится: [stop](#stop_void) воспроизведение, задайте время и [resume](#play_void) воспроизведение.
### Аргументы

- *float* **time** - Время от начала сэмпла, в секундах.

## float getTime () const

Возвращает текущее время от начала сэмпла. Нельзя задать время, если сэмпл уже воспроизводится: [stop](#stop_void) воспроизведение, задайте время и [resume](#play_void) воспроизведение.
### Возвращаемое значение

Текущее время от начала сэмпла, в секундах.
## void setSourceMask ( int mask )

Задаёт новую битовую маску, определяющую, к каким [sound channels](../../../api/library/engine/class.sound_cpp.md#setSourceVolume_int_float_void) относится источник. Чтобы источник звука был слышен, его маска должна совпадать с [player's sound mask](../../../api/library/players/class.player_cpp.md#setSourceMask_int_void) хотя бы в одном бите.
### Аргументы

- *int* **mask** - Целое число, каждый бит которого задаёт звуковой канал.

## int getSourceMask () const

Возвращает текущую битовую маску, определяющую, к каким [sound channels](../../../api/library/engine/class.sound_cpp.md#setSourceVolume_int_float_void) относится источник. Чтобы источник звука был слышен, его маска должна совпадать с [player's sound mask](../../../api/library/players/class.player_cpp.md#setSourceMask_int_void) хотя бы в одном бите.
### Возвращаемое значение

Текущее целое число, каждый бит которого задаёт звуковой канал.
## void setSampleName ( const char * name )

Задаёт новый звуковой файл для окружающего звука.
> **Notice:** Чтобы изменить звуковой файл текущего воспроизводимого окружающего звука, [stop](#stop_void) воспроизведение, задайте имя сэмпла, а затем [resume](#play_void) воспроизведение.


```cpp
if (sound->isPlaying())
{
	// останавливаем воспроизводимый звук
	sound->stop();
	// принудительно обновляем поток звука
	Sound::renderWorld(1);
	// задаём новый файл сэмпла для воспроизведения
	sound->setSampleName("stream_stereo_01.oga");
	// воспроизводим звук
	sound->play();
}


```


### Аргументы

- *const char ** **name** - Путь к звуковому файлу.

## const char * getSampleName () const

Возвращает текущий звуковой файл для окружающего звука.
> **Notice:** Чтобы изменить звуковой файл текущего воспроизводимого окружающего звука, [stop](#stop_void) воспроизведение, задайте имя сэмпла, а затем [resume](#play_void) воспроизведение.


```cpp
if (sound->isPlaying())
{
	// останавливаем воспроизводимый звук
	sound->stop();
	// принудительно обновляем поток звука
	Sound::renderWorld(1);
	// задаём новый файл сэмпла для воспроизведения
	sound->setSampleName("stream_stereo_01.oga");
	// воспроизводим звук
	sound->play();
}


```


### Возвращаемое значение

Текущий путь к звуковому файлу.
## void setPitch ( float pitch )

Задаёт новую высоту тона звука.
### Аргументы

- *float* **pitch** - Коэффициент, на который будет умножена текущая высота тона.

## float getPitch () const

Возвращает текущую высоту тона звука.
### Возвращаемое значение

Текущий коэффициент, на который будет умножена текущая высота тона.
## void setLoop ( int loop )

Задаёт новое значение, указывающее, зациклен ли сэмпл.
### Аргументы

- *int* **loop** - Положительное число, если сэмпл зациклен; иначе **0**.

## int getLoop () const

Возвращает текущее значение, указывающее, зациклен ли сэмпл.
### Возвращаемое значение

Текущее положительное число, если сэмпл зациклен; иначе **0**.
## float getLength () const

Возвращает текущую общую длину звукового сэмпла.
### Возвращаемое значение

Текущая длина сэмпла в секундах.
## void setGain ( float gain )

Задаёт новую громкость звука.
### Аргументы

- *float* **gain** - Громкость в диапазоне [0, 1], где **0** означает отключение звука, **1** - максимальную громкость.

## float getGain () const

Возвращает текущую громкость звука.
### Возвращаемое значение

Текущая громкость в диапазоне [0, 1], где **0** означает отключение звука, **1** - максимальную громкость.

## static AmbientSourcePtr create ( const char * name , int stream = 0 )

Конструктор. Создаёт новый источник окружающего звука с использованием заданного звукового файла.
### Аргументы

- *const char ** **name** - Путь к звуковому файлу.
- *int* **stream** - Положительное значение для создания потокового источника, **0** для создания статического источника. Если флаг установлен, сэмпл не будет полностью загружен в память. Вместо этого его последовательные части будут считываться одна за другой в буфер памяти.

## void play ( )

Запускает воспроизведение сэмпла.
## void stop ( )

Останавливает воспроизведение. Эта функция сохраняет позицию воспроизведения, чтобы воспроизведение файла можно было возобновить с той же точки.
> **Notice:** Воспроизведение не остановится немедленно, так как поток звука обновляется с частотой 30 FPS. Поэтому, когда требуется выполнить операции, требующие остановки воспроизведения (например, обновление времени, с которого должен воспроизводиться сэмпл), необходимо [force update](../../../api/library/engine/class.sound_cpp.md#renderWorld_int_void) поток звука после остановки воспроизведения.
