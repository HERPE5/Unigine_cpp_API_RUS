# Unigine::SoundSource Class (CPP)

**Header:** #include <UnigineSounds.h>

**Inherits from:** Node


Этот класс используется для создания направленных [sound sources](../../../objects/sounds/sound_source.md). Звук источника линейно затухает в указанном диапазоне (см. [*getMinDistance()*](#getMinDistance_float) и [*getMaxDistance()*](#getMaxDistance_float)). Если заданы внутренний и внешний звуковые конусы, они также вносят свой вклад в коэффициент затухания (см. функции [*getConeInnerAngle()*](#getConeInnerAngle_float) и [*getConeOuterAngle()*](#getConeOuterAngle_float)).

> **Notice:** Затухание доступно только для моно-источников звука. Если источник стереофонический, он не будет затухать с расстоянием.


Источники звука автоматически обрабатываются менеджером звука. Когда источник звука находится в пределах [audible range](#getMaxDistance_float), он загружается в память (полный сэмпл или его фрагмент, в зависимости от того, является ли источник [static or streamed](#static_vs_stream)). Когда он выходит за пределы слышимого диапазона, звуковой файл автоматически удаляется из памяти. Статические источники звука инстансируются; потоковые - нет.
 Если вы всё же хотите управлять источником звука вручную, вы можете проверить, остановлено ли его [playing](#isPlaying_int), и после этого удалить его.


Также нет ограничения на количество источников звука в мире, так как рендерятся только те, что в данный момент слышимы. В худшем случае, когда количество одновременно слышимых источников звука превышает возможности аппаратного обеспечения, некоторые из них не будут воспроизведены.


### Создание источника звука


Чтобы создать источник звука, создайте экземпляр класса SoundSource и укажите все необходимые настройки:


```cpp
// создаём новый источник звука, используя заданный звуковой файл сэмпла
SoundSourcePtr sound = SoundSource::create("sound.mp3");

// отключаем приглушение звука при перекрытии
sound->setOcclusion(0);
// задаём расстояние, на котором звук становится чётким
sound->setMinDistance(10.0f);
// задаём расстояние, на котором звук выходит за пределы слышимости
sound->setMaxDistance(100.0f);
// задаём громкость, приводящую к затуханию в 6 дБ
sound->setGain(0.5f);
// зацикливаем звук
sound->setLoop(1);
// запускаем воспроизведение звукового сэмпла
sound->play();


```


### Обновление существующего источника звука


Чтобы обновить настройки источника звука, можно вызвать соответствующие методы:


```cpp
// изменяем файл сэмпла воспроизводимого источника звука
if ((sound->isPlaying()) && (Input::isKeyDown(Input::KEY::KEY_C)))
{
	// задаём новый файл сэмпла
	sound->setSampleName("sound_1.mp3");
	// уменьшаем громкость
	sound->setGain(0.2f);
}


```


Поскольку звук имеет собственный поток, обновляющийся с частотой 30 FPS, изменения не применяются немедленно. Однако можно принудительно выполнить обновление с помощью метода *[renderWorld()](../../../api/library/engine/class.sound_cpp.md#renderWorld_int_void)*.


События звука, такие как *[play()](#play_void)* или *[stop()](#stop_void)*, также обновляются не сразу. Поэтому, когда требуется выполнить операции, требующие остановки воспроизведения (например, обновление времени, с которого должен воспроизводиться сэмпл), необходимо принудительно обновить поток звука после остановки воспроизведения:


```cpp
// проверяем, воспроизводится ли звуковой сэмпл
if (sound->isPlaying())
{
	// останавливаем воспроизведение сэмпла
	sound->stop();
	// принудительно обновляем поток звука
	Sound::renderWorld(1);
	// обновляем время
	sound->setTime(0.0f);
	// воспроизводим сэмпл
	sound->play();
}


```

### Возвращаемое значение

Текущее положительное число, чтобы звук приглушался перекрытием; иначе **0**.
## void setOcclusionMask ( int mask )

Задаёт новую битовую маску, определяющую, какие объекты перекрывают источник звука. Чтобы звук был перекрыт поверхностью объекта, хотя бы один бит этой маски должен совпадать с [occlusion mask of object's surface](../../../api/library/objects/class.object_cpp.md#setSoundOcclusionMask_int_int_void). Каждая поверхность имеет собственное [occlusion value](../../../api/library/objects/class.object_cpp.md#setSoundOcclusion_float_int_void), определяющее, насколько сильно она влияет на звуки в случае перекрытия.
> **Notice:** [Sound occlusion](../../../api/library/engine/class.sound_cpp.md#setSourceOcclusion_int_void) должно быть включено.


### Аргументы

- *int* **mask** - Целое число, каждый бит которого является маской перекрытия источника звука.

## int getOcclusionMask () const

Возвращает текущую битовую маску, определяющую, какие объекты перекрывают источник звука. Чтобы звук был перекрыт поверхностью объекта, хотя бы один бит этой маски должен совпадать с [occlusion mask of object's surface](../../../api/library/objects/class.object_cpp.md#setSoundOcclusionMask_int_int_void). Каждая поверхность имеет собственное [occlusion value](../../../api/library/objects/class.object_cpp.md#setSoundOcclusion_float_int_void), определяющее, насколько сильно она влияет на звуки в случае перекрытия.
> **Notice:** [Sound occlusion](../../../api/library/engine/class.sound_cpp.md#setSourceOcclusion_int_void) должно быть включено.


### Возвращаемое значение

Текущее целое число, каждый бит которого является маской перекрытия источника звука.

## static SoundSourcePtr create ( const char * name , int stream = 0 )

Конструктор. Создаёт новый источник звука мира с использованием заданного звукового файла сэмпла.
### Аргументы

- *const char ** **name** - Путь к звуковому файлу сэмпла.
- *int* **stream** - Положительное значение для создания потокового источника, **0** для создания статического источника. Если флаг установлен, сэмпл не будет полностью загружен в память. Вместо этого его последовательные части будут считываться одна за другой в буфер памяти.

## void play ( )

Запускает воспроизведение сэмпла.
## void stop ( )

Останавливает воспроизведение. Эта функция не сбрасывает позицию воспроизведения, поэтому воспроизведение файла можно [resumed](#play_void) с той же точки.
> **Notice:** Воспроизведение не остановится немедленно, так как поток звука обновляется с частотой 30 FPS. Поэтому, когда требуется выполнить операции, требующие остановки воспроизведения (например, обновление времени, с которого должен воспроизводиться сэмпл), необходимо [force update](../../../api/library/engine/class.sound_cpp.md#renderWorld_int_void) поток звука после остановки воспроизведения.
