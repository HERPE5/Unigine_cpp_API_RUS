# Unigine::WidgetEditLine Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт редактируемое однострочное [text field](../../../code/gui/ui/ui_widgets.md#editline), содержащее текстовую строку.


Объект этого класса выглядит следующим образом:

### Методы класса

## void setText ( const char * text )

Устанавливает новый текст для текстового поля.
### Аргументы

- *const char ** **text** - Содержимое текстового поля.

## const char * getText () const

Возвращает текущий текст текстового поля.
### Возвращаемое значение

Текущее содержимое текстового поля.
## void setSelection ( int selection )

Устанавливает новую позицию, с которой начинается выделение.
### Аргументы

### Возвращаемое значение

Текущая позиция, с которой начинается выделение.
## void setCursor ( int cursor )

Устанавливает новую позицию курсора в текстовом поле.
### Аргументы

- *int* **cursor** - Позиция курсора. Устанавливаемое значение ограничивается диапазоном от 0 до вместимости текстового поля.

## int getCursor () const

Возвращает текущую позицию курсора в текстовом поле.
### Возвращаемое значение

Текущая позиция курсора. Устанавливаемое значение ограничивается диапазоном от 0 до вместимости текстового поля.
## void setCapacity ( int capacity )

Устанавливает новую максимальную длину строки, вводимой в текстовое поле.
### Аргументы

- *int* **capacity** - Максимальное количество символов. Значение по умолчанию — 1024.

## int getCapacity () const

Возвращает текущую максимальную длину строки, вводимой в текстовое поле.
### Возвращаемое значение

Текущее максимальное количество символов. Значение по умолчанию — 1024.
## void setBackground ( int background )

Устанавливает новое значение, указывающее, отрисовывается ли фоновая текстура для текстового поля.
### Аргументы

- *int* **background** - Положительное число, если фоновая текстура отрисовывается; иначе 0. Значение по умолчанию — 1.

## int getBackground () const

Возвращает текущее значение, указывающее, отрисовывается ли фоновая текстура для текстового поля.
### Возвращаемое значение

Текущее положительное число, если фоновая текстура отрисовывается; иначе 0. Значение по умолчанию — 1.
## void setValidator ( int validator )

### Аргументы

- *int* **validator** - Валидатор, одно из значений перечисления Gui:: с префиксом [VALIDATOR_*](../../../api/library/gui/class.gui_cpp.md#VALIDATOR_ANY).

## int getValidator () const

### Возвращаемое значение

Текущий валидатор, одно из значений перечисления Gui:: с префиксом [VALIDATOR_*](../../../api/library/gui/class.gui_cpp.md#VALIDATOR_ANY).
## void setPassword ( )

Устанавливает новое значение, указывающее, является ли текстовое поле полем пароля (все вводимые символы отображаются как точки).
### Аргументы

- **password** - Виджет является полем пароля

## isPassword () const

Возвращает текущее значение, указывающее, является ли текстовое поле полем пароля (все вводимые символы отображаются как точки).
### Возвращаемое значение

Текущее значение: является ли виджет полем пароля
## void setEditable ( bool editable )

Устанавливает новое значение, указывающее, можно ли редактировать содержимое текстового поля.
### Аргументы

- *bool* **editable** - Установите **true**, чтобы разрешить редактирование содержимого текстового поля; **false** — чтобы запретить.

## bool isEditable () const

Возвращает текущее значение, указывающее, можно ли редактировать содержимое текстового поля.
### Возвращаемое значение

**true**, если редактирование содержимого текстового поля разрешено; иначе **false**.
