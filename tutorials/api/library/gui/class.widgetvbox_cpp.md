# Unigine::WidgetVBox Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт контейнер [single vertical column](../../../code/gui/ui/ui_containers.md#vbox).

### Методы класса

## void setBorder ( bool border )

Задаёт новое значение, указывающее, отображается ли граница.
### Аргументы

- *bool* **border** - Значение **true** включает отображение границы; **false** - отключает его.

**true**, если граница отображается; иначе **false**.

## void setStencil ( int stencil )

Задаёт новое значение, указывающее, обрезает ли виджет свои дочерние элементы по установленным [bounds](../../../api/library/gui/class.widget_cpp.md#setWidth_int_void). Всё, что выходит за их пределы, не отображается. Эта опция работает только если у дочерних элементов установлен флаг [ALIGN_OVERLAP](../../../api/library/gui/class.gui_cpp.md#ALIGN_OVERLAP) (иначе они расширят границы контейнера, и обрезки не будет).
### Аргументы

- *int* **stencil** - **1**, если обрезка включена; иначе **0**.

## int getStencil () const

Возвращает текущее значение, указывающее, обрезает ли виджет свои дочерние элементы по установленным [bounds](../../../api/library/gui/class.widget_cpp.md#setWidth_int_void). Всё, что выходит за их пределы, не отображается. Эта опция работает только если у дочерних элементов установлен флаг [ALIGN_OVERLAP](../../../api/library/gui/class.gui_cpp.md#ALIGN_OVERLAP) (иначе они расширят границы контейнера, и обрезки не будет).
### Возвращаемое значение

Текущее значение: **1**, если обрезка включена; иначе **0**.

## static WidgetVBoxPtr create ( const Ptr < Gui > & gui , int x = 0 , int y = 0 )

Конструктор. Создаёт вертикальный контейнер с заданными параметрами и добавляет его в указанный GUI.

- *int* **x** - Горизонтальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.

- *int* **y** - Вертикальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.

## void setPadding ( int l , int r , int t , int b )

Задаёт отступы виджета со всех сторон. Отступ освобождает область вокруг содержимого виджета (внутри него).
### Аргументы

- *int* **l** - Отступ слева в пикселях.
- *int* **r** - Отступ справа в пикселях.
- *int* **t** - Отступ сверху в пикселях.
- *int* **b** - Отступ снизу в пикселях.

## void setSpace ( int x , int y )

Задаёт расстояние между виджетами в контейнере, а также между ними и границей контейнера.
### Аргументы

- *int* **x** - Горизонтальное расстояние. Если указано отрицательное значение, вместо него будет использовано 0.
- *int* **y** - Вертикальное расстояние. Если указано отрицательное значение, вместо него будет использовано 0.
