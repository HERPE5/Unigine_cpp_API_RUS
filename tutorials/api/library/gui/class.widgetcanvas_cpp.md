# Unigine::WidgetCanvas Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс позволяет создать canvas, на котором можно отрисовывать линии, полигоны и текст. Он выполняет отсечение видимой области во время отрисовки.


Объект этого класса выглядит следующим образом:


![Canvas widget with polygons](../../../code/gui/ui/widgets/canvas.png)


> **Notice:** Полигон может быть треугольником, прямоугольником, пятиугольником и т.д.: он может иметь любое количество сторон. Например, если добавить 4 точки в canvas через функцию *[addPolygonPoint()](#addPolygonPoint_int_vec3_int)*, будет отрисован 4-сторонний полигон.


По умолчанию все полигоны двусторонние, то есть обе стороны полигона видны одновременно. Если нужно сделать видимой только одну из них, можно установить [set the 2-sided flag](#setPolygonTwoSided_int_int_void) в 0.


Для повышения производительности можно использовать индексы точек вместо координат точек. Подробнее см. следующие функции:


- *[addLineIndex()](#addLineIndex_int_int_int)*
- *[addPolygonIndex()](#addPolygonIndex_int_int_int)*


> **Notice:** - Чтобы сбросить счётчик ID при перерисовке canvas-виджета, не забудьте вызвать метод [*clear()*](#clear_void).
> - Canvas-виджет не выполняет проверку глубины. Поэтому проверку глубины нужно реализовывать самостоятельно, используя функции, задающие порядок отрисовки линий и полигонов.
