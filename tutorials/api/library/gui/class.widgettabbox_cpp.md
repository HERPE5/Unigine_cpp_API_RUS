# Unigine::WidgetTabBox Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт [box with several tabs](../../../code/gui/ui/ui_containers.md#tabbox).

![](../../../code/gui/ui/widgets/tabbox.png)


## WidgetTabBox Class

### Методы класса

## void setCurrentTab ( int tab )

Задаёт новый номер вкладки.
### Аргументы

- *int* **tab** - Номер вкладки в диапазоне от 0 до общего количества вкладок.

## int getNumTabs () const

## static WidgetTabBoxPtr create ( const Ptr < Gui > & gui , int x = 0 , int y = 0 )

Конструктор. Создаёт контейнер с вкладками с заданными параметрами и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать новый контейнер.
- *int* **x** - Горизонтальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.

## static WidgetTabBoxPtr create ( int x = 0 , int y = 0 )

Конструктор. Создаёт контейнер с вкладками с заданными параметрами и добавляет его в GUI движка.
### Аргументы

- *int* **x** - Горизонтальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.

## void setPadding ( int l , int r , int t , int b )

Задаёт отступы виджета со всех сторон. Отступ освобождает область вокруг содержимого виджета (внутри него).
### Аргументы

- *int* **l** - Отступ слева в пикселях.
- *int* **r** - Отступ справа в пикселях.
- *int* **t** - Отступ сверху в пикселях.
- *int* **b** - Отступ снизу в пикселях.

## void setSpace ( int x , int y )

Задаёт расстояние между виджетами в контейнере, а также между ними и границей контейнера.
### Аргументы

- *int* **x** - Горизонтальное расстояние. Если задано отрицательное значение, вместо него будет использовано 0.
- *int* **y** - Вертикальное расстояние. Если задано отрицательное значение, вместо него будет использовано 0.

## void setTabData ( int num , const char * str )

Задаёт данные для указанной вкладки. Эти данные можно использовать в качестве текстового идентификатора элемента (вместо использования номера элемента).
### Аргументы

- *int* **num** - Номер вкладки в диапазоне от 0 до общего количества вкладок.
- *const char ** **str** - Устанавливаемые данные.

## const char * getTabData ( int num ) const

Возвращает данные указанной вкладки. Эти данные можно использовать в качестве текстового идентификатора элемента (вместо использования номера элемента).
### Аргументы

- *int* **num** - Номер вкладки в диапазоне от 0 до общего количества вкладок.

### Возвращаемое значение

Данные вкладки.
## void setTabHidden ( int num , bool hidden )

Задаёт значение, указывающее, что указанная вкладка не должна отображаться. По умолчанию все вкладки виджета видимы.
### Аргументы

- *int* **num** - Номер вкладки в диапазоне от 0 до общего количества вкладок.
- *bool* **hidden** - true for the tab to be invisible; otherwise, false.

## bool isTabHidden ( int num ) const

Возвращает значение, указывающее, является ли указанная вкладка невидимой.
### Аргументы

- *int* **num** - Номер вкладки в диапазоне от 0 до общего количества вкладок.

### Возвращаемое значение

true, если указанная вкладка невидима; иначе false.

## int addTab ( const char * str , int texture = -1 )

Добавляет новую вкладку с заданным заголовком и иконкой в контейнер.
### Аргументы

- *const char ** **str** - Заголовок вкладки.
- *int* **texture** - Zero-based ID of the icon (icon number in the atlas column). -1 means that a tab has no icon.

### Возвращаемое значение

Номер добавленной вкладки.
