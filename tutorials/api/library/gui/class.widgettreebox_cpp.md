# Unigine::WidgetTreeBox Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт [box with a tree-like hierarchy](../../../code/gui/ui/ui_widgets.md#treebox). Например:

```cpp
int init() {

Gui gui = engine.getGui();

WidgetTreeBox tree = new WidgetTreeBox(gui);

tree.addItem("1st item");  // Добавление элементов в дерево.
tree.addItem("2nd item");
tree.addItem("3rd item");
tree.addItem("4th item");

tree.addItemChild(0,1);   // Делает 2-й элемент дочерним для 1-го.
tree.setItemFolded(0,1);  // Сворачивает дочерние элементы 1-го элемента.

WidgetWindow window = new WidgetWindow(gui);  // Создание окна.
gui.addChild(window,GUI_ALIGN_CENTER);

window.addChild(tree,GUI_ALIGN_CENTER); // Отображение дерева в окне.

return 1;
}

```
