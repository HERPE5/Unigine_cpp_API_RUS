# Unigine::WidgetIcon Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт переключаемую [icon](../../../code/gui/ui/ui_widgets.md#icon) с двумя состояниями — нажата или нет.

## static WidgetIconPtr create ( const Ptr < Gui > & gui , const char * str = 0 , int width = 0 , int height = 0 )

Конструктор. Создаёт иконку указанного размера с использованием указанной текстуры и добавляет её в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать новая иконка.
- *const char ** **str** - Путь к файлу текстуры.
- *int* **width** - Ширина иконки.
- *int* **height** - Высота иконки.

## static WidgetIconPtr create ( const char * str = 0 , int width = 0 , int height = 0 )

Конструктор. Создаёт иконку указанного размера с использованием указанной текстуры и добавляет её в GUI движка.
### Аргументы

- *const char ** **str** - Путь к файлу текстуры.
- *int* **width** - Ширина иконки.
- *int* **height** - Высота иконки.

## void setText ( const char * text )

Устанавливает плавающий текст над иконкой.
### Аргументы

- *const char ** **text** - Плавающий текст.

## const char * getText ( ) const

Возвращает текущий плавающий текст, установленный над иконкой.
### Возвращаемое значение

Плавающий текст.
## void setTextAlign ( int align )

Устанавливает флаг выравнивания для плавающего текста над иконкой. Значение по умолчанию — ALIGN_CENTER.
### Аргументы

- *int* **align** - Флаг выравнивания: одно из значений перечисления Gui с префиксом ALIGN_*.

## int getTextAlign ( ) const

Возвращает текущий флаг выравнивания, установленный для плавающего текста над иконкой.
### Возвращаемое значение

Флаг выравнивания: одно из значений перечисления Gui с префиксом ALIGN_*.
## void setTexture ( const char * texture )

Устанавливает текстуру, используемую как изображение иконки.
### Аргументы

- *const char ** **texture** - Путь к файлу текстуры.

## const char * getTexture ( ) const

Возвращает путь к изображению иконки.
### Возвращаемое значение

Путь к файлу текстуры.
## void setToggleable ( bool toggleable )

Устанавливает значение, указывающее, является ли иконка переключателем или простой кнопкой. Значение по умолчанию — 0.
### Аргументы

- *bool* **toggleable** - Положительное число, чтобы сделать иконку переключателем, 0 — простой кнопкой.

## bool isToggleable ( ) const

Возвращает значение, указывающее, является ли иконка переключателем или простой кнопкой. Значение по умолчанию — 0.
### Возвращаемое значение

Положительное число, если иконка является переключателем; иначе 0.
## void setToggled ( bool toggled )

Устанавливает состояние иконки как переключателя.
### Аргументы

- *bool* **toggled** - Положительное число, чтобы нажать кнопку, 0 — чтобы отпустить.

## bool isToggled ( ) const

Возвращает значение, указывающее, нажата ли иконка, выступающая как переключатель.
### Возвращаемое значение

Возвращает 1, если кнопка нажата; иначе 0.
