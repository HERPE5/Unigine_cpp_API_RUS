## WidgetSlider Class

### Методы класса

---

## static WidgetSliderPtr create ( const Ptr < Gui > & gui , int min = 0 , int max = 100 , int value = 0 )

Конструктор. Создаёт ползунок с заданными свойствами (по умолчанию горизонтальный) и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать ползунок.
- *int* **min** - Минимальное значение.
- *int* **max** - Максимальное значение.
- *int* **value** - Начальное значение.

## static WidgetSliderPtr create ( int min = 0 , int max = 100 , int value = 0 )

Конструктор. Создаёт ползунок с заданными свойствами (по умолчанию горизонтальный) и добавляет его в GUI движка.
### Аргументы

- *int* **min** - Минимальное значение.
- *int* **max** - Максимальное значение.
- *int* **value** - Начальное значение.

## void setButtonHeight ( int height )

Задаёт высоту ручки ползунка в пикселях (для вертикального ползунка).
### Аргументы

- *int* **height** - Высота ручки в пикселях.

## int getButtonHeight ( ) const

Возвращает высоту ручки ползунка в пикселях (для вертикального ползунка).
### Возвращаемое значение

Высота ручки в пикселях.
## void setButtonWidth ( int width )

Задаёт ширину ручки ползунка в пикселях (для горизонтального ползунка).
### Аргументы

- *int* **width** - Ширина ручки в пикселях.

## int getButtonWidth ( ) const

Возвращает ширину ручки ползунка в пикселях (для горизонтального ползунка).
### Возвращаемое значение

Ширина ручки в пикселях.
## void setMaxExpand ( int expand )

Задаёт максимальное значение, до которого может быть расширен верхний предел диапазона значений ползунка.
### Аргументы

- *int* **expand** - Максимальное значение, до которого может быть поднят верхний предел ползунка.

## int getMaxExpand ( ) const

Возвращает текущее максимальное значение, до которого может быть расширен верхний предел диапазона значений ползунка. Верхний предел ползунка может быть расширен только если ползунок прикреплён к editline с флагом Gui::ATTACH_MAX_EXPAND.
### Возвращаемое значение

Максимальное значение, до которого может быть поднят верхний предел ползунка.
## void setMaxValue ( int value )

Задаёт максимальное значение для ползунка.
### Аргументы

- *int* **value** - Максимальное значение.

## int getMaxValue ( ) const

Возвращает максимальное значение ползунка.
### Возвращаемое значение

Максимальное значение.
## void setMinExpand ( int expand )

Задаёт минимальное значение, до которого может быть расширен нижний предел диапазона значений ползунка.
### Аргументы

- *int* **expand** - Минимальное значение, до которого может быть опущен нижний предел ползунка.

## int getMinExpand ( ) const

Возвращает минимальное значение, до которого может быть расширен нижний предел диапазона значений ползунка. Нижний предел ползунка может быть расширен только если ползунок прикреплён к editline с флагом Gui::ATTACH_MIN_EXPAND.
### Возвращаемое значение

Минимальное значение, до которого может быть опущен нижний предел ползунка.

### Аргументы

## int getMinValue ( ) const

## void setOrientation ( int orientation )

Задаёт ориентацию ползунка: горизонтальная (по умолчанию) или вертикальная.
### Аргументы

- *int* **orientation** - 1 для установки горизонтальной ориентации; 0 для установки вертикальной.

## int getOrientation ( ) const

Возвращает текущую ориентацию ползунка: горизонтальная или вертикальная.
### Возвращаемое значение

1, если ориентация вертикальная; 0, если горизонтальная.
## void setValue ( int value )

Задаёт новое текущее значение ползунка, т.е. его позицию.
### Аргументы

- *int* **value** - Значение ползунка.

## int getValue ( ) const

Возвращает текущее значение ползунка, т.е. его позицию.
### Возвращаемое значение

Текущее значение ползунка.
