# Unigine::WidgetSprite Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот базовый класс используется для создания спрайтов, то есть виджетов, работающих с изображениями.


Объект этого класса выглядит следующим образом:


![](../../../code/gui/ui/widgets/sprite.jpg)


Спрайт имеет фоновый слой, который используется для расчёта ограничивающего прямоугольника виджета, и, кроме того, может иметь ряд других слоёв. Всем слоям, включая нижний, можно назначить текстуры, тайлинг и блендинг.


> **Notice:** Вы можете трансформировать все слои, но избегайте вращения фонового слоя. Так как он используется для расчёта ограничивающего прямоугольника, при вращении он растягивается. Вместо этого вращайте другие слои.

## void setIntersectionImageEnabled ( bool enabled = false )
