## WidgetMenuBar Class

### Методы класса

## getNumItems () const

Возвращает текущее количество элементов в панели меню.
### Возвращаемое значение

Текущее количество элементов в панели меню.
## getSpaceY () const

Возвращает текущее вертикальное расстояние между элементами меню и границами меню.
### Возвращаемое значение

Текущее вертикальное расстояние между элементами меню и границами меню, в пикселях.
## getSpaceX () const

Возвращает текущее горизонтальное расстояние между элементами меню и границами меню.
### Возвращаемое значение

Текущее горизонтальное расстояние между элементами меню и границами меню, в пикселях.
## void setSelectionColor ( const Math:: vec4 & color )

Устанавливает новый цвет, используемый для выделения текущего выбора виджета.
### Аргументы

- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md)&* **color** - Цвет в формате RGBA.

## Math:: vec4 getSelectionColor () const

Возвращает текущий цвет, используемый для выделения текущего выбора виджета.
### Возвращаемое значение

Текущий цвет в формате RGBA.

## static WidgetMenuBarPtr create ( const Ptr < Gui > & gui , int x = 0 , int y = 0 )

Конструктор. Создаёт пустую панель меню и добавляет её в указанный GUI.

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать панель меню.
- *int* **x** - Смещение вдоль оси X.
- *int* **y** - Смещение вдоль оси Y.

## static WidgetMenuBarPtr create ( int x = 0 , int y = 0 )

Конструктор. Создаёт пустую панель меню и добавляет её в GUI движка.
### Аргументы

- *int* **x** - Смещение вдоль оси X.
- *int* **y** - Смещение вдоль оси Y.

## void setItemData ( int item , const char * str )

Устанавливает текстовые данные для элемента с указанным номером. Эти данные можно использовать как текстовый идентификатор элемента (вместо использования номера элемента).
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.
- *const char ** **str** - Устанавливаемые текстовые данные элемента.

## const char * getItemData ( int item ) const

Возвращает [text data](#setItemData_int_cstr_void) элемента с указанным номером. Эти данные можно использовать как текстовый идентификатор элемента (вместо использования номера элемента).
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов.

### Возвращаемое значение

Текстовые данные элемента.
## void setItemEnabled ( int item , bool enabled )

Устанавливает флаг включённости для элемента.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов.
- *bool* **enabled** - true, чтобы включить элемент; false — чтобы отключить его.

## bool isItemEnabled ( int item ) const

Возвращает значение, указывающее, включён ли указанный элемент.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.

### Возвращаемое значение

true, если элемент включён; иначе — false.
## void setItemMenu ( int item , const Ptr < WidgetMenuBox > & menu )

### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.
- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[WidgetMenuBox](../../../api/library/gui/class.widgetmenubox_cpp.md)> &* **menu** - Menu box.

## Ptr < WidgetMenuBox > getItemMenu ( int item ) const

Возвращает меню указанного элемента.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.

### Возвращаемое значение

Menu box.
## void setItemSpace ( int item , int space )

## int getItemSpace ( int item ) const

Возвращает расстояние между указанным элементом меню и следующим элементом справа.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.

### Возвращаемое значение

Расстояние между элементами, в пикселях.
## void setItemText ( int item , const char * str )

Устанавливает заголовок для указанного элемента.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.
- *const char ** **str** - Заголовок меню.

## const char * getItemText ( int item ) const

Возвращает заголовок указанного элемента.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.

### Возвращаемое значение

Заголовок элемента.
## void setSpace ( int x , int y )

Устанавливает расстояние между элементами меню и между элементами меню и границами меню.
### Аргументы

- *int* **x** - Горизонтальное расстояние, в пикселях. Если указано отрицательное значение, вместо него будет использовано 0.
- *int* **y** - Вертикальное расстояние, в пикселях. Если указано отрицательное значение, вместо него будет использовано 0.

## int addItem ( const char * str )

Добавляет пустое меню с указанным заголовком.
### Аргументы

- *const char ** **str** - Заголовок меню.

### Возвращаемое значение

Номер добавленного меню.
## int addItem ( const char * str , const Ptr < WidgetMenuBox > & menu )

Добавляет указанное подменю (*MenuBox*) с указанным заголовком.
### Аргументы

- *const char ** **str** - Заголовок меню.
- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[WidgetMenuBox](../../../api/library/gui/class.widgetmenubox_cpp.md)> &* **menu** - Подменю (*MenuBox*).

### Возвращаемое значение

Номер добавленного меню.
## void clear ( )

Удаляет все меню из панели меню.
## void removeItem ( int item )

Удаляет указанный элемент из панели меню.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов панели меню.
