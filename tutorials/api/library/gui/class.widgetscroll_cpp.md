# Unigine::WidgetScroll Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт полосу прокрутки: [horizontal](../../../code/gui/ui/ui_widgets.md#hscroll) или [vertical](../../../code/gui/ui/ui_widgets.md#vscroll).

## WidgetScroll Class

### Методы класса

---

## static WidgetScrollPtr create ( const Ptr < Gui > & gui , int object = 100 , int frame = 10 , int step = 1 , int value = 0 )

Конструктор. Создаёт полосу прокрутки с заданными параметрами и добавляет её в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать полоса прокрутки.
- *int* **object** - Ширина прокручиваемого объекта в пикселях. Это необязательный аргумент.
- *int* **frame** - Ширина видимой области в пикселях. Это необязательный аргумент.
- *int* **step** - Шаг полосы прокрутки в пикселях. Это необязательный аргумент.
- *int* **value** - Начальная позиция полосы прокрутки. Это необязательный аргумент.

## static WidgetScrollPtr create ( int object = 100 , int frame = 10 , int step = 1 , int value = 0 )

Конструктор. Создаёт полосу прокрутки с заданными параметрами и добавляет её в GUI движка.
### Аргументы

- *int* **object** - Ширина прокручиваемого объекта в пикселях. Это необязательный аргумент.
- *int* **frame** - Ширина видимой области в пикселях. Это необязательный аргумент.
- *int* **step** - Шаг полосы прокрутки в пикселях. Это необязательный аргумент.
- *int* **value** - Начальная позиция полосы прокрутки. Это необязательный аргумент.

## void setFrameSize ( int size )

Задаёт размер текущей видимой области.
### Аргументы

- *int* **size** - Размер видимой области в пикселях. Минимум - 1 пиксель.

## int getFrameSize ( ) const

Возвращает размер текущей видимой области.
### Возвращаемое значение

Размер видимой области в пикселях.
## void setObjectSize ( int size )

Задаёт размер всей прокручиваемой области.
### Аргументы

- *int* **size** - Размер прокручиваемого объекта в пикселях. Минимум - 1 пиксель.

## int getObjectSize ( ) const

Возвращает размер всей прокручиваемой области.
### Возвращаемое значение

Размер прокручиваемого объекта в пикселях.
## void setOrientation ( int orientation )

Задаёт ориентацию полосы прокрутки: горизонтальная (по умолчанию) или вертикальная.
### Аргументы

- *int* **orientation** - 1 для установки горизонтальной ориентации; 0 для установки вертикальной.

## int getOrientation ( ) const

Возвращает текущую ориентацию полосы прокрутки: горизонтальная или вертикальная.
### Возвращаемое значение

1, если ориентация горизонтальная; 0, если вертикальная.
## void setStepSize ( int size )

Задаёт шаг полосы прокрутки. Этот шаг используется для приращения позиции прокрутки.
### Аргументы

- *int* **size** - Шаг полосы прокрутки в пикселях. Минимум - 1 пиксель.

## int getStepSize ( ) const

Возвращает шаг полосы прокрутки. Этот шаг используется для приращения позиции прокрутки.
### Возвращаемое значение

Шаг полосы прокрутки в пикселях.
## void setValue ( int value )

Задаёт значение полосы прокрутки, т.е. её позицию.
### Аргументы

- *int* **value** - Позиция полосы прокрутки. Минимальное значение - 0, максимальное значение - разница между шириной объекта и шириной видимой области.

## int getValue ( ) const

Возвращает значение полосы прокрутки, т.е. её позицию.
### Возвращаемое значение

Позиция полосы прокрутки.
## void setScrollColor ( const Math:: vec4 & color )

Задаёт цвет, используемый для полосы прокрутки виджета.
### Аргументы

- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md) &* **color** - Четырёхкомпонентный вектор, задающий цвет в формате RGBA.

## Math:: vec4 getScrollColor ( ) const

Возвращает текущий цвет, используемый для полосы прокрутки виджета.
### Возвращаемое значение

Четырёхкомпонентный вектор, задающий цвет в формате RGBA.
## void setSliderButton ( bool button )

Задаёт отображение кнопок ползунка.
### Аргументы

- *bool* **button** - true для отображения кнопок ползунка, иначе false.

## bool isSliderButton ( ) const

Возвращает значение, указывающее, отображаются ли кнопки ползунка.
### Возвращаемое значение

true, если кнопки ползунка отображаются, иначе false.

## int getMouseWheelOrientation ( ) const

Возвращает ориентацию прокрутки колесом мыши: горизонтальная или вертикальная.
### Возвращаемое значение

1, если ориентация горизонтальная; 0, если вертикальная.
