### Перечисления

## SCROLL_RENDER_MODE

| Имя | Описание |
|---|---|
| **ALWAYS_RENDER** = 0 | Полоса прокрутки отображается всегда. |
| **AUTO_HIDE** = 1 | Полоса прокрутки автоматически скрывается при необходимости. Например, если область контейнера достаточно велика, чтобы показать все элементы, полоса прокрутки не отображается. И наоборот, если не все элементы могут быть показаны одновременно, полоса прокрутки отображается. |
| **ALWAYS_HIDE** = 2 | Полоса прокрутки всегда скрыта. В этом режиме, хотя сама полоса не отображается, её границы всё равно учитываются при расчёте границ виджета. |
| **ALWAYS_HIDE_NO_BOUNDS** = 3 | Полоса прокрутки всегда скрыта, и её размер не добавляется к границам виджета. |

## static WidgetScrollBoxPtr create ( const Ptr < Gui > & gui , int x = 0 , int y = 0 )

Конструктор. Создаёт контейнер с прокруткой на основе заданных параметров и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать новый контейнер.
- *int* **x** - Горизонтальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в контейнере, а также между ними и границей контейнера. Это необязательный параметр.

## static WidgetScrollBoxPtr create ( int x = 0 , int y = 0 )

Конструктор. Создаёт контейнер с прокруткой на основе заданных параметров и добавляет его в GUI движка.
### Аргументы

## void setBorder ( int border )

Задаёт флаг, указывающий, отображается ли однопиксельная граница вокруг содержимого виджета (в форме прямоугольника). По умолчанию 1 (использовать границу).
### Аргументы

- *int* **border** - Положительное число включает границу, 0 - отключает её.

## int getBorder ( ) const

Возвращает флаг, указывающий, отображается ли однопиксельная граница вокруг содержимого виджета (в форме прямоугольника). По умолчанию 1 (использовать границу).
### Возвращаемое значение

Положительное число, если граница включена; иначе 0.
