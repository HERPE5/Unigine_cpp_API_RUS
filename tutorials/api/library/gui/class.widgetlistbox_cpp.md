# Unigine::WidgetListBox Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт [list box](../../../code/gui/ui/ui_widgets.md#listbox), представляющий собой многострочное текстовое поле, в котором можно выбрать [more than one](#setMultiSelection_int_void) элемента.


Объект этого класса выглядит следующим образом:

## WidgetListBox Class

### Методы класса

## int getNumSelectedItems () const

Возвращает текущее количество выбранных элементов в списке.
### Возвращаемое значение

Текущее количество выбранных элементов.
## int getNumItems () const

Возвращает текущее общее количество элементов в списке.
### Возвращаемое значение

Текущее количество элементов.
## void setIconsEnabled ( bool enabled )

Устанавливает новое значение, указывающее, включено ли отображение иконок.
### Аргументы

- *bool* **enabled** - Установите **true**, чтобы включить отображение иконок; **false** — чтобы отключить его.

## bool isIconsEnabled () const

Возвращает текущее значение, указывающее, включено ли отображение иконок.
### Возвращаемое значение

**true**, если отображение иконок включено; иначе **false**.
## void setSelectionColor ( const Math:: vec4 & color )

Устанавливает новый цвет, используемый для выделения текущего выбора виджета.
### Аргументы

- *const  Math::[vec4](../../../api/library/math/class.vec4_cpp.md)&* **color** - Четырёхкомпонентный вектор, задающий цвет в формате RGBA.

## Math:: vec4 getSelectionColor () const

Возвращает текущий цвет, используемый для выделения текущего выбора виджета.
### Возвращаемое значение

Текущий четырёхкомпонентный вектор, задающий цвет в формате RGBA.
## void setMultiSelection ( bool selection )

Устанавливает новое значение, указывающее, включён ли множественный выбор элементов. Значение по умолчанию — 0.
### Аргументы

- *bool* **selection** - Установите **true**, чтобы включить выбор нескольких элементов одновременно; **false** — чтобы отключить его.

## bool isMultiSelection () const

Возвращает текущее значение, указывающее, включён ли множественный выбор элементов. Значение по умолчанию — 0.
### Возвращаемое значение

**true**, если выбор нескольких элементов одновременно включён; иначе **false**.

## void setTexture ( const char * texture )

Устанавливает текстуру с мини-иконками, используемыми для элементов списка. Текстура представляет собой вертикальную полосу квадратных иконок.

## int addItem ( const char * str , int texture = -1 )

Добавляет новый элемент с указанным текстом и иконкой. По умолчанию новый элемент не выбран.
### Аргументы

- *const char ** **str** - Текст элемента.
- *int* **texture** - ID иконки, начиная с 0. -1 означает, что у элемента нет иконки.

### Возвращаемое значение

Номер добавленного элемента.
