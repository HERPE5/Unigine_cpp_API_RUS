## WidgetGroupBox Class

### Методы класса

---

## static WidgetGroupBoxPtr create ( const Ptr < Gui > & gui , const char * str = 0 , int x = 0 , int y = 0 )

Конструктор. Создаёт group box с указанными параметрами и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать новый box.
- *const char ** **str** - Заголовок box. Это опциональный параметр.
- *int* **x** - Горизонтальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.

## static WidgetGroupBoxPtr create ( const char * str = 0 , int x = 0 , int y = 0 )

### Аргументы

- *int* **x** - Горизонтальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.

## void setBackground ( int background )

Устанавливает значение, указывающее, должна ли отрисовываться фоновая текстура для box.
### Аргументы

- *int* **background** - 1, чтобы отрисовывать фоновую текстуру, 0 — не отрисовывать.

## int getBackground ( ) const

Возвращает значение, указывающее, отрисовывается ли фоновая текстура для box.
### Возвращаемое значение

Возвращает 1, если фоновая текстура отрисовывается; иначе 0.
## void setBorder ( int border )

Устанавливает флаг, указывающий, отрисовывается ли однопиксельная граница вокруг содержимого виджета (в форме box). Значение по умолчанию — 1 (использовать границу).
### Аргументы

- *int* **border** - Положительное число, чтобы включить границу, 0 — чтобы отключить её.

## int getBorder ( ) const

Возвращает флаг, указывающий, отрисовывается ли однопиксельная граница вокруг содержимого виджета (в форме box). Значение по умолчанию — 1 (использовать границу).
### Возвращаемое значение

Положительное число, если граница включена; иначе 0.

## void setStencil ( int stencil )

Устанавливает значение, указывающее, обрезает ли виджет своих дочерних элементов по своим границам. Всё, что находится за их пределами, не отрисовывается. Значение по умолчанию — 0.
### Аргументы

- *int* **stencil** - 1, чтобы включить обрезку; иначе 0.

## int getStencil ( ) const

Возвращает значение, указывающее, обрезает ли виджет своих дочерних элементов по установленным границам. Всё, что находится за их пределами, не отрисовывается. Эта опция работает только если у дочерних элементов установлен флаг ALIGN_OVERLAP (иначе они расширят границы виджета box, и обрезка не будет выполнена).
### Возвращаемое значение

Возвращает 1, если обрезка включена; иначе 0.
