## static WidgetGridBoxPtr create ( const Ptr < Gui > & gui , int num = 2 , int x = 0 , int y = 0 )

Конструктор. Создаёт grid box с указанными параметрами и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать новый box.
- *int* **num** - Количество столбцов в сетке. Это опциональный параметр.
- *int* **x** - Горизонтальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.

## static WidgetGridBoxPtr create ( int num = 2 , int x = 0 , int y = 0 )

Конструктор. Создаёт grid box с указанными параметрами и добавляет его в GUI движка.
### Аргументы

- *int* **num** - Количество столбцов в сетке. Это опциональный параметр.
- *int* **x** - Горизонтальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.
- *int* **y** - Вертикальное расстояние между виджетами в box и между ними и границей box. Это опциональный параметр.

## void setColumnRatio ( int num , int ratio )

Устанавливает соотношение ширины к высоте для указанного столбца.
### Аргументы

- *int* **num** - Номер столбца в диапазоне от 0 до общего количества столбцов.
- *int* **ratio** - Соотношение ширины к высоте.

## int getColumnRatio ( int num ) const

Возвращает текущее соотношение ширины к высоте для указанного столбца.
### Аргументы

- *int* **num** - Номер столбца в диапазоне от 0 до общего количества столбцов.

### Возвращаемое значение

Соотношение ширины к высоте.
## void setNumColumns ( int columns )

Устанавливает количество столбцов в сетке.
### Аргументы

- *int* **columns** - Количество столбцов.

## int getNumColumns ( ) const

Возвращает количество столбцов в сетке.
### Возвращаемое значение

Количество столбцов.
