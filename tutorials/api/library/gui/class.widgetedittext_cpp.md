# Unigine::WidgetEditText Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт простую редактируемую многострочную [text area](../../../code/gui/ui/ui_widgets.md#edittext), содержащую текстовые строки.


Объект этого класса выглядит следующим образом:


![](../../../code/gui/ui/widgets/edittext.png)


> **Notice:** Опции [wrapping](../../../api/library/gui/class.widget_cpp.md#setFontWrap_int_void) слов и [rich text](../../../api/library/gui/class.widget_cpp.md#setFontRich_int_void) не поддерживаются для этого класса.

## void setBackground ( int background )

Устанавливает новое значение, указывающее, отрисовывается ли фоновая текстура для текстового поля. Значение по умолчанию — 1.
### Аргументы

- *int* **background** - **1** — отрисовывать фоновую текстуру; **0** — не отрисовывать.

## int getBackground () const

Возвращает текущее значение, указывающее, отрисовывается ли фоновая текстура для текстового поля. Значение по умолчанию — 1.
### Возвращаемое значение

Текущее значение: **1** — отрисовывать фоновую текстуру; **0** — не отрисовывать.
## void setEditable ( bool editable )

Устанавливает новое значение, указывающее, можно ли редактировать содержимое текстового поля. Значение по умолчанию — true.
### Аргументы

- *bool* **editable** - Установите **true**, чтобы разрешить редактирование содержимого текстового поля; **false** — чтобы запретить.

## bool isEditable () const

Возвращает текущее значение, указывающее, можно ли редактировать содержимое текстового поля. Значение по умолчанию — true.

**true**, если редактирование содержимого текстового поля разрешено; иначе **false**.

**true**, если изменение строки при прокрутке включено; иначе **false**.

## int getLineWidth ( int line , int end = -1 ) const

Возвращает ширину текстовой строки (место, занимаемое символами).
### Аргументы

- *int* **line** - Индекс строки от 0 до [total number of lines](#getNumLines_int).
- *int* **end** - Индекс последнего символа, до которого возвращается ширина строки. Если установлено -1, учитываются все символы строки.

### Возвращаемое значение

Ширина текстовой строки, в пикселях.
