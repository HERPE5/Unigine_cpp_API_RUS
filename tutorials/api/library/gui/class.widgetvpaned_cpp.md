# Unigine::WidgetVPaned Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт [horizontal movable bar](../../../code/gui/ui/ui_containers.md#vpaned), которая делит окно на две изменяемые по размеру панели.


Объект этого класса выглядит следующим образом:


![](../../../code/gui/ui/widgets/vpaned.png)


Этот виджет должен содержать ровно два дочерних элемента. Если предоставлено меньше дочерних элементов, ничего не будет отрисовано; если предоставлено больше, приложение может завершиться аварийно.


## WidgetVPaned Class

### Методы класса

---

## static WidgetVPanedPtr create ( const Ptr < Gui > & gui )

Конструктор. Создаёт новый вертикальный контейнер с возможностью изменения размера его дочерних элементов и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать новый контейнер.

## static WidgetVPanedPtr create ( )

Конструктор. Создаёт новый вертикальный контейнер с возможностью изменения размера его дочерних элементов и добавляет его в GUI движка.
## void setFirstSize ( int size )

Задаёт размер первого дочернего элемента.
### Аргументы

- *int* **size** - Размер первого дочернего элемента в пикселях.

## int getFirstSize ( ) const

Возвращает размер первого дочернего элемента.
### Возвращаемое значение

Размер первого дочернего элемента в пикселях.
## void setFixed ( int fixed )

Задаёт номер дочернего элемента с фиксированным размером. По умолчанию 0.
### Аргументы

- *int* **fixed** - Номер дочернего элемента:

  - 0 - размер обоих дочерних элементов не фиксирован.
  - 1 - размер первого дочернего элемента фиксирован.
  - 2 - размер второго дочернего элемента фиксирован.

## int getFixed ( ) const

Возвращает номер дочернего элемента с фиксированным размером.
### Возвращаемое значение

Номер дочернего элемента. 0 означает, что размер обоих дочерних элементов не фиксирован.
## void setSecondSize ( int size )

Задаёт размер второго дочернего элемента.
### Аргументы

- *int* **size** - Размер второго дочернего элемента в пикселях.

## int getSecondSize ( ) const

Возвращает размер второго дочернего элемента.
### Возвращаемое значение

Размер второго дочернего элемента в пикселях.
## void setValue ( int value )

Определяет, как будут изменяться размеры дочерних виджетов. По умолчанию 0.
### Аргументы

- *int* **value** - Значение в диапазоне **[-32767; 32767]**. **-32767** означает, что при изменении размера верхний дочерний элемент останется фиксированным. **32767** означает, что при изменении размера нижний дочерний элемент останется фиксированным. **0** означает, что размеры обоих дочерних элементов будут изменяться одинаково. Другие значения задают пропорции, в которых изменяются размеры дочерних элементов.

## int getValue ( ) const

Возвращает значение, определяющее, как будут изменяться размеры дочерних виджетов.
### Возвращаемое значение

Значение в диапазоне **[-32767; 32767]**. **-32767** означает, что при изменении размера верхний дочерний элемент останется фиксированным. **32767** означает, что при изменении размера нижний дочерний элемент останется фиксированным. **0** означает, что размеры обоих дочерних элементов будут изменяться одинаково. Другие значения задают пропорции, в которых изменяются размеры дочерних элементов.
