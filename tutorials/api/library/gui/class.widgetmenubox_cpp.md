# Unigine::WidgetMenuBox Class (CPP)

**Header:** #include <UnigineWidgets.h>

**Inherits from:** Widget


Этот класс создаёт [menu box](../../../code/gui/ui/ui_widgets.md#menubox).


Объект этого класса выглядит следующим образом:


![](../../../code/gui/ui/widgets/menubox.png)


Меню может быть как отдельным, так и прикреплённым к [menu bar](../../../api/library/gui/class.widgetmenubar_cpp.md). В первом случае им нужно управлять вручную. С помощью этого виджета можно выполнять следующее:


- Создавать иерархические меню.
- Использовать другие виджеты в качестве элементов меню (см. [example](../../../code/gui/ui/ui_widgets.md#menubox_widget)).

## WidgetMenuBox Class

### Методы класса

## const char * getCurrentItemData () const

Возвращает текущие текстовые данные выбранного элемента (последнего элемента, по которому был выполнен щелчок). Эти данные можно использовать в качестве текстового идентификатора элемента (вместо использования номера элемента).
### Возвращаемое значение

Текущие текстовые данные выбранного элемента или nullptr, если ни один элемент не выбран.
## const char * getCurrentItemText () const

Возвращает текущий текст выбранного элемента (последнего элемента, по которому был выполнен щелчок).
### Возвращаемое значение

Текущий текст выбранного элемента или nullptr, если ни один элемент не выбран.
## void setCurrentItem ( )

Задаёт новое выделение элемента (номер последнего элемента, по которому был выполнен щелчок). Если ничего не выбрано, значение равно -1 (установка выделения на несуществующий номер элемента также сбросит значение на -1).
### Аргументы

- **item** - Номер выбранного элемента.

## getCurrentItem () const

Возвращает текущее выделение элемента (номер последнего элемента, по которому был выполнен щелчок). Если ничего не выбрано, значение равно -1 (установка выделения на несуществующий номер элемента также сбросит значение на -1).
### Возвращаемое значение

Номер текущего выбранного элемента.
## getNumItems () const

Возвращает текущее общее количество элементов в меню.
### Возвращаемое значение

Текущее общее количество элементов в меню.
## void setTexture ( const char * texture )

Задаёт новый путь к файлу текстуры с мини-иконками, используемыми с элементами списка. Текстура представляет собой вертикальную полосу из квадратных иконок.
### Аргументы

- *const char ** **texture** - Путь к используемому файлу текстуры.

## const char * getTexture () const

Возвращает текущий путь к файлу текстуры с мини-иконками, используемыми с элементами списка. Текстура представляет собой вертикальную полосу из квадратных иконок.
### Возвращаемое значение

Текущий путь к используемому файлу текстуры.
## getSpaceY () const

Возвращает текущее вертикальное расстояние между элементами меню, а также между элементами и границами меню.
### Возвращаемое значение

Текущее вертикальное расстояние между элементами меню и границами меню, в пикселях.
## getSpaceX () const

Возвращает текущее горизонтальное расстояние между элементами меню, а также между элементами и границами меню.
### Возвращаемое значение

Текущее горизонтальное расстояние между элементами меню и границами меню, в пикселях.

## void setCurrentItemHighlight ( bool highlight )

## Math:: vec4 getCurrentItemColor () const

Возвращает текущий цвет подсветки для элемента, по которому был выполнен щелчок последним. **[highlight state](#setCurrentItemHighlight_int_void)** должно быть включено.

## static WidgetMenuBoxPtr create ( const Ptr < Gui > & gui , int x = 0 , int y = 0 )

Конструктор. Создаёт пустое меню с указанным расстоянием между элементами меню, а также между элементами и границами меню, и добавляет его в указанный GUI.
### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Gui](../../../api/library/gui/class.gui_cpp.md)> &* **gui** - [GUI](../../../api/library/gui/class.gui_cpp.md), которому будет принадлежать меню.
- *int* **x** - Горизонтальное расстояние.
- *int* **y** - Вертикальное расстояние.

## static WidgetMenuBoxPtr create ( int x = 0 , int y = 0 )

Конструктор. Создаёт пустое меню с указанным расстоянием между элементами меню, а также между элементами и границами меню, и добавляет его в GUI движка.
### Аргументы

- *int* **x** - Горизонтальное расстояние.
- *int* **y** - Вертикальное расстояние.

### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Image](../../../api/library/common/class.image_cpp.md)> &* **image** - Устанавливаемое изображение.

## Ptr < Image > getImage ( ) const

Возвращает изображение с мини-иконками, используемыми с элементами меню.
### Возвращаемое значение

Изображение с мини-иконками (вертикальная полоса из квадратных иконок).
## void setItemData ( int item , const char * str )

Задаёт текстовые данные для заданного элемента. Эти данные можно использовать в качестве текстового идентификатора элемента (вместо использования номера элемента).
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов.
- *const char ** **str** - Устанавливаемые текстовые данные элемента.

## const char * getItemData ( int item ) const

Возвращает [text data](#setItemData_int_cstr_void) элемента с указанным номером. Эти данные можно использовать в качестве текстового идентификатора элемента (вместо использования номера элемента).
### Аргументы

- *int* **item** - Item number in range from 0 to the total number of items.

### Возвращаемое значение

Текстовые данные элемента.
## void setItemEnabled ( int item , bool enabled )

Задаёт значение, указывающее, включён ли заданный элемент (т.е. можно ли по нему щёлкнуть).
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов.
- *bool* **enabled** - true, чтобы включить элемент, false - чтобы отключить его.

## int isItemEnabled ( int item ) const

Возвращает значение, указывающее, включён ли заданный элемент (т.е. можно ли по нему щёлкнуть).
### Аргументы

- *int* **item** - Item number in range from 0 to the total number of items.

### Возвращаемое значение

Положительное число, если элемент включён; иначе 0.
## void setItemSelectable ( int item , int selectable )

Задаёт значение, указывающее, можно ли выбрать заданный элемент.
### Аргументы

- *int* **item** - Номер элемента в диапазоне от 0 до общего количества элементов.
- *int* **selectable** - 1, чтобы сделать элемент выбираемым; иначе 0.

## int isItemSelectable ( int item ) const

Возвращает значение, указывающее, можно ли выбрать заданный элемент. По умолчанию элемент является выбираемым.
### Аргументы

- *int* **item** - Item number in range from 0 to the total number of items.

### Возвращаемое значение

1, если элемент является выбираемым; иначе 0.
## void setItemSeparator ( int item , int separator )

- *int* **separator** - Положительное число добавляет разделитель, 0 - удаляет его.

## int isItemSeparator ( int item ) const

Проверяет, размещён ли разделитель после заданного элемента.
### Аргументы

- *int* **item** - Item number in range from 0 to the total number of items.

Положительное число, если разделитель размещён; иначе 0.

## void setSpace ( int x , int y )

Задаёт расстояние между элементами меню, а также между ними и границами меню.
### Аргументы

- *int* **x** - Горизонтальное расстояние. Если задано отрицательное значение, вместо него будет использовано 0.
- *int* **y** - Вертикальное расстояние. Если задано отрицательное значение, вместо него будет использовано 0.

## int addItem ( const char * str , int texture = -1 )

Добавляет новый элемент с заданным текстом и иконкой.
### Аргументы

- *const char ** **str** - Текст элемента.
- *int* **texture** - ID иконки, начиная с нуля (т.е. номер иконки в текстуре иконок). -1 means that an item has no icon.

### Возвращаемое значение

Номер добавленного элемента.
## void clear ( )

Удаляет все элементы из меню.
## void removeItem ( int item )

Удаляет заданный элемент из меню.
### Аргументы

- *int* **item** - Item number in range from 0 to the total number of items.

## void resetCurrentItem ( )
