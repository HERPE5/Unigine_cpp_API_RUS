# Unigine::PackageUng Class (CPP)

**Header:** #include <UniginePackageUng.h>


`UNG` — это нативный формат архива, используемый движком. Архивы `UNG` бесшовно интегрированы в [virtual file system](../../../principles/filesystem/index_cpp.md) движка и автоматически загружаются при размещении в папке `data`. Файлы, хранящиеся в архиве `UNG`, обрабатываются так же, как обычные, неархивированные файлы — их не нужно явно извлекать или распаковывать.


Содержимое архивов `UNG` полностью прозрачно для движка: доступ к архивированным файлам осуществляется по их стандартным путям, как если бы они не были упакованы. Однако важно отметить следующее:


- Пакет `UNG` не может содержать другой пакет `UNG`.
- [mount point](../../../principles/filesystem/index_cpp.md#mount_points) не может быть упакована в архив, хотя может ссылаться на него.
- [Data Streaming](../../../principles/data_streaming/index.md) не поддерживается для сжатых файлов внутри архивов. Хотя сжатые файлы в архивах читаются быстрее, их нельзя передавать потоково. Поэтому по умолчанию сжимаются только файлы, не требующие потоковой передачи.
- Сжатие бинарных форматов (например, `.texture`, `.mesh` или `.lmap`) **не рекомендуется**, так как эти форматы уже сжаты внутренне и требуют потоковой передачи для эффективной загрузки во время выполнения.
- Для файлов, расширения которых отмечены для сжатия, применяется алгоритм сжатия **LZ4**. Список сжимаемых расширений задаётся при создании пакета через конструктор.


Подробнее см. статью: **[File System](../../../principles/filesystem/index_cpp.md#file_packages)**.

## PackageUng ( const char * password = "" , const char * compress_extension_list = "json xml txt node world prop track mat basemat" )

Конструктор. Инициализирует объект **PackageUng** с [optional password](../../../code/data_protection_cpp.md) и указанным списком расширений для сжатия. По умолчанию список включает форматы, не требующие [Data Streaming](../../../principles/data_streaming/index.md).
### Аргументы

- *const char ** **password** - Пароль, используемый для защиты архива. Если пусто, защита паролем не применяется.
- *const char ** **compress_extension_list** - Разделённый пробелами список расширений файлов, которые должны сжиматься при добавлении в пакет.

## static bool isSupported ( )

## bool readFile ( unsigned char * data , size_t size )

Читает содержимое текущего выбранного файла и помещает его в массив данных.
> **Notice:** Эта операция выполняется для текущего выбранного файла. Чтобы выбрать файл, используйте [selectFile()](#selectFile_cstr_size_t_int).


### Аргументы

- *unsigned char ** **data** - Массив данных.
- *size_t* **size** - Размер файла, в байтах.

### Возвращаемое значение

true, если файл успешно прочитан; иначе false.
## bool selectFile ( const char * path , size_t & size )

Выбирает файл с указанным путём как текущий и помещает его размер в предоставленную переменную.
### Аргументы

- *const char ** **path** - Относительный путь к файлу внутри пакета.
- *size_t &* **size** - Переменная-ссылка для хранения размера выбранного файла.

### Возвращаемое значение

true, если файл успешно выбран; иначе false.
## bool writeFile ( const char * path , const unsigned char * OUT_data , size_t size )

Записывает данные в пакет по указанному пути.
### Аргументы

### Возвращаемое значение

true, если данные успешно записаны в файл; иначе false.
