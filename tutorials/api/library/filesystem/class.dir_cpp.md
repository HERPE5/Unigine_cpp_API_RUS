# Unigine::Dir Class (CPP)

**Header:** #include <UnigineDir.h>


Этот класс позволяет пользователю получать различные атрибуты каталога, включая информацию, специфичную для файлов. Также класс предоставляет возможность копировать файлы в разные каталоги.


> **Notice:** Класс Dir не может разрешить относительный путь, поэтому требуется запрос к *[FileSystem::getAbsolutePath()](../../../api/library/filesystem/class.filesystem_cpp.md#getAbsolutePath_cstr_String)*.


### Пример использования


Ниже приведён пример вывода имён всех вложенных каталогов в указанном каталоге:


```cpp
// создаём дескриптор для указанного каталога и открываем его
Unigine::DirPtr dir = Unigine::Dir::create();

// задаём строку пути (относительный или абсолютный)
// класс Dir не может разрешить относительный путь, поэтому требуется запрос к FileSystem
dir->open(Unigine::FileSystem::getAbsolutePath("path"));
// или, если путь абсолютный, можно использовать: dir->open("path");

// перебираем все вложенные каталоги и выводим их имена
int num_dirs = dir->getNumDirs();
for (int i = 0; i < num_dirs; ++i)
{
	const char *dirname = dir->getDirName(i);
	Unigine::Log::message("Dir name %s\n", dirname);
}
// всегда закрывайте дескриптор каталога перед выходом из области видимости
dir->close();


```

## int chmod ( const char * path , int mode )
