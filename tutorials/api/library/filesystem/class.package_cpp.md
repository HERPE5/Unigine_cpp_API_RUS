# Unigine::Package Class (CPP)

**Header:** #include <UnigineFileSystem.h>


Внешний пакет Unigine.


## Package Class

### Методы класса

---

## virtual const char * getFilePath ( int num ) =0

Возвращает путь к файлу с указанным индексом.
### Аргументы

- *int* **num** - Индекс файла в пакете.

### Возвращаемое значение

Относительный путь к файлу внутри пакета.
## virtual int getNumFiles ( ) =0

Возвращает количество файлов в пакете.
### Возвращаемое значение

Количество файлов пакета.
## virtual bool readFile ( unsigned char * data , size_t size ) =0

Читает текущий выбранный файл.
### Аргументы

- *unsigned char ** **data** - Указатель на буфер назначения данных.
- *size_t* **size** - Размер буфера данных.

### Возвращаемое значение

true, если файл успешно прочитан; иначе возвращается false.
## virtual bool selectFile ( const char * path , size_t & size ) =0

Выбирает файл с указанным путём и помещает его размер в указанный буфер.
### Аргументы

- *const char ** **path** - Относительный путь к выбираемому файлу внутри пакета.
- *size_t &* **size** - Буфер для получения размера выбранного файла, в байтах.

### Возвращаемое значение

true, если файл выбран; иначе возвращается false.
## virtual ~Package ( )

Виртуальный деструктор.
## int findFile ( const char * path ) const

Возвращает индекс файла в пакете по его имени.
### Аргументы

- *const char ** **path** - Относительный путь к файлу внутри пакета.

### Возвращаемое значение

Индекс файла. Число от 0 до общего количества файлов в пакете, либо -1, если файл не существует.
## size_t getFileSize ( int num ) const

Возвращает размер файла с указанным индексом внутри пакета.
### Аргументы

- *int* **num** - Индекс файла в пакете.

### Возвращаемое значение

Размер файла с указанным индексом, в байтах.
