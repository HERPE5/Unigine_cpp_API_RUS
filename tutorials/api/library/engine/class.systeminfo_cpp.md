# Класс Unigine.SystemInfo (CPP)

**Заголовочный файл:** #include <UnigineSystemInfo.h>


Этот класс используется для получения подробной информации о системе и окружении движка. Он предоставляет метрики использования RAM и VRAM, характеристики CPU и GPU, сведения об операционной системе, версию движка и характеристики платформы.


> **Notice:** Этот класс статический и не может быть инстанцирован. Вместо этого вызывайте методы напрямую.


## Класс SystemInfo

### Перечисления

### Структуры

## struct MemoryStatistics

### Поля

- *bool* **out_of_ram_committed** - Флаг, указывающий, исчерпал ли процесс зарезервированную (committed) RAM.
- *bool* **out_of_ram** - Флаг, указывающий, исчерпал ли процесс физическую RAM.
- *bool* **out_of_vram** - Флаг, указывающий, исчерпал ли процесс VRAM.
- *long long* **ram_free** - Свободная физическая RAM.
- *long long* **ram_usage** - Физическая RAM, используемая в данный момент.
- *long long* **ram_limit** - Физическая RAM, доступная движку.
- *long long* **ram_total** - Общий объём физической RAM.
- *long long* **ram_committed_free** - Свободная виртуальная память, доступная в системе.
- *long long* **ram_committed_usage** - Объём виртуальной памяти, зарезервированной процессом движка.
- *long long* **ram_committed_background** - Объём виртуальной памяти, зарезервированной всеми фоновыми процессами.
- *long long* **ram_committed_limit** - Объём виртуальной памяти, который процесс движка может зарезервировать.
- *long long* **ram_committed_total** - Общий объём виртуальной RAM.
- *long long* **gpu_ram_usage** - Объём RAM, используемой GPU (выделенной процессом движка).
- *long long* **gpu_ram_background** - Объём RAM, используемой GPU (выделенной всеми фоновыми процессами).
- *long long* **gpu_vram_free** - Объём неиспользуемой VRAM.
- *long long* **gpu_vram_usage** - Объём VRAM, используемой процессом движка.
- *long long* **gpu_vram_background** - Объём VRAM, используемой всеми фоновыми процессами.
- *long long* **gpu_vram_limit** - VRAM, доступная движку.
- *long long* **gpu_vram_budget** - Бюджет VRAM, предоставленный ОС.
- *long long* **gpu_vram_total** - Общий объём VRAM.
