# Класс Unigine::Memory (CPP)

**Заголовочный файл:** #include <UnigineMemory.h>


Этот класс управляет [memory allocations](../../../principles/allocator/index.md).


> **Примечание:** Этот класс статический и не может быть инстанцирован. Вместо этого вызывайте методы напрямую.


## Класс Memory

### Методы класса

## int getFrameAllocations () const

Возвращает текущее количество выделений памяти, выполненных за кадр.
### Возвращаемое значение

Текущее количество выделений.
## int getMaxAllocations () const

Возвращает текущее максимальное количество выделений памяти, сделанных во время выполнения (пиковое потребление).
### Возвращаемое значение

Текущее количество выделений.
## int getLiveAllocations () const

Возвращает текущее количество выполненных выделений памяти.
### Возвращаемое значение

Текущее количество выделений.
## size_t getInstancePoolUsage () const

Возвращает текущий объём памяти, выделенной в пулах экземпляров. Пулы экземпляров хранят выделения, определённые разработчиками. Обычно это выделения, которые требуются регулярно. Они работают так же, как [dynamic pools](../../../principles/allocator/index.md#dynamic_pool), но пулы экземпляров не имеют ограничения по размеру.
### Возвращаемое значение

Текущий объём памяти.
## size_t getDynamicPoolUsage () const

Возвращает текущий объём памяти, выделенной в [dynamic pools](../../../principles/allocator/index.md#dynamic_pool) (доступно только на Windows).
### Возвращаемое значение

Текущий объём памяти.
## size_t getStaticPoolUsage () const

Возвращает текущий объём памяти, выделенной в [static pools](../../../principles/allocator/index.md#static_pool).
### Возвращаемое значение

Текущий объём памяти.
## bool isStatisticsEnabled () const

Возвращает текущее значение, указывающее, включён ли сбор статистики памяти, необходимой для конфигурации пулов.
### Возвращаемое значение

**true**, если включено; иначе **false**.
## size_t getMemoryUsage () const

Возвращает текущий общий объём используемой памяти в байтах.
### Возвращаемое значение

Текущий объём используемой памяти в байтах.
---

## int isInitialized ( )

Возвращает статус менеджера памяти.
### Возвращаемое значение

**1**, если менеджер памяти инициализирован; иначе **0**.
## static void allocate ( size_t size )

Выделяет динамическую память.
### Аргументы

- *size_t* **size** - Размер выделяемого блока памяти.

## static int deallocate ( void * ptr )

Освобождает динамическую память.
### Аргументы

- *void ** **ptr** - Указатель на выделенный блок памяти.

## static void deallocate ( void * ptr , size_t size )

Освобождает динамическую память.
### Аргументы

- *void ** **ptr** - Указатель на выделенный блок памяти.
- *size_t* **size** - Размер выделенного блока памяти.

## static void logInfo ( )

Выводит [information](../../../principles/allocator/index.md#analyze_ram_pools) о небольших выделениях в статических и динамических пулах памяти.
