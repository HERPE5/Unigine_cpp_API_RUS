# Класс Unigine::Sounds (CPP)

**Заголовочный файл:** #include <UnigineSounds.h>

> **Notice:** Этот класс является одиночкой (singleton).


Класс *Sounds* содержит методы для работы с источником звукового вывода.


## Класс Sounds

### Методы класса

---

## void setCurrentDeviceName ( const char * name )

Изменяет имя текущего устройства, тем самым меняя используемое устройство. Поддерживаются только имена, полученные методом *[getDeviceName()](#getDeviceName_int_cstr)*.
### Аргументы

- *const char ** **name** - Новое имя устройства.

## const char * getCurrentDeviceName ( )

Возвращает имя используемого в данный момент устройства.
### Возвращаемое значение

Имя текущего устройства.
## const char * getDefaultDeviceName ( )

Возвращает имя устройства, установленного в системе по умолчанию.
### Возвращаемое значение

Имя устройства по умолчанию.
## int isDeviceConnected ( )

Возвращает значение, указывающее, подключено ли устройство в данный момент.
### Возвращаемое значение

true, если устройство подключено; иначе false.
## int isDeviceEnumerationSupported ( )

Возвращает значение, указывающее, поддерживается ли перечисление устройств. Если нет, дальнейшие действия (например, получение имени устройства) будут невозможны.
## const char * getDeviceName ( int num )

Возвращает имя устройства по его индексу.
### Аргументы

- *int* **num** - Индекс устройства.

### Возвращаемое значение

Имя устройства.
## int getNumDevices ( )

Возвращает общее количество доступных устройств.
### Возвращаемое значение

Количество устройств.
## void updateDeviceList ( )

Обновляет список доступных устройств каждые 5 секунд.
