# Класс Unigine.SystemDialog (CPP)

**Заголовочный файл:** #include <UnigineWindowManager.h>


Этот класс используется для создания и управления системными диалоговыми окнами, отображающими информационные сообщения, предупреждения и сообщения об ошибках.


## Класс SystemDialog

### Методы класса

---

## SystemDialog ( )

Конструктор.
## void setType ( int type )

Устанавливает тип системного диалогового окна.
### Аргументы

- *int* **type** - Устанавливаемый тип диалогового окна: одно из значений [TYPE_*](#TYPE_ERROR).

## int getType ( )

Возвращает текущий тип системного диалогового окна.
### Возвращаемое значение

Устанавливаемый тип диалогового окна: одно из значений [TYPE_*](#TYPE_ERROR).
## void setTitle ( const char * title )

Устанавливает новый заголовок для системного диалогового окна.
### Аргументы

- *const char ** **title** - Устанавливаемый заголовок диалогового окна.

## const char * getTitle ( )

Возвращает текущий заголовок системного диалогового окна.
### Возвращаемое значение

Текущий заголовок диалогового окна.
## void setMessage ( const char * message )

Устанавливает новое сообщение системного диалогового окна.
### Аргументы

- *const char ** **message** - Устанавливаемое сообщение диалогового окна.

## const char * getMessage ( )

Возвращает текущее сообщение системного диалогового окна.
### Возвращаемое значение

Текущее сообщение диалогового окна.
## void setDefaultButtonReturn ( int val )

Устанавливает кнопку по умолчанию, которая будет нажата, когда пользователь нажимает клавишу *Return* на клавиатуре.
### Аргументы

- *int* **val** - Номер устанавливаемой кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).

## int getDefaultButtonReturn ( )

Возвращает текущую кнопку по умолчанию, которая будет нажата, когда пользователь нажимает клавишу *Return* на клавиатуре.
### Возвращаемое значение

Номер кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).
## void setDefaultButtonEscape ( int escape )

Устанавливает кнопку по умолчанию, которая будет нажата, когда пользователь нажимает клавишу *Escape* на клавиатуре.
### Аргументы

- *int* **escape** - Номер устанавливаемой кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).

## int getDefaultButtonEscape ( )

Возвращает текущую кнопку по умолчанию, которая будет нажата, когда пользователь нажимает клавишу *Escape* на клавиатуре.
### Возвращаемое значение

Номер кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).
## int getNumButtons ( )

Возвращает общее количество кнопок системного диалогового окна.
### Возвращаемое значение

Общее количество кнопок диалогового окна.
## int addButton ( )

Добавляет новую кнопку в системное диалоговое окно.
### Возвращаемое значение

Номер новой добавленной кнопки.
## int addButton ( const char * name )

Добавляет новую кнопку в системное диалоговое окно.
### Аргументы

- *const char ** **name** - Имя добавляемой кнопки.

### Возвращаемое значение

Номер новой добавленной кнопки.
## void removeButton ( int num )

Удаляет кнопку с указанным номером из системного диалогового окна.
### Аргументы

- *int* **num** - Номер удаляемой кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).

## void swapButtons ( int num_0 , int num_1 )

Меняет местами две кнопки с указанными номерами.
### Аргументы

- *int* **num_0** - Номер первой кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).
- *int* **num_1** - Номер второй кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).

## const char * getButtonName ( int num )

Возвращает имя кнопки по её номеру.
### Аргументы

- *int* **num** - Номер кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).

### Возвращаемое значение

Имя кнопки с указанным номером.
## void setButtonName ( int num , const char * name )

Устанавливает новое имя для кнопки с указанным номером.
### Аргументы

- *int* **num** - Номер переименовываемой кнопки в диапазоне от 0 до [total number of buttons](#getNumButtons_int).
- *const char ** **name** - Новое имя, устанавливаемое для кнопки с указанным номером.
