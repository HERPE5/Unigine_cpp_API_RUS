# Класс Unigine.GlobalConfig (CPP)

**Заголовочный файл:** #include <UnigineConfig.h>

> **Примечание:** Этот класс является одиночкой (singleton).


Этот класс используется для управления глобальной конфигурацией — различными персональными настройками, такими как хелперы (каркасное отображение, профайлер и т.д.). По умолчанию эти настройки хранятся в [configuration file](../../../code/configuration_file_cpp.md) `configs/default.global`, но при необходимости расположение файла можно изменить.


### См. также


- Статья [Configuration Files](../../../code/configuration_file_cpp.md).


## Класс GlobalConfig

### Методы класса

---

## void setPath ( const char * path )

***Console*:**`global_config`Устанавливает новый путь к файлу глобальной конфигурации (по умолчанию: `configs/default.global`). Путь может быть указан как абсолютный или относительно папки *[*-data_path*](../../../code/command_line.md#data_path)* или *<project_name>*, если задан *[*-project_name*](../../../code/command_line.md#project_name)*. Этот параметр хранится в следующем файле конфигурации: **[*.boot](../../../code/configuration_file_cpp.md#boot)**.
### Аргументы

- *const char ** **path** - Новый путь к файлу глобальной конфигурации, который нужно установить.

## const char * getPath ( ) const

***Console*:**`global_config`Возвращает текущий путь к файлу глобальной конфигурации (по умолчанию: `configs/default.global`). Этот параметр хранится в следующем файле конфигурации: **[*.boot](../../../code/configuration_file_cpp.md#boot)**.
### Возвращаемое значение

Текущий путь к файлу глобальной конфигурации.
## void setAutosave ( bool autosave )

***Console*:**`global_config_autosave`Устанавливает значение, указывающее, сохраняются ли текущие настройки глобальной конфигурации автоматически в соответствующий файл глобальной конфигурации (по умолчанию `configs/default.global`) при загрузке, закрытии и сохранении мира, а также при завершении работы движка.
### Аргументы

- *bool* **autosave** - true — включить автоматическое сохранение текущих настроек глобальной конфигурации; false — отключить.

## bool isAutosave ( ) const

***Console*:**`global_config_autosave`Возвращает значение, указывающее, сохраняются ли текущие настройки глобальной конфигурации автоматически в соответствующий файл глобальной конфигурации (по умолчанию `configs/default.global`) при загрузке, закрытии и сохранении мира, а также при завершении работы движка.
### Возвращаемое значение

true, если автоматическое сохранение текущих настроек глобальной конфигурации включено; иначе 0.
## bool load ( )

***Console*:**`global_config_load`Загружает глобальную конфигурацию из файла. Чтобы изменить путь к файлу конфигурации, используйте метод [*setPath()*](#setPath_cstr_void).
### Возвращаемое значение

**true**, если глобальная конфигурация успешно загружена из файла; иначе **false**.
## bool save ( ) const

***Console*:**`global_config_save`Сохраняет текущую глобальную конфигурацию в файл. Чтобы изменить путь к файлу конфигурации, используйте метод [*setPath()*](#setPath_cstr_void).
### Возвращаемое значение

**true**, если текущая глобальная конфигурация успешно сохранена в файл; иначе **false**.
## void reset ( )

Сбрасывает настройки в файле глобальной конфигурации к значениям по умолчанию.
