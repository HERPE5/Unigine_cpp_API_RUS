# Класс Unigine::Sound (CPP)

**Заголовочный файл:** #include <UnigineSounds.h>

> **Notice:** Этот класс является одиночкой (singleton).


Управляет общими настройками звука, такими как громкость, скорость звука, коэффициент Доплера, адаптация звука и каналы звукового микшера. Настройки можно загрузить из файла `*.sound` или изменить с помощью соответствующих функций ниже.


В файле `*.sound` настройки звука хранятся в разделе *<sound>*, например:


```xml
<?xml version="1.0" encoding="utf-8"?>
<settings version="2.16.0.2">
	<sound>
		<enabled>1</enabled>
		<sound_manager_load_samples>0</sound_manager_load_samples>
		<sound_manager_sample_static_memory>64</sound_manager_sample_static_memory>
		<sound_manager_sample_stream_memory>16</sound_manager_sample_stream_memory>
		<sound_reverb>2</sound_reverb>
		<sound_occlusion>1</sound_occlusion>
		<al_sound_skip_errors>0</al_sound_skip_errors>
		<scale>1</scale>
		<volume>1</volume>
		<doppler>1</doppler>
		<velocity>343.299988</velocity>
		<adaptation>1</adaptation>
		<attenuation>3</attenuation>
		<hrtf>0</hrtf>
		<source source="0" limit="2"/>
		<source source="1" limit="4"/>
		<source source="2" limit="4"/>
		<source source="4" volume="0.4"/>
	</sound>
</settings>

```


### Пример использования


В приведённом ниже примере показано, как загрузить настройки звука из файла `*.world`, изменить их, а затем сохранить обратно в файл настроек звука. Настройки загружаются при запуске. Пока источник звука (*[AmbientSource](../../../api/library/sounds/class.ambientsource_cpp.md)*) воспроизводится, вы можете использовать клавиатуру для изменения громкости звука, включения и выключения звуков, а также отображения текущей скорости звука. При завершении работы текущие настройки звука сохраняются.


`AppWorldLogic.cpp`


```cpp
#include "AppWorldLogic.h"
#include <UnigineGame.h>
#include <UnigineLog.h>
#include <UnigineProfiler.h>
#include <UnigineSounds.h>

using namespace Unigine;

AmbientSourcePtr source;

int AppWorldLogic::init()
{
	// загружаем настройки звука из файла
	Sound::loadSettings("sound_settings.sound");

	// создаём источник звука, воспроизводящий сэмпл
	source = AmbientSource::create("sounds/ambient_source.oga", 1);
	source->setLoop(1);
	source->play();

	return 1;
}

int AppWorldLogic::update()
{
	// включаем/выключаем звуки в сцене
	if (Input::isKeyPressed(Input::KEY_Z)) {
		Sound::setEnabled(!Sound::isEnabled());
		Log::message("The enabled flag is %d\n", Sound::isEnabled());
	}

	// выводим текущую скорость звука
	if (Input::isKeyPressed(Input::KEY_C)) {
		Log::message("Sound velocity: %f\n", Sound::getVelocity());
	}

	// делаем звук громче
	if (Input::isKeyPressed(Input::KEY_N)) {
		if (Sound::getVolume() != 1.0f) Sound::setVolume(Sound::getVolume() + 0.1f);
		Log::message("The sound is louder %f\n", Sound::getVolume());
	}

	// делаем звук тише
	if (Input::isKeyPressed(Input::KEY_M)) {
		if (Sound::getVolume() > 0.0f) Sound::setVolume(Sound::getVolume() - 0.1f);
		Log::message("The sound is quieter %f\n", Sound::getVolume());
	}

	return 1;
}

int AppWorldLogic::shutdown()
{
	// сохраняем настройки звука в файл
	Sound::saveSettings("sound_settings.sound", 1);

	return 1;
}


```


## Класс Sound

### Методы класса

---

## void setAdaptation ( float adaptation )

Устанавливает окклюзию звука с указанным временем адаптации.
### Аргументы

- *float* **adaptation** - Время адаптации звука к фильтру, используемое, когда источник звука становится перекрытым или наоборот.

## float getAdaptation ( )

Возвращает текущее время, установленное для адаптации звука, которое используется, когда источник звука становится перекрытым или наоборот.
### Возвращаемое значение

Время адаптации звука к фильтру.
## void setAttenuation ( int attenuation )

Устанавливает указанный режим затухания звука. Затухание — это способность звука снижать громкость по мере удаления игрока от него.
### Аргументы

- *int* **attenuation** - Одна из переменных [*ATTENUATION_**](#ATTENUATION_EXPONENT). Значение по умолчанию — [ATTENUATION_LINEAR_CLAMPED](#ATTENUATION_LINEAR_CLAMPED).

## int getAttenuation ( )

Возвращает текущий режим затухания звука.
### Возвращаемое значение

Одна из переменных [*ATTENUATION_**](#ATTENUATION_EXPONENT).
## void setData ( const char * data )

Устанавливает пользовательские данные, связанные с миром. Эта строка записывается непосредственно в файл `*.world`, в дочерний тег *data* тега *sound*, например:
```xml
<world version="2.16.0.2">

	<sound>
		<data>User data</data>
	</sound>

</world>


```


### Аргументы

- *const char ** **data** - Новые пользовательские данные. Данные могут содержать строку в формате XML

## const char * getData ( )

Возвращает пользовательские строковые данные, связанные с миром. Эта строка записывается непосредственно в тег data файла `*.world`, в дочерний тег *data* тега *sound*, например:
```xml
<world version="2.16.0.2">

	<sound>
		<data>User data</data>
	</sound>

</world>


```


### Возвращаемое значение

Пользовательские данные. Данные могут содержать строку в формате XML.
## void setDoppler ( float doppler )

Устанавливает коэффициент Доплера. Этот параметр позволяет усилить или ослабить эффект доплеровского сдвига. По умолчанию установлено значение 1.0f.
### Аргументы

- *float* **doppler** - Коэффициент Доплера.

## float getDoppler ( )

Возвращает текущий коэффициент Доплера. Этот параметр позволяет усилить или ослабить эффект доплеровского сдвига. Значение по умолчанию — 1.0f.
### Возвращаемое значение

Коэффициент Доплера.
## void setEnabled ( int enabled )

Включает или отключает все звуки в сцене.
### Аргументы

- *int* **enabled** - true, чтобы включить все звуки, false, чтобы отключить их.

## int isEnabled ( )

Возвращает значение, указывающее, включены ли звуки в сцене.
### Возвращаемое значение

true, если звуки включены; иначе **false**.
## void setHRTF ( int hrtf )

Включает или отключает режим HRTF (Head Related Transfer Function). Этот режим обеспечивает имитацию объёмного звука для проводных стереонаушников.
### Аргументы

- *int* **hrtf** - true, чтобы включить бинауральный звук; false, чтобы отключить его.

## int isHRTF ( )

Возвращает значение, указывающее, включён ли бинауральный звук HRTF (Head Related Transfer Function). HRTF обеспечивает имитацию объёмного звука для проводных стереонаушников.
### Возвращаемое значение

true, если бинауральный звук включён; иначе false.
## void setSourceReverbMode ( int mode )

Устанавливает режим реверберации звука.
### Аргументы

- *int* **mode** - Режим реверберации. Одна из переменных [REVERB_*](#REVERB_DISABLED). Значение по умолчанию — [REVERB_MULTIPLE](#REVERB_MULTIPLE).

## int getSourceReverbMode ( )

Возвращает текущий режим реверберации звука.
### Возвращаемое значение

Текущий режим реверберации звука. Одна из переменных [REVERB_*](#REVERB_DISABLED). Значение по умолчанию — [REVERB_MULTIPLE](#REVERB_MULTIPLE).
## void setSourceOcclusion ( int occlusion )

Включает или отключает окклюзию звуков. Если включено, звук будет перекрываться, когда между слушателем и источником звука находятся другие узлы.
### Аргументы

- *int* **occlusion** - true, чтобы включить окклюзию звуков, false, чтобы отключить её.

## int isSourceOcclusion ( )

Возвращает значение, указывающее, включена ли окклюзия звуков. Если включено, звук будет перекрываться, когда между слушателем и источником звука находятся другие узлы.
### Возвращаемое значение

true, если окклюзия звуков включена; иначе false.
## void setScale ( float scale )

Устанавливает временной масштаб для воспроизведения звука.
### Аргументы

- *float* **scale** - Временной масштаб звука. Указанное значение ограничивается диапазоном **[0; 2]**.

## float getScale ( )

Возвращает текущий временной масштаб для воспроизведения звука.
### Возвращаемое значение

Временной масштаб звука.
## void setSourceLimit ( int source , int limit )

Ограничивает количество одновременно воспроизводимых источников звука на один канал микшера. Эта настройка также доступна в глобальных [sound settings](../../../editor2/settings/sound_global/index.md#volume_channels) редактора.
### Аргументы

- *int* **source** - Номер [channel](../../../principles/bit_masking/index.md#source_mask) микшера (от **0** до **31**).
- *int* **limit** - Максимальное количество источников звука, которые могут воспроизводиться одновременно.

## int getSourceLimit ( int source )

Возвращает текущее количество одновременно воспроизводимых источников звука на один канал микшера.
### Аргументы

- *int* **source** - Номер канала микшера (от **0** до **31**).

### Возвращаемое значение

Максимальное количество источников звука, которые могут воспроизводиться одновременно.
## void setSourceVolume ( int source , float volume )

Устанавливает громкость указанного канала микшера.
### Аргументы

- *int* **source** - Номер канала микшера (от **0** до **31**).
- *float* **volume** - Громкость канала. Указанное значение ограничивается диапазоном **[0;1]**, где 0 означает приглушённый звук, а 1 — максимальную громкость.

## float getSourceVolume ( int source )

Возвращает текущую громкость указанного канала микшера.
### Аргументы

- *int* **source** - Номер канала микшера (от **0** до **31**).

### Возвращаемое значение

Громкость указанного канала микшера. Возвращаемое значение находится в диапазоне [0;1], где 0 означает приглушённый звук, а 1 — максимальную громкость.
## float getTotalTime ( )

## float getVelocity ( )

Если игроки перемещаются очень быстро, вам может потребоваться скорректировать это значение, чтобы предотвратить чрезмерное искажение звука доплеровским сдвигом.

Текущее значение скорости для расчёта доплеровского сдвига.

## int loadSettings ( const char * name , bool clear = false )

Загружает настройки звука из указанного файла.
### Аргументы

### Аргументы

true, если состояние звука успешно загружено; иначе false.
## void renderWorld ( int force )

Принудительно обновляет звуковую систему: все изменения звука (такие как события *[play()](../../../api/library/sounds/class.ambientsource_cpp.md#play_void)* или *[stop()](../../../api/library/sounds/class.ambientsource_cpp.md#stop_void)* и изменения параметров) будут применены сразу. Звуковой поток обновляется с частотой 30 кадров в секунду. Представьте, что у вас воспроизводится [sound sample](../../../api/library/sounds/class.ambientsource_cpp.md), и вы хотите обновить время, с которого должен воспроизводиться сэмпл. Но воспроизведение не остановится немедленно, поэтому новое значение времени не будет установлено. Вам нужно принудительно обновить звуковой поток после его остановки:
```cpp
AmbientSourcePtr sound = AmbientSource::create("ambient_sample.oga");
// ...
// проверяем, воспроизводится ли звуковой сэмпл
if (sound->isPlaying())
{
	// останавливаем воспроизведение сэмпла
	sound->stop();
	// принудительно обновляем звуковой поток
	Sound::renderWorld(1);
	// обновляем время
	sound->setTime(45.0f);
	// продолжаем воспроизведение сэмпла
	sound->play();
}


```


### Аргументы

- *int* **force** - true для принудительного обновления звуковой системы; иначе false.

### Аргументы

- *int* **force** - Флаг принудительного сохранения, указывающий, включено ли принудительное сохранение настроек звука.

### Возвращаемое значение

## bool saveState ( const Ptr < Stream > & stream )

Сохраняет состояние звука в поток. Состояние звука включает такие настройки, как громкость, скорость, адаптация, коэффициент Доплера, временной масштаб и количество источников звука с их громкостью.
**Пример** использования методов saveState() и [restoreState()](#restoreState_Stream_int):


```cpp
// создаём источник звука, воспроизводящий сэмпл, и устанавливаем его состояние
source = AmbientSource::create("sounds/ambient_source.oga", 1);
Unigine::Sound::setScale(0.75f);

// сохраняем состояние
BlobPtr blob_state = Blob::create();
Unigine::Sound::saveState(blob_state);

// изменяем состояние
Unigine::Sound::setScale(1.25f);

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем указатель в начало blob-объекта
Unigine::Sound::restoreState(blob_state);


```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель Stream.

### Возвращаемое значение

true, если состояние звука успешно сохранено; иначе false.
## int restoreState ( const Ptr < Stream > & stream )

Восстанавливает состояние звука из потока. Состояние звука включает такие настройки, как громкость, скорость, адаптация, коэффициент Доплера, временной масштаб и количество источников звука с их громкостью.
**Пример** использования методов [saveState()](#saveState_Stream_int) и restoreState():


```cpp
// создаём источник звука, воспроизводящий сэмпл, и устанавливаем его состояние

// изменяем состояние
Unigine::Sound::setScale(1.25f);

// восстанавливаем состояние
blob_state->seekSet(0);				// возвращаем указатель в начало blob-объекта
Unigine::Sound::restoreState(blob_state);


```


### Аргументы

- *const [Ptr](../../../api/library/common/class.ptr_cpp.md)<[Stream](../../../api/library/common/class.stream_cpp.md)> &* **stream** - Умный указатель Stream.

### Возвращаемое значение

true, если состояние звука успешно восстановлено; иначе false.
