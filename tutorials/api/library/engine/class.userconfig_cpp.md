# Класс Unigine.UserConfig (CPP)

**Заголовочный файл:** #include <UnigineConfig.h>

> **Notice:** Этот класс является одиночкой (singleton).


Этот класс используется для управления пользовательской конфигурацией — различными персональными настройками, такими как вспомогательные инструменты (каркасное отображение, профайлер и т.д.). По умолчанию эти настройки хранятся в [configuration file](../../../code/configuration_file_cpp.md) `configs/default.user`, но при необходимости вы можете изменить расположение файла.


### См. также


- Статья о [Configuration Files](../../../code/configuration_file_cpp.md).


## Класс UserConfig

### Методы класса

---

## void setPath ( const char * path )

***Консольная команда*:**`user_config`Устанавливает новый путь к файлу пользовательской конфигурации (по умолчанию: `configs/default.user`). Путь можно указать как абсолютный или относительный к папке *[*-data_path*](../../../code/command_line.md#data_path)* или *<project_name>*, если задан параметр *[*-project_name*](../../../code/command_line.md#project_name)*. Этот параметр хранится в следующем файле конфигурации: **[*.boot](../../../code/configuration_file_cpp.md#boot)**.
### Аргументы

- *const char ** **path** - Новый путь к файлу пользовательской конфигурации.

## const char * getPath ( ) const

***Консольная команда*:**`user_config`Возвращает текущий путь к файлу пользовательской конфигурации (по умолчанию: `configs/default.user`). Этот параметр хранится в следующем файле конфигурации: **[*.boot](../../../code/configuration_file_cpp.md#boot)**.
### Возвращаемое значение

Текущий путь к файлу пользовательской конфигурации.
## void setAutosave ( bool autosave )

***Консольная команда*:**`user_config_autosave`Устанавливает значение, указывающее, сохраняются ли текущие настройки пользовательской конфигурации автоматически в соответствующий файл конфигурации пользователя (по умолчанию `configs/default.user`) при загрузке, закрытии и сохранении мира, а также при завершении работы движка.
### Аргументы

- *bool* **autosave** - true, чтобы включить автоматическое сохранение текущих настроек пользовательской конфигурации; false — чтобы отключить.

## bool isAutosave ( ) const

***Консольная команда*:**`user_config_autosave`Возвращает значение, указывающее, сохраняются ли текущие настройки пользовательской конфигурации автоматически в соответствующий файл конфигурации пользователя (по умолчанию `configs/default.user`) при загрузке, закрытии и сохранении мира, а также при завершении работы движка.
### Возвращаемое значение

true, если автоматическое сохранение текущих настроек пользовательской конфигурации включено; иначе 0.
## bool load ( )

***Консольная команда*:**`user_config_load`Загружает пользовательскую конфигурацию из файла. Чтобы изменить путь к файлу конфигурации, используйте метод [*setPath()*](#setPath_cstr_void).
### Возвращаемое значение

**true**, если пользовательская конфигурация успешно загружена из файла; иначе **false**.
## bool save ( ) const

***Консольная команда*:**`user_config_save`Сохраняет текущую пользовательскую конфигурацию в файл. Чтобы изменить путь к файлу конфигурации, используйте метод [*setPath()*](#setPath_cstr_void).
### Возвращаемое значение

**true**, если текущая пользовательская конфигурация успешно сохранена в файл; иначе **false**.
## void reset ( )

Сбрасывает настройки в файле пользовательской конфигурации на значения по умолчанию.
