# Camera Matrices


В UNIGINE у камеры есть 2 матрицы: *view* и *projection*. Они используются при рендеринге изображения с камеры в [viewport](../../../api/library/rendering/class.viewport_cpp.md).


> **Примечание:** В UNIGINE матрица view называется **modelview**. Однако далее в тексте мы будем использовать общий термин *view*, чтобы избежать путаницы в терминах.


Прежде чем перейти к основным аспектам матриц камеры, необходимо узнать особенности системы координат, используемой UNIGINE, и освежить общие знания о векторных пространствах и матрицах трансформации, используемых при рендеринге вершин.


## Система координат


3D-пространство в UNIGINE представлено правосторонней декартовой системой координат: оси **X** и **Y** образуют горизонтальную плоскость, ось **Z** направлена вверх.


![](coordinates.gif)

*Система координат*


### Оси и направления


Для узлов в виртуальной сцене:


- Ось **+Z** считается ***направлением вверх***. Чтобы переместить узел вверх/вниз, [translate](../../../code/fundamentals/matrix_transformations/index_cpp.md#translation_matrix) его вдоль оси **Z**.
- Ось **+Y** считается ***направлением вперёд***. Чтобы переместить узел вперёд/назад, [translate](../../../code/fundamentals/matrix_transformations/index_cpp.md#translation_matrix) его вдоль оси **Y**.


![](object_directions.png)

*Векторы направления объекта*


Для виртуальной камеры:


- Ось **+Y** считается ***направлением вверх***.
- Ось **-Z** считается ***направлением вперёд***.


Камера со стандартной единичной матрицей трансформации смотрит вниз:


![](camera_directions.png)

*Векторы направления камеры*


### Работа с направлениями


Как видите, векторы направления узлов и камер отличаются. Например, если вам нужно получить направление вперёд для узла, следует вызвать метод *getAxisY()* для его матрицы трансформации:


```cpp
// получаем матрицу трансформации узла
Mat4 t = node->getWorldTransform();
// получаем вектор "вперёд" узла из матрицы
vec3 node_forward = t.getAxisY();

```


А если вам нужно получить направление вперёд для камеры, следует вызвать метод *-getAxisZ()* для её матрицы трансформации:


```cpp
// получаем обратную matrix modelview, так как она равна матрице мировой трансформации
mat4 camera_transform = camera->getIModelview();
// получаем вектор "вперёд" камеры из матрицы
vec3 camera_forward = -camera_transform.getAxisZ(); // будет возвращён отрицательный вектор Z

```


Однако камера может быть [set to a player node](../../../api/library/players/class.player_cpp.md#setCamera_Camera_void). В этом случае, если вы просто вызовете *getAxisY()*, как для любого другого узла, вы получите направление вверх камеры. Чтобы избежать этого, реализуйте следующее:


```cpp
// получаем матрицу трансформации узла
Mat4 t = node->getWorldTransform();
// получаем вектор "вперёд" из матрицы
vec3 forward = vec3(node->isPlayer() ? -t.getAxisZ() : t.getAxisY());

```


Направление вперёд узла/камеры (если она назначена узлу игрока) также можно получить с помощью метода *[Node::getDirection()](../../../api/library/nodes/class.node_cpp.md#getDirection_int_vec3)/[getWorldDirection()](../../../api/library/nodes/class.node_cpp.md#getWorldDirection_int_vec3)*:


```cpp
vec3 forward = node->getDirection(node->isPlayer() ? Math::AXIS_NZ : Math::AXIS_Y);

```


> **Примечание:** Вы можете изменить направления узла с помощью метода *[Node::setDirection()](../../../api/library/nodes/class.node_cpp.md#setDirection_vec3_vec3_int_void)/[setWorldDirection()](../../../api/library/nodes/class.node_cpp.md#setWorldDirection_vec3_vec3_int_void)*.


## Векторные пространства и матрицы трансформации


Существуют следующие векторные пространства:


- **Local space** - пространство, в котором все вершины объекта определены относительно центра этого объекта.
- **World space** - пространство, в котором все вершины объекта определены относительно центра мира.
- **View space** - пространство, в котором все вершины объекта определены относительно камеры.
- **Clip space** - пространство, в котором все вершины объекта определены в кубоиде с размерами [-1;1] по каждой оси. Координата Z вершины определяет, насколько далеко вершина находится от экрана.
- **Screen space** - пространство, в котором все вершины объекта сплющены и имеют экранные координаты.


При рендеринге вершина преобразуется из одного пространства в другое в следующем порядке:


![](space_transformations.png)


Используются следующие матрицы для преобразования между пространствами:


- **World Transformation Matrix** хранит трансформацию объекта относительно начала координат мира. Эта матрица используется для преобразования вершин объекта из локального пространства в мировое: матрица умножается на каждую вершину объекта. В UNIGINE такое преобразование выполняется автоматически при добавлении узла в мир. Когда узел добавляется в мир как дочерний узел другого узла, у него также есть **Local Transformation Matrix**, хранящая трансформацию объекта относительно его родителя. Чтобы преобразовать локальную матрицу трансформации такого объекта в мировую, локальная матрица трансформации объекта умножается на локальную матрицу трансформации родителя. Подробнее о локальных и мировых матрицах трансформации см. в главе [Matrix Hierarchy](../../../code/fundamentals/matrix_transformations/index_cpp.md#hierarchy).
- **[View Matrix](#view_matrix)** используется для преобразования вершин объекта из мирового пространства в пространство view. > **Примечание:** В UNIGINE матрица view называется **modelview**.
- **[Projection Matrix](#projection_matrix)** используется для преобразования вершин объекта из пространства view в пространство clip.


Каждый узел, добавленный в мир, имеет *матрицу мировой трансформации*. Однако передавать эту матрицу в шейдер для рендеринга вершин нецелесообразно: это приведёт к потере точности из-за преобразования координат из double во float. По этой причине в UNIGINE узел сначала преобразуется в пространство view: произведение матрицы мировой трансформации и матрицы view вычисляется на CPU и передаётся в шейдер. Такая матрица называется *Modelview* (в общем смысле).


Таким образом, преобразование координат вершины объекта можно представить следующей формулой:


```text
VertexClip = ProjectionMatrix * ModelviewMatrix * VertexLocal

```


Здесь *ModelviewMatrix* - это произведение матрицы мировой трансформации и матрицы view. Порядок умножения матриц читается справа налево.


## View Matrix


В UNIGINE **View** матрица - это ***матрица 4x4***, которая управляет тем, как камера смотрит на сцену. [view matrix](../../../api/library/rendering/class.camera_cpp.md#getModelview_Mat4) равна *обратной матрице мировой трансформации камеры*: она хранит позицию и поворот камеры в мировом пространстве.


> **Примечание:** Как упоминалось выше, в UNIGINE матрица view называется **modelview**.


Матрица используется для преобразования вершин объекта из мирового пространства в пространство view (координаты вершин задаются относительно начала координат камеры): матрица view камеры умножается на матрицу мировой трансформации объекта, а затем результирующая матрица умножается на вершины объекта.


| ![](world_space_camera.png) | ![](view_space.png) |
|---|---|
| *Объект и камера в мировом пространстве* | *Объект в пространстве view* |


> **Примечание:** Координаты всех точек и векторов, передаваемых в шейдеры, преобразуются в пространство view (т.е. вычисляются относительно камеры). Это делается во избежание [precision loss](#modelview_calculation).


## Projection Matrix


**Projection** матрица - это матрица, определяющая, как вершины рендерятся на экране. Значения матрицы проекции зависят от типа проекции:


- Для [orthographic projection](../../../principles/world_management/index.md#camera_orthographic) используется следующая матрица: ![](ortho_proj_matrix.gif)
- Для [perspective projection](../../../principles/world_management/index.md#camera_perspective) используется следующая матрица: ![](perspective_proj_matrix.gif)


По умолчанию матрица проекции камеры не хранит соотношение сторон экрана (ширина к высоте): *коррекция соотношения сторон* выполняется автоматически для текущего viewport. Если выполняется ручная коррекция соотношения сторон, [automatic aspect correction](../../../api/library/rendering/class.viewport_cpp.md#setAspectCorrection_int_void) для viewport должна быть отключена во избежание некорректных результатов.


Если вы меняете FOV (или ширину и высоту для ортографической проекции), ближнюю и дальнюю плоскости отсечения, матрица обновляется.


Матрица проекции используется для преобразования вершин объекта из *пространства view* в *пространство clip*. Это пространство представлено кубоидом с размерами [-1;1] по каждой оси и используется для отсечения вершин: все вершины внутри этого объёма будут отрендерены на экране. В этом пространстве координата Z каждой вершины определяет, насколько далеко вершина находится от экрана.


> **Примечание:** В UNIGINE в шейдер фактически передаётся *матрица проекции с обратной глубиной (reverse depth)* для выполнения преобразования: в этой матрице элементы, хранящие ближнюю и дальнюю плоскости отсечения, умножаются на -1.


Затем координаты вершин в пространстве clip автоматически преобразуются в нормализованные координаты устройства с помощью перспективного деления. Отображение этих координат в пространство экрана выполняется на GPU с использованием *вектора трансформации viewport*, хранящего следующее:


```glsl
(width, height, 1/width, 1/height)

```
