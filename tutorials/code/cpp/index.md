# C++ API


Этот раздел содержит информацию о Unigine C++ API. Он состоит из двух частей:


- [Reference documentation](../../api/index.md)
- [Common usage examples](../../code/cpp/usage/index.md)


Движок Unigine позволяет экспортировать код C++ в UnigineScript и наоборот, обеспечивая гибкое расширение функциональности Unigine. Он позволяет экспортировать или импортировать [variables](../../code/cpp/usage/script/variables.md), [functions](../../code/cpp/usage/script/functions.md) и [classes](../../code/cpp/usage/script/classes.md). Также возможна [load a custom library dynamically](../../code/cpp/plugin.md) во время выполнения движка.


Все файлы заголовков C++ API находятся в директории `Unigine/include/`.
