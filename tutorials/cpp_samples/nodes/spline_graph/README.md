# Spline Graph

Этот пример демонстрирует, как создавать и визуализировать сплайн-граф (***SplineGraph***) и перемещать объект вдоль него. **SplineGraph** создаётся на этапе *Initialization* путём добавления точек и сегментов с помощью методов API *addPoint(), addSegment()*, с контрольными точками, размещёнными случайным образом.

-Создаётся меш куба и добавляется в сцену.
-На этапе *Update* куб перемещается вдоль сплайна, переключаясь между последовательными сегментами и вычисляя точку на нём с помощью методов *calcSegment**.
