# Water Waves Customization Gerstner

Этот пример демонстрирует, как управлять спектром волн **Global Water** в режиме **Manual** через API, задавая параметры волн (октавы - набор волн определённого масштаба/частоты, количество на октаву, длина, амплитуда, фаза и крутизна).

Поскольку все параметры волн управляются на стороне CPU, их можно динамически генерировать, изменять или сохранять для воспроизводимых результатов и внешней интеграции (например, для обработки пакетов Weather Control от IOS).

> [!NOTE]Максимальное количество волн - **256**, но более высокие значения значительно влияют на производительность, поэтому рекомендуется держать количество ниже 100 и использовать минимально возможное число.
