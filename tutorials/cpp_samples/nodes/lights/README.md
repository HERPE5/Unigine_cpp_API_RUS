# Lights

Этот пример демонстрирует, как создавать источники света и изменять их параметры во время выполнения:

-**World Light** - бесконечно удалённый источник света, отбрасывающий ортографически спроецированные лучи на сцену.
-**Projected Light** - источник света, испускающий свет из одной точки, формируя сфокусированный луч, направленный в определённом направлении.
-**Omni Light** - точечный источник, испускающий свет во всех направлениях (360 градусов) и реалистично воспроизводящий отбрасывание теней.
