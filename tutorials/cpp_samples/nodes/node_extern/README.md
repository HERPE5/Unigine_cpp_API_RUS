# Node Extern

UNIGINE позволяет расширять свою готовую функциональность различными способами, включая добавление пользовательских узлов с индивидуальным поведением, функциями и визуализацией (при необходимости).

Этот пример демонстрирует, как реализовать пользовательский узел на основе класса **NodeExtern**, с визуализацией ограничивающего объёма и настройкой параметров узла во время выполнения (например, цвета ограничивающего объёма). Такие узлы затем можно добавлять в сцену через API.
