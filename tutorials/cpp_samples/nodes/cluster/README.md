# Cluster

Этот пример демонстрирует динамическое управление **ObjectMeshCluster** в UNIGINE, показывая, как добавлять/удалять экземпляры мешей во время выполнения через взаимодействие с пользователем. **Mesh Cluster** позволяет запекать идентичные меши (с одинаковым материалом, применённым к их поверхностям) в один объект, что обеспечивает менее загруженное пространственное дерево, уменьшает количество выборок текстур и ускоряет рендеринг.

**Основные возможности:**

-**Размещение и удаление** - клик по пустой земле добавляет новый меш в точке клика, клик по существующей геометрии кластера удаляет выбранный экземпляр меша из кластера
-**Трассировка лучей и проверка пересечений** - выпускает луч от камеры через позицию мыши, чтобы определить, кликнул ли пользователь по мешу кластера или по террейну

**Варианты использования:**

-Разбрасывание объектов вроде камней, травы или мусора
-Динамическое редактирование уровня и дизайн окружения
-Приложения, чувствительные к производительности, с большим количеством похожих экземпляров мешей.
