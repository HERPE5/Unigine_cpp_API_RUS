# Water Waves Generation Field Height

Этот пример иллюстрирует эффект симуляции волн на поверхности воды, созданной с помощью объекта **Field Height**.

Код генерирует карту высот, которая динамически модулируется во времени синусоидальной функцией, создавая колеблющееся визуальное представление.

Такой подход может быть полезен для создания кильватерных волн от кораблей, возмущений воды вокруг плавающих объектов, таких как буи, и многого другого.
