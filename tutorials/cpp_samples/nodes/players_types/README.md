# Player Types

Этот пример демонстрирует, как создавать и настраивать четыре доступных типа **Players**:

-**PlayerDummy** - камера с ручным управлением, не имеющая физических свойств и не способная сталкиваться с объектами.
-**PlayerPersecutor** - камера преследования от третьего лица, следующая за целью с настраиваемой дистанцией.
-**PlayerSpectator** - камера свободного полёта без физического тела.
-**PlayerActor** - игрок с твёрдым физическим телом, аппроксимируемым капсулой, обладающий физическими свойствами. Может передвигаться только по земле.

Каждый игрок создаётся с соответствующими настройками (столкновения, параметры движения, настройки камеры), а панель GUI позволяет **переключаться между ними во время выполнения**. Также можно изменять параметры камеры, такие как **FOV и ближняя/дальняя плоскости отсечения**.
