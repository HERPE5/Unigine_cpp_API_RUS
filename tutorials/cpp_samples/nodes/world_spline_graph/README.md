# World Spline Graph

Этот пример демонстрирует, как интегрировать систему геометрии на основе сплайнов в окружение мира.

Создаётся экземпляр класса *WorldSplineGraph*, заполняемый данными из внешнего файла `*.spl`, который определяет пространственную структуру графа. Затем к каждому сегменту применяется геометрия из предопределённого файла `*.node`, отрисовываемая в режиме растяжения, чтобы она бесшовно соответствовала форме и длине каждого сплайна.

Такой подход позволяет эффективно строить дороги, трубопроводы, рельсы и другие непрерывные структуры в мире.
