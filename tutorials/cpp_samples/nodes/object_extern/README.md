# Object Extern

UNIGINE позволяет расширять свою готовую функциональность различными способами, включая добавление собственных объектов с пользовательской геометрией и поведением (например, пользовательские системы частиц, меши с пользовательским отсечением, анимированные решения рендеринга толпы на GPU и т.д.).

Этот пример демонстрирует, как реализовать пользовательские объекты на основе класса **ObjectExtern**, с пользовательским рендерингом, физикой и свойствами, сохраняя при этом полную интеграцию с движком. Такие объекты затем можно добавлять в сцену через API.
