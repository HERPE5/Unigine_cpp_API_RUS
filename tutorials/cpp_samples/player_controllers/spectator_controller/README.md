# Spectator Controller

Этот пример реализует контроллер камеры **Spectator** от первого лица с настраиваемым движением и определением физических столкновений с помощью **сферической формы столкновений**, назначенной реагировать на столкновения с геометрией (например, с террейном) в мире.

Параметры движения, такие как скорость, ускорение при спринте, скорость поворота и чувствительность мыши, можно настраивать в реальном времени с помощью слайдеров в разделе *Parameters*.

**Варианты использования:**

-Создание пользовательских инструментов камеры с учётом физики для редактирования сцен или тестирования.
-Навигация и исследование 3D-сцен от первого лица с сохранением настраиваемого взаимодействия с геометрией.
