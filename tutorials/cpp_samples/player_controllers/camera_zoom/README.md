# Camera Zoom

Этот пример демонстрирует систему масштабирования и фокусировки камеры, позволяющую пользователю осматривать предопределённые цели в сцене и настраивать уровень масштабирования. По сцене расставлены три информационные панели, каждая с внутримировой GUI-панелью, показывающей расстояние до игрока и размеры. Эти панели обновляются автоматически в реальном времени на основе позиции игрока.

Пользователь может выбрать любую цель с помощью специальных кнопок UI, что заставляет камеру сфокусироваться на выбранном объекте.

Масштабирование управляется слайдером, регулирующим поле обзора камеры. По мере изменения FOV связанные параметры, такие как чувствительность мыши и масштабирование дистанции рендеринга, также корректируются для обеспечения согласованного восприятия. Кнопка сброса восстанавливает все значения по умолчанию.

Такая настройка полезна для сценариев, требующих просмотра с фокусом на объекте, таких как инструменты осмотра, прогулки по сцене или любых других случаев, где настраиваемое масштабирование и фокусировка камеры помогают пользователям лучше понять или исследовать сцену.
