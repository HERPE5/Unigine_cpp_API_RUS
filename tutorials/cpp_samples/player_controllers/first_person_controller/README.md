# First-Person Controller

Этот пример демонстрирует контроллер персонажа от первого лица, реализованный как компонент, прикреплённый к *PlayerDummy*.

Контроллер использует коллизии Shape-Surface для определения земли, стен и наклонных поверхностей и применяет движение с учётом наклона для обеспечения стабильной ходьбы по наклонной геометрии. Он поддерживает ходьбу, бег, прыжки, движение в воздухе, плавное приседание и вращение камеры с вертикальными ограничениями. Автоматическое преодоление ступеней позволяет персонажу преодолевать небольшие препятствия, а коллизии Shape-Shape используются для взаимодействия с физическими объектами путём приложения импульсов.
