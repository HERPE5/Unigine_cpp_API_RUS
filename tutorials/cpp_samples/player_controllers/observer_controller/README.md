# Observer Controller

Этот пример воспроизводит свободную камеру, используемую в UnigineEditor. Камера предлагает следующие ключевые возможности:

-**Режим свободного полёта** Свободное перемещение камеры во всех направлениях с помощью клавиатуры и мыши.
-**Фокусировка на объектах** Центрирование камеры на любом выбранном объекте с автоматической регулировкой дистанции.
-**Масштабирование и панорамирование** Приближение и отдаление, а также панорамирование с сохранением направления обзора.
-**Меню управления скоростью** Переключение между предустановленными скоростями движения (**1-3**) или настройка пользовательских значений скорости.
-**Управление позицией** Установка или телепортация камеры в конкретные мировые координаты через меню.
