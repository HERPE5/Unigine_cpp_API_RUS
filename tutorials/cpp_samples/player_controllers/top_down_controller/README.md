# Top-Down Controller

Этот пример демонстрирует, как настроить и управлять контроллером камеры вида сверху для геймплея в стиле стратегии или тактики в реальном времени. Он реализует основные возможности, типичные для таких игр, включая движение камеры, масштабирование, вращение, прокрутку у краёв экрана, выбор юнитов и отслеживание фокуса. Реализация основана на узле *PlayerDummy*.
