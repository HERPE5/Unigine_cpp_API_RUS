# Orbit Camera Controller

Этот пример демонстрирует орбитальную камеру, вращающуюся вокруг цели.
Компонент *CameraOrbitSample* обеспечивает орбитальное движение камеры вокруг целевого объекта с использованием узла *PlayerDummy* и компонента *CameraControls* для обработки настраиваемого управления движением камеры и масштабированием.

Поведение камеры можно настроить с помощью доступных параметров: *Angular Speed, Zoom Speed, Min/Max Distance* и *Min/Max Vertical Angle*. Параметр *Target* определяет объект, вокруг которого вращается камера.
