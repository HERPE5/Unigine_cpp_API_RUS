# Two-Point Perspective

Этот пример показывает, как симулировать проекцию с двухточечной перспективой с помощью техники сдвига объектива, реализованной через вторичный *Dummy Player*. При включении пример динамически регулирует матрицу проекции фиктивной камеры, чтобы визуально выровнять вертикальные линии, сохраняя направление обзора.

Эффект достигается путём регулировки матрицы проекции экземпляра *PlayerDummy* в соответствии с углом наклона активной камеры. Во время фазы рендеринга *Dummy Player* временно заменяет главную камеру для применения изменённого обзора.

Такой подход можно использовать для архитектурной визуализации или стилизованных эффектов камеры, где желательна более ортографическая вертикальная перспектива.
