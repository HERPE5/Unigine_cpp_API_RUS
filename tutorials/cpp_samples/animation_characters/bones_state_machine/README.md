# Bones: State Machine [Animation Graph]

Этот пример демонстрирует создание анимированного конечного автомата на основе ObjectMeshSkinned.
Конечный автомат - это паттерн проектирования, который управляет различными состояниями объекта&#8212;такими как ожидание, ходьба или крадущийся шаг&#8212;и обрабатывает переходы между ними. Пример показывает, как настраивать конечные автоматы с динамическим управлением ходьбой, поворотом в состоянии ожидания и бегом.

Реализация конечных автоматов позволяет создавать сложное, гибкое поведение персонажей.
