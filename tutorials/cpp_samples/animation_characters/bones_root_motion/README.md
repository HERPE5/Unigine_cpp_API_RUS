# Bones: Root Motion [Animation Graph]

Этот пример демонстрирует реализацию техники root motion.

Слева - обычная зацикленная анимация. Справа смещение корневой кости перемещает сам объект.

Root motion особенно полезен для реалистичного движения персонажей, транспортных средств или объектов в играх и симуляциях.
