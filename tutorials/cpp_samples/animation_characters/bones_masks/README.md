# Bones: Masks

Этот пример демонстрирует использование масок костей для выборочного применения данных анимации.

Маски позволяют создавать сложные комбинации анимаций. Например, можно сохранить исходные движения тела, ограничив анимацию головы или рук только вращением, или масштабированием отдельных костей.

В этом примере правая (детская) модель имеет компонент, перечисляющий кости с использованием маски только вращения из анимации левой (взрослой) модели. Масштаб маскируется, поэтому перечисленные кости сохраняют исходный размер. Если маска не применена, кости выглядят растянутыми, поскольку все трансформации (включая масштаб) копируются со взрослой модели. Это видно на руках детской модели, где маска не используется.

Этот метод отлично подходит для многослойных анимаций, позволяя смешивать движения, добавлять эффекты или исключать определённые части модели для достижения конкретных визуальных результатов или поведения без дублирования полных наборов анимаций.
