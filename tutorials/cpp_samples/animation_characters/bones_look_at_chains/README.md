# Bones: Look At Chains

Этот пример демонстрирует использование LookAt-цепочек для наведения на цель.

Цепочка содержит кости позвоночника и головы. Задавая разные веса для каждой кости, можно регулировать эффект наведения. Ограничение представлено вектором полюса, задающим плоскость для направления "вверх" каждой кости.

LookAt-цепочки обеспечивают интерактивное управление позицией и ориентацией глаз, головы, плеч и других частей тела персонажа. Это полезно для анимации игрового окружения в различных ситуациях.
