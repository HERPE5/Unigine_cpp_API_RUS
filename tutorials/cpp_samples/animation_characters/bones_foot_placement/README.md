# Bones: Foot Placement

Этот пример демонстрирует упрощённый вариант размещения стоп на поверхности с помощью IK-цепочек.
Для определения контакта с поверхностью применяется трассировка лучей: в каждом кадре луч отправляется вниз от позиции стопы для поиска пересечений с поверхностью. Полученная точка контакта и нормаль поверхности затем используются для корректировки позиции и ориентации костей стопы, обеспечивая реалистичное размещение стоп.
