# Bones: Inverse Kinematics

Этот пример демонстрирует управление костями с помощью обратной кинематики

Вектор полюса используется как ограничение, задающее плоскость сгибания сустава.

Пример полезен для создания анимаций, в которых кости персонажа автоматически позиционируются и ориентируются для достижения реалистичного движения.
