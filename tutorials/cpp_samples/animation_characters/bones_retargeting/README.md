# Bones: Retargeting [Animation Graph]

Этот пример демонстрирует, как одна и та же анимация может использоваться на скелетах с разными пропорциями.

Пара слева представляет использование анимации без ретаргетинга. Справа анимация ретаргетируется со взрослой модели на детскую. Соотношение длин костей между скелетами учитывается для корректировки компонента позиции.

Ретаргетинг полезен, когда нужно использовать один и тот же источник анимации для разных персонажей или объектов с различными пропорциями, но схожей структурой скелета. Такой подход значительно ускоряет процесс подготовки анимаций.
