# Bones: Constraints

Этот пример демонстрирует использование ограничений вращения костей и показывает, как они влияют на работу обратной кинематики.
Показано, как создать IK-цепочку для костей персонажа, задать целевую позицию и автоматически управлять движением костей для получения реалистичных поз. Цель - это объект, который динамически обновляется в соответствии с позицией камеры игрока.
