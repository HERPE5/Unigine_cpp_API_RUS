# Navigation Sectors Demo

Этот пример демонстрирует несколько материальных шаров, собирающих монеты в кубе с препятствиями, ориентируясь с помощью <i>Navigation Sector</i>. Параметр *Route radius* управляет шириной навигации - увеличение создаёт более широкие пути, сохраняющие безопасное расстояние от препятствий, а уменьшение позволяет прокладывать путь через более узкие пространства.
