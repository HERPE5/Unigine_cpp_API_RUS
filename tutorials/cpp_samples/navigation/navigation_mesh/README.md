# Navigation Mesh

Этот пример демонстрирует настройку поиска пути между двумя точками с препятствиями с помощью *Navigation Mesh*. Параметр *Route radius* управляет шириной навигации - увеличение создаёт более широкие пути, сохраняющие безопасное расстояние от препятствий, а уменьшение позволяет прокладывать путь через более узкие пространства.
