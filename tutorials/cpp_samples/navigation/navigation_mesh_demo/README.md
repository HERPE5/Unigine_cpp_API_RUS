# Navigation Mesh Demo

Этот пример демонстрирует несколько материальных шаров, собирающих монеты на плоскости с препятствиями, ориентируясь с помощью *Navigation Mesh*. Параметр *Route radius* управляет шириной навигации - увеличение создаёт более широкие пути, сохраняющие безопасное расстояние от препятствий, а уменьшение позволяет прокладывать путь через более узкие пространства.
