# Multiple Async Raycast Requests

Этот пример демонстрирует запуск и управление большим количеством асинхронных запросов пересечения на основе лучей одновременно.

Результаты визуализируются в реальном времени, а статистика задержки отображается для анализа производительности.

Такой подход полезен для стресс-тестирования систем пересечения, профилирования задержки асинхронных запросов или создания интерактивных инструментов, опирающихся на высокочастотные пространственные запросы.

В этом примере объект-эмиттер непрерывно вращается и перемещается по вертикали, испуская лучи в нескольких направлениях (по срезам и стекам) для обнаружения пересечений с объектами в мире. Каждый луч обрабатывается асинхронно.

Все активные запросы отслеживаются на завершение. По завершении результаты (точки пересечения и нормали) визуализируются с помощью инструментов *Visualizer*. Гистограмма задержки вычисляется на основе того, сколько кадров прошло между запросом и ответом, и результаты отображаются в *UI*.

Пример использует двойную буферизацию для безопасного многопоточного доступа и демонстрирует эффективное планирование большого числа асинхронных операций.
