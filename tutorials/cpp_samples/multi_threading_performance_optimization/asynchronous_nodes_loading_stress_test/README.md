# Asynchronous Nodes Loading Stress-Test

Этот пример демонстрирует асинхронную загрузку большого количества узлов с помощью класса *AsyncQueue*, обеспечивая при этом корректную активацию в главном потоке.

В UNIGINE узлы мира должны создаваться только из главного потока. Чтобы соблюсти это ограничение и не блокировать главный поток, пример выполняет первоначальную загрузку узла в фоновом потоке, а затем планирует последующую задачу в главном потоке для завершения активации вызовом *updateEnabled()* - метода, регистрирующего узел и его дочерние элементы в пространственной структуре мира.

При включённом встроенном профилировщике можно наблюдать, как движок плавно справляется с растущей нагрузкой, избегая всплесков по кадрам.

Подробную информацию о доступных режимах выполнения, типах потоков и приоритетах см. в API класса *AsyncQueue*.
