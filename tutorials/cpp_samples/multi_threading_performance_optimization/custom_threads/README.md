# Custom Threads

Этот пример показывает определение и управление фоновыми потоками в **UNIGINE** путём наследования от класса *Thread* и переопределения метода *process()*.

Демонстрируются два пользовательских типа потоков:

<ol>
-**InfiniteThread** - непрерывно выводит сообщения во время работы.
-**CountedThread** - выполняет конечное число итераций перед завершением.
</ol>
Потоки запускаются во время инициализации компонента и выполняются параллельно с основным циклом движка. Бесконечный поток явно останавливается через *stop()*, как только конечный поток завершит все итерации.

Этот пример иллюстрирует базовые принципы многопоточности и может служить основой для выноса вычислений или операций *I/O* из главного потока.
