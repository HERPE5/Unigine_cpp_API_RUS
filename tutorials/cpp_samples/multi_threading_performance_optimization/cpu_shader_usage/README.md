# CPU Shader Usage

Этот пример демонстрирует реализацию пользовательского CPU-шейдера путём наследования от класса *CPUShader* для выполнения многопоточной обработки данных вне основного цикла рендеринга.

Система асинхронно обновляет несколько экземпляров *ObjectMeshCluster* с помощью вспомогательной структуры *AsyncCluster*. Каждый кластер поддерживает две свои версии: одну для рендеринга и одну для фоновых обновлений. В конце каждого кадра они меняются местами, чтобы видимый кластер всегда показывал актуальный результат без задержки кадра.

Такой подход особенно эффективен для процедурной анимации в реальном времени, крупномасштабных обновлений мешей или любой логики на стороне CPU, выигрывающей от многопоточности при сохранении синхронизации с рендерингом.

Параллельная логика инкапсулирована в производном классе шейдера *UpdateClusterCPUShader*, где метод *process()* переопределяется для выполнения обновлений по каждому кластеру. Этот метод автоматически диспетчеризируется с помощью *CPUShader::runAsync()*, позволяя распределить нагрузку по доступным потокам CPU. Операции свопа, проверки видимости и решения об обновлении обрабатываются независимо для каждого кластера.
