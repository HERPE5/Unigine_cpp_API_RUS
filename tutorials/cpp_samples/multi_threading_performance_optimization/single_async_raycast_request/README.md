# Single Async Raycast Request

Этот пример демонстрирует выполнение одного асинхронного запроса пересечения на основе позиции курсора мыши пользователя на сцене. Результат включает точку попадания и нормаль поверхности, которые визуализируются на сцене вместе с информацией о задержке.

Такая настройка демонстрирует реализацию неблокирующих запросов пересечения, подходящих для выбора объектов или похожих взаимодействий в реальном времени, управляемых вводом.

Пример демонстрирует обнаружение пересечений со всеми объектами в мире с помощью комбинации методов *World::getIntersection()* и *Landscape::getIntersection()*. Один луч испускается от текущей позиции камеры через курсор мыши. Если луч пересекает какую-либо геометрию, точка попадания и нормаль поверхности отрисовываются с помощью *Visualizer*. Запросы пересечения обрабатываются асинхронно. Коллбэк обрабатывает результат и записывает задержку в кадрах. Средние и максимальные значения задержки обновляются в реальном времени и отображаются в *UI* примера.
