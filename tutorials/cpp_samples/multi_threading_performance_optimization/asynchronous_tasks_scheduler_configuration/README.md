# Asynchronous Tasks Scheduler Configuration

Этот пример демонстрирует планирование и запуск различных типов задач с помощью *класса AsyncQueue*. Показано выполнение операций в разных типах потоков, управление количеством потоков и выбор того, должны ли задачи завершаться в течение текущего кадра или выполняться свободно в фоновом режиме.

-**Async** - неблокирующее выполнение в одном потоке. Полезно для разгрузки задач без остановки главного потока.
-**Async Multithread** - параллельное выполнение в нескольких потоках. Каждый поток получает свою часть работы. Не блокирует вызывающую сторону.
-**Frame-Async Multithread** - то же, что и **Async Multithread**, но гарантирует, что все потоки завершат свои задачи в течение текущего кадра.
-**Sync Multithread** - многопоточное выполнение, блокирующее вызывающий поток до завершения всех потоков.
-**Frame-Sync Multithread** - то же, что и **Sync Multithread**, но гарантирует, что все потоки завершат свои задачи в течение текущего кадра.

Подробную информацию о доступных режимах выполнения, типах потоков и приоритетах см. в API класса *AsyncQueue*.
