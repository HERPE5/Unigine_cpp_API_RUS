# Microprofiler Custom Counters

Этот пример демонстрирует методы отслеживания производительности и оценки времени, затрачиваемого на разные участки кода. Для этого используется **Microprofile** - продвинутый профилировщик CPU/GPU с поддержкой покадрового анализа.

Профилирование крайне важно для выявления узких мест производительности и оптимизации выполнения кода. Такой анализ помогает понять, влияют ли какие-либо участки кода негативно на скорость проекта.
