# Asynchronous Meshes And Textures Loading

Этот пример показывает загрузку ресурсов, таких как меши и текстуры, в фоновом режиме с помощью класса *AsyncQueue*. Файлы загружаются в отдельном потоке, поэтому основное приложение остаётся отзывчивым.

Меши и текстуры добавляются в очередь загрузки, и система слушает события, чтобы узнать, когда каждый ресурс готов. Когда меш завершает загрузку, он удаляется из очереди. Для текстур используется обработчик событий для обработки их завершения. Пример также демонстрирует группировку и управление запросами ресурсов, упрощая контроль процесса загрузки.

Такая асинхронная загрузка полезна для потоковой передачи больших уровней, загрузки ресурсов по требованию в VR или предзагрузки данных в симуляциях без зависания интерфейса.
