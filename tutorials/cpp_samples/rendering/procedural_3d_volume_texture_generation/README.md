# Procedural 3D Volume Texture Generation

Этот пример показывает, как процедурно генерировать данные *3D*-изображения и использовать их как текстуру плотности для объёмного материала в реальном времени. Результат визуализируется с помощью объёмного бокса, который динамически обновляется каждый кадр на основе пользовательской симуляции полей.

Пример инициализирует *3D*-изображение с предопределённым разрешением и заполняет его воксельными данными, полученными из набора движущихся полей. Каждое поле представляет абстрактную сферическую зону влияния, вносящую вклад в плотность вокселя в зависимости от расстояния. Динамика полей обновляется каждый кадр для симуляции движения.

Необработанные данные изображения доступны напрямую через указатель на пиксели и изменяются каждый кадр, при этом значения плотности отображаются на каналы *RGBA*. Результирующее изображение затем загружается в материал как *3D*-текстура, используемая в объёмной модели затенения.

Пример демонстрирует, как работать с классом *Image* и эффективно обновлять ресурсы *GPU* во время выполнения. Такой подход можно использовать для генерации объёмных эффектов, таких как облака, туман или процедурно управляемые визуальные явления.
