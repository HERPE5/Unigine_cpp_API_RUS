# Mesh To Mask Texture

Этот пример демонстрирует, как рендерить меш в текстуру с помощью пользовательского материала, создавая изображение для использования в качестве маски. Меш рендерится с выделенного обзора камеры прямо в текстуру, которая затем назначается в слот albedo материала предпросмотра.

Используйте манипулятор, чтобы перемещать обзор камеры и наблюдать, как разные углы обзора влияют на сгенерированную маску текстуры.

Пример сравнивает два подхода к рендерингу:

-**Renderer.RenderMesh** - стандартный рендеринг на основе камеры **(рекомендуется для большинства случаев)**. Движок автоматически подготавливает матрицы, состояния рендеринга и шейдеры, поэтому нужно лишь предоставить меш, материал, трансформацию и камеру.
-**MeshRender.Render** - низкоуровневая, **полностью ручная** настройка проекции и modelview. Этот метод обеспечивает более тонкий контроль над конвейером рендеринга, но требует явной настройки матриц проекции и вида, конфигурации RenderState и ручного управления параметрами шейдера.

Оба метода дают идентичные визуальные результаты, позволяя выбрать подход, наиболее подходящий для вашего рабочего процесса.

Эта техника полезна для динамических декалей, процедурных эффектов или любых функций, требующих генерации текстуры из 3D-геометрии в реальном времени.
