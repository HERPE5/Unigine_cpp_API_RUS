# CAD-Like View

Этот пример демонстрирует, как построить раскладку в стиле CAD, объединив четыре синхронизированных обзора одной сцены: сверху, сбоку, спереди и в перспективе. Каждый обзор использует собственную камеру с отдельной матрицей проекции - ортографической для технических видов и перспективной для основного. Каждый обзор рендерится за пределами экрана и отображается через *WidgetSpriteViewport*.
Обзоры расположены в сетке 2x2 с помощью виджетов GUI. При изменении размера окна разрешения текстур автоматически обновляются для соответствия новой раскладке и сохранения чёткости вьюпортов.

Кубы обзора (viewcube) центрируются на главном объекте для сохранения согласованности во всех обзорах. Они помогают указать ориентацию камеры и обновляются в зависимости от размера окна и позиций вьюпортов.

Эта настройка идеальна для инструментов, требующих точного осмотра сцены с нескольких направлений, таких как моделирование, дизайн уровней или приложения в стиле CAD.
