# Compute Shader

Этот пример демонстрирует систему частиц на основе GPU, реализованную с помощью вычислительных шейдеров. Он инициализирует динамический рендерер частиц, обновляет позиции и скорости частиц каждый кадр с использованием механизма пинг-понг текстур и использует статические меши с UV-развёрткой для влияния на поведение частиц.

Такие трансформации меш-в-частицы хорошо подходят для визуальных эффектов в реальном времени, таких как симуляции жидкости или дыма или интерактивные арт-инсталляции.
