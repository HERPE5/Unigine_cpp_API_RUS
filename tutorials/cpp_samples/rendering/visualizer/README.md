# Visualizer

Этот пример демонстрирует полный набор возможностей класса *Visualizer*.

Пример показывает, как использовать *Visualizer* для отладки позиций узлов, векторов физики, ограничивающих объёмов и произвольной геометрии как в мировом пространстве, так и в пространстве экрана. Используйте элементы управления для исследования области.

*VisualizerUsage.cpp* рендерит широкий набор примитивов, включая точки, линии, боксы, усечённые пирамиды (frustum), сферы, капсулы и границы объектов с помощью методов *Visualizer*.

Функции *2D*-визуализатора можно включать и выключать соответствующими чекбоксами.

Включайте или отключайте тест глубины, переключайте отдельные примитивы и наблюдайте, как разные параметры рендеринга ведут себя в реальном времени.
