# Textures

Этот пример демонстрирует, как создавать и обновлять процедурные текстуры на статических мешах в реальном времени с помощью C++ API.

Каждому мешу назначается изображение собственной генерации, которое обновляется каждый кадр по цветовому паттерну на основе времени. Данные пикселей записываются вручную в экземпляр класса *Image*, а результат применяется в слот текстуры albedo материала меша с помощью *Material::setTextureImage()*.

Этот метод позволяет генерировать динамические паттерны, шум или другую процедурную графику без использования compute-шейдеров или внешних файлов изображений.
