# Weapon Clipping

В играх от первого лица модели оружия могут проходить сквозь стены или геометрию, когда камера подходит слишком близко. Этот пример решает проблему, рендеря оружие отдельно в текстуру и накладывая её поверх основной сцены.

Используются две камеры с идентичными трансформациями для обеспечения выравнивания. Их маски Viewport настраиваются через редактор UNIGINE следующим образом: одна рендерит окружение без оружия, другая — только оружие. Вид оружия рисуется в текстуру с помощью *Viewport::renderTexture2D()*, а затем накладывается на экран с помощью *Render::renderScreenMaterial()*. Система обрабатывает изменение размера окна, изоляцию состояния рендеринга и позволяет включать дополнительные настройки, такие как пропуск теней в проходе рендеринга оружия.

Такой подход обеспечивает постоянную видимость оружия, даже когда камера находится близко к стенам, не влияя на основной конвейер рендеринга.
