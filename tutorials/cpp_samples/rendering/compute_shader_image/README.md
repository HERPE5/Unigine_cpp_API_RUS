# Compute Shader Image

Этот пример демонстрирует, как создать текстуру во время выполнения и полностью обновлять её на GPU с использованием вычислительных шейдеров с доступом на чтение-запись (unordered). 2D-текстура создаётся динамически и назначается в слот albedo материала.

Каждый кадр вычислительный шейдер обновляет текстуру, используя параметр симуляции - время кадра (ifps) - и диспетчеризуя потоки GPU группами **32x32**. Затем шейдер изменяет содержимое текстуры с использованием unordered-доступа, при этом все вычисления и запись полностью выполняются на GPU. CPU отвечает только за начальную настройку и обновление параметров.

Вычислительный шейдер используется для выполнения пользовательских операций над текстурами, что позволяет манипулировать изображением в реальном времени или процедурно генерировать контент.
