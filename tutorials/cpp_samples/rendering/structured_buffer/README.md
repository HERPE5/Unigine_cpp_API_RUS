# Structured Buffer

Этот пример демонстрирует, как сжать текстуру в формат **DXT1** с помощью compute-шейдеров и структурированных буферов.

При инициализации загружается compute-материал и подготавливается исходная текстура. Структура *DXT1Block* используется для хранения сжатых данных, а её размер зависит от размеров текстуры (в блоках 4x4). На GPU создаётся структурированный буфер для хранения результата.

Compute-шейдер выполняется в два этапа: разогрев для запуска компиляции шейдера и собственно проход сжатия. Количество групп вычислений рассчитывается динамически на основе размера текстуры и размера группы потоков для эффективного параллельного выполнения.

По завершении сжатия буфер GPU асинхронно передаётся в память CPU. Новое изображение со сжатыми данными создаётся в формате **DXT1** и сохраняется в файл `*.dds`.

Откройте консоль (`), чтобы увидеть метрики производительности сжатия и путь к сохранённому файлу.

Этот метод переносит всю тяжёлую обработку на GPU, минимизирует нагрузку на CPU и использует преимущества структурированного доступа к памяти для оптимальной производительности.
