# Gbuffer Read

Этот пример демонстрирует, как получать доступ к текстурам *G-buffer* на разных этапах процесса рендеринга, настраивая пользовательский *Viewport* и перехватывая его вывод на этапе рендеринга *G-buffer*.

Временный вьюпорт используется для рендеринга выбранного узла с упрощённым конвейером, чтобы остановить рендеринг после заполнения *G-buffer*. Когда рендеринг достигает этого этапа, срабатывает callback для получения текстур *G-buffer*, таких как глубина, albedo, нормали, металличность и шероховатость. Эти текстуры затем копируются в пользовательские render target и отображаются на плоскостях экрана с помощью пользовательских материалов.

Такая настройка полезна для отладки, анализа материалов или разработки эффектов постобработки, требующих прямого доступа к промежуточным данным в конвейере рендеринга.
