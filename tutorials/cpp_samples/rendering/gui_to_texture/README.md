# Gui To Texture

Этот пример демонстрирует, как рендерить элементы GUI в текстуру с помощью *Gui::render()*. Вместо отрисовки напрямую на экран, GUI перенаправляется в пользовательский фреймбуфер, что изолирует его конвейер рендеринга и позволяет применять результирующую текстуру к материалам.

Компонент **GuiToTexture** поддерживает два режима обновления:

-В режиме **Manual** текстура обновляется только при явном вызове *renderToTexture()*. Это используется в примере **WidgetClock**, где GUI (цифровые часы) перерисовывается раз в секунду, только когда отображаемое время меняется.
-Режим **Automatic** включён по умолчанию и обновляет текстуру GUI каждый кадр. Это демонстрируется в примере **WidgetNoSignal**, где метка *"No Signal"* перемещается по экрану как заставка. Поскольку позиция виджета меняется каждый кадр, текстуру нужно постоянно обновлять, чтобы отразить эти изменения.

Процесс рендеринга включает сохранение и очистку текущего состояния рендеринга, привязку текстуры, настройку вьюпорта, рендеринг виджетов GUI и восстановление состояния рендеринга. Также генерируются мипмапы для обеспечения правильной фильтрации на разных масштабах и дистанциях.

Этот пример можно использовать для отображения динамических элементов GUI на игровых мониторах, панелях управления или других подобных поверхностях.
