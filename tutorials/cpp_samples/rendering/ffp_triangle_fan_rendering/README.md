# FFP Triangle Fan Rendering

Этот пример демонстрирует, как отрисовывать простую 2D-фигуру с помощью *Fixed Function Pipeline (Ffp)* в UNIGINE через C++ API. Цветная фигура из 16 вершин отрисовывается прямо на экране с использованием ортографической проекции.

Логика рендеринга вызывается каждый кадр путём подключения к циклу рендеринга движка. Режим Ffp включается для отрисовки, а затем отключается, изолируя этот рендеринг от остальной части кадра.

Такой подход полезен для быстрых визуальных наложений, инструментов редактора или отладочных задач, где рендеринг на основе шейдеров не требуется.
