# Split-Screen Texture

Этот пример демонстрирует, как захватывать виды с двух разных камер в отдельные текстуры и реализовать разделённый экран с помощью C++ API.

Каждая камера рендерит своё изображение в текстуру с помощью *Viewport::renderTexture2D()*. Эти текстуры отображаются в вертикальной раскладке разделённого экрана с помощью элементов *WidgetSprite*, а также одновременно применяются к поверхностям путём назначения в слот albedo материалов статических мешей. Раскладка динамически подстраивается под изменение размера экрана.

Такая настройка может использоваться для совместного использования экрана в мультиплеере, сравнения камер или игровых мониторов, рендерящихся с нескольких точек обзора.
