# Camera To Texture

Этот пример показывает, как захватывать вывод камеры в реальном времени и проецировать его на текстуру albedo материала с помощью *Viewport::renderTexture2D()*.

Создаётся отрисовываемая 2D-текстура и назначается текстурой albedo материала, применённого к плоскости. Каждый кадр обзор активной камеры рендерится в эту текстуру, обновляя внешний вид объекта, к которому она применена. Настройки выборки текстуры, такие как линейная фильтрация и анизотропия, настроены для обеспечения визуального качества. UV-трансформация также скорректирована для компенсации переворота, зависящего от платформы.

Этот метод можно использовать для таких функций, как мониторы безопасности, живые трансляции с камер, динамические зеркала, порталы или мини-карты в ваших мирах.
