# Gbuffer Write

Этот пример демонстрирует, как изменять текстуры *G-buffer* на разных этапах процесса рендеринга, внедряя пользовательский материал в конце прохода *G-buffer*.

Обработчик события регистрируется с помощью *getEventEndOpacityGBuffer()*, который срабатывает, когда все текстуры *G-buffer* (albedo, нормаль и т.д.) заполнены. В этом callback применяется пользовательский пост-материал для изменения содержимого этих текстур с использованием динамических параметров, таких как influence, plasticity и color. Временные render target используются для выполнения промежуточных записей, а затем изменённые текстуры возвращаются обратно в конвейер.

Эта техника позволяет манипулировать данными *G-buffer* в реальном времени во время процесса рендеринга, обеспечивая пользовательские поверхностные эффекты или продвинутую предобработку материалов.
