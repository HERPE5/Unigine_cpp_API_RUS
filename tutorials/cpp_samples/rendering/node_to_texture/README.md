# Node To Texture

Этот пример демонстрирует, как рендерить конкретный узел и его дочерние узлы в текстуру с помощью *Viewport::renderNodeTexture2D()*. Вместо рендеринга всей сцены пользовательский вьюпорт захватывает только целевой узел, каким он видится с камеры, и выводит результат в 2D-текстуру.

Текстура затем назначается как текстура albedo материала. Для получения чистого вывода вьюпорт настроен пропускать прозрачные объекты, буферы скорости, постэффекты и отладочные визуализаторы. Освещение наследуется от мира, а окружение переопределяется на чёрный кубмап, чтобы предотвратить влияние фона.

Этот пример может быть полезен для рендеринга превью персонажей, динамических миниатюр предметов или изолированных обзоров объектов прямо на поверхностях.
