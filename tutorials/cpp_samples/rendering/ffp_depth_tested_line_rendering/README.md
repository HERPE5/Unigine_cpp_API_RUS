# FFP Depth-Tested Line Rendering

Этот пример демонстрирует, как отрисовывать пользовательские визуальные элементы (линии) с помощью *FFP* с включённым тестированием глубины.

Элементы отрисовываются на этапе визуализатора и правильно сортируются относительно геометрии сцены с использованием буфера глубины.

Пример настраивает callback рендеринга через *Render::getEventEndVisualizer()*, который используется для отрисовки простого отрезка линии в пространстве камеры. Отрисовка выполняется с помощью *FFP*, со смешиванием и тестированием глубины, настраиваемыми вручную через класс *RenderState*.

Сцена включает красную линию, пересекающую объект. Матрица проекции модифицируется для учёта обратной глубины и переотображения диапазона, обеспечивая правильную визуальную сортировку. Вершины линии преобразуются из мирового пространства в пространство камеры с использованием текущей матрицы modelview и рендерятся в экранном пространстве.

Этот пример можно использовать для быстрой отрисовки различных дополнительных или отладочных элементов (таких как полупрозрачные объекты, рамки, *3D*-сетки и системы координат, следы пути, шлейфы движения, визуализация линии видимости и т.д.), обеспечивая согласованность с содержимым сцены.
