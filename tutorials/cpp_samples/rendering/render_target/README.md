# Render Target

Этот пример демонстрирует, как рисовать напрямую в текстуру с помощью класса *RenderTarget*. Система инициализирует несколько текстур, включая слой фона и динамическую результирующую текстуру, которая затем назначается материалу объекта. *RenderTarget* используется для перенаправления вывода рендеринга из основного фреймбуфера в текстуру, обеспечивая полный контроль над тем, как компонуются спрайты. Каждая операция отрисовки включает трансформацию на основе UV для размещения и масштабирования спрайта и использует пользовательский материал с прямым доступом к задействованным текстурам. После каждой отрисовки результат смешивается с фоном, и генерируются мипмапы для правильного внешнего вида на разных дистанциях. Спрайты появляются как по клику мыши, так и автоматически в случайных позициях на поверхности стены.

Состояния рендеринга сохраняются и восстанавливаются вокруг каждой операции, чтобы изолировать поток закадрового рендеринга от остальной части конвейера.

Эта техника подходит для создания эффектов, таких как размещение декалей, рисование пользователем, маркеры попаданий или процедурные текстурные наложения в реальном времени.
