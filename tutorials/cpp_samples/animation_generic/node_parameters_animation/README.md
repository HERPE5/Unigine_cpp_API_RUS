# Node Parameters Animation

Этот пример демонстрирует анимацию узлов с помощью **объектов анимации узлов**. Это будет полезно для создания сложных сценариев анимации объектов сцены в реальном времени.
Анимации узлов могут служить основой для различных эффектов, включая появление/исчезновение элементов, вращения, изменение размера и другое.
