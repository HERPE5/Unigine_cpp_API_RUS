# Widget Animation

Этот пример показывает, как анимировать виджеты с помощью **объектов анимации во время выполнения**.
Демонстрируется программное управление и анимация элементов интерфейса. Использование динамических анимаций помогает создавать более живые, привлекательные пользовательские интерфейсы и позволяет автоматизировать их поведение.
