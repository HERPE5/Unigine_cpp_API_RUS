# Material Parameters Animation

Этот пример демонстрирует анимацию материалов с помощью **объектов анимации материалов**. Это полезно для реализации динамических изменений свойств материалов в реальном времени.
Особенно полезно для сцен, где свойства объектов должны изменяться в зависимости от действий пользователя или событий мира, таких как изменения погоды или времени суток.
