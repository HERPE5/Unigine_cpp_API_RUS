# Curve2D Animation

Этот пример демонстрирует анимацию трансформаций узла и параметров материала с помощью *Curve2D*. Отдельные треки *Curve2d* управляют позицией, вращением и масштабом узла, вычисляемыми каждый кадр для построения итоговой матрицы трансформации.

Такая настройка полезна для создания зацикленных движений и динамических эффектов материалов без использования внешних ресурсов анимации.
