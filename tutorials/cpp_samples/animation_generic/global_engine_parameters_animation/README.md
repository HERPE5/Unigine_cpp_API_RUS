# Global Engine Parameters Animation

Этот пример демонстрирует анимацию глобальных параметров движка с помощью **модификаторов анимации синглтонов**. Показана анимация в реальном времени гравитации физики и цвета фона рендеринга через выделенные треки и воспроизведения анимации.

Модификаторы анимации дают программный контроль над эффектами сцены, изменениями погоды, переходами времени и анимацией физических свойств, что делает сцены более увлекательными и интерактивными.

> [!NOTE]
> Все треки анимации, воспроизведения и объекты управляются системой анимации и имеют "время жизни движка", то есть существуют с момента загрузки или создания до завершения работы движка, и поэтому сохраняются между разными мирами.
> Активные воспроизведения необходимо останавливать при переключении на другой мир, если вы не хотите, чтобы они продолжали воспроизводиться там.
