# Reverberation Zone

Этот пример демонстрирует контроллер *зоны реверберации (Reverberation Zone)*, использующий компонент SoundReverb для создания настраиваемых акустических зон. Эти зоны влияют на источники звука в своих границах, симулируя реалистичную реверберацию окружения, добавляющую глубину и достоверность звуковым впечатлениям.

Настройте ползунок *Gain* в разделе параметров для управления различными свойствами реверберации, включая плотность, время затухания и усиление отражений.

Визуальные границы чётко обозначают затронутые области, обеспечивая точный пространственный контроль над акустическими эффектами по всей сцене.
