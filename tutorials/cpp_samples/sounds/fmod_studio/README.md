# FMOD Studio

Перед запуском этого примера выполните шаги, описанные в разделе настройки или в руководстве по интеграции FMOD, ссылка на которое приведена ниже.

Этот пример демонстрирует, как управлять, симулировать и визуализировать аудиособытия в реальном времени с помощью плагина *FMOD Studio*.

Настройка включает неподвижный объект (машину) и движущийся объект, представляющий источник звука с эффектом Доплера, который можно включать/выключать и настраивать через вкладку *Doppler* раздела параметров GUI. Дополнительные звуковые настройки, такие как ветер, дождь, звук оборотов двигателя машины и общая громкость окружения, также можно настраивать в реальном времени во вкладках *Ambience, Engine* и *VCA*.

**Варианты использования:**

-Прототипирование игровой механики на основе звука (например, звук транспорта, пространственное окружение, эффекты Доплера)
-Демонстрация динамических аудиопараметров и эффектов на основе движения, таких как сдвиг Доплера.

**Требования примера**

1. Скачайте и установите **FMOD Engine (версия 2.03.08)** для вашей ОС, доступный на официальном сайте (**![https://www.fmod.com/download](https://www.fmod.com/download)**).

2. Перейдите в папку установки FMOD и скопируйте следующие файлы в папку `bin` вашего проекта:

**для Windows:**

-`fmod.dll, fmodL.dll` из `/api/core/lib/x64/`
-`fsbank.dll, libfsbvorbis64.dll, opus.dll` из `/api/fbank/lib/x64/`.
-`fmodstudio.dll, fmodstudioL.dll` из `/api/studio/lib/x64/`

**для Linux**

-`libfmod.so.13, libfmodL.so.13` из `/api/core/lib/x64/`
-`libfsbank.so.13, libfsbankL.so.13, libfsbvorbis.so, libopus.so` из `/api/fbank/lib/x64/`
-`libfmodstudio.so.13, libfmodstudioL.so.13` из `/api/studio/lib/x64/`
