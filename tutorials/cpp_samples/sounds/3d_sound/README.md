# 3D Sound

Этот пример демонстрирует, как создать источник звука (*SoundSource*) и настроить его базовые параметры: громкость, высоту тона, режим зацикливания и тип воспроизведения. Источник звука обладает настраиваемыми свойствами пространственного звука с регулируемым минимальным и максимальным затуханием по расстоянию, визуализируемым в сцене.

UNIGINE позволяет работать с источниками звука так же, как и с другими узлами: их можно легко перемещать, вращать или масштабировать. Кроме того, у них есть специфические характеристики, подробно описанные в соответствующей статье.
