# Ambient Sound

Этот пример показывает реализацию компонента, управляющего воспроизведением окружающего звука (*AmbientSource*) с интерактивными элементами управления GUI с помощью класса *AmbientSource*. Компонент создаёт источник окружающего звука, который непрерывно воспроизводится в фоне, и предоставляет настройку параметров в реальном времени через отдельный интерфейс.

Потоковый режим можно динамически переключать через чекбокс *Stream*, пересоздавая источник звука для переключения между предзагруженным аудио (меньшая задержка) и потоковым аудио (меньшее использование памяти). Такой подход идеально подходит для фоновой музыки, звуков окружения и других постоянных аудиоэлементов, усиливающих погружение в сцену.
