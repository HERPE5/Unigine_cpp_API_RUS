# FMOD Core

Перед запуском этого примера выполните шаги, описанные в разделе настройки или в руководстве по интеграции FMOD, ссылка на которое приведена ниже.

Этот пример загружает плагин *FMOD* и инициализирует систему *Core* для демонстрации воспроизведения как 2D-, так и 3D-звуковых экземпляров, поддерживая до **1024** одновременных звуковых каналов. Вы можете переключаться между 2D- и 3D-сценами, чтобы наблюдать разное поведение звука и взаимодействовать с ним.

Представлены два звуковых режима:

-**2D-воспроизведение музыки**: стандартное воспроизведение аудио с поддержкой регулировки громкости и эффектом DSP искажения (distortion)
-**3D-воспроизведение музыки**: звук исходит от красной сферы в 3D-пространстве, демонстрируя позиционное аудио в окружении. Перемещайте камеру, чтобы в реальном времени ощутить изменения направления звука и затухания.

**Варианты использования:**

-Интеграция FMOD Core в среды выполнения для игр или симуляций
-Прототипирование пространственного звукового дизайна и размещения 3D-аудио.

**Требования примера**

1. Скачайте и установите **FMOD Engine (версия 2.03.08)** для вашей ОС, доступный на официальном сайте (**![https://www.fmod.com/download](https://www.fmod.com/download)**).

2. Перейдите в папку установки FMOD и скопируйте следующие файлы в папку `bin` вашего проекта:

**для Windows:**

-`fmod.dll, fmodL.dll` из `/api/core/lib/x64/`
-`fsbank.dll, libfsbvorbis64.dll, opus.dll` из `/api/fbank/lib/x64/`.
-`fmodstudio.dll, fmodstudioL.dll` из `/api/studio/lib/x64/`

**для Linux**

-`libfmod.so.13, libfmodL.so.13` из `/api/core/lib/x64/`
-`libfsbank.so.13, libfsbankL.so.13, libfsbvorbis.so, libopus.so` из `/api/fbank/lib/x64/`
-`libfmodstudio.so.13, libfmodstudioL.so.13` из `/api/studio/lib/x64/`
