# Keyboard And Mouse

Этот пример демонстрирует добавление мониторинга ввода с клавиатуры и мыши, отслеживание состояний клавиш, движений мыши, событий колеса и позиций курсора в разных системах координат. Отображаются данные ввода в реальном времени, включая нажатия клавиш, дельты мыши и текстовый ввод. Пример показывает три режима работы мыши:

-**GRAB** - блокирует и скрывает курсор
-**SOFT** - блокирует курсор в пределах окна, но оставляет его видимым
-**USER** - без ограничений курсора.
