# Joystick

Этот пример демонстрирует добавление продвинутой обработки ввода с **джойстика**, поддерживающей несколько контроллеров с мониторингом осей/кнопок в реальном времени и эффектами отдачи (force feedback) в UNIGINE. Он включает динамический UI для тестирования более 10 типов отдачи (пружины, вибрации, волны) и автоматически обрабатывает события подключения/отключения устройств. Идеально подходит для гоночных/лётных симуляторов или любых проектов, требующих точного ввода с контроллера с тактильной обратной связью.
