# Procedural Mesh Updates Mesh Clusters

Этот пример демонстрирует правильный порядок операций для изменения и применения данных процедурного меша во время выполнения. Он служит минимальным примером, показывающим, как строить геометрию, настраивать процедурный режим и применять изменения к *ObjectMeshCluster*.

Тот же рабочий процесс и методы применения также доступны для других объектов, поддерживающих процедурные меши, таких как *ObjectMeshStatic*, *ObjectGuiMesh*, *DecalMesh* и *ObjectMeshClutter*.

В коде компонента вы найдёте линейную реализацию конвейера процедурного меша, демонстрирующую, как геометрия генерируется и применяется в правильном порядке.

Используйте этот пример, чтобы понять базовый процесс обновления процедурных мешей, и попробуйте настроить конфигурации, чтобы найти наиболее подходящую для ваших нужд.

Обратитесь к статье Procedural Mesh Workflow для получения дополнительной информации о поведении памяти, стратегиях обновления и рекомендациях при работе с процедурной геометрией.
