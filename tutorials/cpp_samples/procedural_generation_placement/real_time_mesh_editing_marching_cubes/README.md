# Real-Time Mesh Editing Marching Cubes

Этот пример демонстрирует симуляцию копания земли, изменение фрагмента террейна, представленного мешем, через API. Фрагмент поверхности земли генерируется с использованием алгоритма Marching Cubes.

Кликните **ЛКМ**, чтобы выкопать землю в определённой точке (режущая сфера визуализируется вокруг курсора). Установите желаемый радиус режущей сферы (*Digging Radius*), определяющий объём удаляемой земли.

**Удерживайте Ctrl + ЛКМ**, чтобы вместо этого добавить объём.
