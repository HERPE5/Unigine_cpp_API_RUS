# Timer-Based Node Spawning

Этот пример демонстрирует настраиваемый спаунер узлов, создающий объекты через определённые интервалы. Частоту спауна можно настраивать в реальном времени, с визуальным индикатором, показывающим прогресс текущего цикла спауна через меняющую цвет сферу.

Этот пример будет полезен для генерации игровых объектов с определённой периодичностью - например, врагов, бонусов, эффектов или других элементов игрового мира.
