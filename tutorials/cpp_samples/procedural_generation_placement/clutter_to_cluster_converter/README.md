# Clutter-To-Cluster Converter

Этот пример демонстрирует, как динамически генерировать clutter (**ObjectMeshClutter**) и преобразовывать его в оптимизированный кластер (**ObjectMeshCluster**) в реальном времени. Clutter генерируется с использованием случайного зерна, и процесс преобразования переносит все ключевые параметры из clutter: материалы, свойства поверхности, LOD, тени, физику и настройки столкновений.

Полученный кластер наследует трансформацию и иерархию clutter, но позволяет **выборочно редактировать и удалять отдельные элементы** группы. Очень часто при построении миров необходимо случайным образом разбросать меши по определённой области, а затем вручную переместить некоторые из них (например, при создании лесов).

**Возможности UI:**

-**Generate Clutter** - Создаёт случайную раскладку мешей clutter.
-**Convert to Cluster** - Объединяет все экземпляры clutter в единый **ObjectMeshCluster** с идентичным визуальным/физическим поведением.
