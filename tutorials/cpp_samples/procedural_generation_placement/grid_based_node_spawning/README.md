# Grid-Based Node Spawning

Этот пример показывает, как создавать узлы и размещать их по настраиваемой сетке.

Настройте размеры сетки, размер ячейки и переключайтесь между размещением от угла или от центра.

Система автоматически очищает и пересоздаёт всю сетку при изменении параметров, предоставляя визуализацию изменений раскладки в реальном времени.
