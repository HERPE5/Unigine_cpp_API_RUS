# Procedural Mesh Modification

Этот пример демонстрирует, как динамически генерировать, изменять и применять процедурную геометрию во время выполнения с использованием различных методов изменения процедурных мешей.

Динамическая поверхность меша строится и анимируется во времени с помощью тригонометрических функций. Геометрия перестраивается каждый кадр в зависимости от текущей конфигурации.

Вы можете экспериментировать с различными процедурными режимами (такими как *Dynamic, File* или *Blob*), а также настраивать способ хранения и доступа к геометрии, выбирая разные флаги использования MeshRender (только для DirectX 12). Эти флаги определяют, хранятся ли данные вершин и/или индексов в RAM вместо VRAM, позволяя GPU рендерить непосредственно из системной памяти.

Кроме того, вы можете выбрать, происходит ли генерация меша в **основном** потоке или в **фоновом**, что даёт больше контроля над производительностью и отзывчивостью во время обновлений.

-**Dynamic** - самая высокая производительность, хранится в RAM и VRAM, не выгружается из памяти автоматически.
-**Blob** - умеренная производительность, хранится в RAM и VRAM, автоматически выгружается из памяти.
-**File** - самая низкая производительность, все данные хранятся на диске, автоматически выгружаются из памяти.

Вы также можете переключаться между различными режимами обновления (*Async* или *Force*), выбирать стратегии передачи памяти (*Copy* или *Move*) и опционально включать ручное управление *MeshRender*, при котором вы явно обновляете его содержимое после изменения данных меша, вместо того чтобы полагаться на автоматические обновления. Кроме того, данные столкновений можно явно генерировать после изменения геометрии, так как они не создаются автоматически.

Используйте этот пример, чтобы понять, как работает изменение процедурных мешей в разных конфигурациях, и изучить, как стратегии обновления влияют на производительность.

Обратитесь к статье Procedural Mesh Workflow для получения дополнительной информации о поведении памяти, стратегиях обновления и рекомендациях при работе с процедурной геометрией.
