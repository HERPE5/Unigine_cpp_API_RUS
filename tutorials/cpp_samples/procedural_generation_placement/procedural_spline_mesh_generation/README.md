# Procedural Spline Mesh Generation

Этот пример демонстрирует процедурную генерацию мешей на основе сплайнов с использованием мировых точек в качестве контрольных узлов. Система создаёт три геометрических типа: **RIBBON, SQUARE PIPE** и **ROUND PIPE** с настраиваемой шириной, уровнем подразбиения и длиной сегмента. Параметры UV-развёртки позволяют управлять повторением и растяжением текстуры как по длине, так и по ширине.

Сгенерированный меш обновляется в реальном времени по мере манипуляции контрольными точками (с поддержкой перемещения вдоль одной оси или плоскостных ограничений), а визуализатор показывает путь сплайна и каркас. Интерактивный интерфейс предоставляет элементы управления для всех параметров генерации и переключения типа меша.
