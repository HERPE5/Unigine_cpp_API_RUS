# HTTP Request Handling

Этот пример демонстрирует, как реализовать асинхронные *HTTP GET*-запросы к внешнему *REST API* и отобразить полученные данные в пользовательском интерфейсе.

В качестве демонстрации пример выполняет два последовательных запроса к внешнему API погоды и отображает результаты в реальном времени.

<ol>
-**Geocoding** - определение местоположения по названию с помощью *geocoding-api.open-meteo.com*.
-**Current weather conditions** - получение актуальных метеорологических данных для выбранного местоположения с помощью *api.open-meteo.com*.
</ol>
Для асинхронного выполнения *HTTP*-запросов используется библиотека **![github.com/yhirose/cpp-httplib](https://github.com/yhirose/cpp-httplib)**. Дополнительные подробности от сервера можно посмотреть в консоли.

*JSON*-ответ обрабатывается с помощью класса *Json* и отображается в *UI* примера. Дополнительные детали ответа можно посмотреть в выводе консоли.

Вы можете интерактивно протестировать рабочий процесс, введя название города в *UI*, просмотрев список возможных совпадений и выбрав конкретное местоположение. Это запускает запрос актуальных данных о погоде, которые затем разбираются и отображаются в *UI*.

Асинхронная обработка гарантирует, что сетевые операции не блокируют и не снижают производительность симуляции.

Этот пример может служить основой для интеграции любых внешних поставщиков данных.
