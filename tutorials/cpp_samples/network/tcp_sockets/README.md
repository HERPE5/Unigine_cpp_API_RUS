# TCP Sockets

Этот пример демонстрирует, как устанавливать и управлять *TCP*-соединениями сокетов между сервером и несколькими клиентами, каждый из которых представлен приложением UNIGINE. Клиенты могут подключаться к серверу, обмениваться текстовыми сообщениями через консоль (команда **send_msg**) и получать обновления трансформации камеры от сервера.

**Для работы этого примера нужно запустить два экземпляра приложения 'C++ Samples'.**

Каждый экземпляр может работать в одном из двух режимов: *Server* или *Client*. Чтобы выбрать режим, нажмите на соответствующую кнопку ниже. Там же можно указать желаемые *host и port*.

Сервер использует неблокирующий сокет для приёма клиентских подключений и создаёт отдельный фоновый поток для каждого подключения. Протокол связи основан на пользовательских сообщениях (например, текст или трансформации камеры), упаковываемых и распаковываемых с помощью потоков *Blob*. На стороне клиента создаётся сокет и устанавливается соединение с сервером. Входящие и исходящие сообщения отправляются/принимаются с помощью двух потокобезопасных очередей. Чтобы отправить текстовые сообщения собеседнику, используйте специфичную для примера консольную команду `send_msg` (например, `**send_msg hello world**`)

Входящие сообщения разбираются с использованием заголовков сообщений. И клиент, и сервер используют буферизацию сообщений, тайм-ауты и проверки валидности для поддержания стабильности соединения и предотвращения обработки некорректных данных.

Пример предоставляет возможности для настройки адреса и порта сервера, переключения между режимами и отслеживания активных подключений.
