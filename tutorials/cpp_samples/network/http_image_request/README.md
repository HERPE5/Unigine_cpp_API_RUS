# HTTP Image request

Этот пример показывает, как реализовать асинхронный *HTTP*-запрос к *REST API* для загрузки файлов изображений и применения их к объектам сцены во время выполнения.

Выполняются два запроса для получения тестовых данных изображений:

<ol>
-**eu.httpbin.org/image/png** - для загрузки изображения *PNG*
-**eu.httpbin.org/image/jpeg** - для загрузки изображения *JPEG*
</ol>
Для загрузки во время выполнения в экземпляр класса *Image* из необработанных данных поддерживаются только форматы *PNG* и *JPEG*.

Для выполнения *HTTP*-запросов используется библиотека **![github.com/yhirose/cpp-httplib](https://github.com/yhirose/cpp-httplib)**.

После получения изображения оно загружается из необработанных байтовых данных с помощью метода *Image::load()*. В случае успеха изображение назначается в слот текстуры albedo целевого материала с помощью *Material::setTextureImage()*. Текстура применяется во время выполнения к указанной поверхности объекта сцены. Если загрузка не удалась, скачанные данные записываются в файл для дальнейшего анализа.

Этот пример демонстрирует практический подход к получению внешних медиаресурсов, их проверке и использованию в сценах или логике приложения.
