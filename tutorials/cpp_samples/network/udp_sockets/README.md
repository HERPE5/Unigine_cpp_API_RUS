# UDP Sockets

Этот пример показывает, как использовать API сокетов для отправки и получения UDP-сообщений между двумя собеседниками в сети.

**Для работы этого примера нужно запустить два экземпляра приложения 'C++ Samples'.**

Каждый экземпляр может работать в одном из двух режимов: *Sender* или *Receiver*. Чтобы выбрать режим, нажмите на соответствующую кнопку ниже. Там же можно указать *имя хоста и порт Receiver*.

В режиме *Sender* приложение упаковывает трансформацию камеры игрока в датаграмму и отправляет её Receiver на каждом обновлении движка.

В этом режиме также можно отправлять собеседнику текстовые сообщения с помощью специфичной для примера консольной команды `send_msg` (например, `**send_msg hello world**`).

В режиме *Receiver* приложение получает и интерпретирует входящие сообщения от собеседника: текстовые сообщения записываются в консоль, а трансформации камеры применяются к игроку.
