# Usc Variable

Этот пример демонстрирует, как работать с различными типами переменных в *UnigineScript* с помощью класса *Variable* из кода *C++*.

Различные типы (*int, long, float, double*) и векторные типы (*vec3, vec4, dvec3* и т.д.) оборачиваются в объекты *Variable* и передаются в callback-функцию *UnigineScript*.
