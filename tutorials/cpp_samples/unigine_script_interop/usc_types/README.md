# Usc Types

Этот пример демонстрирует, как включить преобразование типов между пользовательскими типами *C++* и *UnigineScript* с помощью класса Variable.

Вводится пользовательский класс *MyVector3* для представления *3D*-вектора. Для интеграции этого класса со средой *UnigineScript* реализуются пользовательские специализации шаблонов *TypeToVariable* и *VariableToType*. Они позволяют автоматически преобразовывать значения между *MyVector3* и *vec3* внутри среды выполнения *UnigineScript*.
