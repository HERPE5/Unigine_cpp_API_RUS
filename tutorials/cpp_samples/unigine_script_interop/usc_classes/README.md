# Usc Classes

Этот пример демонстрирует, как экспортировать классы из *C++* в *UnigineScript*.

Простой класс *C++* с именем *ExternClass* используется для экспорта пользовательского *MyExternObject* в среду *UnigineScript*. Это позволяет скриптам создавать экземпляры класса, вызывать его методы и взаимодействовать с его свойствами во время выполнения.
