# Usc Structures

Этот пример демонстрирует, как предоставлять структуры *C++* для *UnigineScript* с помощью класса *Interpreter*.

Он определяет простую структуру *C++* *MyVector* с четырьмя полями типа float (*x, y, z, w*) и регистрирует её. Каждое поле сопоставляется через явные методы получения и установки для обеспечения полного доступа на чтение/запись со стороны *UnigineScript*.
