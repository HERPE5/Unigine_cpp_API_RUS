# Usc Transfer

Этот пример демонстрирует, как передавать сложные данные между *UnigineScript* и *C++* с помощью класса Variable и утилиты *TypeToVariable*.

В примере показано несколько способов передачи и возврата объектов Image между скриптом и нативным кодом. Сравниваются прямая передача объекта, преобразование через *Variable* и использование *TypeToVariable*.
