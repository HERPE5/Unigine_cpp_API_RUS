# Usc Inheritance

Этот пример демонстрирует, как работать с контейнерами *UnigineScript* через *C++ API*. Он показывает композицию классов, регистрацию конструкторов, связь базового и производного классов и предоставление виртуальных методов в контексте скриптинга.

Каждый класс в иерархии регистрируется через класс *Interpreter*, позволяя скриптам создавать экземпляры производных типов, взаимодействовать с ними, вызывать унаследованные методы и переопределять поведение.
