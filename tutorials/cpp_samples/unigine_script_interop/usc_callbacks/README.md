# Usc Callbacks

Этот пример демонстрирует, как вызывать функции *UnigineScript* из кода *C++* через callback'и.

Механизм основан на экземплярах класса *Variable* и позволяет вызывать по имени как пользовательские, так и встроенные функции скрипта.

Пример регистрирует функцию-обёртку на *C++*, чтобы предоставить возможность вызова скрипта из *UnigineScript* через класс *Interpreter*.
