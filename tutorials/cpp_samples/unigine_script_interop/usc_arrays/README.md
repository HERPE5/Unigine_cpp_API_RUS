# Usc Arrays

Этот пример демонстрирует интеграцию между *C++* и *UnigineScript* путём регистрации внешних функций *C++*, манипулирующих типами массивов *UnigineScript*.

Зарегистрированные функции позволяют устанавливать и получать значения, генерировать тестовые данные и перечислять содержимое как *ArrayVector* (индексированный контейнер), так и *ArrayMap* (ассоциативный контейнер).
