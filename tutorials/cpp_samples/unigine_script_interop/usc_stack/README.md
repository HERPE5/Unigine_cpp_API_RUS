# Usc Stack

Этот пример демонстрирует, как использовать стек, реализованный через *C++*, в *UnigineScript*.

Пример определяет простую функцию форматирования на стороне *C++*. Эта функция принимает форматную строку и подставляет токены значениями, извлечёнными из стека времени выполнения. Значения передаются из скрипта и помещаются в стек перед вызовом.
