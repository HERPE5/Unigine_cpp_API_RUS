# Body Fracture Explosion

Этот пример демонстрирует, как симулировать взрыв, разрушающий физические объекты в своём радиусе с помощью класса *BodyFracture*. Каждый объект, затронутый взрывом, динамически разрушается на отдельные физические фрагменты в зависимости от его близости к центру взрыва и убывания силы взрыва с расстоянием.

Сила, приложенная к фрагментам, отталкивает их наружу от центра взрыва, создавая реалистичный эффект разлёта. Встроенная отладочная визуализация чётко отображает радиус взрыва и направление приложенных сил, упрощая понимание и настройку поведения разрушения и динамики взрыва. Взрыв можно вручную запустить с помощью простой кнопки интерфейса.

Этот пример идеально подходит для сценариев, требующих реалистичного разрушения, динамических эффектов фрагментации или визуального представления повреждений физических объектов.
