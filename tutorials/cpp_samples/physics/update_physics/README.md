# Update Physics

Этот пример демонстрирует разницу между методами *update()* и *updatePhysics()*.

В примере представлены два физических куба, которые двигаются вперёд-назад вдоль оси X. Логика движения реализована в файле *UpdatePhysicsUsageController.cpp*.

Используйте *updatePhysics()* для реализации непрерывных или зависящих от физики операций (например, приложение силы, реакция на столкновения), так как он выполняется с фиксированным временным шагом, в отличие от *update()*, который зависит от частоты кадров рендеринга.

Используйте слайдер **Max FPS**, чтобы изменить целевую частоту кадров.

**Зелёный куб** использует *updatePhysics()*, вызываемый с фиксированной частотой кадров физики, и должен считаться корректным примером для логики, связанной с физикой.

**Красный куб** использует *update()*, который выполняется на каждом кадре рендеринга. Такой подход может приводить к нестабильным результатам при взаимодействии с физикой, и его обычно следует избегать при реализации движения, управляемого физикой.
