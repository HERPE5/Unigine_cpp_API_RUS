# Body Events

Этот пример демонстрирует, как использовать события *Frozen*, *Position* и *ContactEnter* класса *Body* через C++ API.

Эти события позволяют определять, когда тело останавливается, движется или сталкивается с другим телом или поверхностью.

Пример строит пирамиду из коробок, клонируя меш и располагая его в несколько слоёв. Настройки физики скорректированы для повышения стабильности сложенных коробок и обеспечения точного определения состояний движения или покоя.

Такой подход полезен для отладки физического поведения, предоставления визуальной обратной связи в симуляциях или запуска интерактивной логики на основе изменения состояний тел.

События *Frozen*, *Position* и *ContactEnter* каждого тела подключаются к соответствующим обработчикам. Все подписки управляются через экземпляр класса *EventConnections*, который хранит все соединения в одном месте и обеспечивает корректную очистку при завершении работы. Например, обработчик *Frozen* изменяет материал коробки, когда она останавливается. Обработчик *Position* изменяет материал при каждом обновлении позиции. Обработчик *ContactEnter* визуализирует точки контакта при столкновениях.
