# Body Fracture Falling Spheres

Этот пример демонстрирует непрерывное разрушение объектов с использованием класса *BodyFracture*. Сферы периодически создаются каждые 3 секунды и свободно падают под действием гравитации. При столкновении с землёй каждая сфера динамически разрушается на несколько физических фрагментов.

Пример включает отладочную визуализацию, отображающую каркасы мешей, что даёт чёткое представление о внутренней структуре меша и паттернах разрушения, возникающих при ударе.

Этот пример можно использовать для изучения и оценки механики разрушения, тестирования настроек разрушения на основе мешей и визуального анализа поведения при поломке в сценариях реального времени.
