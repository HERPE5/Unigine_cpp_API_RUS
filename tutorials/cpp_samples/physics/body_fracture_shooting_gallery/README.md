# Body Fracture Shooting Gallery

Этот пример показывает, как симулировать взаимодействия на основе снарядов в простой установке тира с помощью **Fracture Body**. При нажатии левой кнопки мыши перед камерой появляется снаряд, летящий вперёд. Целевые объекты в сцене физически реагируют на удар и могут разрушаться с помощью системы **Fracture Body** для симуляции реалистичных эффектов разрушения.

**Варианты использования:**

-Прототипирование механики стрельбы на основе физики.
-Демонстрация импульсных взаимодействий **Fracture Body**.
-Тестирование поведения разрушения в настройках разрушаемого окружения.
