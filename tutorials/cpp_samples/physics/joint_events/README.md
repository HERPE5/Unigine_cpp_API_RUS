# Joint Events

Этот пример демонстрирует, как использовать событие *Broken* класса *Joint* через C++ API. Это событие позволяет реагировать, когда соединение разрушается под действием физических сил во время симуляции.

Создаётся простая структура моста путём клонирования меша и соединения нескольких секций с помощью шарнирных соединений (*hinge*). Некоторые секции динамические (*BodyRigid*), а другие статические (*BodyDummy*) для закрепления концов. Кроме того, на мост сбрасываются несколько грузов, чтобы вызвать разрушение соединений. Сцена настроена так, чтобы продемонстрировать физическое поведение соединений под нагрузкой.

Это можно использовать для обнаружения разрушения в системах, основанных на соединениях, или для добавления визуальной обратной связи к механике разрушения.

Событие *Broken* каждого соединения подключается к обработчику с помощью экземпляра класса *EventConnections*, который хранит все соединения в одном месте и обеспечивает автоматическую очистку при завершении работы компонента. Когда соединение разрушается, срабатывает обработчик события, изменяя цвет материала связанных объектов, чтобы визуально обозначить разрыв.
