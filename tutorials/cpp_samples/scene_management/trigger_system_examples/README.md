# Trigger System Examples

Этот пример иллюстрирует, как реализовать простой компонент-триггер пятью разными способами:

-**Intersection Trigger** выполняет проверку границ через *World::getIntersection()*.
-**Math Trigger** выполняет проверку, находится ли объект внутри сферы или куба триггера, используя координаты объекта (самый простой и производительный способ).
-**World Trigger** использует встроенный узел *WorldTrigger*, который автоматически определяет, когда узлы входят в заданный объём или покидают его.
-**Physical Trigger** использует встроенный узел *PhysicalTrigger*, вызывающий события, когда физический объект оказывается внутри него или снаружи. Чтобы быть обнаруженным триггером, физические объекты должны одновременно иметь и тело (body), и форму (shape).
-
**Node Trigger** использует встроенный узел *NodeTrigger*, у которого нет визуального представления, и вызывает события при включении или перемещении.

Нажмите *Cube Active*, чтобы увидеть Node Trigger в действии. Этот чекбокс включает/выключает демонстрационный куб, вызывая события включения/отключения, которые меняют цвет текста таблички и анимируют материал куба при перемещении с помощью манипулятора (кликните по кубу, чтобы появился манипулятор).
