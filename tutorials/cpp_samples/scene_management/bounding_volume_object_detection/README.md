# Bounding Volume Object Detection

Этот пример демонстрирует, как обнаруживать пересечения между усечённой пирамидой (frustum), сферой или боксом и ограничивающими боксами узлов. Для наглядности границы узлов отображаются в сцене, что позволяет быстро визуально оценить, когда узлы пересекают заданные объёмы.

Такой подход можно использовать для реализации систем определения того, какие объекты попадают в ограничивающий объём, и запуска событий, таких как начало диалогов, появление врагов, активация эффектов или любая другая реакция.

Функция *init()* создаёт три типа ограничивающих объёмов: усечённую пирамиду, сферу и бокс. Функция *update()* выполняет проверки пересечений. Она использует функцию *World::getIntersection()* для получения списка узлов, пересекающих заданные границы, и изменяет их цвет с помощью функции *change_color()*.
