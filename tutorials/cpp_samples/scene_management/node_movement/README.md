# Node Movement

Этот пример сравнивает три подхода к перемещению и повороту 3D-объекта с использованием разных методов трансформации узла и показывает, что использование любого из них приводит к одинаковому результату:

Красный куб управляется с помощью *translate()* и *rotate()*.

Зелёный куб: *setPosition()* и *setRotation()*.

Синий куб: *setTransform()*.
