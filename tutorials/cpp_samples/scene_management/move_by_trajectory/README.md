# Move By Trajectory

Этот пример демонстрирует три типа движения по заданному пути:

-**Красный самолёт**: линейная интерполяция.
-**Синий самолёт**: сплайновая интерполяция.
-**Зелёный самолёт**: путь из файла.

Пример содержит компонент *PathTrajectorySaver*, иллюстрирующий, как создать собственный файл пути, который открывается через узел *WorldTransformPath*.

В разделе параметров можно включать и отключать **визуализацию пути**, настраивать **скорость** самолётов или **переключаться между камерами**, чтобы получить вид от первого лица с каждого самолёта.
