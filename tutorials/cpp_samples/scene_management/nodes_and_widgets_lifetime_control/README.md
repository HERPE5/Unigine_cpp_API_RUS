# Nodes And Widgets Lifetime Control

Этот пример демонстрирует, как настройки времени жизни узлов и виджетов влияют на сохранность объектов при переходах между мирами.

При запуске пример создаёт узел-плоскость и экранную кнопку, каждый с настраиваемыми режимами времени жизни. Переключайте виджет между режимами времени жизни **WORLD** и **WINDOW**, а узел — между режимами **WORLD** и **ENGINE**.

Используйте консольную команду `**world_load world_name**` (например, `**world_load arcade**`) для переключения миров и наблюдения за тем, как разные настройки времени жизни влияют на сохранность объектов. Объекты с временем жизни *WORLD* существуют только в текущем мире, тогда как узлы с временем жизни *ENGINE* и виджеты с временем жизни *WINDOW* остаются активными после загрузки другого мира.
