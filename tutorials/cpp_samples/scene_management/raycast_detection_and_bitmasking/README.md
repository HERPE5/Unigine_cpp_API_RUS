# Raycast Detection And Bitmasking

Этот пример демонстрирует, как находить пересечения с геометрией с помощью **трассировки лучей (raycasting)**, учитывая различные битовые маски *Intersection* (используются первые 8 бит из 32).

Трассировка лучей заключается в обнаружении пересечений с объектами сцены вдоль пути луча, пущенного из точки **A** в точку **B**. Этот процесс визуализируется в примере через представление лазерного луча (длина лазера зависит от длины луча).

В методе *update()* функция *World::getIntersection()* проверяет пересечения луча с объектами сцены на основе заданной маски пересечения. Если луч попадает в объект с совпадающей маской (хотя бы один бит), пересечение обнаруживается. После этого луч обновляется, а в точке пересечения рендерятся визуальные эффекты искр.

Маску пересечения лазера можно изменить, переключая соответствующие чекбоксы. Если бит маски стены не совпадает с маской лазера, лазер пройдёт сквозь неё.

Использование трассировки лучей позволяет легко реализовывать различные игровые механики, такие как стрельба или обнаружение целей во время навигации.
