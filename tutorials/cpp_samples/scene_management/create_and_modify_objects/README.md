# Create And Modify Objects

Этот пример демонстрирует основы работы с ***объектами (Objects)*** — как создавать и изменять объекты через API, показывая различия между разными типами объектов (*ObjectMeshStatic, ObjectMeshDynamic, ObjectParticles*). **Объекты** характеризуются набором поверхностей, опциональным физическим телом и специфичными для типа свойствами.

В этом примере мы создаём и настраиваем три типа объектов с интерактивными элементами управления:

**1. Объект статического меша (Material Ball)**

-Загружает существующий файл **.mesh** *(material_ball.mesh)*.
-Назначает объекту материал.
-Добавляет *Body* со столкновением в форме *бокса*.

**2. Объект динамического меша (тетраэдр)**

-Вручную конструирует пользовательский *ObjectMeshDynamic*.
-Применяет стеклоподобный материал.
-Добавляет *Body* со столкновением в форме *сферы*.

**3. Система частиц**

-Создаёт стандартный объект *ObjectParticles*.
-Настраивает *параметры, специфичные для частиц*, такие как частота появления и время жизни, и включает *маску столкновений* для взаимодействия частиц.

**Изменения во время выполнения (через меню примера)**

-Настройка цвета albedo материала **статического меша**.
-Изменение меша (высоты основания тетраэдра) в **динамическом меше**.
-Настройка частоты появления частиц в **системе частиц**.
-Переключение визуализации поверхностей и физических форм объектов.

Для более сложных объектов, таких как *ObjectWaterGlobal* и *ObjectLandscapeTerrain*, см. соответствующие примеры.
