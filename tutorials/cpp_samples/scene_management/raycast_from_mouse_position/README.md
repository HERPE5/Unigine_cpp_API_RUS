# Raycast From Mouse Position

Этот пример демонстрирует, как находить пересечение между лучом, пущенным от камеры через курсор мыши, и геометрией.

Компонент *MouseRayIntersection* показывает, как использовать *World::getIntersection()* для обнаружения объектов статических мешей, пересекаемых лучом, пущенным из позиции игрока в направлении, указанном курсором мыши.

Имя поражённого объекта отображается рядом с курсором на экране.
