# Create Mesh Primitives

Этот пример демонстрирует, как создавать параметрические 3D-примитивы во время выполнения в UNIGINE.

Он показывает использование класса **Mesh** и узлов **ObjectMeshDynamic** для процедурной генерации различных базовых форм (**Box, Sphere, Cylinder, Capsule, Prism с настраиваемым числом граней** и **Plane**) через код.

Каждая форма строится с настраиваемым размером и разрешением, добавляется к поверхности меша и размещается в мире в заданной позиции.

Такой подход позволяет генерировать динамическую геометрию для инструментов, расширений редактора, процедурных окружений и быстрого прототипирования.
