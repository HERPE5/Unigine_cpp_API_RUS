# Node State Save-Restore

Этот пример демонстрирует, как сохранять и восстанавливать состояние произвольного узла (Node) с помощью методов *saveState()* и *restoreState()*. В этом примере мы:

-При *инициализации* создаём контейнер ***Blob*** для хранения состояния и сохраняем начальное состояние связанного узла.
-Включаем визуализатор (полупрозрачный бокс) в сохранённой позиции для визуализации.
-Сохраняем и восстанавливаем состояние узла в любой момент, нажимая кнопки *Save* и *Restore* на панели UI примера.

**Варианты использования**:

-Сохранения в играх
-Системы Undo/Redo
-Сериализация сцены
