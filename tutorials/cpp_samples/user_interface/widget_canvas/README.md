# Widget Canvas

Этот пример демонстрирует, как использовать класс *WidgetCanvas* для рисования векторных фигур и текста. Canvas поддерживает добавление линий, полигонов и текста путём задания их геометрии через позиции вершин. Элементы слоятся по порядку рисования и раскрашиваются индивидуально.

Содержимое canvas остаётся чётким независимо от масштабирования или поворота. В этом примере весь canvas трансформируется во времени, вращаясь и перемещаясь в 3D-пространстве, сохраняя при этом чёткость содержимого. Геометрия строится с помощью вспомогательных функций, генерирующих радиальные линии и правильные многоугольники, а раскладка обновляется каждый кадр с помощью матрицы трансформации.

Это можно использовать для создания чётких, масштабируемых элементов UI, процедурных диаграмм, пользовательских наложений или динамических визуализаций данных в инструментах или приложениях.
