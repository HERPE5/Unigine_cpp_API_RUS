# Object Frame

Этот пример показывает, как динамически создавать и отображать прямоугольные рамки вокруг объектов сцены с помощью *WidgetCanvas*. Эти рамки включают подписи объектов и появляются только если объект видим и находится в пределах определённого расстояния от камеры.

Вы также можете делать скриншоты с помощью кнопки *Snap Screenshot*. Захваченное изображение не включает отрендеренные рамки, но все метаданные рамки (включая *ID* объекта, имя, трансформацию и экранные координаты рамки) сохраняются в отдельный файл *JSON*. Скриншот и метаданные рамки сохраняются в папке контента примера.

Ограничивающий бокс каждого объекта вычисляется рекурсивно на основе всех его компонентов-мешей. Полученный прямоугольник проецируется в экранное пространство и проверяется на видимость. Если он видим и не заслонён, рисуется *2D*-рамка с помощью класса *WidgetCanvas*.

Все метаданные, такие как *ID* объекта, имя, позиция и поворот в мировом пространстве, а также координаты прямоугольника в экранном пространстве, собираются и сохраняются в виде структурированного документа *JSON* с помощью *класса Json*.

Такой подход полезен для создания визуальных наложений, аннотаций или отладочных элементов *UI*, где данные, специфичные для объекта, нужно выделить или сохранить во внешнем файле.
