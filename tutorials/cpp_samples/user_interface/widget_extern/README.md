# Widget Extern

Этот пример демонстрирует, как создать пользовательский виджет GUI, унаследовав его от *WidgetExternBase* через C++ API. Пользовательский класс переопределяет ключевые методы, такие как *render()*, *arrange()* и *checkCallbacks()*, для реализации уникального визуального и интерактивного поведения.

Виджет регистрируется с уникальным ID класса с помощью *WidgetExternBase::addClassID()*, после чего его можно создавать с помощью *WidgetExtern::create()*.

Такая настройка позволяет полностью контролировать рендеринг и логику виджета напрямую в C++.
