# Object Text

Этот пример демонстрирует, как создавать и управлять текстовыми объектами в сцене через API, используя класс *ObjectText*.

Он показывает различные возможности рендеринга текста, включая настраиваемые параметры шрифта, анимацию цвета и поддержку форматированного текста:

**Левый объект** - статический блок *форматированного текста (rich text)* с разными цветами, размерами шрифта и обводками.

**Центральный объект** - редактируемый пользователем текст, который можно настроить через окно параметров. Поддерживает настройку ширины переноса, теста глубины, обводки, вертикального и горизонтального интервалов, разрешения шрифта, размера и режима форматированного текста.

**Правый объект** - динамический текстовый объект, непрерывно обновляющий свой цвет во времени и отображающий текущие значения RGBA в реальном времени.
