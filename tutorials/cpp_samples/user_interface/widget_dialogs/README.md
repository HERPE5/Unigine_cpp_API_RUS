# Widget Dialogs

Этот пример демонстрирует, как создавать и управлять системой диалогов GUI с помощью диалоговых виджетов UNIGINE через C++ API. Экземпляр *WidgetWindow* содержит несколько кнопок, каждая из которых открывает свой тип диалога: *WidgetDialogMessage*, *WidgetDialogFile*, *WidgetDialogColor* или *WidgetDialogImage*.

Каждая кнопка подключена к обработчику события, который создаёт и настраивает соответствующий диалоговый виджет. Диалоги отображаются по центру экрана и поддерживают взаимодействие пользователя через кнопки *OK* и *Cancel*. Общий обработчик управляет этими ответами, логирует действия в консоль и удаляет диалог после этого для освобождения ресурсов.

Такой подход можно использовать для создания простых и интерактивных инструментов GUI, панелей настроек или утилит разработки, требующих встроенных диалоговых взаимодействий.
