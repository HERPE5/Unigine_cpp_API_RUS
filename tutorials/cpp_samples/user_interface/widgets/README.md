# Widgets

Этот пример демонстрирует реализацию различных UI-виджетов в UNIGINE. Он показывает, как создавать, настраивать и управлять интерактивными элементами **GUI**.

Пример включает несколько типов виджетов с возможностями обработки событий, демонстрируя, как создавать и позиционировать виджеты, настраивать визуальные свойства, обрабатывать взаимодействия пользователя и т.д., такие как **слайдеры, скроллы, кнопки, чекбоксы, выпадающие списки и т.д.**.
