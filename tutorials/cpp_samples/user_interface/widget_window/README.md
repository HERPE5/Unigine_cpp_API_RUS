# Widget Window

Этот пример демонстрирует, как создать базовый *WidgetWindow* с помощью C++ API и обрабатывать взаимодействия пользователя (события строки ввода и нажатия кнопки) через подключение функций-обработчиков.

Окно включает *WidgetEditLine* и *WidgetButton*. *WidgetEditLine* отслеживает изменения текста через *Widget::getEventChanged()* и логирует новый ввод, а WidgetButton использует *Widget::getEventClicked()* для выполнения действия при нажатии. Размеры шрифта настроены для лучшей читаемости, а компоновка выполняется автоматически.

Такой подход подходит для создания интерактивных элементов UI непосредственно в нативной системе GUI UNIGINE.
