# User Interface

Этот пример показывает, как сгенерировать пользовательский интерфейс из описания, хранящегося в файле **.ui** (формат *XML*), через C++ API. Пример также демонстрирует, как получить виджет UI по имени с помощью *getWidgetByName()* и подписаться на события для реализации пользовательской обработки действий (в частности, выбора *File -&gt; Reload* из главного меню или ввода текста в текстовое поле на вкладке **EditText**).
