# Asynchronous Terrain Albedo Height Brushes

Этот пример демонстрирует несколько техник деструктивного изменения **ландшафтного terrain (Landscape Terrain)** во время выполнения путём изменения базовых текстур **Landscape Layer Map** с помощью **Landscape::asyncTextureDraw()** в сочетании с пользовательскими базовыми материалами.

В нём представлены три различных режима рисования:

-**Albedo Painter:** позволяет рисовать по текстуре albedo terrain с помощью настраиваемой кисти (текстура, маска, размер, угол, непрозрачность и цвет).
-**Height Painter:** позволяет изменять высоту с помощью значений высоты и параметров масштабирования, а также поддерживает режимы альфа- или аддитивного смешивания.
-**Height To Albedo:** преобразует данные высоты terrain в цвет albedo на основе выбранного пользователем градиента и заданного диапазона высот.

Вы можете динамически изменять параметры кисти через панель UI (текстуры, маски, градиент, размер, интервал, угол, непрозрачность и цвет) и визуализировать кисть в виде ортографической декали, проецируемой на terrain.

**Варианты использования**

-Инструменты рисования по terrain во время выполнения для редакторов уровней и интерфейсов построения мира
-Системы скульптинга terrain в играх или симуляциях
-Пользовательские рабочие процессы текстурирования на основе высоты для стилизованных или процедурно изменённых terrain
-Визуализация поведения смешивания terrain с интерактивностью UI.
