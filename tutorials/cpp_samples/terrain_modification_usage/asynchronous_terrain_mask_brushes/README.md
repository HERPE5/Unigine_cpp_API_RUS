# Asynchronous Terrain Mask Brushes

Этот пример демонстрирует рисование данных маски **Landscape Layer Map** в реальном времени с помощью настраиваемой системы кисти.

**Ключевые возможности:
**

-Изменение terrain с помощью *Landscape::asyncTextureDraw()*
-Параметры кисти:

-Текстура, маска
-Размер, угол, интервал, непрозрачность

-Визуальное превью кисти через *DecalOrtho*
-Работает на основе пользовательского базового материала (**landscape_mask_brush.basemat**) для применения изменений.

Идеально подходит для инструментов редактирования во время выполнения, управления растительностью или любой системы, требующей динамического создания масок terrain.
