# Height Slicing

Этот пример демонстрирует гибридный подход к редактированию terrain, использующий как **недеструктивные** (с помощью нескольких **Landscape Layer Map**), так и **деструктивные** (с помощью метода **Landscape::asyncTextureDraw()**) техники изменения **Landscape Terrain**.

**Принцип работы:**

-Сэмплирование данных высоты из **исходной (Source)** Landscape Layer Map
-
Использование **Landscape::asyncTextureDraw()** в сочетании с пользовательским материалом с аддитивным смешиванием высоты для изменения **целевой (Target)** Layer Map, если сэмплированная высота выше заданного порога:

-Целевой terrain выравнивается (ограничивается порогом высоты)
-Целевой albedo (на уровне высоты порога) окрашивается в оранжевый.

Этот пример идеально подходит для инструментов, требующих выборочного штампования terrain, масок эрозии или пользовательского скульптинга terrain.
