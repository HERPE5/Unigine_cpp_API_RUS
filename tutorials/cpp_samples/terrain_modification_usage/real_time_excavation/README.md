# Real-Time Excavation

Этот пример демонстрирует **деструктивное изменение в реальном времени** **Landscape Layer Map** с использованием 3D-объекта (например, тракторного грейдера) в качестве инструмента раскопки.

**Ключевые возможности:**

-Сэмплирует базовую высоту terrain из **исходного слоя**
-Проецирует **карту глубины** грейдера на terrain с помощью **ортографической камеры**
-Использует пользовательский материал (**digging_tool.basemat**) для обновления данных высоты и очистки слоёв маски
-Применяет обновления асинхронно с помощью *Landscape::asyncTextureDraw()*
-Поддерживает полное интерактивное перемещение и вращение грейдера с помощью виджета *Manipulator*.

Этот пример идеально подходит для разработки механик деформации terrain в симуляторах, играх про строительство или любых сценариях, требующих скульптинга landscape во время выполнения на основе взаимодействия с объектом.
