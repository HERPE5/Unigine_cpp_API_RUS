# Asynchronous Terrain Data Fetch

Этот пример демонстрирует, как получать подробную информацию из объекта **LandscapeTerrain** в произвольной точке его поверхности с помощью **LandscapeFetch**.

**Ключевые возможности:**

-Пускает луч от камеры через курсор мыши
-Выполняет асинхронные тесты пересечения с terrain
-Получает:

-**Высоту** поверхности
-**Нормаль** поверхности
-**Значения масок смешивания** для всех настроенных слоёв
-Albedo поверхности

-Визуализирует результаты в viewport с помощью:

-**Вектора нормали**
-Плавающего **текстового блока**, показывающего данные запроса к terrain.

Эта функция может использоваться для отладки terrain, расширений редактора, динамического размещения контента и визуализации атрибутов terrain в реальном времени.
