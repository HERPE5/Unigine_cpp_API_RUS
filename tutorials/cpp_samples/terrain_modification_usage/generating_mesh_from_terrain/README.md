# Generating Mesh From Terrain

Этот пример демонстрирует, как сгенерировать процедурный меш (**ObjectMeshDynamic**), представляющий выбранную область **Landscape Terrain**.

**Ключевые возможности:**

-Данные terrain (высота и albedo) запрашиваются во время выполнения с помощью **LandscapeFetch**
-Разрешение, позицию, масштаб и поворот меша можно настроить через UI
-Опционально рендерить ограничивающий бокс и наложение каркаса (wireframe)
-Идеально подходит для:

-Превью terrain во время выполнения
-Упрощённых мешей **LOD** или извлечения данных для анализа/симуляции.

Сгенерированный меш использует базовый материал и включает данные о цвете, сэмплированные из слоя albedo terrain. Используйте кнопку **Generate** для запроса данных terrain и построения меша в реальном времени.
