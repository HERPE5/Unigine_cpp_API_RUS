# Polygon-Based Procedural Modifications

Этот пример демонстрирует процедурную генерацию полигональных объектов из мировых точек, позволяя редактировать landscape и размещать объекты во время выполнения.

Он динамически создаёт полигональную геометрию и применяет её в нескольких контекстах:

-**ObjectMeshStatic** - создаёт *ObjectMeshStatic* и размещает его в центре *WorldBoundBox*, образованного точками.
-**DecalMesh** - создаёт *DecalMesh* и размещает его в центре *WorldBoundBox*, образованного точками.
-**DecalOrtho** - рендерит меш в текстуру, применяемую в слот albedo материала *DecalOrtho*.
-**Terrain mask** - рендерит меш в маску Layer Map для управления размещением clutter (кубы) на landscape.
-**Level terrain** - выравнивает высоту terrain до значения самой низкой точки в области полигона.
-**Lower terrain** - понижает terrain на 20 единиц в области полигона.
