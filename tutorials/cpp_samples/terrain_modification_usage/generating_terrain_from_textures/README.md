# Generating Terrain From Textures

Этот пример демонстрирует, как динамически генерировать **Landscape Layer Map** с использованием тайловых текстур **albedo, height** и **mask**. Процесс использует API **LandscapeMapFileCreator** и **LandscapeMapFileSettings** для построения полностью функционального файла **.lmap** и его настройки для использования с объектом **Landscape Terrain**.

**Ключевые возможности:**

-Поддерживает ввод на основе тайлов с задаваемым пользователем размером сетки и разрешением
-
Загружает и проверяет тайлы изображений для:

-**Albedo**
-**Height**
-**Маски травы**
-**Маски камня**

-Применяет настройки смешивания для каждого слоя с помощью ***LandscapeMapFileSettings***
-Автоматически создаёт и присоединяет объекты landscape к миру.

Этот рабочий процесс идеально подходит для генерации terrain во время выполнения, инструментов процедурного terrain или расширений редактора, которым нужно собирать данные terrain из источников изображений.
