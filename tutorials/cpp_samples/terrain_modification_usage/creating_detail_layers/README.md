# Creating Detail Layers

Этот пример демонстрирует, как добавлять и управлять слоями деталей для объекта **LandscapeTerrain** с помощью методов *getDetailMask()* и *addDetail()*.

Он динамически создаёт и настраивает три типа деталей terrain:

-**Трава (Grass)**
-**Камень (Stone)**
-**Снежные шапки (Snow caps)** (простой белый материал, применяемый в зависимости от высоты с помощью ограничений высоты - без текстуры).

**Каждая деталь:**

-Привязана к отдельной маске детали
-Получает пользовательский материал
-Упорядочена визуально с помощью *swapRenderOrder()* для обеспечения естественного смешивания (камень под травой, трава под снегом).

Такая настройка полезна для детализации terrain в стиле биомов, визуального наслоения материалов и настройки terrain в реальном времени.
