# Real-Time Terrain Rut Deformation

Этот пример демонстрирует недеструктивное изменение **Landscape Terrain** во время выполнения путём динамического порождения нескольких **Landscape Layer Map** под движущимися объектами (например, транспортными средствами или персонажами) для создания реалистичных следов колеи на terrain. Каждый след рендерится с помощью выделенной **Landscape Layer Map**, которая аддитивно смешивается с данными высоты terrain и альфа-смешивается с albedo, создавая визуально убедительные следы без изменения исходных слоёв terrain.

**Ключевые возможности**

-Автоматическое порождение следов на основе движения объекта
-Карты следов порождаются только тогда, когда объект переместился на минимальное расстояние (задаётся пользователем)
-Количество активных карт следов ограничено для производительности (настраиваемый лимит)
-Смешивание albedo и высоты обрабатывается через стандартное недеструктивное наслоение, обеспечивая простое удаление или замену следов.

**Настраиваемые параметры**

-**Min Distance Between Tracks** - управляет тем, как часто порождаются новые карты следов в зависимости от движения
-**Max Number of Track Maps** - ограничивает количество одновременно активных слоёв следов для управления памятью и производительностью.

**Варианты использования**

-Системы следов транспортных средств или персонажей для игр и симуляций
-Временные эффекты terrain (например, следы шин, отпечатки ног, следы скольжения)
-Процедурный контент во время выполнения, не изменяющий базовый terrain постоянно.
