# Speed Boat

Этот пример демонстрирует, как симулировать динамическую пену кильватерного следа за движущейся лодкой с помощью комбинации ***ортографических декалей (Orthographic Decals)*** и ***систем частиц***. Эффект пены реагирует на скорость лодки в реальном времени:

-**Размер декали** подстраивается в зависимости от площади, покрытой частицами
-**Время жизни, частота появления и скорость частиц** масштабируются пропорционально скорости лодки.

Ползунок **Beaufort** позволяет управлять состоянием моря — от спокойного (**0**) до штормового (**8**) — чтобы наблюдать, как пена реагирует в разных условиях волнения. Такая настройка идеально подходит для добавления убедительного кильватерного следа и следов движения кораблям или водному транспорту в реальном времени.
