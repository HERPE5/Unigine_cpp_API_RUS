# JSON

Этот пример показывает, как сгенерировать структурированный документ *JSON*, содержащий объекты, массивы и различные типы данных, такие как строки, числа, булевы значения и null. Также демонстрируется, как рекурсивно обходить и выводить эту структуру с отступами, имитируя форматированный вывод.

Пример начинается с построения пользовательской структуры *JSON* в памяти с помощью *Json::create()* и методов управления дочерними элементами. Узлы добавляются динамически и включают как именованные, так и безымянные дочерние элементы различных типов. После построения структура рекурсивно обходится и выводится в консоль в читаемом формате с использованием отступов и запятых в зависимости от типа и позиции узла. Код демонстрирует, как различать массивы, объекты и примитивные значения при выводе.

Этот пример полезен для изучения основ работы с *JSON*, таких как создание структурированных данных, обход дерева элементов и форматирование вывода. Он может служить основой для обработки данных *JSON* (например, ответов на запросы *REST API*), а также для сложных инструментов сериализации или отладки.
