# Inverse FPS Usage

Этот пример демонстрирует важность использования *Game::getIFps()* для реализации логики движения, независимой от частоты кадров.

В примере два куба движутся туда-сюда вдоль оси X. Их движение реализовано в файле *IFpsMovementController.cpp*.

Зелёный куб использует *Game::getIFps()* для масштабирования своего движения на дельту времени кадра. Это обеспечивает постоянную скорость при разной частоте кадров.

Красный куб не использует *Game::getIFps()* и просто применяет постоянное смещение за кадр, что приводит к непостоянному поведению при изменении частоты кадров.

Используйте слайдер *Max FPS*, чтобы изменить целевую частоту кадров.

Этот пример демонстрирует, почему использование логики, основанной на времени, важно для постоянного результата при разной частоте кадров.
