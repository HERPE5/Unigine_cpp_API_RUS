# Advanced Event Connection Patterns

Этот пример демонстрирует продвинутое использование **системы событий** UNIGINE.

*EventsAdvancedSample.cpp* запускает пользовательские события вращения при нажатии определённых клавиш. Каждое событие передаёт один или несколько аргументов подключённым обработчикам.

*EventsAdvancedUnit.cpp* показывает, как подключать различные типы обработчиков, включая:

-Методы класса с дополнительными аргументами
-Свободные функции с отброшенными или дополнительными аргументами
-Лямбды с использованием *connectUnsafe()*
-Сохранение подключений с помощью *EventConnection* или *EventConnectionId* для последующего отключения

Этот пример помогает понять гибкие паттерны обработки событий в модульных системах компонентов.
