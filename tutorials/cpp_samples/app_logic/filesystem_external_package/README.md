# File System External Package

Этот пример демонстрирует создание пользовательского пакета данных с помощью кода и его использование для генерации объектов на сцене. Создаётся меш box, который размещается на сцене 64 раза с разными позициями и вращениями.

Пакет - это набор файлов и данных для проектов UNIGINE, хранящихся в одном файле. Класс *Package* является поставщиком данных для файловой системы. Его можно использовать для загрузки всех необходимых ресурсов. Пакеты удобны для переноса файлов между вашими проектами или обмена данными с другими пользователями, будь то контент (отдельная модель или сцена с набором объектов, управляемых логикой, реализованной через компоненты C++) или файлы (плагины, библиотеки, исполняемые файлы и т.д.).

Класс *ExternalPackage* описывает генерацию меша (в данном случае box) и его сохранение во временный файл по указанному пути. Класс также реализует интерфейс для поиска, чтения и получения информации о файлах внутри пакета.

Класс *ExternalPackageSample* добавляет созданный внешний пакет, и его содержимое используется для создания мешей с разными позициями и ориентациями. Такой подход позволяет быстро и удобно управлять большим количеством объектов без их ручного добавления.

Использование этого примера поможет понять, как организовать работу с внешними файлами, создавать и управлять собственными пакетами данных, реализовать механизм загрузки и чтения данных из пакета.
