# Euler Angle Composition And Decomposition

Этот пример демонстрирует, как порядок углов влияет на итоговое вращение. Также можно наблюдать различные способы разложения текущего вращения по разным последовательностям углов.
Этот пример помогает понять 3D-вращения с использованием углов Эйлера. Он показывает, как разные последовательности могут приводить к разным ориентациям в пространстве.
