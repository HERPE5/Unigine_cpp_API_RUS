# Component System Example

Этот пример иллюстрирует, как реализовать логику вашего приложения с помощью набора строительных блоков - **компонентов** - и назначить эти блоки узлам. Логический компонент объединяет узел, свойство и класс C++, содержащий реализацию логики.

Пример включает управляемую пешку с базовым движением, вращающиеся кубы, периодически создающие снаряды, и плавающую UI-метку, отображающую здоровье, время выживания и количество активных компонентов.

Пример демонстрирует, как:

-Разложить логику приложения на модульные, переиспользуемые компоненты
-Создавать и назначать пользовательские логические компоненты во время выполнения
-Реализовать взаимодействие между независимо управляемыми компонентами.
