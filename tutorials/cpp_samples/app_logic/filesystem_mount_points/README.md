# File System Mount Points

Этот пример демонстрирует функциональность точек монтирования в файловой системе движка.

*MountPointsSample.cpp* позволяет добавлять или удалять точки монтирования для папки и архива пакета через API. Если точка монтирования активна, изображение, хранящееся внутри, будет загружено и отображено.

Смонтированные пути отображаются в окне *UI*, где можно переключать монтирование/размонтирование каждого ресурса. Доступ к изображениям осуществляется через виртуальные пути, определяемые местом монтирования.

Пример иллюстрирует концепцию виртуализированного доступа к файлам: если ресурс недоступен через точку монтирования, движок его не найдёт и не отобразит.

Такой подход полезен для работы с внешним контентом (хранящимся вне папки **data**), модульной загрузки данных или переключения наборов ресурсов во время выполнения.
