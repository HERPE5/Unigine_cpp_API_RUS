# Console Interaction

Этот пример демонстрирует взаимодействие со встроенной консолью движка и добавление пользовательских консольных команд и переменных через API с помощью классов *Console* и *ConsoleVariable*. Показано, как определять различные типы консольных переменных: *ConsoleVariableInt*, *ConsoleVariableFloat* и *ConsoleVariableString*, а также как регистрировать пользовательские консольные команды.

Команды связываются с функциями обратного вызова с помощью *MakeCallback* и могут выполняться напрямую из кода или вводиться вручную через консоль. Команды также можно динамически добавлять и удалять во время выполнения, что делает систему гибкой для различных сценариев использования. Доступ к консольным переменным и их изменение возможны как из кода, так и через интерфейс консоли.

Для демонстрации, чтобы переместить материальный шар на сцене, используйте пользовательскую команду `**control_node [x] [y] [z]**` в консоли (`), где *x, y, z* - целевые мировые координаты (например, `**control_node 0 5 1**`).

Эта функциональность может использоваться для разработки, отладки, быстрого прототипирования и настроек во время выполнения в интерактивных приложениях.
