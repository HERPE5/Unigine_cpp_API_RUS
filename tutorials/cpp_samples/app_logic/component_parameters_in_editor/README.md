# Component Parameters In Editor

Этот пример демонстрирует возможные вариации параметров компонентов, доступных в **Component System**. Он включает примитивные типы, векторы, маски, файлы, свойства, материалы, узлы, кривые, структуры, массивы и продвинутые возможности, такие как условная видимость и фильтрация значений.

Выберите **component_parameters** *Node Dummy* в редакторе и изучите все вариации параметров в окне *Parameters*. Это служит исчерпывающим справочником по доступным типам параметров и их настройкам.
