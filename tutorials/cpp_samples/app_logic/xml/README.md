# XML

Этот пример демонстрирует создание и работу с документом *XML* с помощью класса *Xml*. Создаётся вложенное дерево *XML* с несколькими дочерними узлами, каждый из которых содержит аргументы и опционально текстовое значение.

Структура строится с помощью метода *Xml::addChild()*, а аргументы разбираются с помощью *Xml::getArgName()* и *Xml::getArgValue()*. После построения дерево *XML* рекурсивно обходится для отображения структуры и всех атрибутов в выводе консоли.

Такой подход демонстрирует использование класса *Xml* для работы с иерархическими данными, что полезно для конфигурационных файлов, данных уровней и другого структурированного контента в формате *XML*.
