# Type Safe Callbacks

Этот пример демонстрирует использование класса *CallbackBase* через C++ API для оборачивания и вызова функций и методов класса с разным количеством аргументов.

Механизм коллбэков полезен в таких сценариях, как системы, управляемые событиями, взаимодействие с пользовательским интерфейсом или управление асинхронными задачами в приложениях, требующих динамического вызова функций.

Откройте консоль (`), чтобы просмотреть лог выполнения коллбэков.

Коллбэки создаются с помощью метода *MakeCallback* как для отдельных функций, так и для методов экземпляра, включая параметризованные версии с числом аргументов до четырёх. После создания коллбэки можно выполнить с помощью метода *CallbackBase::run()*, опционально передавая разные аргументы во время выполнения. Это позволяет динамически хранить и запускать функции через единый интерфейс.
