# Materials And Properties Enumeration

Этот пример демонстрирует доступ ко всем материалам и свойствам проекта через API.

Пример проходит по списку зарегистрированных в *Property Manager* через *Properties::getProperty()* и выводит имена и количество дочерних элементов для каждого. Также получаются все доступные материалы из *Materials Manager* через *Materials::getMaterial()*, и они перечисляются вместе с их путями к файлам и количеством дочерних элементов.

Это может служить справочником по доступу и работе с ресурсами проекта во время выполнения - будь то инспекция, динамическое назначение или логика управления контентом.
