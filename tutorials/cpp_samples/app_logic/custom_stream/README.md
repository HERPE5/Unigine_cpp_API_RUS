# Custom Stream

Этот пример демонстрирует создание пользовательского класса потока путём наследования от *StreamBase* и его использование для чтения из файлов и записи в файлы. Полученный поток используется для сериализации и десериализации базовых типов данных в бинарный файл и обратно.

Пример предоставляет обёртку вокруг стандартных функций файлового *I/O* языка *C* и интегрируется с системой потоков **UNIGINE**, реализуя интерфейс *StreamBase*. В логике примера сначала создаётся бинарный файл и заполняется данными через *Stream::writeString()*, *writeInt()* и *writeFloat()*. Затем файл повторно открывается в режиме чтения, и те же значения считываются обратно с помощью соответствующих методов *Stream 'read'*, проверяя работоспособность пользовательского потока.

Этот пример служит справочником по реализации пользовательских источников потоков (например, из памяти, сети или виртуальных файловых систем) и их интеграции с инструментами сериализации движка.
