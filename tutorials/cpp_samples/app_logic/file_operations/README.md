# File Operations

Этот пример показывает, как создать текстовый файл и отобразить его содержимое внутри виджета через C++ API с помощью класса *File*. Чтобы создать текстовый файл, введите текст с клавиатуры внутри виджета *Writer* и нажмите <b>Write</b>, чтобы сохранить. Нажмите **Read** внутри виджета *Reader*, чтобы отобразить записанную информацию. Сохранённая информация будет отображаться в тех же виджетах при следующем запуске примера.
